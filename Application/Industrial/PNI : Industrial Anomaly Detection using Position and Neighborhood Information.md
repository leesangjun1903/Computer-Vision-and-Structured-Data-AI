
# PNI : Industrial Anomaly Detection using Position and Neighborhood Information

## 1. 핵심 주장 및 주요 기여

### 1.1 핵심 주장 요약

**PNI(Position and Neighborhood Information)**는 기존의 산업용 이상 탐지 방법들이 **위치 정보(Position Information)와 이웃 정보(Neighborhood Information)를 무시**한다는 점을 지적합니다.[1]

PatchCore와 CFLOW-AD 같은 선행 방법들은 각 패치의 특징을 독립적으로 평가합니다. 그러나 실제 산업 검사에서는 같은 특징이라도 잘못된 위치에 있으면 결함이 될 수 있습니다. 예를 들어 케이블 검사에서 개별 전선 색상 자체는 정상이지만 배열 순서가 틀리면 제품이 불량인 경우가 있습니다.[1]

### 1.2 세 가지 주요 기여[1]

1. **조건부 확률 분포를 이용한 이상 탐지**: 위치와 이웃 정보에 조건화된 정상 특징 분포를 모델링
2. **합성 이미지 기반 정제 네트워크**: 세부 사항과 경계선을 개선하는 픽셀 단위 정제 기법
3. **포괄적 절제 연구**: 각 컴포넌트의 효과를 정량적으로 입증

***

## 2. 해결하고자 하는 문제

### 2.1 문제 정의[1]

기존 방법들은 이상 점수를 다음과 같이 계산합니다:

$$S(x) = -\log p(\Phi_i(x))$$

이 식에서 $\Phi_i(x)$는 위치 $x$의 특징 벡터이고, $p(\Phi_i(x))$는 정상 데이터에서 이 특징의 확률입니다.

### 2.2 제안하는 개선 방향[1]

PNI는 위치와 이웃 정보 $\Omega$로 조건화된 확률을 사용합니다:

$$S(x) = -\log p(\Phi_i(x)|\Omega)$$

이를 통해 **같은 특징도 다른 맥락에서는 다르게 평가**되어야 한다는 원리를 적용합니다.

### 2.3 핵심 과제

- 비정상 샘플을 학습에 사용할 수 없음 (산업 현장의 현실)
- 미세한 결함도 정확히 위치 파악 필요
- 거짓 양성과 거짓 음성 모두 최소화 필요

***

## 3. 제안하는 방법 (수식 포함)

### 3.1 기본 확률 모델링[1]

임베딩 코어셋 $C_{emb}$에 기반한 조건부 확률은:

$$p(\Phi_i(x)|\Omega) = \sum_{c \in C_{emb}} p(\Phi_i(x)|c, \Omega) p(c|\Omega)$$

계산 효율성을 위해 근사식을 적용합니다:

$$p(\Phi_i(x)|\Omega) \approx \max_{c \in C_{emb}} p(\Phi_i(x)|c, \Omega) T_\tau(p(c|\Omega))$$

여기서 임계값 함수 $T_\tau(x)$는 다음과 같이 정의됩니다:

$$T_\tau(x) = \begin{cases} 1, & \text{if } x > \tau \\ 0, & \text{otherwise} \end{cases}$$

이 설정에서 $\tau = 1/(2|C_{emb}|)$입니다. [1]

### 3.2 조건부 분포의 이중 모델링[1]

정상 특징 분포 $p(c|\Omega)$는 두 가지 확률의 평균으로 근사됩니다:

$$p(c|\Omega) \approx \frac{p(c|N_p(x)) + p(c|x)}{2}$$

#### 이웃 정보 모델링 (MLP): $p(c|N_p(x))$ [1]

$$N_p(x) = \{\Phi_i(m, n) \mid |m-h| \leq p/2, |n-w| \leq p/2, (m,n) \neq (h,w)\}$$

이웃 패치 특징들을 연결한 1차원 벡터를 MLP의 입력으로 사용합니다. 출력은 분포 코어셋 크기 $|C_{dist}|$의 확률 분포입니다.

**손실함수**: 교차 엔트로피 손실을 사용하여, 진정한 중심 특징에 가장 가까운 코어셋 인덱스를 원-핫 벡터로 설정하고 온도 스케일링(T=2)을 적용합니다.[1]

#### 위치 정보 모델링 (히스토그램): $p(c|x)$ [1]

알고리즘 1에 따라 히스토그램을 생성합니다:

- 모든 훈련 이미지에서 각 위치 $x$에 대해 $C_{dist}$ 벡터의 인덱스 누적
- 각 $p \times p$ 이웃 구역에 대해 히스토그램 생성
- 정규화하여 확률로 변환

이는 **동일한 위치에서 정상 특징이 어떤 분포를 따르는지** 학습합니다.[1]

### 3.3 특징 유사도 모델링[1]

$$p(\Phi_i(x)|c_{emb}, \Omega) \approx p(\Phi_i(x)|c_{emb}) \approx e^{-\lambda||\Phi_i(x) - c_{emb}||^2}$$

이 식에서 $\lambda = 1$로 설정하며, $p(\Phi_i(x)|c_{emb})$는 $\Omega$와 독립적이라 가정합니다. [1]

### 3.4 픽셀 단위 정제 네트워크[1]

정제 네트워크 $f$는 합성 결함 이미지 데이터셋 $\mathcal{D} = \{(I, \hat{A}, A)\}$로 훈련됩니다:

$$\theta^* = \arg\min_\theta \sum_{(I,\hat{A},A) \in \mathcal{D}} l(f(I, \hat{A}; \theta), A)$$

**손실함수**는 회귀 손실과 그래디언트 손실의 결합입니다:[1]

$$l = \frac{l_{reg} + l_{grad}}{2}$$

$$l_{reg} = \frac{||\tilde{A} - A||_2}{HW}$$

$$l_{grad} = \frac{||\nabla_h \tilde{A} - \nabla_h A||_2 + ||\nabla_w \tilde{A} - \nabla_w A||_2}{2HW}$$

여기서:
- $\tilde{A}$: 정제된 이상 맵
- $A$: 지면 진실 이상 맵
- $\nabla_h, \nabla_w$: 수직/수평 편미분
- $H, W$: 맵의 높이와 너비[1]

## 4. 모델 구조

### 4.1 전체 파이프라인[1]

PNI 알고리즘은 세 가지 단계로 구성됩니다:

#### **Step 1: 코어셋 생성**
- 사전 학습 모델 $\phi$ (예: ResNet-50)로부터 계층 특징 추출
- 중간 해상도 특징 ($\phi_{i,2}$와 $\phi_{i,3}$)을 연결
- 적응 평균 풀링으로 패치 레벨 특징 $\Phi_i \in \mathbb{R}^{d \times h^* \times w^*}$ 생성
- 탐욕적 코어셋 부분표본으로 $C_{emb}$ (임베딩) 및 $C_{dist}$ (분포) 생성[1]

#### **Step 2: 정상 특징 분포 훈련**

**MLP 훈련**:[1]
- 입력: $N_p(x)$의 연결된 이웃 특징 (d × (p²-1) 차원)
- 아키텍처: 10개 완전 연결 층, 각 2,048개 뉴런
- 배치 정규화 및 ReLU 활성화
- 출력: $|C_{dist}|$ 크기의 확률 분포
- 훈련: Adam 옵티마이저, 15 에포크, 학습률 10⁻³, 배치 크기 2,048[1]

**히스토그램 생성**:[1]
- 모든 훈련 이미지에서 각 위치의 $C_{dist}$ 인덱스 누적
- $p \times p$ 이웃 패치에 대해 강화된 추정
- 정규화하여 위치별 확률 분포 생성

#### **Step 3: 픽셀 단위 정제 네트워크**
- 네 가지 합성 방법으로 결함 이미지 생성: CutPaste, CutPaste(scar), DRÆM, 수동 그리기
- DenseNet161 기반 인코더-디코더 아키텍처
- 조기 융합: 첫 컨볼루션 후 특징 융합
- 훈련: Adam, 60,000 반복, 학습률 10⁻⁴, 배치 크기 8[1]

### 4.2 네트워크 매개변수[1]

| 항목 | 값 |
|------|-----|
| 임베딩 코어셋 크기 | 전체 특징의 1% |
| 분포 코어셋 크기 | 2,048 |
| 이웃 패치 크기 | 9×9 |
| MLP 층 수 | 10 |
| MLP 채널 | 2,048 |
| 온도 스케일링 | 2 |
| 임계값 | τ = 1/(2\|Cdist\|) |
| 이상 맵 융합 비율 | 10% |

## 5. 성능 향상 분석

### 5.1 벤치마크 성능[1]

#### MVTec AD 데이터셋 (이미지 레벨):

| 방법 | I-AUROC | P-AUROC |
|------|---------|---------|
| CFLOW-AD | 98.26% | 98.62% |
| PatchCore | 99.1% | 98.1% |
| **PNI** | **99.56%** | **98.98%** |
| PNI (앙상블) | 99.63% | 99.06% |

PNI는 이미지 레벨에서 PatchCore 대비 **0.46% 향상**, 픽셀 레벨에서 **0.88% 향상**을 달성했습니다.[1]

#### AUPRO 지표 (지역 기반 평가):

| 방법 | 객체 | 텍스처 | 평균 |
|------|------|--------|------|
| Tsai et al. [2] | 95.7% | 95.0% | 95.5% |
| PEFM | 95.30% | 95.95% | 95.52% |
| **PNI** | **96.34%** | **95.47%** | **96.05%** |

PNI는 AUPRO에서 0.53% 향상을 달성했습니다.[1]

### 5.2 산업 응용 관점의 효과[1]

거짓 양성(FPR)과 거짓 음성(FNR) 감소:

| 메트릭 | PatchCore | PNI | 개선 |
|--------|-----------|-----|------|
| FNR | 10.7% | 9.5% | -11.2% |
| FPR | 3.4% | 2.0% | -41.2% |

- **FNR 감소**: 고객에게 도달하는 불량품 **48% 감소**
- **FPR 감소**: 낭비되는 양품 **63% 감소**[1]

이는 산업 검사에서 매우 중요한 개선입니다. 실제로 0.46%의 AUROC 개선이 상당한 경제적 효과를 가져옵니다.

### 5.3 절제 연구 (Ablation Study)[1]

각 컴포넌트의 영향 분석 (MVTec AD):

| 컴포넌트 | 이웃 | 위치 | 정제 | I-AUROC | P-AUROC | 객체 | 텍스처 |
|---------|------|------|------|---------|---------|------|--------|
| 기본라인 | - | - | - | 98.92% | 98.18% | 99.01% | 98.75% |
| +이웃 | ✓ | - | - | 99.44% | 98.62% | 99.38% | 99.55% |
| +위치 | ✓ | ✓ | - | 99.46% | 98.80% | 99.46% | 99.46% |
| 전체 | ✓ | ✓ | ✓ | 99.56% | 98.98% | 99.55% | 99.59% |

**주요 발견**:[1]
- 이웃 정보 추가: I-AUROC **48.1% 오류 감소**
- 위치 정보: 객체 클래스에서만 효과적
- 정제 네트워크: 텍스처 클래스에서 더 효과적

## 6. 모델의 한계

### 6.1 데이터 관련 한계[1]

**합성 이미지의 제한성**:
- 정제 네트워크는 합성 결함 이미지(CutPaste, DRÆM 등)로 훈련
- 실제 산업 결함의 다양성을 완전히 반영하지 못함
- 새로운 유형의 결함에 대한 일반화 불확실

### 6.2 방법론적 한계

**위치 정보의 선택성**:
- 위치 정보는 객체 클래스(병, 케이블 등)에만 강한 효과
- 텍스처 클래스(카펫, 가죽 등)에는 거의 효과 없음
- 이는 위치 기반 접근법의 내재적 제약[1]

**계산 복잡도 증가**:
- MLP 훈련으로 인한 추가 계산
- 히스토그램 생성 및 조회의 오버헤드
- 정제 네트워크의 추가 추론 단계

**하이퍼파라미터 튜닝**:
- 이웃 패치 크기, MLP 구조, 온도 스케일링 등 다수의 하이퍼파라미터
- 새로운 도메인에서의 최적화 필요성

### 6.3 일반화 관련 한계

**도메인 시프트**:
- MVTec AD와 BTAD 데이터셋 성능 우수
- 다른 산업 환경, 카메라, 조명 조건에 대한 평가 부재
- 실제 현장 배포 시 성능 저하 가능성

**새로운 결함 유형**:
- 훈련 중 본 적 없는 결함에 대한 적응 능력 미지수
- 온라인 학습이나 지속적 적응의 어려움

## 7. 모델의 일반화 성능 향상 가능성

### 7.1 현재 성능과 한계 평가

PNI는 벤치마크 데이터셋(MVTec AD, BTAD)에서는 최고 성능을 보이지만, **폐쇄된 환경에서의 우수한 성능이 실제 산업 현장의 다양성을 반영하는지 불명확**합니다.[1]

### 7.2 일반화 능력 강화 방안[3][4][5]

#### 7.2.1 도메인 적응 기법

**도메인 특화 미세조정**:[4][5]
- 새로운 산업 도메인에서 정상 이미지만으로 메모리 뱅크(코어셋) 업데이트
- 히스토그램 재생성으로 위치 특정 분포 적응
- MLP는 고정하거나 저학습률로 미세조정

**자가감시 학습(Self-supervised Learning)**:[5]
- 사전 학습 특징 추출 네트워크를 도메인 특정 이미지로 추가 훈련
- 이상 탐지 성능과 특징 표현의 일반화 능력 동시 향상

#### 7.2.2 메타학습 접근법

**소수샷 학습(Few-shot Learning)**:
- 극소수의 비정상 샘플로부터 학습
- 새로운 결함 유형에 빠르게 적응
- 코어셋 동적 업데이트 기법 활용

#### 7.2.3 강화된 특징 모델링

**주의 메커니즘(Attention Mechanisms)**:[4][5]
- 이웃 정보 모델링 시 적응형 가중치 도입
- 중요한 이웃 특징에 더 높은 가중치 부여
- 채널 및 공간 주의 메커니즘 결합

**다중 스케일 특징**:[5]
- 단일 해상도가 아닌 다중 스케일 특징 활용
- 미세한 결함과 큰 구조적 결함 동시 포착

#### 7.2.4 향상된 합성 이미지 생성

**고급 합성 기법**:[6][5]
- 실제 현장 데이터와 유사한 합성 결함 생성
- 다양한 조명, 각도, 텍스처 조건 시뮬레이션
- 생성 모델(GAN, 확산 모델)을 활용한 현실적 이상 합성

#### 7.2.5 시스템 수준의 개선

**온라인 적응 학습**:[5]
- 배포 후 정상 이미지의 지속적 학습
- 코어셋 점진적 업데이트
- 드리프트 감지 및 자동 재훈련

**앙상블 전략**:[4][1]
- 다양한 백본 네트워크 활용 (ResNet, EfficientNet, Vision Transformer)
- 결과 조합으로 견고성 향상
- PNI 앙상블: I-AUROC 99.63%, P-AUROC 99.06%[1]

### 7.3 실제 일반화 성능 시뮬레이션[7][6]

최근 연구들에서 보고하는 일반화 개선 사례:

| 기법 | 기본 성능 | 개선 후 | 개선율 |
|------|----------|--------|--------|
| Vision Transformer 기반 [8] | ~80% AUROC | ~98% AUROC | +22.5% |
| 도메인 적응 [4] | 85% | 93% | +8.6% |
| 메타학습 [9] | 75% (소수샷) | 89% (소수샷) | +14% |
| 앙상블 [1] | 99.56% (단일) | 99.63% (앙상블) | +0.07% |

## 8. 2020년 이후 관련 최신 연구 비교 분석

### 8.1 주요 경쟁 방법 비교

#### **PaDiM (Patch Distribution Modeling, 2020)**[10][11]

**핵심 아이디어**:
- 사전 학습 CNN의 각 계층에서 추출한 특징으로 다변량 가우스 분포 생성
- 각 패치별로 Mahalanobis 거리 계산

**성능 (MVTec AD)**:[11][10]
- I-AUROC: 95.3%
- P-AUROC: 97.5%

**장점**:
- 매우 빠른 추론 속도 (가장 빠름)
- 간단한 구현
- 메모리 효율적

**단점**:
- PatchCore에 비해 낮은 성능
- 위치 정보 미흡
- 이웃 특징 상관관계 무시

**PNI와의 비교**:
- PNI는 위치/이웃 정보로 추가 3-4% AUROC 향상[1]

#### **PatchCore (Towards Total Recall in Industrial Anomaly Detection, 2022)**[12][11]

**핵심 아이디어**:
- 정상 특징의 메모리 뱅크 구성
- 탐욕적 코어셋 부분표본으로 대표 특징 선택
- 테스트 시 최근접 이웃 탐색으로 이상 점수 계산

**성능 (MVTec AD)**:[12][1]
- I-AUROC: 99.1%
- P-AUROC: 98.1%

**장점**:
- 매우 높은 성능
- 효율적인 비모수 모델링
- 모든 패치에 정보 접근 가능

**단점**:
- 위치/이웃 정보 고려 부족
- 추론 속도 느림 (최근접 이웃 검색)
- 메모리 사용량 많음

**PNI와의 비교**:
- PNI: I-AUROC 99.56% (+0.46%), P-AUROC 98.98% (+0.88%)[1]
- FNR 48% 감소, FPR 63% 감소[1]

#### **CFLOW-AD (Conditional Normalizing Flows for Anomaly Detection, 2021)**[13][11]

**핵심 아이디어**:
- 조건부 정규화 흐름(conditional normalizing flow)으로 특징 분포 모델링
- 위치 인코딩 블록 도입 (위치 정보 부분적 활용)

**성능 (MVTec AD)**:
- I-AUROC: 98.26%
- P-AUROC: 98.62%

**장점**:
- 위치 인코딩으로 공간 정보 포함
- 생성 모델의 이론적 토대
- 좋은 시각화 가능성

**단점**:
- 높은 훈련 시간 (가장 느림)
- 위치 정보 활용이 암시적
- PatchCore보다 낮은 성능

**PNI와의 비교**:
- PNI의 명시적 위치/이웃 정보가 CFLOW-AD의 암시적 방식보다 효과적[1]
- PNI: +1.3% (I-AUROC), +0.36% (P-AUROC) 향상[1]

#### **FastFlow (2021)**[14][15]

**핵심 아이디어**:
- 2D 정규화 흐름으로 전역/지역 특징 관계 모델링
- 효율적인 경량 구조

**성능 (MVTec AD)**:
- I-AUROC: 99.4%
- P-AUROC: 98.5%

**장점**:
- 추론 속도 매우 빠름 (CFLOW-AD 대비 1.5배)
- 다양한 백본 네트워크 호환
- 견고한 성능

**단점**:
- 위치 정보 명시적 모델링 없음
- 이웃 정보 활용 부족

**PNI와의 비교**:
- PNI: +0.16% (I-AUROC), +0.48% (P-AUROC) 향상[1]
- PNI의 정제 네트워크로 추가 개선

### 8.2 최근 동향 (2023-2025)

#### **1. Vision Transformer 기반 방법들**[8][16]

**동향**: Vision Transformer(ViT) 아키텍처를 기반으로 한 이상 탐지 방법 급증

**주요 특징**:
- 전역 맥락(global context) 정보를 지역 특징과 통합
- 자주의(self-attention) 메커니즘으로 패치 간 관계 학습
- 메모리 모듈로 정상 특징 보존

**성능 개선**:[16][8]
- 기존 CNN 기반 방법 대비 약 **20% AUROC 개선**
- 예: CVE-AE (Coordinate attention ViT) AUROC ~98%

**한계**:
- 계산량 증가로 실시간 처리 어려움
- 소수 샘플 환경에서 과적합 위험
- 새로운 도메인 일반화 불확실

#### **2. 확산 모델(Diffusion Models) 기반 방법들**[17][6]

**동향**: 생성 기반 이상 탐지로의 패러다임 전환

**주요 특징**:[6][17]
- 정상 데이터의 재구성으로 이상 탐지
- 이상의 다양한 합성으로 데이터 증강
- 조건부 확산으로 특정 유형 이상 생성

**성능**:
- 구조적 이상(structural anomalies) 탐지 강화
- 논리적 이상(logical anomalies) 탐지도 개선

**한계**:
- 높은 계산 비용 (반복적 디노이징)
- 합성 품질이 결과의 품질 결정

#### **3. 그래프 기반 방법들**[6]

**동향**: 패치 간 관계를 그래프로 모델링

**주요 특징**:
- 그래프 신경망으로 패치 간 상호작용 포착
- 공간적 구조 정보 활용
- 멀티스케일 특징 통합

#### **4. 하이브리드 접근법**[18][19][5]

**동향**: 여러 방법을 결합하여 성능 향상

**주요 결합**:
- CNN + Transformer (공간 + 시간 정보)
- 자기감시 + 약감시 학습
- 경량 네트워크 + 깊이 깊은 네트워크

**사례**:
- MemSeg: 반감시 학습 + 합성 이상[5]
- 하이브리드 앙상블: 다양한 백본의 결합[1]

### 8.3 PNI의 위치 및 기여도 평가

## 9. 향후 연구에 미치는 영향과 고려 사항

### 9.1 연구 커뮤니티에 미치는 영향[20][21][1]

#### **1. 위치/이웃 정보의 중요성 강조**[1]

PNI의 발표로 산업 이상 탐지 커뮤니티에서 다음의 인식 전환이 기대됩니다:

- **독립적 패치 평가의 한계**: 기존 방법들이 무시했던 공간 의존성 중요성 재확인
- **조건부 확률의 활용**: 단순 거리 기반에서 확률 기반 모델로의 진화 촉진
- **비모수 + 파라미터 모델의 혼합**: 히스토그램(비모수)과 MLP(파라미터)의 조화로운 조합 모델 확산

#### **2. 합성 데이터 기반 정제의 새로운 관점**[1]

- **정제 네트워크의 역할**: 이상 맵의 세부사항 개선이라는 새로운 후처리 방법 제시
- **합성 이미지 활용도 증대**: 단순 훈련 데이터 증강 외 정제를 위한 활용
- **멀티스테이지 파이프라인**: 특징 추출 → 이상 점수 → 정제 순의 3단계 구조 주목

#### **3. 절제 연구의 중요성**[1]

- 각 컴포넌트의 정량적 기여도 분석이 논문의 신뢰성 강화
- 후속 연구자들이 추종할 모델

### 9.2 향후 연구 시 고려할 구체적 사항

#### **9.2.1 방법론적 확장 및 개선**

**1) 적응형 이웃 패치 크기**[11][1]

현재 PNI는 고정된 9×9 패치 크기를 사용합니다. 개선 방향:

- **동적 패치 크기**: 객체 크기나 특징 다양성에 따라 적응형 패치 크기 적용
- **멀티스케일 이웃**: 여러 스케일의 이웃 정보 동시 활용
- 기대 효과: 미세한 결함과 거시적 이상을 동시에 탐지

**2) 향상된 코어셋 선택 기법**[5][1]

현재: 무작위 + 탐욕적 부분표본 추출

개선:
- **가중치 기반 코어셋**: 위치/이웃 정보를 고려한 중요도 기반 선택
- **샘플 기반 적응**: 도메인별 최적 코어셋 크기 자동 결정
- **동적 업데이트**: 새로운 정상 샘플 추가 시 점진적 코어셋 갱신

**3) MLP 구조 최적화**[11][1]

현재: 10층 × 2,048 채널 고정

개선:
- **경량 구조**: 계산량 감소를 위한 깊이/폭 감소 실험
- **주의 메커니즘**: 이웃 특징에 선택적 가중치 부여
- **조건부 정규화**: 배치 정규화 대신 인스턴스 정규화나 계층 정규화 비교

**4) 정제 네트워크 강화**[6][1]

현재: 4가지 합성 방법 (CutPaste, DRÆM 등)

개선:
- **확산 모델 기반 합성**: 더 현실적인 합성 결함 생성
- **적응형 정제**: 이상 유형에 따른 선택적 정제
- **경량화**: 실시간 처리를 위한 정제 네트워크 경량화

#### **9.2.2 일반화 능력 강화**[3][4][5]

**1) 크로스도메인 평가**

현재 부족한 부분:
- MVTec AD, BTAD만 평가됨
- 다른 산업 데이터셋에서의 성능 미검증

개선:
- LOCO-AD, VISION 데이터셋 등 추가 벤치마크 평가
- 실제 산업 현장 데이터 수집 및 평가
- 도메인 시프트 시나리오 체계적 분석

**2) 소수 샘플 학습 (Few-shot Learning)**[9]

극저수의 정상 이미지만 있는 상황:
- 코어셋 크기 극소화 시 성능 변화 분석
- 메타학습을 통한 빠른 적응
- 기대 성능: 20-30개 정상 이미지로도 >90% AUROC

**3) 온라인 적응 (Online Adaptation)**

배포 후 지속적 성능 개선:
- 새로운 정상 이미지 도착 시 코어셋 점진적 갱신
- 드리프트 감지 및 자동 재훈련 메커니즘
- 개인정보 보호를 고려한 로컬 적응

#### **9.2.3 계산 효율성 개선**[14][11]

**1) 추론 속도 최적화**

현재: PatchCore 대비 느림

개선:
- MLP 추론 병렬화
- 히스토그램 조회 최적화 (해시 테이블 활용)
- 정제 네트워크 생략 옵션 (성능/속도 트레이드오프)

**2) 메모리 효율성**

현재: 코어셋 + MLP 가중치 + 히스토그램

개선:
- 지식 증류로 MLP 경량화
- 히스토그램 압축 (양자화)
- 모바일/엣지 디바이스 배포 최적화

**3) 훈련 시간 단축**

현재: MLP 훈련 + 정제 네트워크 훈련

개선:
- 빠른 수렴을 위한 학습률 스케줄 최적화
- 멀티 GPU 분산 훈련
- 사전 학습된 가중치 활용

#### **9.2.4 안정성 및 신뢰성 개선**[22][1]

**1) 이상 유형별 성능 분석**

세밀한 분석 필요:
- 구조적 이상 vs 텍스처 이상 vs 논리적 이상
- 크기별 이상 탐지율 (극소형, 소형, 중형, 대형)
- 다양한 배경 복잡도에서의 성능

**2) 불확실성 정량화**

신뢰도 측정:
- 베이지안 접근으로 예측 불확실성 추정
- 저신뢰도 영역에서의 명시적 거부
- 신뢰도 기반 이상 점수 보정

**3) 적대적 견고성**

새로운 공격에 대한 저항:
- 회전, 스케일 변화에 대한 견고성 평가
- 조명 변화, 카메라 위치 변화 평가
- 적대적 예제에 대한 방어 메커니즘

#### **9.2.5 해석 가능성 강화**[23][5]

**1) 주의 시각화**

의사결정 과정 투명화:
- 이웃 정보에서 중요한 패치 시각화
- 위치 정보의 영향 분석
- MLP 활성화 패턴 분석

**2) 기여도 분석**

각 컴포넌트의 역할 분명화:
- SHAP, LIME 등을 통한 특징 기여도 분석
- 위치/이웃 정보의 상대적 영향도
- 이상 패턴별 결정 경계 분석

**3) 결과 설명**

산업 현장에서의 이해도 향상:
- 자연어 기반 이상 설명 생성
- 유사 정상 샘플과의 비교 제시
- 결함 확률 분포의 시각화

**단기 (1-2년)**:
- Vision Transformer와의 결합
- 도메인 적응 기법 통합
- 경량화된 버전 개발

**중기 (2-5년)**:
- 온라인 적응 학습 구현
- 다양한 산업 데이터셋 확대
- 실제 현장 배포 및 검증

**장기 (5년 이상)**:
- 기초 모델(Foundation Model) 활용
- 멀티 모달 이상 탐지
- 자체 학습(Self-learning) 능력 강화

### 10.4 최종 평가

PNI는 **산업용 이미지 이상 탐지 분야에서 의미 있는 진전을 이룬 연구**입니다. 특히 위치와 이웃 정보의 중요성을 강조하고, 실제 산업 검사에서 요구되는 낮은 거짓 양성/음성률을 달성한 점은 주목할 가치가 있습니다. 

다만 **벤치마크 데이터셋 중심의 평가와 새로운 도메인에서의 일반화 능력 미검증**은 향후 보완이 필요한 부분입니다. 또한 추가된 컴포넌트(MLP, 히스토그램, 정제 네트워크)로 인한 계산 복잡도 증가는 실제 배포 시 고려해야 할 요소입니다.

향후 연구자들은 PNI의 기본 아이디어를 유지하면서 **효율성 개선, 일반화 능력 강화, 해석 가능성 추가**라는 세 가지 방향에 초점을 맞추어 더욱 실용적이고 견고한 이상 탐지 시스템을 구축할 수 있을 것으로 기대됩니다.
