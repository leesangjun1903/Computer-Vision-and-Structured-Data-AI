
# DiffusionAD: Norm-guided One-step Denoising Diffusion for Anomaly Detection

## 1. 논문의 핵심 주장과 주요 기여

**DiffusionAD**는 산업 제조 환경에서의 이상 탐지를 위한 혁신적인 확산 기반 파이프라인으로, 기존 생성 기반 모델들의 부족한 재구성 품질을 근본적으로 개선한다.

### 주요 기여:

**1) 노이즈-노름(Noise-to-Norm) 패러다임**[1]
- 기존 자동 인코더의 핵심 문제점 해결: 저차원 표현에서도 이상 정보가 포함되어 이상이 정상처럼 재구성되는 문제 극복
- 이상 영역을 가우시안 노이즈로 교란하여 구별 특성을 제거 후 정상으로 재구성
- 이상 불변적 재구성이 아닌 **이상 제거적 재구성** 달성

**2) 원스텝 디노이징(One-step Denoising) 패러다임**[1]
- 반복적 디노이징(400 스텝)에서 벗어나 **단일 추론으로 300배 속도 향상**
- 추론 속도: 0.09 FPS → 23.5 FPS로 **실시간 응용 가능**
- DiffAD (1.2 FPS) 대비 **약 20배 빠른 추론**

**3) 노름 가이드(Norm-guided) 패러다임**[1]
- 다양한 크기의 이상을 처리하기 위해 두 가지 노이즈 스케일 통합
- 미세한 이상: 작은 노이즈 스케일로 세밀한 픽셀 복원
- 큰 이상: 큰 노이즈 스케일로 의미론적 수준의 복원

## 2. 해결하고자 하는 문제

### 기존 방법의 한계:

**자동 인코더(AE) 기반 방법의 문제점:**
- 저차원 압축에서 이상 정보가 여전히 포함되어 이상을 정상처럼 재구성 (거짓 음성)
- 복원 능력 부족으로 정상 영역도 부정확하게 재구성 (거짓 양성)

**기존 확산 기반 방법:**
- 높은 추론 비용: 20~1000회의 반복 디노이징 필요
- 실시간 응용 불가능

**이상 표현의 다양성:**
- 미세한 스크래치부터 대규모 구조 결함까지 다양한 형태
- 각각 다른 복원 전략 필요

### DiffusionAD의 해결책:
확산 모델의 우수한 밀도 추정과 샘플링 품질을 활용하면서 모든 문제를 **동시에 해결**[1]

## 3. 제안하는 방법 (수식 포함)

### 3.1 기본 확산 모델 원리

**순방향 노이즈 프로세스:**

$$x_t = \sqrt{\bar{\alpha}_t}x_0 + \sqrt{1-\bar{\alpha}_t}\epsilon_t, \quad \epsilon_t \sim \mathcal{N}(0, I) \quad (1)$$

**훈련 목표:**

$$L = \mathbb{E}_{t \sim [1,T], x_0 \sim q(x_0), \epsilon \sim \mathcal{N}(0,I)} \left[ \|\epsilon - \epsilon_\theta(x_t, t)\|^2 \right] \quad (2)$$

**역방향 디노이징 프로세스:**

$$x_{t-1} = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{1-\alpha_t}{\sqrt{1-\bar{\alpha}_t}}\epsilon_\theta(x_t, t)\right) + \tilde{\beta}_t z \quad (3)$$

### 3.2 원스텝 디노이징

**원스텝 재구성 공식:**

$$\hat{x}_0 = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \sqrt{1-\bar{\alpha}_t}\epsilon_\theta(x_t, t)\right) \quad (6)$$

**핵심 관찰:** $$t < 500$$일 때, 원스텝 디노이징이 반복 디노이징과 유사한 복원 품질 제공[1]

### 3.3 이미지 가이드 메커니즘

**기본 이미지 가이드:**

$$\epsilon_\theta(x_t, t, r_t) = \epsilon_\theta(x_t, t) - \sqrt{1-\bar{\alpha}_t}w\nabla_{x_t}\text{sim}(x_t, r_t) \quad (5)$$

### 3.4 노름 가이드 디노이징

**두 개의 노이즈 스케일 정의:**

$$S = \{0,1,\ldots,\tau\}, \quad B = \{\tau+1,\tau+2,\ldots,T\}, \quad \tau = 300$$

**작은 스케일 재구성:**

$$\hat{x}_0^s = \frac{1}{\sqrt{\alpha_{t_s}}}\left(x_{t_s} - \sqrt{1-\bar{\alpha}_{t_s}}\epsilon_\theta(x_{t_s})\right)$$

**유사성 측도:**

$$\text{sim}(x_{t_s}, n_{t_s}) = -\|n_{t_s} - x_{t_s}\|^2$$

**노름 가이드 노이즈 예측:**

$$\epsilon_\theta(x_{t_s}, n_{t_s}) = \epsilon_\theta(x_{t_s}) - \sqrt{1-\bar{\alpha}_{t_s}}w(n_{t_s} - x_{t_s}) \quad (7)$$

**최종 노름 가이드 재구성:**

$$\hat{x}_0^{ng} = \frac{1}{\sqrt{\alpha_{t_s}}}\left(x_{t_s} - \sqrt{1-\bar{\alpha}_{t_s}}\epsilon_\theta(x_{t_s}, n_{t_s})\right) \quad (8)$$

### 3.5 훈련 손실 함수

**노이즈 손실:**
$$L_{\text{noise}} = \frac{1}{2}\left(\|\epsilon_{t_b} - \epsilon_\theta(x_{t_b})\|^2 + \|\epsilon_{t_s} - \epsilon_\theta(x_{t_s})\|^2\right) \quad (9)$$

**마스크 손실:**
$$L_{\text{mask}} = \text{SmoothL1}(\hat{M}, M) + \gamma L_{\text{focal}}(\hat{M}, M) \quad (10)$$

**전체 손실:**
$$L_{\text{total}} = L_{\text{noise}} + L_{\text{mask}} \quad (11)$$

### 3.6 이상 합성 전략

**합성 이상:**
$$S = \beta(M \odot N) + (1-\beta)(M \odot A) + \bar{M} \odot N$$

- $$M$$: Perlin 노이즈 마스크
- $$A$$: DTD 텍스처 또는 자가 증강
- $$\beta$$: 불투명도 파라미터[1]

## 4. 모델 구조

### 4.1 전체 파이프라인

**재구성 서브네트워크:**
- U-Net 아키텍처 (PixelCNN + Wide ResNet + Transformer 기반)
- 정상 샘플로만 훈련
- 노이즈를 예측하여 이상 제거 재구성[1]

**세그먼테이션 서브네트워크:**
- 원본 이미지와 재구성 이미지의 불일치 및 공통점 활용
- 픽셀 수준의 이상 스코어 예측
- 거짓 양성 감소 및 이상 강조[1]

### 4.2 구현 세부사항

**확산 모델:**
- $$T = 1000$$ (전체 타임스텝)
- $$\tau = 300$$ (스케일 분할점)
- 기본 채널: 128, 어텐션 해상도: 32, 16, 8
- 헤드 수: 4

**훈련:**
- 배치 크기: 16 (정상 8 + 합성 이상 8)
- 에포크: 3000
- 옵티마이저: Adam (학습률 10⁻⁴)
- 이미지 크기: 256 × 256

## 7. 한계 및 과제

### 7.1 명시적 한계[1]

**1) 고정된 노이즈 스케일:**
- 모든 이미지에 동일한 $$t_s = 200$$, $$t_b = 400$$ 적용
- 극도로 다양한 이상에는 최적이 아닐 수 있음

**2) 이상 합성 전략의 한계:**
- Perlin 노이즈와 텍스처 기반 합성이 실세계 이상을 완벽히 반영하지 못함
- 매우 복잡한 구조적 결함 표현 제한

**3) 계산 복잡도:**
- 256×256 해상도에서만 평가
- 고해상도 이미지 처리 성능 미지수

### 7.2 이론적 한계

- $$t < 500$$에서 원스텝이 효과적인 이유에 대한 이론적 분석 부족[1]
- 두 노이즈 스케일의 상호작용에 대한 깊이 있는 분석 필요
- 다양한 도메인에서 일반화되는 이유에 대한 형식적 분석 부재

### 7.3 실무적 과제

- 새로운 산업 환경에 대한 적응 프로세스 체계화 필요
- 모바일/엣지 디바이스 배포 시 최적화 필요
- 의사 결정 과정의 해석 가능성 부족

| AnoDDPM | 2022 | 반복 | - | 매우 느림 | 의료 이미지 |
| DiffAD | 2023 | 50 스텝 | 98.7% | 1.2 FPS | 첫 본격 확산 기반 |
| KLAD | 2023 | 20 스텝 | - | - | 개선된 스텝 |
| DDAD | 2023 | 조건화 | 99.8% | ? | 최고 성능 |
| **DiffusionAD** | **2023** | **원스텝 + 노름** | **99.7%** | **23.5 FPS** | **효율성-성능 최적** |
| GLAD | 2024 | 적응형 | 높음 | - | 동적 스텝 |
| TransFusion | 2024 | 투명도 | 99.2% | - | 점진적 복원 |
| InvAD | 2025 | 잠재 역 | 높음 | 약 2배 빠름 | 재구성 불필요 |

### 10.3 방향별 연구 동향

**속도 최적화 방향:**
- 반복 → DDIM → **원스텝(DiffusionAD) → 재구성 불필요(InvAD)**
- DiffusionAD의 원스텝은 **효율성과 성능의 최적 균형점**[1]

**적응성 향상:**
- 고정 파라미터 → **동적 조정(GLAD)** → 도메인 특화

**이상 다양성 처리:**
- 단일 네트워크 → **다중 스케일(DiffusionAD의 노름 가이드)** → 통합 프레임워크

**통합 프레임워크:**
- 재구성 → 판별 → **생성+판별 통합(HDM)**

### 10.4 DiffusionAD의 위치와 기여

**강점:**
1. **효율성-성능 균형**: 23.5 FPS로 실시간 처리하면서 99.7% AUROC[1]
2. **단순하면서 효과적**: 원스텝 디노이징이라는 우아한 아이디어[1]
3. **우아한 해결책**: 노름 가이드로 다양한 이상 처리[1]
4. **광범위한 벤치마킹**: 4개 데이터셋, 다양한 지표에서 우수성 증명[1]

**개선 여지:**
- 성능: DDAD (99.8%)가 약간 높지만 속도 미공개[6]
- 적응성: GLAD의 동적 스케일 선택 미실현[7]
- 통합: HDM처럼 생성-판별 통합 미실현[12]

**향후 방향성:**
- DiffusionAD + GLAD 통합: 동적 노름 가이드
- DiffusionAD + HDM: 통합 프레임워크
- 원스텝 + InvAD: 재구성 불필요 원스텝

### 10.5 분야의 성숙도 평가

| 시기 | 단계 | 특징 | DiffusionAD의 역할 |
|------|-----|------|------------------|
| 2021-2022 | 도입 | 가능성 탐색, 높은 비용 | 문제 인식 |
| **2023-2024** | **성장** | **다양한 최적화 기법** | **전환점 (실시간 가능)** |
| 2025+ | 성숙 | 산업 표준화, 이론 심화 | 기초 연구 |

## 결론

DiffusionAD는 **2023년 이상 탐지 분야에서 확산 모델의 실무 적용을 가능하게 한 획기적인 연구**이다. 특히 원스텝 디노이징과 노름 가이드 패러다임은 이후 연구들에 영감을 주었으며, **실시간 추론 가능성은 산업 응용의 새로운 가능성**을 열었다.[1]

**주요 성과:**
- **속도:** 반복 대비 300배 향상 (0.09 FPS → 23.5 FPS)[1]
- **성능:** 4개 데이터셋 평균 98.6% Image AUROC[1]
- **실용성:** 제조 라인에 실시간 적용 가능[1]

**향후 발전 방향:**
적응형 노이즈 스케일, 향상된 이상 합성, 멀티모달 처리, 크로스 도메인 일반화 등을 통해 더욱 강력한 이상 탐지 시스템으로 발전할 것으로 기대된다. 동시에 GLAD의 동적 스케일 선택, HDM의 통합 프레임워크, InvAD의 재구성 불필요 방식 등과의 통합을 통해 다음 세대 이상 탐지 시스템이 등장할 것으로 예상된다.
