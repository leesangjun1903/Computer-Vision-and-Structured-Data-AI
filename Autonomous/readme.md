# Imitation Learning
> Imitation Learning (모방 학습)은 기계 학습(Machine Learning)의 한 분야로, 시스템 혹은 에이전트(Agent)가 전문가(expert)의 시범(demonstration)을 관찰하고 따라 함으로써 특정 작업을 수행하는 방법을 배우는 기술입니다.

> 전문가 데이터 활용: 학습의 핵심은 사람이 직접 운전하는 영상, 로봇을 조작하는 데이터 등 "올바른 행동"이 기록된 데이터셋입니다.
> 보상 신호 부재: 전통적인 강화 학습(Reinforcement Learning)에서는 에이전트가 스스로 행동하며 "보상"을 받아 학습하지만, 모방 학습에서는 보상 신호 없이 전문가의 행동 자체를 정답으로 간주하고 따라 합니다.
