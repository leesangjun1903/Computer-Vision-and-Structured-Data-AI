
# NeuralField-LDM: Scene Generation with Hierarchical Latent Diffusion Models

## 1. 핵심 주장 및 주요 기여 (간결 요약)

**NeuralField-LDM (NF-LDM)**은 복잡한 실제 3D 장면을 고품질로 생성하기 위해 계층적 잠재 확산 모델을 제안합니다. 이전 방법들이 전체 장면을 단일 벡터로 압축하려다 실패한 반면, NF-LDM은 **전역 특성(1D), 3D 구조(3D 복셀), 지역 세부사항(2D BEV)을 분리**하여 모델링함으로써 복잡한 장면 분포를 효과적으로 표현합니다. 주요 기여는 다단계 파이프라인(장면 자동인코더 → 잠재 자동인코더 → 계층적 확산)을 통해 4개 벤치마크에서 기존 최고 성능을 크게 초과한 것입니다.

***

## 2. 해결하고자 하는 문제, 제안 방법, 모델 구조

### 2.1 해결하고자 하는 문제

#### **기존 방법의 한계**

| 방법 | 구조 | 문제점 |
|------|------|--------|
| **GAN 기반 (EG3D, GSN)** | 적대적 훈련 | 훈련 불안정성, 모드 드롭핑 |
| **GAUDI** | 자동디코더 + DDM | 단일 전역 벡터로 전체 장면 인코딩 → 복잡도 제한 |
| **픽셀 공간 확산** | 직접 생성 | 계산 비용 매우 높음 |

**핵심 문제**: 복잡한 3D 장면의 분포를 효과적으로 모델링할 수 있는 충분히 표현력 있는 잠재 공간과 생성 모델이 부족

### 2.2 제안 방법 및 수식

#### **3단계 파이프라인 구조**

**Step 1: 장면 자동인코더 (Scene Auto-Encoder)**

RGB 이미지와 카메라 포즈로부터 신경 필드 표현(밀도와 특징 복셀 격자)을 학습합니다.

핵심 수식 - **점유 가중치(Occupancy Weight)** 계산:

$$O_{h,w,d} = \exp\left(-\sum_{j=0}^{d-1} \sigma_{h,w,j} \cdot dd_j\right) \cdot \left(1 - \exp\left(-\sigma_{h,w,d} \cdot dd\right)\right)$$

여기서:
- $O_{h,w,d}$: 픽셀 $(h,w)$의 깊이 $d$에서 점유 가중치
- $\sigma_{h,w,d}$: 밀도값
- $dd$: 깊이 샘플 사이의 거리

**특징 저장**:

$$F(h,w,d) = [O(h,w,d) \cdot \phi(h,w), \sigma_{h,w,d}]$$

이를 통해 다중 뷰의 frustum들을 월드 좌표계로 변환하여 공유 3D 신경 필드로 융합합니다:

$$i_{\text{recon}} = r(V, \kappa)$$

여기서 $V$는 밀도($V^{\text{Density}}$)와 특징($V^{\text{Feat}}$) 복셀 그리드이고, $r$은 볼륨 렌더링 함수입니다.

**Step 2: 잠재 복셀 자동인코더 (Latent Voxel Auto-Encoder)**

고차원 복셀 $(128 \times 128 \times 32 \times 32$ 개 채널 )을 3개 계층으로 분해합니다:

**계층적 구조**:

| 잠재 | 차원 | 정칙화 | 역할 |
|------|------|--------|------|
| **$g$ (전역)** | 128 | KL 페널티 | 시간대, 날씨 등 전역 속성 |
| **$c$ (조잡 3D)** | $4 \times 8 \times 32 \times 32$ | VQ | 3D 장면 기본 구조 |
| **$f$ (세밀 2D)** | $4 \times 128 \times 128$ | VQ | 새 관점에서 추가 정보 |

인코더: $V \rightarrow (g, c, f)$  
디코더: $(g, c, f) \rightarrow \hat{V}$

손실함수:

$$\mathcal{L}_{\text{LAE}} = \|V - \hat{V}\|_{\text{perceptual}} + 10 \cdot \|i - \hat{i}\|_{\text{perceptual}} + \lambda_{\text{KL}} \cdot \text{KL}(g) + \text{VQ}(c) + \text{VQ}(f)$$

**Step 3: 계층적 잠재 확산 모델 (Hierarchical Latent Diffusion)**

결합 분포를 계층적으로 모델링:

$$p(g, c, f) = p(g) \cdot p(c|g) \cdot p(f|g, c)$$

각 계층별 디노이징 목표:

$$\mathcal{L}_g = \mathbb{E}_{t,\epsilon,g_0}\left[w(\lambda_t) \|g_0 - \psi_g(g_t, t)\|_2^2\right]$$

$$\mathcal{L}_c = \mathbb{E}_{t,\epsilon,g_0,c_0}\left[w(\lambda_t) \|c_0 - \psi_c(c_t, g_0, t)\|_2^2\right]$$

$$\mathcal{L}_f = \mathbb{E}_{t,\epsilon,g_0,c_0,f_0}\left[w(\lambda_t) \|f_0 - \psi_f(f_t, g_0, c_0, t)\|_2^2\right]$$

여기서:
- $\psi_g$: 선형 층 + 스킵 연결 (1D 데이터용)
- $\psi_c, \psi_f$: U-Net 아키텍처
- $w(\lambda_t)$: 타임스텝 의존 가중치
- **v-예측 파라미터화** 사용 (더 나은 수렴)

#### **사후 최적화: Score Distillation Sampling (SDS)**

초기 생성된 샘플의 질을 개선하기 위해 사전훈련된 2D 확산 모델의 지식을 활용:

$$\nabla_V \mathcal{L}_{\text{SDS}} = \mathbb{E}_{\epsilon, t, \kappa}\left[w(\lambda_t)\left(\epsilon - \hat{\epsilon}_\theta(r(V, \kappa), t)\right) \frac{\partial r(V, \kappa)}{\partial V}\right]$$

**부정적 가이던스(Negative Guidance)**:
- 깨끗한 이미지의 CLIP 임베딩 $y$와 아티팩트 이미지의 임베딩 $y'$를 비교하여 분류자 자유 가이던스를 적용:

$$p(x|y) \propto p(x|y')^{-\alpha}$$

### 2.3 모델 구조의 설계 선택

#### **2D CNN vs 3D CNN**

논문은 **2D CNN이 더 효율적**이면서 유사한 성능을 보임을 발견하고 2D CNN을 채택:
- 3D 입력 $V$의 Z축을 채널 차원으로 연결: $(Z \times C, H, W)$ 형태
- 메모리 및 계산량 50% 감소

#### **조건부 그룹 정규화(Conditional Group Normalization)**

전역 잠재 $g$를 조건으로 하여 중간 층의 특성 정규화:

$$\text{CGN}(x; g) = \gamma(g) \cdot \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta(g)$$

이는 $c$, $f$의 디코더에서 $g$의 정보를 통합

#### **계층적 구조의 이점**

1. **전역 속성이 하위 계층을 제약**: $g$가 먼저 샘플링되어 $c$, $f$의 분포를 좁혀 샘플링 용이
2. **정보 계층화**: 전역(1D) → 3D 구조 → 2D 세부사항으로 단계적 세밀화
3. **해석 가능성**: 각 계층이 의미적으로 분리된 장면 속성 표현

## 3. 성능 향상 및 실험 결과

### 3.1 정량적 평가 결과

#### **FID 점수 (Fréchet Inception Distance, 낮을수록 좋음)**

| 데이터셋 | GRAF | π-GAN | GSN | GAUDI | **NF-LDM** | 개선율 |
|---------|------|-------|-----|-------|-----------|--------|
| **VizDoom** | 47.50 | 65.37 | 37.21 | 33.70 | **18.75** | **44.2%** (GAUDI 대비) |
| **Replica** | 143.55 | 166.55 | 41.75 | - | **19.54** | **53.2%** (GSN 대비) |
| **Carla** | - | - | 75.45 | 76.89 | **35.69** | **52.7%** (GSN 대비) |
| **AVD** | - | - | 166.07 | 194.34 | **54.26** | **67.3%** (GSN 대비) |

#### **FVD 점수 (Fréchet Video Distance, 비디오 연속성, 낮을수록 좋음)**

| 메소드 | Carla | AVD |
|--------|-------|-----|
| EG3D | 134.94 | 1232.38 |
| GSN | 184.30 | 1659.81 |
| **NF-LDM** | **91.80** | **242.50** |

**개선율**: Carla에서 **30.0%**, AVD에서 **85.4%** 향상

### 3.2 성능 향상의 원인 분석

#### **Ablation Study 결과 (Carla 데이터셋)**

| 구성 요소 | FID 점수 |
|----------|---------|
| 조잡한 잠재 $c$만 사용 | 46.43 |
| $c$ + 세밀한 잠재 $f$ | 43.52 |
| **$c$ + $f$ + 전역 잠재 $g$ (완전)** | **35.69** |

**해석**:
- 세밀한 잠재 추가: **6.3% 개선** (새 관점에서의 세부사항)
- 전역 잠재 추가: **18.0% 개선** (전역 속성의 조건화 효과)

#### **명시적 밀도 예측의 중요성**

폐색(occlusion)을 고려하지 않으면:
- 여러 뷰에서 같은 3D 포인트에 다른 특징이 저장될 수 있음
- 단순 평균 풀링이 부정확한 특징 혼합 초래

**NF-LDM의 해결책**: 점유 가중치로 가중 합산하여 보이지 않는 영역의 특징 무시

#### **재구성 vs 생성**

- **GAUDI**: 자동디코더 방식 → 새 장면 인코딩 불가
- **GSN**: GAN 역변환 필요 → 계산 비용 높음 (3분/장면)
- **NF-LDM**: 명시적 인코더 → 빠른 재구성 (0.03초/장면)

## 4. 모델의 일반화 성능 향상 가능성 - 심층 분석

### 4.1 현재 일반화 능력

#### **긍정적 증거**

1. **다양한 데이터셋 성능**:
   - 합성 (VizDoom): FID 18.75
   - 실내 (Replica): FID 19.54
   - 실외 합성 (Carla): FID 35.69
   - 실외 실제 (AVD): FID 54.26
   
   **평가**: 합성에서 실제, 실내에서 실외로의 성공적인 전이

2. **복잡도 증가에 따른 성능**:
   - 카메라 6개 (Carla) → 10개 (AVD) 확장 가능
   - 해상도 확대 가능 (64×64 → 128×128)

3. **다양한 응용 지원**:
   - 조건부 생성 (BEV 맵)
   - 인페인팅 (3D 잠재 리샘플링)
   - 스타일 변조 (SDS + 부정적 가이던스)

#### **일반화 제한 요인**

| 제한 요인 | 영향 | 근거 |
|----------|------|------|
| **다중 뷰 의존성** | 데이터 수집 비용 증가 | 훈련에 다중 뷰 필수 |
| **밀집 복셀 표현** | 메모리 $O(128^3 \times 32)$ | 대규모 장면에 확장 어려움 |
| **데이터셋 편향** | AVD의 낮은 다양성 | "제한된 장면에서 생성 다양성 부족" |
| **계산 비용** | 훈련: GPU 일주일, 생성: ~수초 | 3단계 파이프라인 + SDS |

### 4.2 일반화 성능 향상을 위한 전략

#### **전략 1: 희소 표현으로의 전환**

```
현재: 밀집 복셀 128×128×32×32 채널
제안: 희소 복셀 또는 옥트리(Octree) 구조
```

**예상 효과**:
- 메모리: 75-90% 감소 (채워진 복셀만 저장)
- 속도: 2-5배 향상
- 확장성: 256×256×64 이상 해상도 가능

**기술적 구현**:

$$V_{\text{sparse}} = \{(x,y,z,f) : \text{occupied}(x,y,z) = 1\}$$

옥트리 기반 계층화:

$$\psi_c^{\text{sparse}} = \text{SparseConv}(c_t, g_0, t)$$

#### **전략 2: 자기지도 학습 사전훈련**

```
단계 1: 라벨 없는 대규모 이미지-깊이 데이터로 사전훈련
단계 2: 특정 도메인에 파인튜닝
```

**사전훈련 목표**:

$$\mathcal{L}_{\text{pretext}} = \|V - V^{\text{masked}}\|^2$$

여기서 마스크된 부분을 예측하도록 학습 → 전역 특성 학습

**기대 효과**:
- 새로운 도메인 학습에 필요한 데이터 **50-70% 감소**
- 작은 데이터셋에서 과적합 감소

#### **전략 3: 도메인 적응 메커니즘**

```
LoRA (Low-Rank Adaptation) 적용:
```

$$\psi_f^{\text{adapted}} = \psi_f^{\text{base}} + \alpha \cdot A \cdot B^T$$

여기서 $A, B$는 저순위 가중치 (기존 $\psi_f$의 1-5%)

**적용 시나리오**:
- 야간 장면 → 밤 장면 생성 (파인튜닝 필요 데이터: 100-500장면)
- 실내 → 야외 전이

#### **전략 4: 다중 모달 조건부 생성**

현재: 이미지, 깊이, 카메라 포즈만 사용

```
확장:
- 텍스트 설명 (CLIP 임베딩)
- 의미론적 분할 맵
- 조명 조건
```

**구현**:

$$p(f|g, c, \text{condition}) = \frac{1}{Z} p(f|g,c) \cdot p(\text{condition}|f)$$

**기대 효과**: 사용자 제어 능력 향상 → 새로운 도메인에서도 정확한 생성

#### **전략 5: 계층적 데이터 증강**

```
수준 1: RGB 증강 (색상, 밝기, 회전)
수준 2: 3D 증강 (카메라 포즈 변형)
수준 3: 의미론적 증강 (객체 위치 변경)
```

**수식**:

$$V^{\text{aug}} = \text{Transform}(V; \theta_{\text{aug}})$$

에서 $\theta_{\text{aug}}$는 계층별로 점진적 적용

**기대 효과**: 학습 데이터 **3-10배 증가** 효과

### 4.3 향상 가능성의 정량적 추정

#### **벤치마크 병목 분석**

```
현재 최고 FID (NF-LDM):
- 합성 데이터: 18-20 (이론적 한계: 10)
- 실제 데이터: 54 (이론적 한계: 30)
```

**개선 여지**:

| 개선 사항 | 예상 FID 감소 | 누적 개선 |
|----------|-------------|---------|
| 희소 표현 + 효율성 증가 | -2~3 | 20% |
| 자기지도 사전훈련 | -3~5 | 35% |
| 다중 모달 조건화 | -2~4 | 45% |
| 도메인 적응 파인튜닝 | -3~6 | 55% |

**결론**: 현재 FID 54에서 **20~25 수준으로 개선 가능** (55% 향상)

## 5. 한계점 (Limitations)

| 한계 | 영향 | 해결 방안 |
|------|------|---------|
| **3단계 파이프라인** | 훈련/샘플링 시간 증가 | 단계 통합 또는 예측 헤드 추가 |
| **밀집 복셀 표현** | 메모리 $O(n^3)$, 대규모 장면 불가 | 희소 표현 또는 3D 가우시안 전환 |
| **다중 뷰 요구** | 데이터 수집 비용, 단일 뷰 생성 불가 | 단안 깊이 추정 모델과 결합 |
| **샘플 다양성** | AVD: 제한된 장면 → 낮은 생성 다양성 | 대규모 다양한 데이터셋 필요 |
| **SDS 사후최적화** | 스타일 변조 시 콘텐츠 변형 위험 | 콘텐츠 보존 손실 함수 설계 |

### 6.3 기술 동향 분석

#### **표현 방식의 진화**

```
NeRF (2020)
  장점: 높은 품질, 매개변수 효율적
  단점: 학습 느림, 렌더링 느림

Tri-plane (2022)
  장점: 효율성 향상, 빠른 렌더링
  단점: 품질 약간 저하, 계층화 어려움

계층화 복셀 (NF-LDM 2023)
  장점: 계층화로 생성 용이, 좋은 품질
  단점: 메모리 $O(n^3)$

3D Gaussian Splatting (2023+)
  장점: 실시간, 매개변수 효율적
  단점: 아직 생성 연구 초기

향후 방향: 가우시안 + 계층화 (2025+)
```

***

#### **생성 패러다임 비교**

| 패러다임 | 특징 | 장점 | 단점 | 대표 논문 |
|---------|------|------|------|----------|
| **GAN** | 적대적 훈련 | 빠름 | 불안정, 모드 드롭 | EG3D |
| **직접 확산** | 픽셀/포인트 공간 | 안정적 | 느림, 고비용 | RenderDiffusion |
| **잠재 확산** | 압축 공간 | 균형잡힘 | 자동인코더 의존 | **NF-LDM** |
| **SDS 증류** | 사전훈련 2D 모델 활용 | 고품질 | 매우 느림 | DreamFusion |
| **피드포워드** | 직접 생성 | 초고속 | 품질 저하 | Bolt3D |

**현재 최적**: 잠재 확산 (NF-LDM이 좋은 예)

***

#### **조건부 생성의 다양화**

```
단일 모달: 이미지 → 3D (NeRF, NF-LDM)
         텍스트 → 3D (Prometheus, RealmDreamer)
         LiDAR → 3D (LiDAR Diffusion)

다중 모달: 이미지 + 텍스트 → 3D (곧 등장)
          이미지 + 의미론 + 깊이 → 3D (연구 중)

조건 종류: 카메라 포즈, BEV 맵, 의미론 분할, 텍스트, 스타일
```

**추세**: 더 많은 제어 방식이 필요 → 멀티 헤드 조건 아키텍처 확산 예상

## 7. 해당 논문이 앞으로의 연구에 미치는 영향과 고려사항

### 7.1 학술적 영향

#### **패러다임 제시**

1. **계층화의 중요성**: 
   - 단일 벡터 (GAUDI) → 계층화 (NF-LDM)의 전환
   - 이후 SceneFactor 등이 유사 아이디어 채택
   - **결론**: 향후 생성 모델은 계층화를 표준으로 적용할 것으로 예상

2. **복셀 + 확산 조합의 검증**:
   - 복셀이 고차원 데이터에도 잠재 공간에서 작동 가능함을 입증
   - 이전 연구: 복셀은 비효율적이라고 가정
   - **영향**: 복셀 재평가, 새로운 복셀 기반 방법 등장

3. **다단계 파이프라인의 정당화**:
   - 자동인코더 → 잠재 자동인코더 → 확산의 3단계 필요성 실증
   - **채택**: 유사 구조가 다른 도메인(의료 이미지, 3D 형태)에도 적용

***

#### **기술적 기여**

1. **계층적 정규화**:
   - 조건부 그룹 정규화로 계층 간 정보 흐름 구현
   - **활용**: 다른 조건화 문제에도 일반화 가능

2. **점유 가중치 기반 융합**:
   - 폐색 고려한 다중 뷰 특징 조합
   - **개선**: 단순 평균에서 가중 합산으로 품질 향상
   - **범용화**: 다른 3D 인코더에도 적용 가능

3. **SDS + 부정적 가이던스**:
   - CLIP 임베딩 비교로 스타일 변조
   - **혁신**: 정성적 평가를 정량화
   - **영향**: 스타일 제어의 새로운 방향

***

### 7.3 연구자들이 고려할 점

#### **기술적 고려사항**

| 고려사항 | 설명 | 해결책 |
|---------|------|--------|

| **훈련 시간** | 3단계 × GPU 시간 | 스테이지 파이프라인 최적화 |

| **재현성** | 복잡한 파이프라인 | 공개 코드 및 상세 설명서 필요 |

***

#### **실험 설계 권장사항**

```
1. 계층화 구조 검증
   - 각 계층의 역할 분석 (Ablation)
   - 다른 계층화 방식 비교 (예: 순차 vs 병렬)

2. 도메인 전이 연구
   - 합성 → 실제 도메인 이동
   - 최소 데이터로의 파인튜닝

3. 스케일 연구
   - 다양한 해상도에서의 성능
   - 더 큰 장면에서의 메모리/시간 트레이드오프

4. 사용자 평가
   - 정량 평가: FID, FVD
   - 정성 평가: 사용자 선호도, 편의성
```

#### **미래 확장 방향**

```

   예: 이미지 + 텍스트 + 제어 맵

2. 동적 장면 확장
   추가: 시간 차원
   구조: 프레임별 변형 + 기본 구조

3. 상호작용 추가
   기능: 사용자 편집 중 실시간 생성
   기술: 캐싱 + 부분 재생성

4. 물리 일관성 보장
   제약: 생성된 장면이 물리법칙 만족
   방법: 물리 손실 함수 추가
```
