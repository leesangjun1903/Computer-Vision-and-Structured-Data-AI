# RT-1: Robotics Transformer for Real-World Control at Scale

### 1. 핵심 주장과 주요 기여

RT-1의 핵심 주장은 **대규모의 다양한 데이터셋과 고용량 트랜스포머 아키텍처를 결합하면 로봇이 효과적으로 일반화할 수 있다**는 것입니다. 이는 컴퓨터 비전과 자연언어처리에서 성공한 패러다임을 로봇 학습에 처음으로 대규모로 적용한 사례입니다.[1]

**주요 기여:**

- **130,000개의 실제 로봇 데모**를 수집하여 700개 이상의 서로 다른 작업을 학습[1]
- **효율적인 토큰화 기반 트랜스포머 아키텍처**로 실시간 제어(3Hz)를 가능하게 함[1]
- **이질적 데이터 통합(다중 로봇, 시뮬레이션)**을 통해 일반화 성능 향상[1]
- 본 것 없는 작업에 대해 기존 방법 대비 **25-36% 성능 향상**, 배경 변화에 대해 **18% 향상**[1]

### 2. 문제 정의 및 해결 방법

#### 2.1 해결하려는 문제

기존 로봇 학습의 핵심 문제는:
1. **데이터 수집의 높은 비용**: 실제 로봇 데이터 수집은 엔지니어링 집약적이거나 비싼 인간 시연이 필요
2. **제한된 일반화 능력**: 작업별 데이터셋 수집으로 인한 시일로화된 모델들
3. **실시간 추론 속도 제약**: 고용량 모델이 로봇의 실시간 제어(≥3Hz)를 만족하기 어려움
4. **멀티태스크 학습의 어려움**: 다양한 작업을 단일 모델로 처리하면서 높은 성능 유지[1]

#### 2.2 제안 방법: 토큰화 기반 아키텍처

RT-1은 다음과 같은 혁신적 접근을 제안합니다:

**입력 토큰화:**
- 6개 이미지를 ImageNet 사전학습된 EfficientNet-B3으로 처리하여 $$9 \times 9 \times 512$$ 특성맵 추출[1]
- 이를 81개 시각 토큰으로 평탄화
- 자연언어 명령어를 Universal Sentence Encoder로 임베딩한 후 **FiLM(Feature-wise Linear Modulation) 계층**으로 이미지를 조건화[1]

**TokenLearner를 통한 압축:**

81개 시각 토큰을 **8개 토큰으로 압축**하여 추론 속도를 $$2.4 \times$$ 향상[1]

**수식 표현:**

토큰화 과정은 다음과 같이 표현됩니다:

$$\text{Image Tokens} = \text{Flatten}(\text{FiLM}(I, e(L)))$$

여기서 $$I$$는 이미지, $$L$$은 언어명령, $$e(L)$$는 임베딩 함수입니다.

TokenLearner는 다음과 같이 동작합니다:

$$T_{\text{compressed}} = \text{Attention}_{\text{element-wise}}(T_{\text{original}})$$

이를 통해 81개 토큰에서 8개 토큰으로 감소합니다.[1]

**Transformer 백본:**
- 8계층 자기 주의(self-attention) 레이어 포함
- 19M 파라미터의 디코더 전용 Transformer
- 6개 이미지의 8개 토큰씩 총 48개 토큰으로 구성된 입력 시퀀스[1]

**액션 토큰화:**

각 액션 차원을 **256개 빈으로 이산화**:[1]

$$a_{\text{discretized}} = \text{argmax}_{i} \left( a \in \text{bin}_i \right), \quad i \in $$

로봇 액션 공간: 7D (팔 이동: x, y, z + 회전: roll, pitch, yaw + 그리퍼 개방도) + 3D (베이스 이동: x, y + 회전: yaw) + 1D (모드 선택)[1]

**손실 함수:**

$$\mathcal{L} = -\sum_{t=0}^{T} \sum_{d=1}^{D} \log P(a_t^{(d)} | I, L, a_{ < t})$$

여기서 각 차원의 확률은 범주형 교차 엔트로피로 계산됩니다.[1]

### 3. 모델 구조 상세 분석

#### 3.1 전체 아키텍처

[Figure 3에서 나타나는 구조를 참고]

| 계층 | 구성요소 | 파라미터 | 기능 |
|------|---------|---------|------|
| **입력 처리** | ImageNet 사전학습 EfficientNet-B3 + FiLM 레이어 | 16M | 언어 조건화된 이미지 토큰 생성 |
| **토큰 압축** | TokenLearner | 추가 학습 가능 파라미터 | 81 → 8 토큰 압축 |
| **시퀀스 모델링** | 8계층 Transformer 디코더 | 19M | 토큰 간 의존성 모델링 및 액션 생성 |
| **출력** | 범주형 분포 (256 bins × 액션 차원) | - | 각 시간단계별 이산화 액션 |

**특징:**
- 총 파라미터: **35M**[1]
- 추론 속도: **15ms (3Hz 제어 주파수 달성)**[1]
- 시각-언어 조기 융합(early fusion)으로 관련 특징에 집중[1]

#### 3.2 핵심 설계 선택

**1) 이산화된 액션 표현의 중요성:**
- 연속 가우시안 분포보다 **29% 성능 향상**[1]
- 다중 모드 분포를 효과적으로 표현 가능

**2) ImageNet 사전학습의 효과:**
- 사전학습 제거 시 본 것 없는 작업 성능 **33% 저하**[1]
- 대규모 다양한 이미지 데이터의 일반화 지식 활용

**3) FiLM 기반 조건화:**
- 0으로 초기화된 FiLM 가중치로 사전학습 가중치 보존[1]
- Gato의 후기 융합(late fusion)보다 **40% 이상 디스트랙터 견고성 향상**[1]

- 배경과 방해물을 효과적으로 억제
- Layer 2, Head 6에서 특히 명확한 선택성 관찰

이는 어텐션의 "병목" 효과가 콤팩트하면서도 정보 풍부한 표현을 생성함을 의미합니다.[1]

**가설 2: 데이터 다양성의 영향**

$$\text{Generalization Impact} = f(\text{Data Quantity}, \text{Data Diversity})$$

결과:

**결론: 데이터 다양성이 데이터 양보다 $$\times 3.7$$ 더 중요**

### 5. 한계 및 제약 조건

논문에서 명시된 한계:

**1) 모방 학습의 근본적 제약:**[1]
- 시연자의 성능을 초과할 수 없음
- 바이어스된 데모로부터의 학습 제약

**2) 개념 조합의 한계:**[1]
- 보이지 않은 새로운 모션에 일반화 불가
- 학습 데이터에서 본 개념의 **조합만 가능**
  예: "apple" + "pick" → "pick apple" 가능
      하지만 완전히 새로운 동작은 불가

**3) 조작 작업의 제한성:**[1]
- 현재 주방 환경의 단순 조작 작업만 포함
- 더 복잡한 손 조작이나 정밀 작업 미포함

**4) 환경 견고성 제약:**[1]
- 배경 변화 견고성(59%)이 다른 지표보다 낮음
- 환경 다양성 확대 필요

### 6. 최신 연구 기반 미래 영향 및 고려사항

#### 6.1 RT-1이 로봇 학습에 미친 영향

RT-1의 발표(2022년 12월, arXiv 논문 인용 **1,745회**)는 로봇 학습 분야에 혁신적 변화를 촉발했습니다:[2]

**직계 후속 연구:**

**RT-2 (2023년 7월):** 비전-언어-액션 모델로 진화[3][4]
- 웹 규모 VLM을 로봇 제어와 직접 결합
- 인터넷 규모 데이터로부터의 신흥 능력(emergent capabilities) 획득[3]
- 연쇄적 사고(chain-of-thought) 추론으로 다단계 의미 추론 가능[3]
- 본 것 없는 작업에서 RT-1 대비 **약 2배 일반화 성능 향상**[4]

**SARA-RT (2024년 1월):** 효율성 개선[5]
- RT-2 기반 모델을 더 가볍고 빠르게 개선
- 최고 성능의 SARA-RT-2: **14% 더 빠르고 10.6% 더 정확**[5]
- 포인트 클라우드 Transformer에 적용 시 **2배 이상 속도 향상**[5]

**RDT-1B (2024년 10월):** 양손 조작으로 확장[6]
- **1.2B 파라미터**의 확산 기반 기초 모델
- 가장 큰 멀티 로봇 데이터셋 사용

#### 6.2 새로운 패러다임의 등장

**1) 확산 기반 정책(Diffusion-based Policies):**[7][8]

Multimodal Diffusion Transformer (MDT, 2024):[8]
- 토큰화 기반 접근과 생성 모델 결합
- LIBERO 벤치마크에서 **15% 절대 성능 향상**
- 희소하게 주석된 데이터(2% 미만 언어 주석)에서 효과적[8]

확산 정책의 수식적 표현:

$$x_t = x_{t-1} - \epsilon_\theta(x_{t-1}, c, t)$$

여기서 $$\epsilon_\theta$$는 학습된 디노이징 네트워크, $$c$$는 조건(언어/목표 이미지)[8]

**2) 메모리 기반 정책(Memory-augmented Policies, 2025):**[9]

LiteVLP (2025년 3월):[9]
- 과거/미래 경험 처리 능력 추가
- RT 계열 모델의 **비용 효율성 3배 향상**
- 도메인 시프트 감소

**3) 계층적 접근(Hierarchical Approaches, 2025):**[10]

HiRT (2025년 2월):[10]
- 낮은 주파수: VLM으로 의미적 특징 추출
- 높은 주파수: 비전 기반 정책으로 실시간 상호작용
- 계산 비용과 추론 지연 감소

#### 6.3 멀티모달 학습의 진화[11]

최신 검토논문(2024년 12월)에서 강조하는 Transformer 기반 로봇 학습의 발전:[11]

**강점:**
- 다중 모달리티 처리: 시각, 언어, 고유감각 통합[11]
- 낮은 데이터 샘플 효율성(few-shot learning)[11]
- 장기 범위 의존성 모델링[11]

**미해결 과제:**
- 부분 관찰성(partial observability) 문제[11]
- 현실적 시간 제약과의 불일치[11]
- 다중 로봇 형태 간 일반화[11]

#### 6.4 Sim-to-Real 전이의 발전

TRANSIC (2024년 CoRL):[12]
- 인간-루프 온라인 수정 기반 전이
- RT-1의 시뮬레이션 데이터 흡수와 결합
- 가구 조립 같은 접촉 집약적 작업에서 성공

이는 RT-1의 **이질적 데이터 흡수 능력**이 현실 세계의 sim-to-real 격차 극복에도 활용됨을 의미합니다.[12]

### 7. 향후 연구 시 고려사항

#### 7.1 데이터 수집 및 큐레이션

**현안:**
- 대규모 로봇 데이터는 여전히 비용이 높음
- RT-1의 성공이 데이터 다양성에 크게 의존[1]

**권장사항:**
1. **자동화된 데이터 수집**: AutoRT와 같은 자동 데모 생성 시스템 개발[5]
2. **합성 데이터 활용**: 시뮬레이션 데이터의 효과적 통합 방법 연구[1]
3. **능동적 학습**: 모델이 부족한 분야를 자동으로 식별하여 수집 지시[1]

#### 7.2 일반화 능력의 다층적 개선

**구체적 개선 방향:**

1. **환경 다양성 확대:**[1]
   - 현재 배경 견고성(59%)이 병목
   - 다양한 조명, 텍스처, 배경의 더 많은 데이터 수집

2. **새로운 개념에 대한 일반화:**[1]
   - 개념 조합만 가능한 제약 극복
   - 메타 학습(meta-learning) 또는 인컨텍스트 학습 도입

3. **동적 장면 대응:**[10]
   - HiRT 같은 계층적 접근으로 다양한 시간 스케일 처리[10]

#### 7.3 효율성과 배포

**임계 과제:**
- 모델 크기와 실시간성의 트레이드오프
- 온디바이스 배포의 어려움

**해결책:**

1. **주의 메커니즘 개선:**[5]
   - SARA-RT처럼 적응형 주의로 **14% 속도 향상**[5]
   - 스파스 어텐션 또는 계층적 주의 탐구

2. **양자화 및 압축:**
   - 온디바이스 확산 정책(2025년)이 보여준 경로[13]
   - 라이트급 VLA 모델(TinyVLA) 개발[14]

3. **메모리 효율성:**
   - 장기 시퀀스 처리(현재 6 이미지) 확대
   - 효율적 메모리 구조 활용[9]

#### 7.4 안전성과 해석성

**로봇 배포의 필수 요소:**

1. **정책 해석성 강화:**
   - 어텐션 맵 시각화(Figure 13)가 좋은 시작[1]
   - 인과성 분석 및 주요 결정 요인 추출

2. **실패 모드 분석:**
   - 언제 모델이 실패하는지 정량화
   - 신뢰도 추정 메커니즘

3. **안전 제약:**
   - 제약 만족 학습(Constrained Decision Transformer) 참고[11]
   - 보수적 정책 학습

#### 7.5 장기 비전: 범용 로봇 정책

**최종 목표:**
- 단일 모델이 수천 개의 작업을 수행 가능
- 새로운 환경, 로봇, 작업에 빠르게 적응

**달성 경로:**
1. RT-1 → RT-2 진화: VLM 기반 의미 이해 강화[3]
2. 확산 정책 통합: 생성 능력으로 다양한 행동 표현[8]
3. 메모리 기능 추가: 문맥 기반 적응[9]
4. 다중 로봇 학습: 형태 간 지식 전이 극대화[6][1]

이러한 진화를 통해 로봇은 인간의 비디오 데이터, 다른 로봇의 경험, 시뮬레이션 데이터를 모두 활용할 수 있는 진정한 범용 에이전트가 될 수 있을 것으로 예상됩니다.

***

### 결론

RT-1은 **대규모, 다양한 데이터와 고용량 트랜스포머의 결합**이 로봇 학습에서도 혁신을 일으킬 수 있음을 증명한 이정표 연구입니다. 특히 **데이터 다양성의 중요성** 강조, **이질적 데이터 통합**, **실시간 추론 가능성** 달성이 이후 연구의 토대를 마련했습니다. 

후속 연구들(RT-2, SARA-RT, RDT-1B 등)은 이 기초 위에서 VLM 통합, 효율성 개선, 확산 모델 결합으로 더욱 강력한 모델로 진화하고 있으며, 로봇이 진정한 범용 에이전트로 나아가는 길을 열었습니다.
