## 1. Executive Summary (10문장 이내)

1. 본 논문은 테이블형(tabular) 데이터에서 최근 제안된 딥러닝 모델들이 기존 트리 앙상블 기법(XGBoost)을 실제로 능가하는지를 엄밀하게 검증한 비교 연구이다.
2. 비교 대상 딥러닝 모델은 TabNet, NODE, DNF-Net, 1D-CNN이며, 이들을 11개의 다양한 테이블 데이터셋에 동일한 하이퍼파라미터 최적화 프로토콜로 평가하였다.
3. 핵심 발견은 각 딥러닝 모델이 자신의 원 논문에서 사용된 데이터셋에서는 좋은 성능을 보이지만, **미확인(unseen) 데이터셋에서는 XGBoost보다 현저히 낮은 성능**을 보인다는 것이다.
4. XGBoost는 11개 데이터셋 중 8개에서 딥러닝 모델들을 유의미하게 ($p < 0.005$) 능가하였다.
5. 딥러닝 모델들은 하이퍼파라미터 최적화에 훨씬 더 많은 반복 횟수와 시간을 필요로 하였다.
6. 긍정적 결과로, **딥러닝 모델과 XGBoost의 앙상블**이 단일 모델 및 비딥러닝 고전 앙상블보다 더 나은 성능을 보였다.
7. 앙상블에서 모델 선택 시 검증 손실 기반 정렬이 무작위 선택보다 효과적이었으며, 3개 모델만으로도 최적에 근접한 성능을 달성할 수 있었다.
8. 딥러닝 모델들의 성능이 자신의 원 논문 데이터에서만 우수한 이유로 선택 편향(selection bias)과 하이퍼파라미터 불균등 최적화가 지목된다.
9. 저자들은 "No Free Lunch" 원칙을 인정하면서도, 현 시점에서 tabular 데이터에는 XGBoost가 더 실용적인 선택임을 결론짓는다.
10. 향후 연구 방향으로 더 다양한 벤치마크 구축, 최적화가 용이한 딥러닝 구조 개발, 그리고 앙상블 방법론 심화 연구가 필요함을 제언한다.

### 1-1. 연구의 목적과 필요성

**문제 상황:**
테이블형 데이터는 의료, 금융, 제조, 기후과학 등 현실 세계에서 가장 흔히 접하는 데이터 유형이다. XGBoost로 대표되는 GBDT(Gradient Boosted Decision Trees) 계열이 오랫동안 이 분야의 표준으로 자리잡아 왔다.

**연구 필요성:**
- 2020~2021년 사이 TabNet, NODE, DNF-Net, 1D-CNN 등 딥러닝 기반 테이블 모델들이 잇따라 발표되며 GBDT를 능가한다고 주장하였다.
- 그러나 각 논문은 **서로 다른 데이터셋을 벤치마크**로 사용하여 공정한 비교가 불가능하였다.
- 표준 벤치마크(ImageNet, GLUE 등)가 존재하지 않으며, 일부 모델은 오픈소스 구현도 없었다.
- 기존 비교 연구들이 모델별 하이퍼파라미터 최적화를 동등하게 수행하지 않아 결론의 신뢰성이 낮았다.

**연구 목적:**
1. 딥러닝 모델이 **다른 데이터셋에서도 일반화되는가?** (정확도 측면)
2. **훈련 및 하이퍼파라미터 탐색 비용**은 어떠한가? (효율성 측면)

### 2-1. 상세 분석

#### 해결하고자 하는 문제

"테이블 데이터에 대한 딥러닝 모델들이 XGBoost보다 실제로 우수한가?" 라는 질문에 대한 엄밀하고 공정한 실증적 검증. 특히:
- 서로 다른 벤치마크로 인한 비교 불가능성 해소
- 하이퍼파라미터 최적화 불균등 문제 해소
- 계산 비용 및 최적화 난이도 포함한 종합적 비교

#### 제안하는 방법 (수식 포함)

**균일 가중 앙상블 (Uniform Ensemble):**

$$p(y|x) = \sum_{k=1}^{K} p_{\theta_m}(y|x, \theta_m) $$

**검증 손실 기반 가중 앙상블 (Weighted Ensemble):**

$$p(y|x) = \sum_{k=1}^{K} l_k^{\text{val}} \cdot p_{\theta_m}(y|x, \theta_m) $$

여기서 $l_k^{\text{val}}$는 $k$번째 모델의 정규화된 검증 손실(normalized validation loss)이다. 식 (1)은 식 (2)의 특수한 경우($l_k^{\text{val}} = 1/K$)이다.

**하이퍼파라미터 최적화:** HyperOpt (Bayesian Optimization)를 사용하여 각 데이터셋에 대해 1,000 스텝 수행 (p.4, Section 3.1.2)

**통계 검증:** Friedman 비모수 검정 (유의수준 95%, $p < 0.05$ 기각) (p.5, Section 3.1.2)

#### 모델 구조

| 모델 | 구조 핵심 아이디어 | 주요 특징 |
|---|---|---|
| **XGBoost** | Gradient Boosted Decision Trees | 잔차 기반 순차 학습, 그래디언트 강하 손실 최소화 |
| **TabNet** | Sequential attention + Sparsemax | 각 행(row)별 피처 선택, 희소 마스크 기반 인코더 |
| **NODE** | Oblivious Decision Trees (ODTs) | 각 레벨에서 하나의 피처만 선택, 미분 가능한 트리 앙상블 |
| **DNF-Net** | Disjunctive Normal Form (DNF) 시뮬레이션 | DNNF 블록: FC 레이어 + 소프트 이진 결합 레이어 |
| **1D-CNN** | 1D Convolutional Network | FC 레이어로 지역성 특성 생성 후 1D-Conv 레이어 적용 |

**NODE의 ODT 분기 방식:**

각 노드에서 하나의 피처 $x_{f_i}$를 선택하고 임계값 $t_i$와 비교:

$$\text{split}_i = \sigma\left(\frac{x_{f_i} - t_i}{\tau}\right)$$

여기서 $\sigma$는 시그모이드 함수, $\tau$는 온도 파라미터로 미분 가능성을 보장한다. (Popov et al., 2020 기반)

#### 성능 향상 및 한계

**성능 향상:**

| 지표 | XGBoost | Deep Ensemble w XGBoost | 개선율 |
|---|---|---|---|
| 평균 상대 성능 열화(%) | 3.34% | **2.32%** | ~1.02%p 향상 |
| Shrutime 손실 | 13.82±0.19 | **13.10±0.15** | 5.2% 향상 |
| Blastchar 손실 | 20.39±0.21 | **20.18±0.16** | 1.0% 향상 |

**한계:**
- 11개 데이터셋만 사용 → 일반화 범위 제한
- 1D-CNN은 원 논문의 특정 Kaggle 데이터셋을 실험에 포함하지 않음
- 런타임 비교가 소프트웨어 최적화 수준 차이로 불공정할 수 있음
- 이미지/텍스트에서 전이학습이 성공한 것처럼, tabular 사전학습(pre-training) 가능성은 탐구하지 않음

## 4. 저자 직접 보고 결과 vs. 해석 분리

### 4-1. 저자가 직접 보고한 결과

**연구 주제:**
- 테이블 데이터에서 딥러닝(TabNet, NODE, DNF-Net, 1D-CNN)과 XGBoost의 성능 및 최적화 비용 비교 (p.1, Abstract)

**방법:**
- 11개 데이터셋, HyperOpt 기반 Bayesian 최적화 1,000 스텝 (p.4, Section 3.1.2)
- Friedman 비모수 검정, 유의수준 95% (p.5)
- 앙상블: 균일 가중( $p(y|x) = \sum_{k=1}^{K} p_{\theta_m}(y|x, \theta_m)$ ) 및 검증 손실 가중 방식

**직접 보고된 결과:**
- XGBoost: 평균 상대 성능 열화 **3.34%** (Table 3, p.7)
- Deep Ensemble w XGBoost: **2.32%** (best, Table 3, p.7)
- NODE: **14.21%** (worst among all, Table 3, p.7)
- 11개 데이터셋 중 8개에서 XGBoost  >  딥러닝 모델 ($p < 0.005$) (p.5)
- Figure 1: 검증 손실 기반으로 3개 모델 선택 시 거의 최적 성능 달성

### 4-2. 논문을 기반으로 한 해석 (리뷰어 관점)

> ⚠️ **이 부분은 논문의 결과를 토대로 한 해석이며, 저자의 직접 주장이 아닙니다.**

1. **선택 편향(Selection Bias)의 구조적 문제:** 각 딥러닝 모델이 자신의 원 논문 데이터에서만 좋은 성능을 보인다는 패턴은, 논문 게재 과정에서 모델에 유리한 데이터셋이 선별되었을 가능성을 강하게 시사한다. 이는 학계의 출판 편향(publication bias)과도 연결된다.

2. **XGBoost의 하이퍼파라미터 견고성:** XGBoost가 더 적은 최적화 반복으로 수렴하는 현상은, 수십 년의 실증적 경험이 축적된 기본 하이퍼파라미터 값의 견고성에 기인할 가능성이 높다. 딥러닝 모델의 기본값은 상대적으로 덜 검증되어 있다.

3. **앙상블 효과의 해석:** 딥러닝+XGBoost 앙상블이 클래식 앙상블(XGBoost+SVM+CatBoost)보다 더 나은 것은, 딥러닝과 트리 기반 모델이 서로 다른 데이터 패턴(비선형성의 종류, 피처 상호작용 방식)을 학습한다는 모델 다양성(diversity)의 효과로 해석될 수 있다.

4. **1D-CNN의 상대적 선전:** 1D-CNN이 7.56%로 딥러닝 중 가장 좋은 성능을 보인 것은, 해당 모델의 원 논문 데이터셋이 실험에 포함되지 않아 선택 편향이 적기 때문일 수 있어, **단순한 구조의 미확인 데이터 성능**으로 해석하는 것이 더 타당하다.

## 6. 논문이 답하지 않는 질문

1. **사전학습(Pre-training) 효과:** 대규모 비지도 사전학습(예: BERT 방식)을 tabular 데이터에 적용하면 딥러닝 모델의 성능이 개선되는가? 논문은 지도학습만을 다룬다.

2. **데이터 크기에 따른 성능 변화:** 데이터 크기가 매우 작거나(N<1,000) 매우 클 때(N>1M) 딥러닝과 XGBoost의 상대적 성능은 어떻게 달라지는가?

3. **결측값(Missing Values) 처리:** tabular 데이터의 주요 특성인 결측값 상황에서의 성능 비교는 포함되지 않았다.

4. **불균형 데이터(Imbalanced Dataset):** 클래스 불균형이 심한 데이터셋에서의 비교는 수행되지 않았다.

5. **해석 가능성(Interpretability) 비교:** TabNet은 해석 가능성을 주요 장점으로 내세우지만, 논문은 성능 수치만 비교하며 해석 가능성의 품질 비교는 수행하지 않았다.

6. **최적 앙상블 구성 방법:** 어떤 딥러닝 모델을 앙상블에 포함시키는 것이 최적인지, 더 원칙적인 선택 기준이 제시되지 않았다.

7. **메타러닝(Meta-Learning) 활용 가능성:** 데이터셋 특성을 자동으로 분석하여 최적 모델을 추천하는 AutoML 방향은 다루지 않았다.

8. **범주형 피처(Categorical Feature) 처리 비교:** 범주형 피처가 많은 데이터셋에서의 성능 차이는 별도로 분석되지 않았다.

9. **딥러닝 모델의 최신 발전 반영:** SAINT, FT-Transformer 등 2021년에 발표된 유망한 모델들은 비교에 포함되지 않았다.

10. **앙상블의 추론(Inference) 비용:** 앙상블이 성능을 향상시키지만, 실시간 추론이 필요한 환경에서의 적용 가능성은 논의되지 않았다.

4. 미래 tabular 연구는 **다양한 데이터셋에서의 성능을 체계적으로 검증**해야 한다.

3. **더 넓은 벤치마크** 구축 (표준화된 tabular 데이터 벤치마크, ImageNet/GLUE에 준하는)

### 8-1. 모델의 일반화 성능 향상 가능성 (중점 분석)

본 논문의 핵심 발견 중 하나는 딥러닝 모델들이 **미확인 데이터셋에서 일반화 성능이 낮다**는 것이다. 이를 극복하기 위한 가능성을 구체적으로 분석한다.

#### (1) 사전학습(Pre-training)을 통한 일반화 향상

현재 비교된 모델들은 모두 **특정 데이터셋에서의 지도학습**에 의존한다. 자연어처리에서 BERT의 성공처럼, 대규모 tabular 데이터에서의 비지도 사전학습이 일반화 성능을 향상시킬 수 있다.

$$\mathcal{L}_{\text{pretrain}} = \mathcal{L}_{\text{reconstruction}} + \lambda \mathcal{L}_{\text{contrastive}}$$

- **SAINT** (Somepalli et al., 2021): 행(row) 간 어텐션과 대조 사전학습(contrastive pre-training)을 통해 일반화 성능 향상을 시도
- **TabPFN** (Hollmann et al., 2023): 메타러닝으로 소규모 tabular 데이터에 대한 사전학습 트랜스포머 구현

#### (2) 데이터 증강(Data Augmentation)을 통한 일반화 향상

이미지/텍스트와 달리 tabular 데이터에는 검증된 증강 기법이 부재하다. 가능한 방향:

$$\tilde{x}_i = x_i + \epsilon_i, \quad \epsilon_i \sim \mathcal{N}(0, \sigma^2_i)$$

- 가우시안 노이즈 추가 (피처별 분산 고려)
- Mixup 기법의 tabular 적용:

$$\tilde{x} = \lambda x_i + (1-\lambda) x_j, \quad \lambda \sim \text{Beta}(\alpha, \alpha)$$

#### (3) 도메인 적응(Domain Adaptation) 관점

각 딥러닝 모델이 자신의 원 논문 데이터에 특화되어 있는 문제는, 모델이 데이터의 특정 통계적 특성에 과도하게 적응했기 때문으로 볼 수 있다. **메타러닝(MAML 등)** 프레임워크를 통해 새로운 데이터셋에 빠르게 적응하는 능력을 향상시킬 수 있다.

$$\theta^* = \theta - \alpha \nabla_\theta \mathcal{L}_{\mathcal{T}_i}(f_\theta)$$

#### (4) 앙상블을 통한 일반화 향상 (논문의 긍정적 발견)

본 논문에서 직접 검증된 가장 현실적인 방향이다. 딥러닝과 XGBoost의 앙상블은:
- 딥러닝의 **비선형 피처 조합** 능력
- XGBoost의 **견고한 일반화** 능력

두 가지를 상호 보완하여 일반화 성능을 향상시킨다. 앞으로는 **동적 앙상블(dynamic ensemble)**, 즉 입력 데이터의 특성에 따라 각 모델의 기여도를 조절하는 방향이 유망하다.

### 8-2. 2020년 이후 최신 연구 비교 분석 및 영향

#### 주요 후속 연구 비교

| 논문 | 발표 시기 | 핵심 방법 | 본 논문과의 관계 |
|---|---|---|---|
| **SAINT** (Somepalli et al., 2021) | 2021.06 | 행-열 교차 어텐션 + 대조 사전학습 | 본 논문이 다루지 않은 사전학습의 가능성 제시 |
| **Revisiting Deep Learning for Tabular Data** (Gorishniy et al., 2021) | NeurIPS 2021 | FT-Transformer (피처 토크나이저 + 트랜스포머), ResNet 재평가 | 본 논문의 결론과 부분 일치: 단순 ResNet도 경쟁력 있음을 보임 |
| **Why Tree-Based Models Still Outperform Deep Learning on Tabular Data** (Grinsztajn et al., 2022) | NeurIPS 2022 | 벤치마크 45개 데이터셋, 트리 우위의 구조적 원인 분석 | 본 논문의 결론을 훨씬 더 넓은 스케일에서 확인 및 원인 규명 |
| **TabPFN** (Hollmann et al., 2023) | ICLR 2023 | 소규모 tabular에 대한 사전학습 트랜스포머, 추론 시 학습 없음 | 본 논문의 한계(소규모 데이터)를 메타러닝으로 해결 시도 |
| **Regularization is All You Need** (Kadra et al., 2021) | 2021 | 정규화 강도를 학습하는 단순 MLP | 단순 구조도 충분할 수 있음을 보여줌 |
| **XGBoost vs. Deep Learning: A Large-Scale Evaluation** (Multiple groups) | 2022~2023 | 더 넓은 규모의 비교 | 본 논문의 방법론을 확장·검증 |

#### 해당 논문이 앞으로의 연구에 미치는 영향

1. **벤치마크 표준화 촉진:** 본 논문은 tabular 데이터 연구에서 표준 벤치마크의 부재를 명확히 지적하였고, 이후 더 체계적인 벤치마크(예: OpenML-CC18, TabZilla) 구축을 촉진하였다.

2. **공정한 비교 프로토콜의 확립:** 동일한 하이퍼파라미터 최적화 프로토콜(HyperOpt, 1,000 스텝)과 동일한 데이터 분할을 사용하는 비교 방법론은 이후 연구들의 표준이 되었다.

3. **앙상블 방향 제시:** XGBoost와 딥러닝의 앙상블이 유망함을 보여줌으로써, **하이브리드 접근법**에 대한 연구가 활성화되었다.

4. **딥러닝 커뮤니티에 대한 경계:** tabular 딥러닝 논문들이 자신에게 유리한 데이터셋만 선택하는 관행에 경종을 울려, 이후 논문들이 더 다양한 데이터셋에서의 검증을 포함하도록 유도하였다.

#### 앞으로 연구 시 고려할 점

1. **⚠️ 데이터셋 다양성 확보:** 최소 20개 이상의 다양한 도메인, 크기, 특성 유형의 데이터셋을 포함해야 한다. Grinsztajn et al.(2022)은 45개 데이터셋으로 확장하여 더 강력한 결론을 도출하였다.

2. **⚠️ 동등한 계산 예산:** 각 모델에 동일한 총 계산 예산(GPU 시간)을 부여하는 것이 더 공정한 비교를 가능하게 한다. 반복 횟수만이 아닌 실제 연산량을 기준으로 해야 한다.

3. **💡 데이터 특성에 따른 조건부 분석:** 데이터 크기, 피처 유형(범주형/수치형 비율), 피처 수, 클래스 불균형도 등에 따라 어떤 모델이 유리한지를 조건부로 분석해야 한다.

4. **💡 사전학습 및 전이학습 효과 검증:** 이미지/텍스트에서처럼, 대규모 tabular 데이터로 사전학습된 모델이 소규모 하위 작업에서 어떤 이점을 제공하는지 체계적으로 검증해야 한다.

5. **💡 AutoML 통합:** 모델 선택과 하이퍼파라미터 최적화를 자동화하는 AutoML 방향에서, 어떤 데이터셋 메타 특성이 XGBoost 대비 딥러닝의 상대적 강점을 예측하는지 연구해야 한다.

6. **⚠️ 해석 가능성 vs. 성능 트레이드오프:** TabNet의 마스크 기반 피처 선택이 실제로 유의미한 피처를 선택하는지, 해석 가능성의 품질을 정량적으로 평가해야 한다.

7. **💡 최적화 난이도의 이론적 이해:** XGBoost가 하이퍼파라미터에 더 견고한 이유를 이론적으로 이해하고, 이를 딥러닝 설계에 활용하는 방향이 중요하다. (예: 강한 유도 편향(inductive bias) 설계)
