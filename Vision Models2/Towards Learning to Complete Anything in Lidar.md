## 1. Executive summary — 9문장

1. **CAL, Complete Anything in Lidar**은 희소한 단일 LiDAR 스캔에서 객체의 관측되지 않은 부분을 완성하고, 객체별 영역과 의미 정보를 함께 예측하는 방법입니다. **[pp.1–3, Figure 1]**
2. 학습 데이터는 정합된 RGB 영상과 LiDAR 시퀀스에서 객체를 분할·추적하고, 여러 시점의 관측을 누적하여 자동으로 생성합니다. **[pp.3–4, Figure 2]**
3. 이렇게 만든 객체별 의사 라벨은 불완전하지만, 저자들은 이를 이용해 단일 스캔에서 더 완성된 객체 형상을 추론하는 모델을 학습할 수 있다고 보고합니다. **[pp.2–5, Figures 2–4]**
4. 학습된 모델은 추론 시 RGB 영상 없이 LiDAR만 사용하며, 예측한 CLIP 특징과 사용자가 제공한 텍스트를 비교하여 객체의 의미 범주를 결정합니다. **[pp.4–5, Figure 3]**
5. SemanticKITTI에서 CAL의 제로샷 성능은 $PQ^\dagger=13.12$, $\text{mIoU}=13.09$로, 저자들이 구성한 LODE+SAL 및 LiDiff+SAL 비교 방법보다 주요 지표가 높습니다. **[p.7, Table 2]**
6. 그러나 동일 데이터셋의 완전 지도학습 PaSCo 단일 모델은 $PQ^\dagger=26.49$, $\text{mIoU}=28.22$이므로 상당한 성능 격차가 남아 있습니다. **[p.6, Table 1]**
7. 핵심 구성요소 분석에서는 객체 라벨의 공간적 범위를 넓히는 CRF 보정과, CLIP 특징을 군집화한 학습용 보조 과제가 유용한 것으로 나타납니다. **[pp.8–9, Tables 3–7]**
8. 반면 일부 희소 범주의 최종 모델 PQ는 0이며, KITTI-360에서는 CRF 보정 후 표준 PQ가 낮아지는 등 개선 효과가 지표와 데이터셋에 따라 달라집니다. **[pp.21–22, Tables 13, 15]**
9. 따라서 이 연구는 개방 어휘 기반 객체·장면 완성을 위한 유망한 학습 방법을 제시하지만, 모든 새로운 객체나 환경에 대한 일반화를 입증한 연구로 해석할 수는 없습니다. **[pp.6–9, 18–22]**

> **용어 풀이**
>
> - **LiDAR:** 레이저로 주변 물체까지의 거리를 측정하여 3차원 점들을 얻는 센서.
> - **의사 라벨, pseudo-label:** 사람이 직접 작성한 정답 대신 다른 모델이나 데이터 처리 과정으로 만든 학습용 정답.
> - **제로샷, zero-shot:** 여기서는 CAL을 목표 의미 범주의 수작업 라벨로 학습하지 않고, 추론 시 텍스트로 범주를 지정하는 설정.
> - **CLIP 특징:** 이미지와 텍스트의 의미를 비교할 수 있도록 표현한 숫자 벡터.
> - **$PQ^\dagger$:** 객체 분할과 인식의 품질을 평가하는 수정된 panoptic 지표.
> - **mIoU:** 각 의미 범주에서 예측 영역과 정답 영역이 얼마나 겹치는지 계산한 뒤 평균한 지표.

## 2. 연구 배경·목표·필요성

### 2.1 해결하려는 문제

**[저자 보고]** 기존 LiDAR 분할은 센서가 직접 관측한 점을 분류하는 데 집중합니다. 그러나 로봇이나 자율주행 시스템이 공간을 이해하려면 가려진 객체의 뒷면이나 관측이 부족한 영역까지 추론할 필요가 있습니다. 기존 장면 완성 방법은 이러한 문제를 다루지만, 대체로 데이터셋에 수작업으로 정의된 제한된 의미 범주에 의존합니다. **[pp.1–3, §1–2]**

논문에서 다루는 과제의 차이는 다음과 같습니다.

| 과제 | 예측하는 내용 | CAL과의 관계 |
|---|---|---|
| 의미 분할 | 관측된 점이 자동차·도로 등 어떤 범주인지 | CAL이 확장하려는 기본 인식 기능 |
| Semantic Scene Completion, SSC | 관측되지 않은 영역을 포함한 공간의 점유와 의미 범주 | CAL의 정량 평가 과제 |
| Panoptic Scene Completion, PSC | SSC 결과에 개별 객체의 구분까지 추가 | CAL의 핵심 목표 |
| Amodal 3D detection | 가려진 부분을 포함한 객체 전체 범위를 3D 박스로 표현 | CAL이 정성적으로 보여 준 응용 |

**근거:** pp.1–3, §1–3; pp.7–8, Figure 5.

> **용어 풀이**
>
> - **점유, occupancy:** 공간의 작은 구역에 물체가 존재하는지 여부.
> - **인스턴스, instance:** 같은 종류 안에서도 구별되는 개별 객체로, 자동차 A와 자동차 B를 따로 구분하는 개념.
> - **Panoptic:** 모든 영역의 의미 범주를 정하면서, 개별 객체의 정체성도 구분하는 표현.
> - **Amodal:** 현재 보이는 부분뿐 아니라 가려진 부분을 포함한 객체 전체를 다루는 것.

### 2.2 연구의 목적

**[저자 보고]** 연구의 목적은 크게 세 가지입니다.

1. **수작업 의미 라벨에 대한 의존도를 낮추는 것:** 영상 기반 모델과 시간적 관측을 활용하여 객체별 3D 학습 신호를 자동으로 얻습니다.
2. **단일 스캔에서 객체의 누락된 형상을 완성하는 것:** 학습할 때 여러 시점을 사용하더라도, 추론은 하나의 LiDAR 스캔으로 수행합니다.
3. **학습 단계의 고정된 범주 목록을 넘어 인식하는 것:** 최종 의미 범주는 추론 시 텍스트와 CLIP 특징의 유사도로 결정합니다.

**근거:** pp.2–5, §1, §3, Figures 2–3.

### 2.3 왜 필요한가?

**[저자 보고]** 객체의 전체 형상에 대한 수작업 정답을 만드는 데는 비용이 많이 들고, 정해진 범주 밖의 객체는 기존 학습 체계에서 다루기 어렵습니다. 반면 이동하면서 수집한 센서 시퀀스에는 한 시점에서 보이지 않았던 부분이 다른 시점에서 나타나는 정보가 들어 있습니다. CAL은 이 정보를 학습 신호로 이용합니다. **[pp.2–4]**

**[해석]** 이 연구가 바꾸려는 핵심은 **학습 정답을 확보하는 방식**입니다. 사람이 완전한 객체 형상과 범주를 모두 지정해야 한다는 요구를 완화하고, 여러 불완전한 관측으로부터 학습할 수 있는 체계를 제시합니다. 다만 사전학습된 영상 모델과 센서 보정 정보에 의존하므로, 이를 아무런 외부 지식도 사용하지 않는 학습으로 설명하면 부정확합니다. **[pp.3–5, 13–18]**

## 4. 방법론: 데이터, 의사 라벨 생성, 모델 구조, 수식

### 4.1 데이터 소스와 실험 설정

**[저자 보고]** CAL은 SemanticKITTI와 SSCBench-KITTI360에서 평가됩니다. 의사 라벨 생성에는 좌측 전방 RGB 카메라와 LiDAR 시퀀스를 사용하며, 모델 추론에는 LiDAR만 사용합니다. **[p.18, §C.1]**

| 항목 | SemanticKITTI | SSCBench-KITTI360 |
|---|---:|---:|
| 학습용 의사 라벨 스캔 수 | 4,649 | 8,487 |
| 추가로 명시한 검증·시험 스캔 수 | 해당 문단에서 별도 수치 미제시 | 검증 1,780 / 시험 2,165 |
| 주 결과의 평가 분할 | Validation | Test |
| 센서 | 64-beam Velodyne, 10 Hz | 64-beam Velodyne, 10 Hz |
| 객체 마스크 추적 설정 | 전방 32, 후방 8, stride 2 | 동일 |
| 이진 점유 누적 설정 | 전방 72, 후방 1, stride 1 | 전방 72, 후방 36, stride 1 |
| 이동 객체 처리 | 시간에 따라 누적된 이동 흔적 유지 | 기존 3D 객체 트랙으로 이동 객체 제거 |

**근거:** p.6, Table 1; p.13, Table 8; p.14, §A.2; p.18, §C.1.

> **용어 풀이**
>
> - **Beam:** LiDAR의 측정 채널로, 여기서는 두 데이터셋이 같은 64채널 계열 센서를 사용했다는 의미.
> - **Stride:** 연속 프레임 중 얼마 간격으로 프레임을 선택할지 정하는 값.
> - **자차 pose:** 센서를 장착한 차량의 위치와 방향.

**중요한 감독 정보의 구분:** 저자는 의미·장면 완성 정답으로 CAL을 학습하지 않는다고 설명하지만, KITTI-360의 이동 객체 제거에는 데이터셋의 **3D object tracks**를 사용합니다. 따라서 “어떤 종류의 3D 주석 자산도 전혀 사용하지 않는다”는 표현은 맞지 않습니다. **[p.14, §A.2]**

### 4.2 입력과 출력의 표현

입력 점군은 다음과 같이 표현합니다.

$$
\mathcal P=\{p_n\}_{n=1}^{N},
\qquad
p_n=(x_n,y_n,z_n,r_n)\in\mathbb R^4.
$$

- $\mathcal P$: 입력 LiDAR 점군.
- $N$: 점의 수.
- $(x_n,y_n,z_n)$: $n$번째 점의 3차원 좌표.
- $r_n$: 반사 강도.
- $\mathbb R^4$: 좌표 세 개와 강도 한 개로 구성된 공간.

**근거:** p.3, §3.

출력은 고정된 3차원 격자에서의 객체별 점유 마스크와 각 객체의 CLIP 특징입니다. 격자 크기는 $256\times256\times32$, 복셀 한 변은 $0.2\,\text{m}$이며, 전체 공간 크기는 $51.2\times51.2\times6.4\,\text{m}$입니다. **[p.13, Table 8; p.15, §A.4]**

> **용어 풀이 — 복셀, voxel:** 2차원 이미지의 픽셀에 해당하는 3차원 공간의 작은 칸.

360도 LiDAR를 누적하여 감독 신호를 만들지만, 모델이 완성하고 평가하는 공간은 **센서 앞쪽의 고정된 부피**입니다. 이를 주변 360도 전체 공간을 출력하는 모델로 설명해서는 안 됩니다. **[p.15, §A.4]**

### 4.3 의사 라벨 생성 엔진

#### ① 영상에서 객체를 찾고 시간적으로 연결

기준 영상에 SAM을 적용해 객체 마스크를 만들고, SAM2를 사용하여 앞뒤 프레임으로 마스크를 전파합니다. 결과는 동일 객체의 시간별 마스크를 모은 **masklet**입니다. **[p.4, §3.1; p.13, Table 8]**

> **용어 풀이**
>
> - **마스크:** 이미지나 공간에서 특정 객체에 속하는 위치를 표시한 영역.
> - **Masklet:** 여러 프레임에 걸쳐 연결된 동일 객체의 마스크 묶음.
> - **기반 모델, foundation model:** 다양한 데이터로 미리 학습되어 여러 작업에 활용되는 모델.

#### ② 객체별 CLIP 특징을 시간적으로 평균

각 시점에서 객체의 CLIP 특징을 추출하고, 정규화한 특징들을 객체별로 평균합니다. 최종 차원은 768입니다. **[p.4; p.15, §A.5]**

다음은 **원문 서술을 설명하기 위해 다시 쓴 수식**입니다.

$$
f_k=
\frac{1}{|\mathcal T_k|}
\sum_{t\in\mathcal T_k}
\frac{g_{t,k}}{\|g_{t,k}\|_2}
\in\mathbb R^{768}.
$$

- $k$: 객체 인덱스.
- $\mathcal T_k$: 객체 $k$의 특징을 얻은 시점 집합.
- $g_{t,k}$: 시점 $t$에서 추출한 객체 $k$의 CLIP 특징.
- $\|\cdot\|_2$: 벡터의 길이.
- $f_k$: 정규화된 시점별 특징을 평균한 객체 표현.
- $|\mathcal T_k|$: 평균에 사용한 시점 수.

평균 이후 다시 정규화하는지까지는 원문에서 명확하게 설명하지 않으므로, 그 연산을 추가하지 않았습니다.

**[해석]** 여러 시점의 특징을 평균하면 한 시점의 가림이나 외관 변화에 대한 의존도를 줄일 수 있다는 설계 의도가 읽힙니다. 다만 시간 평균만의 효과를 충분히 분리한 실험은 제시되지 않습니다.

#### ③ 2D 마스크를 LiDAR로 옮기고 기하적으로 정제

보정된 카메라–LiDAR 관계를 이용해 영상 마스크에 해당하는 3D 점들을 찾습니다. 이후 DBSCAN으로 구한 3D 군집과 비교하여, 가장 잘 겹치는 군집의 IoU가 0.5를 넘으면 해당 군집으로 마스크를 대체합니다. **[p.4; p.15, §A.3]**

> **용어 풀이**
>
> - **DBSCAN:** 가까이 밀집한 점들을 하나의 집단으로 묶는 군집화 방법.
> - **IoU:** 두 영역의 교집합 크기를 합집합 크기로 나눈 값.
> - **센서 보정, calibration:** 서로 다른 센서의 좌표와 관측 방향을 대응시키는 과정.

#### ④ 서로 다른 두 종류의 감독 신호를 생성

객체 마스크를 자차 pose에 따라 기준 좌표계로 옮겨 누적하면 **객체별 부분 형상**을 얻습니다. 별도로 360도 LiDAR 점을 누적하면 객체 ID가 없어도 **공간이 점유되었는지에 대한 더 넓은 정보**를 얻습니다. **[p.4, Figure 2]**

| 감독 신호 | 포함하는 정보 | 범위가 제한되는 이유 |
|---|---|---|
| 객체 마스크·CLIP 특징 | 어느 객체이며 어떤 의미 특징을 갖는가 | 카메라 시야와 영상 분할·추적 성공 여부 |
| 이진 점유 | 공간에 물체가 존재하는가 | 누적 LiDAR의 관측 범위 |

**[해석]** 이 두 신호의 범위가 다르다는 사실이 CAL의 핵심 설계로 이어집니다. 의미 라벨이 없는 위치라도 점유 정보가 있다면 기하 학습에 활용할 수 있습니다.

#### ⑤ CRF로 객체 라벨을 확장

CRF는 이미 점유된 것으로 확인된 복셀들에서 동작합니다. 라벨이 없는 점유 복셀에 주변 객체 ID를 전파하여 객체 마스크의 범위를 넓힙니다. **[p.14, §A.1]**

구체적으로는 다음과 같습니다.

- 라벨이 있는 복셀은 원래 객체 ID에 초기 확률 1.0을 부여합니다.
- 점유되었지만 미라벨인 복셀은 객체 ID들에 균등한 초기 확률을 부여합니다.
- 정규화된 복셀 좌표를 이용하여 가까운 복셀들이 일관된 라벨을 갖도록 유도합니다.
- 5회 반복 후 기존 라벨을 보존합니다.
- CLIP 특징과 이진 점유 coverage는 바꾸지 않습니다.

> **용어 풀이 — CRF, Conditional Random Field:** 각 위치의 정보와 위치 사이의 관계를 함께 고려하여 일관된 라벨 배정을 찾는 모델.

**정확성상 주의:** 원문에는 CRF의 구체적인 에너지식·거리 정규화 상수·모든 가중치가 제시되어 있지 않습니다. 따라서 일반적인 CRF 공식을 CAL의 정확한 구현식처럼 제시하지 않습니다.

### 4.4 모델 구조

**[저자 보고]** CAL의 구조는 PaSCo를 바탕으로 한 희소 생성 3D U-Net과 Transformer 인스턴스 디코더로 구성됩니다. **[pp.4–5, Figure 3; pp.15–16, §B.1]**

| 구성요소 | 구조와 역할 |
|---|---|
| 입력 특징 생성 | Cylinder3D 기반 MLP와 복셀화 |
| 희소 인코더 | 4개 단계에서 $1{:}1$, $1{:}2$, $1{:}4$, $1{:}8$ 해상도의 특징 생성 |
| 밀집 3D 합성곱 블록 | 저해상도 특징으로 공간 전체의 구조를 처리 |
| 생성 디코더 | $1{:}4\rightarrow1{:}2\rightarrow1{:}1$ 순서로 해상도를 높이며 점유 공간 복원 |
| 점유 head $B_o$ | 디코더 특징에서 직접 이진 점유 예측 |
| 프로토타입 head $S$ | 복셀별 CLIP 프로토타입 범주 예측 |
| 보조 점유 head $B_s$ | $S$의 출력에서 이진 점유 예측 |
| Transformer 디코더 | 예측된 점유 복셀들에서 객체별 마스크와 CLIP 특징 생성 |

> **용어 풀이**
>
> - **희소 연산:** 값이나 점이 존재하는 위치를 중심으로 계산하는 방식.
> - **밀집 연산:** 정해진 격자의 모든 위치를 대상으로 계산하는 방식.
> - **U-Net:** 공간 정보를 압축하는 인코더와 해상도를 복원하는 디코더를 결합한 구조.
> - **MLP:** 여러 완전연결층을 쌓은 신경망.
> - **Transformer의 query:** 객체 후보를 표현하는 학습 가능한 벡터로, 공간 특징에서 필요한 정보를 모으는 역할.

#### CLIP 프로토타입이 필요한 이유

객체별 CLIP 특징에 k-means를 적용하여 유사한 객체들을 의사 범주로 묶습니다. 이 범주는 사람이 정한 정답 범주와 다릅니다. 중심 벡터는 학습 전에 계산하고 고정합니다. **[pp.16–17, §B.2]**

설명용으로 표현하면 다음과 같습니다.

$$
z_k=
\underset{c\in\{1,\ldots,C\}}{\text{argmin}}
\|f_k-\mu_c\|_2^2.
$$

- $f_k$: 객체 $k$의 CLIP 특징.
- $C$: 프로토타입 수.
- $\mu_c$: $c$번째 군집 중심.
- $z_k$: 객체 $k$에 할당한 학습용 의사 범주.
- $\text{argmin}$: 거리가 가장 작은 범주의 번호를 선택하는 연산.

기본 결과는 $C=18$에 해당합니다. 그러나 **18개의 범주만 인식할 수 있다는 의미는 아닙니다.** 최종 의미 인식은 예측된 CLIP 특징과 텍스트를 비교하여 수행합니다. **[p.9, Table 7; p.17]**

#### $B_s$의 역할

이진 점유 라벨은 넓은 공간에 존재하지만, 프로토타입 라벨은 객체 의사 라벨이 있는 곳에만 존재합니다. $B_s$는 프로토타입 예측 출력도 넓은 점유 감독과 연결되도록 하여 두 학습 신호의 불일치를 줄이려는 장치입니다. **[p.16]**

**[해석]** 이 구조는 부분적인 의미 감독이 기하 완성의 범위를 지나치게 제한하는 문제를 완화하려는 설계로 이해할 수 있습니다. 다만 $B_s$의 효과는 모든 지표에서 일관되지는 않습니다.

#### 인스턴스 디코더의 구체적 구성

Transformer 디코더는 3층이며, CLIP 특징 예측 MLP의 차원은 다음과 같습니다.

$$
384\rightarrow512\rightarrow1024\rightarrow768\rightarrow768.
$$

각 숫자는 연속된 층의 특징 차원이며, 마지막 768이 CLIP 특징의 차원입니다. **[p.16, §B.1]**

예측 마스크의 objectness는 부록 기준으로 **그 마스크의 평균 복셀 확률**입니다. 별도의 objectness 신경망이 있다고 단정하면 안 됩니다. **[p.16, §B.2]**

> **용어 풀이 — Objectness:** 예측된 영역을 하나의 유효한 객체 후보로 유지할지 판단하는 점수.

### 4.5 학습 목적함수

#### A. 전체 손실 — 원문 식 (1)

```math
\mathcal L_{\text{total}}
=
\lambda_{\text{occ}}\mathcal L_{\text{occ}}
+
\lambda_{\text{prot}}\mathcal L_{\text{prot}}
+
\lambda_{\text{mask}}\mathcal L_{\text{mask}}
+
\lambda_{\text{CLIP}}\mathcal L_{\text{CLIP}}
+
\mathcal L_{\text{aux}}.
```

**근거:** p.17, §B.3, Eq. (1).

| 기호 | 의미 |
|---|---|
| $\mathcal L_{\text{occ}}$ | 공간이 점유되었는지 예측하는 손실 |
| $\mathcal L_{\text{prot}}$ | 복셀별 CLIP 프로토타입 분류 손실 |
| $\mathcal L_{\text{mask}}$ | 객체별 마스크 예측 손실 |
| $\mathcal L_{\text{CLIP}}$ | 객체 의미 특징의 증류 손실 |
| $\mathcal L_{\text{aux}}$ | PaSCo를 따르는 보조 손실 |
| 각 $\lambda$ | 손실의 상대적 가중치 |

명시된 값은 $\lambda_{\text{mask}}=40$, $\lambda_{\text{CLIP}}=1$, $\lambda_{\text{prot}}=1$입니다.

**원문 표기 불일치:** 식에는 $\lambda_{\text{occ}}$가 있지만 바로 아래 설명에는 $\lambda_{\text{compl}}=1.0$이라고 적혀 있습니다. 점유 손실 가중치를 의미하는 것으로 읽히지만, 기호가 일치하지 않습니다. 또한 $\mathcal L_{\text{aux}}$의 구체적인 식은 이 문서에 전개되어 있지 않습니다. **[p.17]**

> **용어 풀이 — 증류, distillation:** 다른 모델이나 처리 과정이 만든 예측·특징을 학습 신호로 삼아 새로운 모델에 지식을 전달하는 방법.

#### B. 다중 해상도 점유·프로토타입 손실

원문은 세 해상도에서 손실을 계산하여 평균합니다.

```math
\mathcal L_{\text{occ}}
=
\frac{1}{3}
\sum_{L\in\{1,2,4\}}
\mathcal L_{\text{occ}}^{1:L},
\qquad
\mathcal L_{\text{prot}}
=
\frac{1}{3}
\sum_{L\in\{1,2,4\}}
\mathcal L_{\text{prot}}^{1:L}.
```

- $L$: 해상도 축소 배율.
- 위첨자 $1{:}L$: 해당 배율의 공간 격자.
- 각 $\mathcal L^{1:L}$: 해당 해상도에서 계산한 손실.

점유 손실은 두 head의 손실 합입니다.

```math
\mathcal L_{\text{occ}}^{1:L}
=
\text{wBCE}
\left(O_{\text{label}}^{1:L},O_{B_o}^{1:L}\right)
+
\text{wBCE}
\left(O_{\text{label}}^{1:L},O_{B_s}^{1:L}\right).
```

- $O_{\text{label}}^{1:L}$: 누적 LiDAR에서 만든 이진 점유 의사 라벨.
- $O_{B_o}^{1:L}$, $O_{B_s}^{1:L}$: 두 head의 점유 예측.
- $\text{wBCE}$: 가중 이진 교차엔트로피.
- 점유 복셀의 가중치는 **20**입니다.

**근거:** p.17, §B.3.

프로토타입 손실은 교차엔트로피와 Lovász 손실을 결합합니다. 원문이 세부 결합 계수까지 전개하지 않으므로 추가 계수식을 만들지 않습니다. **객체 의사 라벨이 없는 복셀은 이 손실에서 제외합니다.**

> **용어 풀이**
>
> - **교차엔트로피:** 정답에 높은 예측 확률을 주도록 학습시키는 손실.
> - **Lovász 손실:** 영역의 겹침을 나타내는 IoU를 학습 목적에 반영하기 위한 손실.

#### C. 객체 마스크 손실

예측 마스크와 의사 라벨 마스크를 Hungarian matching으로 일대일 대응시킨 뒤 다음 손실을 계산합니다.

```math
\mathcal L_{\text{mask}}
=
\lambda_{\text{CE}}\mathcal L_{\text{CE}}
+
\lambda_{\text{Dice}}\mathcal L_{\text{Dice}},
\qquad
\lambda_{\text{CE}}=2,\quad
\lambda_{\text{Dice}}=1.
```

- $\mathcal L_{\text{CE}}$: 복셀별 이진 교차엔트로피.
- $\mathcal L_{\text{Dice}}$: 예측 마스크와 의사 라벨 마스크의 겹침을 평가하는 손실.
- $\lambda_{\text{CE}}$, $\lambda_{\text{Dice}}$: 두 항의 가중치.

**근거:** p.17, §B.3.

> **용어 풀이**
>
> - **Hungarian matching:** 순서가 없는 예측 객체들과 정답 객체들 사이에서 전체 비용이 가장 작은 일대일 대응을 찾는 알고리즘.
> - **Dice:** 두 영역이 얼마나 겹치는지를 측정하는 기준.

**[해석]** 이때 미라벨 복셀을 matching과 마스크 손실에서 모두 제외한다는 점이 중요합니다. 의사 라벨이 없는 공간을 곧바로 “객체가 없는 정답 영역”으로 취급하지 않으므로, 라벨 범위 밖으로 확장된 완성을 무조건 벌하지 않습니다. **[pp.5, 17–18]**

#### D. CLIP 특징 증류 손실

원문은 다음과 같이 함수 형태로 제시합니다.

```math
\mathcal L_{\text{CLIP}}
=
\text{CosineEmbeddingLoss}
\left(
\text{pred\_embeds},
\text{gt\_embeds}
\right).
```

- $\text{pred embeds}$: 모델이 예측한 객체별 CLIP 특징.
- $\text{gt embeds}$: matching된 의사 라벨 객체의 CLIP 특징.
- $\text{CosineEmbeddingLoss}$: 두 특징의 방향이 가까워지도록 학습시키는 손실.

여기서 `gt_embeds`는 사람이 작성한 의미 범주 정답이 아닙니다. 영상에서 추출한 **교사 특징**입니다. **[pp.17–18]**

### 4.6 추론 시 텍스트 분류

각 의미 범주에 여러 텍스트 표현을 사용하고, 예측 CLIP 특징과의 유사도를 평균합니다. 다음은 **원문 설명의 수식화**입니다. **[p.5; p.18, §C.1]**

```math
s_{k,c}
=
\frac{1}{|\mathcal Q_c|}
\sum_{q\in\mathcal Q_c}
\frac{\hat f_k^\top e(q)}
{\|\hat f_k\|_2\,\|e(q)\|_2},
\qquad
\hat c_k=
\underset{c\in\mathcal C}{\text{argmax}}\;s_{k,c}.
```

- $\hat f_k$: 객체 $k$의 예측 CLIP 특징.
- $\mathcal C$: 추론 시 지정한 의미 범주 집합.
- $\mathcal Q_c$: 범주 $c$를 표현하는 프롬프트 집합.
- $e(q)$: CLIP 텍스트 인코더가 만든 프롬프트 특징.
- $s_{k,c}$: 객체와 범주 사이의 평균 유사도.
- $\hat c_k$: 선택한 의미 범주.
- $\top$: 벡터의 내적을 계산하기 위한 전치 표기.

예를 들어 자동차 범주에는 `car, jeep, SUV, van` 등의 표현을 사용합니다. **[p.18]**

**주의:** 본문은 이 유사도를 이용한 결과를 posterior라고 부르지만, 확률 정규화나 보정 방법은 명시하지 않습니다. 따라서 $s_{k,c}$를 검증된 확률이나 신뢰도로 해석하면 안 됩니다.

### 4.7 학습 규모와 구현상 확인할 사항

**[저자 보고]** 총 학습 파라미터는 118M이며, NVIDIA A100 8개에서 50 epoch, 전체 batch size 8, 학습률 $10^{-4}$로 학습합니다. **[p.18, §B.3]**

후처리 임계값도 데이터셋별로 다릅니다. SemanticKITTI는 overlap·objectness·voxel threshold를 각각 0.1로 설정하고, KITTI-360은 각각 0.4·0.5·0.3으로 설정합니다. **[p.16, §B.2]**

재현 시 확인이 필요한 문서상 불명확성도 있습니다.

- MaskCLIP의 출처가 본문에서는 Ding et al. 2023, 부록에서는 Zhou et al. 2022로 다르게 기재되어 있습니다. **[pp.4, 15]**
- 프로토타입의 최종 분류 결과는 추론 시 사용하지 않는다고 하지만, 복셀 pruning에는 프로토타입 logits를 활용한다고 설명합니다. 따라서 $S$ 모듈 전체를 추론에서 제거한다고 단정할 수 없습니다. **[pp.16–17]**
- KITTI-360의 정답 격자 정렬을 위해 경험적으로 $(0.79,0.3,-0.25)\,\text{m}$ 이동을 적용하며, 저자는 원래의 정확한 변환 절차를 확인하지 못했다고 밝힙니다. **[p.15, §A.4]**

> **용어 풀이**
>
> - **Pruning:** 이후 계산이 필요하지 않다고 판단한 복셀을 제거하여 계산량을 줄이는 과정.
> - **Logit:** 확률로 변환되기 전의 신경망 출력 점수.
> - **Epoch:** 학습 데이터를 한 차례 모두 처리하는 단위.

## 5. 주요 결과와 데이터 해석

### 5.1 지표를 먼저 구분해야 하는 이유

원문은 SSC에 mIoU, PSC에 PQ·SQ·RQ와 수정 지표 $PQ^\dagger$를 사용합니다. **[pp.6–7]**

범주별 PQ의 관계는 다음과 같습니다.

$$
PQ_c=SQ_c\times RQ_c.
$$

- $c$: 평가 범주.
- $SQ_c$: 올바르게 대응된 객체들의 영역 겹침 품질.
- $RQ_c$: 객체를 얼마나 정확하게 찾아 대응시켰는지 나타내는 품질.
- $PQ_c$: 두 요소를 결합한 점수.

$PQ^\dagger$는 **stuff 범주에 대한 최소 IoU 0.5 대응 조건을 제거한 변형**입니다. 따라서 표준 PQ와 값이나 개선 방향이 다를 수 있습니다. **[p.6]**

> **용어 풀이**
>
> - **Thing:** 자동차처럼 개별 개체를 구별하는 범주.
> - **Stuff:** 도로·지면처럼 연속된 영역으로 다루는 범주.
> - CAL은 학습 중 두 종류를 구분하지 않고 모두 마스크 단위로 다룹니다. **[pp.4, 18]**

또한 표의 SQ와 RQ는 범주별 평균이므로, **평균 SQ와 평균 RQ를 곱하면 평균 PQ가 그대로 나온다고 가정해서는 안 됩니다.**

### 5.2 최종 모델 성능

아래 수치는 원문 표의 척도를 그대로 사용했으며 높을수록 좋습니다.

| 데이터셋·분할 | 방법·설정 | $PQ^\dagger$ | 표준 PQ | mIoU |
|---|---|---:|---:|---:|
| SemanticKITTI val | LODE + SAL | 7.74 | 1.96 | 8.12 |
| SemanticKITTI val | LiDiff + SAL | 7.35 | 0.36 | 7.38 |
| SemanticKITTI val | **CAL, ZS** | **13.12** | **5.26** | **13.09** |
| SemanticKITTI val | CAL, semantic oracle | 17.12 | 6.27 | 20.71 |
| SemanticKITTI val | PaSCo, M=1, 완전 지도학습 | 26.49 | 15.36 | 28.22 |
| SemanticKITTI val | PaSCo, ensemble | 31.42 | 16.51 | 30.11 |
| KITTI-360 test | **CAL, ZS** | **8.57** | **1.46** | **8.49** |
| KITTI-360 test | CAL, semantic oracle | 12.56 | 1.71 | 13.34 |
| KITTI-360 test | PaSCo, M=1, 완전 지도학습 | 19.53 | 9.91 | 21.17 |
| KITTI-360 test | PaSCo, ensemble | 26.29 | 10.92 | 22.39 |

**근거:** p.6, Table 1; p.7, Table 2; p.21, Table 14.

**[계산·해석]**

- LODE+SAL 대비 CAL은 $PQ^\dagger$ **5.38점**, mIoU **4.97점** 높습니다.
- SemanticKITTI에서 PaSCo M=1 대비 CAL의 $PQ^\dagger$는 약 **49.5%** 수준이지만, 표준 PQ는 약 **34.2%** 수준입니다.
- KITTI-360에서는 같은 비율이 $PQ^\dagger$ 약 **43.9%**, 표준 PQ 약 **14.7%**입니다.

따라서 “지도학습 성능의 절반”이라는 표현은 **지표와 기준 모델을 함께 명시할 때만** 적절합니다.

> **용어 풀이 — Semantic oracle, SO:** 예측된 마스크의 의미 범주를 정답 복셀 라벨의 다수결로 부여하는 진단 평가입니다. 마스크 자체의 오류는 남지만 의미 분류 오류 일부를 제거합니다. 실제 제로샷 운용 성능과 구분해야 합니다. **[pp.6–7]**

**원문 수치 불일치:** p.7 본문은 KITTI-360의 SO 결과를 17.12로 서술하지만, Tables 1·13·14는 일관되게 **12.56**을 보고합니다. 위 표는 반복 확인되는 표의 값을 채택했습니다.

### 5.3 CRF: 라벨 범위와 최종 모델 효과

#### 라벨 범위

| 데이터셋, validation | 객체 라벨 coverage: CRF 전→후 | 점유 coverage: 360도 누적 전→후 |
|---|---:|---:|
| SemanticKITTI | 28.04% → **70.13%** | 37.36% → **99.96%** |
| KITTI-360 | 27.38% → **50.48%** | 44.15% → **67.63%** |

**근거:** p.8, Table 5.

**99.96%는 점유 정보의 coverage이며, 형상·인식 정확도가 99.96%라는 뜻이 아닙니다.**

#### 보정한 라벨로 학습한 최종 모델

| 데이터셋 | ZS $PQ^\dagger$: CRF 전→후 | ZS 표준 PQ: 전→후 | ZS mIoU: 전→후 |
|---|---:|---:|---:|
| SemanticKITTI | 9.65 → **13.12** | 3.27 → **5.26** | 9.40 → **13.09** |
| KITTI-360 | 7.01 → **8.57** | **2.89 → 1.46** | 7.34 → **8.49** |

**근거:** p.20, Table 12; p.21, Table 13.

**[저자 보고]** KITTI-360에서는 stuff 범주의 성능이 악화될 수 있으며, 낮은 점유 coverage가 CRF의 효과를 제한했을 가능성을 제시합니다. **[p.20, §C.3]**

**[해석]** CRF는 유망하지만, 라벨을 더 많이 부여하는 것과 올바른 객체 경계를 유지하는 것은 별도로 평가해야 합니다. 저자의 원인 설명도 추가 통제실험으로 확정된 결론은 아닙니다.

### 5.4 가장 큰 구성요소 효과: 프로토타입 보조 과제

| 구성 | ZS $PQ^\dagger$ | 표준 PQ | mIoU |
|---|---:|---:|---:|
| 부분 coverage 점유 감독 | 3.73 | 0.01 | 3.15 |
| 위 구성 + 프로토타입 head $S$ | **11.98** | 4.21 | 11.96 |
| 전체 coverage 점유 감독 + $S$ | **13.43** | 5.10 | 12.48 |
| 위 구성 + $B_s$, 최종 CAL | 13.12 | **5.26** | **13.09** |

**근거:** p.9, Table 6.

**[해석]** 이 실험에서 가장 큰 변화는 $S$를 도입했을 때 나타납니다. 반면 $B_s$는 표준 PQ와 mIoU를 높이지만 $PQ^\dagger$를 13.43에서 13.12로 낮춥니다. 모든 구성요소가 모든 지표를 일관되게 개선한다고 설명할 수는 없습니다.

프로토타입 수를 바꾼 Table 7에서는 $C=6,18,50,100$이 극단적인 $C=1,500$보다 좋은 결과를 보입니다. $C=18$은 표준 PQ와 mIoU가 가장 높지만, $PQ^\dagger$의 최고값은 $C=100$의 13.16입니다. 작은 차이의 통계적 의미는 판단할 수 없습니다. **[p.9, Table 7]**

### 5.5 희소 범주와 교사–학생 격차

최종 CAL의 범주별 표준 PQ는 자동차 14.11, 도로 54.08, 지형 22.20인 반면, **bicycle·motorcycle·person·bicyclist·motorcyclist는 각각 0.00**입니다. 이는 제목의 “Anything”을 모든 객체에 대한 높은 정확도로 받아들일 수 없게 하는 중요한 결과입니다. **[p.22, Table 15]**

또한 SemanticKITTI에서 의사 라벨의 ZS $PQ^\dagger$는 16.98이고, 단일 스캔 모델은 13.12입니다. SO에서도 각각 25.90과 17.12입니다. **[p.21, Table 14]**

**[해석]** 영상과 여러 시점을 이용해 얻은 정보를 단일 LiDAR 모델로 전달하는 과정에서 손실이 발생합니다. 본문은 의미 인식을, 부록은 인스턴스 완성을 주요 병목으로 논의하므로, 후속 연구에서는 두 병목을 함께 측정하는 것이 타당합니다. **[p.7; p.20, §C.3]**

## 6. 일반화 성능: 입증된 범위와 아직 입증되지 않은 범위

### 6.1 일반화를 구분해서 봐야 한다

| 일반화의 종류 | 논문에서 확인되는 것 | 확인되지 않은 것 |
|---|---|---|
| **어휘 유연성** | 추론 시 텍스트로 범주를 지정하고 일부 비표준 객체를 질의 | 엄격히 분리한 미관측 범주 전체의 정량 정확도 |
| **부분 관측에서 형상 완성** | 단일 스캔으로 객체·장면 완성 결과 제시 | 실제 형상을 항상 유일하고 정확하게 복원한다는 보장 |
| **데이터셋 간 전이** | 두 데이터셋에서 각각 학습·평가 | 한 데이터셋에서 학습한 고정 모델을 다른 데이터셋에 바로 적용한 성능 |
| **센서 변화 대응** | 두 데이터셋 모두 64-beam Velodyne 사용 | 다른 빔 수·스캔 패턴·센서의 성능 |
| **환경 변화 대응** | 벤치마크 주행 장면에서 평가 | 날씨·야간·다른 국가·도시별 강건성 |
| **데이터 규모 확장** | 자동 의사 라벨을 더 만들 수 있는 구조 | 학습량 증가에 따른 성능 곡선이나 확장 법칙 |

**근거:** p.1, Figure 1; pp.6–9; p.18, §C.1; pp.20–22.

### 6.2 일반화 향상 가능성을 뒷받침하는 설계

**[해석]** 다음 세 가지는 일반화 연구의 출발점으로 유망합니다.

**첫째, 형상과 최종 의미 분류의 분리입니다.** 객체 마스크와 CLIP 특징을 예측하므로 추론 어휘가 학습용 군집 수에 고정되지 않습니다. 이는 어휘 확장에 유리한 설계입니다. 다만 인식하려는 객체가 제대로 분할되지 않으면 텍스트 유연성만으로 문제가 해결되지는 않습니다. **[pp.5, 9, 17]**

**둘째, 불완전한 라벨을 다루는 학습 규칙입니다.** 미라벨 공간을 손실에서 제외하고 더 넓은 점유 감독을 함께 사용하므로, 완전한 객체 정답을 확보하지 못한 데이터도 활용할 수 있습니다. **[pp.5, 17–18]**

**셋째, 수작업 범주 라벨을 추가하지 않고 데이터를 확장할 수 있다는 점입니다.** 그러나 저자는 비교 조건을 맞추기 위해 학습 스캔 수를 제한했으며, 실제 대규모 확장 효과는 측정하지 않았습니다. 따라서 “데이터를 늘리면 일반화가 향상된다”는 것은 이 논문의 확정된 결과가 아닙니다. **[p.18]**

## 7. 통계적으로 취약한 부분과 비교할 수 없는 수치

| 항목 | 판정과 이유 |
|---|---|
| 반복 실험·신뢰구간 | 여러 random seed, 표준편차, 신뢰구간, 유의성 검정이 보고되지 않음 |
| 작은 ablation 차이 | 13.12와 13.16 같은 차이로 특정 설정이 통계적으로 우월하다고 판단할 수 없음 |
| 표준 PQ와 $PQ^\dagger$ | 대응 규칙이 달라 상호 대체할 수 없으며 개선 방향도 다를 수 있음 |
| ZS와 SO | SO는 정답 의미 정보를 사용하는 진단 평가이므로 실제 ZS 성능과 같은 조건이 아님 |
| 의사 라벨과 모델 예측 | 전자는 RGB·다중 시점, 후자는 단일 LiDAR를 사용하므로 입력 정보량이 다름 |
| CAL과 완전 지도학습 | 감독 정보의 종류와 품질이 다르므로 상대적 성능 위치를 보여 주는 비교 |
| PaSCo 단일 모델과 ensemble | 예측 결합·계산 조건이 다르므로 같은 모델 예산으로 취급할 수 없음 |
| Full-grid와 masked-voxel 평가 | 평가하는 복셀 집합 자체가 달라짐 |
| 두 데이터셋의 점수 | 평가 분할, 동적 객체 처리, 정렬, 임계값이 달라 순수한 도메인 차이로 해석할 수 없음 |
| 검출 성능 | Figure 5는 정성적 박스 시각화이며 정량 검출 평가가 아님 |

**근거:** pp.6–9, 14–21.

특히 Table 10에서 의사 라벨의 ZS $PQ^\dagger$가 **16.98에서 20.89**로 높아지는 것은 모델을 개선한 결과가 아닙니다. 의사 라벨이 없는 복셀을 평가에서 제외했기 때문입니다. **[p.19, Table 10]**

또한 LODE+SAL과 LiDiff+SAL은 의미 라벨 없이 학습한 기하 완성 모델을 사용하지만, 해당 완성 모델은 **정답 완성 기하**로 학습합니다. 반면 CAL은 영상과 시간 누적에서 생성한 부분 의사 라벨을 사용합니다. 따라서 Table 2의 차이를 특정 완성 backbone 하나의 순수 효과로 분해할 수 없습니다. **[pp.7–8]**

### 원문 내부 불일치 추가 확인

- **KITTI-360 SO:** 본문 p.7의 17.12와 Tables 1·13·14의 12.56이 불일치합니다.
- **데이터셋 수치 혼입:** p.20의 SemanticKITTI 교사–학생 비교 문단에서 인용한 PaSCo 19.53·26.29는 Table 14상 KITTI-360 수치입니다.
- **손실 가중치:** p.17의 $\lambda_{\text{occ}}$와 $\lambda_{\text{compl}}$ 표기가 불일치합니다.

이 보고서에서는 데이터셋·설정이 명확하고 여러 표에서 일치하는 값을 우선했습니다.

이후 발표된 연구들을 CAL의 직접적인 영향 아래 나온 후속작으로 단정할 근거는 확인하지 못했습니다. 여기서는 **공통 문제를 다루는 관련 연구**로 비교했습니다.

## 11. 결론·시사점·후속 연구

### 11.1 저자가 제시한 시사점

**[저자 보고]** CAL은 시간적 관측으로부터 객체 형상과 질의 가능한 의미 특징을 추출하고, 부분적인 의사 라벨로 단일 LiDAR 기반 객체·장면 완성을 학습하는 방향을 제시합니다. 저자는 이를 amodal perception의 기반을 마련하는 단계로 설명합니다. **[p.9, §5]**

**학술적 시사점에 대한 해석:** 완전한 3D 정답을 확보하는 문제, 객체별 형상을 복원하는 문제, 의미 범주를 확장하는 문제를 하나의 학습 체계에서 다루었다는 점이 중요합니다. 특히 **전체 점유 감독과 부분 객체·의미 감독을 분리하여 결합하는 방식**은 후속 연구에서 독립적으로 검증할 가치가 큽니다. **[pp.4–5, 16–17]**

**실용적 시사점에 대한 해석:** 추론에 카메라를 요구하지 않으면서 텍스트 질의를 지원한다는 점은 다양한 객체를 다루는 3D 환경 표현에 유용한 특성입니다. 다만 실제 주행 성능이나 운영 효과를 측정한 연구는 아니므로, 응용 효과를 현재 결과 이상으로 확정할 수는 없습니다. **[Figures 1, 5; pp.5–8]**

### 11.2 논문이 명시한 제한사항

저자가 밝힌 주요 한계는 다음과 같습니다.

1. **영상 기반 분할·추적 오류:** 가림, 시점 변화, ID 전환 등이 잘못된 형상과 라벨을 만들 수 있습니다.
2. **카메라–LiDAR 시야 차이:** 영상에서 보이지 않는 영역은 객체·의미 라벨을 확보하기 어렵습니다.
3. **높은 의사 라벨 생성 비용:** 영상 마스크 전파 때문에 한 쌍의 의사 라벨 생성에 수 분 정도가 걸릴 수 있습니다.
4. **지도학습과의 성능 격차:** 의미 인식과 인스턴스 완성 모두 개선이 필요합니다.
5. **희소 범주 표현의 부족:** k-means 프로토타입이 드문 객체의 특징을 충분히 보존하지 못할 수 있습니다.

**근거:** p.9, Limitations·Conclusion; pp.19–21, §§C.2–C.3.

> **용어 풀이 — ID 전환:** 추적 중 서로 다른 객체를 같은 객체로 연결하거나, 동일 객체를 다른 객체로 바꾸어 연결하는 오류.

### 11.3 저자가 제안한 후속 연구 방향

**[저자 제안]**

- 기하 정보를 이용한 시간적 객체 연결 개선.
- 더 좋은 영상·언어 기반 모델의 통합.
- 더 큰 무라벨 데이터셋으로의 확장.
- 자기지도 LiDAR forecasting을 이용한 라벨 coverage 개선.
- 희소 범주를 더 잘 보존하는 분포 인식 군집화.
- 짧은 추적 구간과 CRF를 조합한 의사 라벨 생성 비용 절감.

**근거:** p.9; pp.19–21.

> **용어 풀이**
>
> - **자기지도 학습:** 별도의 수작업 정답 대신 데이터 내부의 관계를 학습 신호로 사용하는 방법.
> - **LiDAR forecasting:** 시간적으로 이후의 LiDAR 관측이나 공간 상태를 예측하는 과제.
> - **분포 인식 군집화:** 자주 나타나는 패턴뿐 아니라 드문 패턴의 존재도 고려하여 특징들을 묶는 방식.

### 11.4 가장 유망한 기술과 빠른 검증 방법

### 11.5 일반화 향상을 검증하기 위한 추가 연구 설계

**[추가 검증 제안]** 일반화를 중심으로 연구한다면 다음 순서가 타당합니다.

1. **학습 모델을 고정한 교차 데이터셋·교차 센서 평가:** 대상 데이터에 맞춘 재학습·임계값 조정 여부를 구분하여 보고합니다.
2. **학습 범주와 평가 범주를 분리한 실험:** 새로운 텍스트를 입력할 수 있다는 사실과 새로운 객체를 정확하게 완성한다는 사실을 따로 측정합니다.
3. **기하와 의미의 오류 분리:** ZS·SO, 점유 정확도, 객체 마스크 품질, CLIP 분류 성능을 함께 보고 병목을 확인합니다.
4. **희소 범주와 관측량별 평가:** 전체 평균뿐 아니라 작은 객체·드문 객체·입력 점이 적은 객체의 성능을 별도로 측정합니다.
5. **반복 실험과 장면 단위 불확실성 보고:** 여러 seed와 장면 단위 재표집 등을 통해 작은 차이가 재현되는지 확인합니다.

이 논문에서 후속 연구를 시작한다면, **라벨 coverage·라벨 정확도·단일 스캔으로의 정보 전달을 먼저 분리 검증하는 접근**이 가장 근거가 충분합니다. 새로운 대형 생성 모델을 선택하기에 앞서 이 세 요소를 개선하고 측정하면, 실제로 향상된 것이 형상 완성인지, 의미 인식인지, 환경 일반화인지 명확하게 판단할 수 있습니다.
