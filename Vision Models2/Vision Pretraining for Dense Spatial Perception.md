## 1. 핵심 주장 및 주요 기여 요약

### 핵심 주장

현대의 시각적 기반 모델(visual foundation model)들은 **의미론적 불변성(semantic invariance)**을 우선시하여 세밀한 공간 구조 이해를 희생하는 경향이 있다. 본 논문은 **경계(boundary)와 형상 불연속(shape discontinuity)**이 기하학적 특성 인식을 위한 핵심 단서임을 주장하며, 이를 사전학습의 **네이티브 학습 신호(native learning signal)**로 활용해야 한다고 제안한다.

### 주요 기여

| 기여 | 설명 |
|------|------|
| **경계 중심 사전학습 패러다임** | 경계를 출력이 아닌 학습 신호로 재정의 |
| **Masked Boundary Modeling** | 교사의 경계 예측으로 마스크 집합을 결정하는 자기-지도 학습 |
| **경계 필드의 범주형 재매개변수화** | 붕괴 없이 안정적 학습 가능하게 설계 |
| **LingBot-Vision (1B ViT-g)** | 7B DINOv3보다 밀집 공간 인식에서 우수한 성능 |
| **LingBot-Depth 2.0** | 14개 깊이 완성 벤치마크에서 SOTA 달성 |

## 2. 해결하고자 하는 문제, 제안 방법, 모델 구조, 성능 및 한계

### 2.1 해결하고자 하는 문제

**문제 1: 기존 SSL의 공간 구조 이해 부족**

기존 자기-지도 학습 패러다임들은 다음의 한계를 가진다:

- **자기-증류(self-distillation)** (DINO, DINOv2, DINOv3): 의미론적 일치를 보상하여 세밀한 경계 신호를 억제함
- **마스크 이미지 모델링** (MAE): 공간적으로는 충실하지만 의미론적 표현이 약함
- **언어 지도 학습** (CLIP, SigLIP): 이미지 수준 정렬에 특화되어 밀집 예측에 취약

**문제 2: 무작위 마스킹의 정보 비효율성**

기존 iBOT/MAE의 무작위 마스킹은 내용에 무관하여, 평탄하고 예측 가능한 토큰을 주로 마스킹하고 **정보가 풍부한 경계 토큰은 마스킹을 회피**하는 경향이 있다.

### 2.2 제안하는 방법 (수식 포함)

#### (1) 자기-증류 기반 기준선 (DINO + iBOT)

**EMA 교사 업데이트**:

$$\bar{\theta} \leftarrow \lambda \bar{\theta} + (1 - \lambda) \theta \tag{1}$$

여기서 $\lambda$는 훈련 중 1로 어닐링되는 모멘텀 파라미터.

**이미지 수준 증류 (DINO)**:

$$\mathbf{p}^t = \text{softmax}\!\left(\frac{h_{\bar{\theta}}(\mathbf{z}^\text{cls}) - \mathbf{c}}{\tau_t}\right), \quad \mathbf{p}^s = \text{softmax}\!\left(\frac{h_{\theta}(\mathbf{z}^\text{cls})}{\tau_s}\right) \tag{2}$$

$$\mathcal{L}_{\text{DINO}} = -{\mathbf{p}^t(\mathbf{x}^{(1)})}^\top \log \mathbf{p}^s(\mathbf{x}^{(2)}) \tag{3}$$

여기서 $\tau_t < \tau_s$ (교사 샤프닝), $\mathbf{c}$는 붕괴 방지를 위한 센터링 벡터.

**패치 수준 증류 (iBOT)**:

$$\mathcal{L}_{\text{iBOT}} = -\frac{1}{|\mathcal{M}|} \sum_{i \in \mathcal{M}} \mathbf{q}_i^{t\top} \log \mathbf{q}_i^s, \quad \mathbf{q}_i = \text{softmax}\!\left(\frac{g(\mathbf{z}_i^p) - \mathbf{c}_{\text{iBOT}}}{\tau}\right) \tag{4}$$

#### (2) 경계-강제 마스크 모델링 (Boundary-Forcing Masked Modeling)

**경계 토큰 집합 정의**:

```math
\mathcal{B} = \bigl\{ i \in \{1,\ldots,N\} : \text{예측된 경계가 } \text{patch}(i) \text{와 교차함} \bigr\}
```

**강제 마스크 집합**:

$$\mathcal{M}^+ = \mathcal{M} \cup \mathcal{B} \tag{6}$$

$\mathcal{M}$은 기존의 무작위 마스크, $\mathcal{B}$는 경계 토큰 집합. 경계 토큰은 **의미론적 목표( $\mathcal{L}\_{\text{iBOT}}$ )와 기하학적 목표($\mathcal{L}_{\text{bnd}}$) 모두**로 지도된다.

#### (3) 경계 필드의 범주형 재매개변수화

경계 픽셀 $p$의 속성 벡터:

$$\mathbf{a}(p) = \bigl(d_p,\; \theta_p,\; \phi^1_p,\; \phi^2_p\bigr) \tag{7}$$

- $d_p$: 가장 가까운 선분까지의 거리
- $\theta_p$: 선분 방향각
- $\phi^1_p, \phi^2_p$: 선분 끝점 위치각

각 채널 $c \in \{d, \theta, \phi^1, \phi^2\}$에 대해 **소프트 범주형 레이블**로 변환:

$$\bar{y}^c_k(p) \propto \exp\!\left(-\frac{\delta^c\bigl(k,\, a^c(p)\bigr)^2}{\tau_\ell}\right), \quad k=1,\ldots,K \tag{8}$$

여기서 $\delta^c$는 빈 $k$의 중심에서 $a^c(p)$까지의 거리 ($\theta$ 채널은 원형 호 거리 사용), $\tau_\ell$은 레이블 온도.

**경계 손실 함수 (크로스 엔트로피)**:

$$\mathcal{L}_{\text{bnd}} = -\frac{1}{|\mathcal{B}|} \sum_{p \in \mathcal{B}} \sum_c \bar{y}^c(p)^\top \log \hat{y}^c(p) \tag{9}$$

#### (4) 전체 훈련 목적 함수

$$\mathcal{L} = \mathcal{L}_{\text{DINO}} + \lambda_i \mathcal{L}_{\text{iBOT}} + \lambda_b \mathcal{L}_{\text{bnd}} + \lambda_k \mathcal{L}_{\text{KoLeo}} \tag{10}$$

- $\lambda_i = \lambda_b = 1$, $\lambda_k = 0.1$
- $\mathcal{L}_{\text{KoLeo}}$: 배치 내 클래스 토큰 특징 분산 정규화

#### (5) A-contrario 검증 (NFA 테스트)

경계 후보 선분의 유효성 검증:

$$\text{NFA}(n, k) = N_t \cdot \sum_{i=k}^{n} \binom{n}{i} p^i (1-p)^{n-i} \tag{11}$$

- $n$: 지지 픽셀 수, $k$: 정렬된 픽셀 수
- $p = 1/16$ (정렬 허용 오차 $\pi/16$)
- $\text{NFA} \leq \varepsilon = 1$이면 경계 후보 수용
- **범주형 경계 필드의 균일 분포 = a-contrario 귀무가설**과 자연스럽게 일치

### 2.3 모델 구조

```
[LingBot-Vision 아키텍처]

입력 이미지
    ↓
┌─────────────────────────────────────────┐
│ ViT-g/16 백본 (~1.1B 파라미터)           │
│ - SwiGLU FFN                            │
│ - RoPE (fp32)                           │
│ - 4개 레지스터 토큰                       │
└─────┬──────────────┬────────────────────┘
      │              │
      ↓              ↓
  클래스 토큰     패치 토큰 × N
      │              │
      ↓         ┌────┴────┐
  DINO 헤드   iBOT 헤드  경계 헤드
  (이미지 수준) (패치 수준) (3-layer MLP)
                          │
                    sub-token 해상도
                    (stride s=2)
                    K=32 bin 분류기
                    (코사인 유사도 기반)
```

**교사-학생 파이프라인**:
- EMA 교사: 온라인 경계 필드 예측 + a-contrario 검증
- 단일 블록 ViT 코너 포인트 탐지기 (고정, 초소형)
- 학생: 강제 마스크 $\mathcal{M}^+$ 하에서 이중 목표 학습

**훈련 3단계**:
1. **사전학습** (300k 이터레이션, 256px)
2. **Gram 앵커링** (100k 이터레이션, DINOv3 방식)
3. **고해상도 적응** (100k 이터레이션, 512px)

**증류 모델**: ViT-L (300M), ViT-B (86M), ViT-S (21M)

### 2.5 한계

1. **선분(line segment) 가정**: 경계를 직선 선분의 연쇄로 모델링하므로, 매우 복잡한 비선형 곡선 경계의 표현력이 제한될 수 있음
2. **코너 포인트 탐지기 의존성**: 초기 경계 부트스트래핑을 위해 고정된 단일 블록 ViT 코너 탐지기를 사용하므로 완전한 end-to-end 학습은 아님
3. **ImageNet 분류 성능 트레이드오프**: DINOv3-7B (87.87%) 대비 LingBot-Vision (86.32%)로 이미지 수준 분류에서 열세. 경계 중심 사전학습이 지역적 구조에 투자하기 때문
4. **계산 비용**: ViT-g 1B 모델 훈련은 여전히 대규모 컴퓨팅 자원 필요 (DINOv3의 1/3 수준이나 절대적으로는 고비용)
5. **옥외 장면 한계**: KITTI(옥외 주행)에서는 DINOv3-7B(2.346)에 뒤처짐(2.552) — 도로/하늘처럼 경계가 적은 장면에서 경계 학습의 이점이 약화됨
6. **ViT-S 한계**: ViT-S 크기에서 KITTI와 Cityscapes 성능이 DINOv3-S에 뒤처짐

## 3. 일반화 성능 향상 가능성

### 3.1 일반화를 가능하게 하는 핵심 메커니즘

#### (가) 기하학적으로 구조화된 표현의 범용성

경계와 형상 불연속은 특정 도메인에 종속되지 않는 **보편적 시각 구조**다. LingBot-Vision이 학습한 경계 중심 표현은 다양한 하위 작업(깊이, 분할, 추적, 동영상)에 **공통으로 전이**된다:

- **깊이 추정**: 물체 경계 = 깊이 불연속 → 경계 인식 능력이 직접 기여
- **의미론적 분할**: 클래스 경계 정렬 → mIoU 향상
- **동영상 추적**: 경계 토큰의 시간적 안정성 → 감독 없이 추적 가능

#### (가) 스케일-데이터 상호작용에서의 일반화

그림 8의 데이터 스케일링 실험이 일반화 성능 향상의 핵심 근거를 제공한다:

$$\text{LingBot-Vision 이점}(D) > \text{DINOv2 이점}(D) \quad \text{as } D \to 150\text{M}$$

- DINOv2: 20M→150M에서 D102 0.752→0.755 (포화 현상)
- LingBot-Vision: 20M→150M에서 D102 0.777→0.795 (지속 향상)

이는 **경계 사전학습이 데이터 스케일에서 복합적 이득(compounding gain)**을 제공하며, 더 많은 데이터에서 더 큰 이점을 보임을 의미한다. 즉, **사전학습 품질이 데이터 양이 증가해도 희석되지 않는다**.

#### (나) 파라미터 효율적 일반화

증류 실험에서 확인된 일반화 전이:

$$\text{0.3B LingBot-Vision ViT-L: NYUv2 RMSE} = 0.310 \approx \text{7B DINOv3: RMSE} = 0.309$$

**23배 적은 파라미터**로 동등 성능 달성. 이는 경계 표현이 파라미터 효율적으로 일반화됨을 보여준다.

#### (다) 도메인 간 일반화 (Domain Generalization)

LingBot-Depth 2.0 평가에서 확인:
- 실내 (NYU, DIODE-Indoor), 실외 (DIODE-Outdoor, KITTI), 투명 물체 (ClearGrasp), 반사 표면 (HAMMER) 등 다양한 도메인에서 일관된 성능
- 특히 ClearGrasp (투명 물체, RMSE 0.010/0.012)에서 강점 — 경계 인식이 시각적으로 어려운 도메인에서도 기하학적 단서를 추출하는 능력 시사

#### (라) 동영상에서의 시간적 일반화

동영상 지도 학습 없이도 경계 토큰이 **프레임 간 안정적으로 추적** 가능:
- 로봇 조작 장면, 고양이 동영상, 실내 파노라마에서 코사인 유사도 기반 추적 성공
- 이는 학습된 경계 표현이 시간 도메인으로 자연스럽게 일반화됨을 시사

#### (마) 일반화 한계 및 주의점

| 조건 | 일반화 성능 |
|------|-----------|
| 경계 풍부한 장면 (실내, 정밀 작업) | ✅ 강한 이점 |
| 경계 희소한 장면 (도로, 하늘, 넓은 평원) | ⚠️ 이점 약화 |
| 소형 모델 (ViT-S) | ⚠️ 일부 벤치마크 성능 저하 |
| 이미지 수준 분류 | ❌ 의미론적 모델 대비 약세 |

## 4. 앞으로의 연구에 미치는 영향 및 고려할 점

### 4.1 연구에 미치는 영향

#### (가) 사전학습 패러다임의 전환

기존의 **"경계는 출력"이라는 출력-중심 관점**에서 **"경계는 학습 신호"라는 입력-중심 관점**으로의 전환을 제시한다. 이는 자기-지도 학습의 설계 공간을 근본적으로 확장한다:

- 마스킹 전략의 재설계: 무작위 → 구조 기반
- 지도 신호의 재설계: 의미론적 → 기하학적 + 의미론적 이중 채널

#### (나) 체화 인공지능(Embodied AI) 및 로보틱스

경계 인식 능력이 로봇 정책의 지각 기반으로 직접 활용 가능:
- LingBot-Depth 2.0: 투명 물체, 반사 표면 처리 능력 → 실제 로봇 조작에 실용적
- 경계 토큰 추적: 로봇 시각 추적, 조작 물체 추적에 응용 가능
- DINO-WM (Zhou et al., ICML 2025)과 같은 세계 모델의 지각 기반으로 활용 가능성

#### (다) 멀티모달 및 비디오 모델

- 비디오 사전학습 없이도 동영상 객체 분할에서 video-pretrained V-JEPA 2.1과 경쟁
- 이는 **이미지 수준 경계 사전학습이 시간적 일관성을 내포**할 수 있음을 시사, 비디오 이해 연구에 새로운 방향 제시

#### (라) 확장 법칙(Scaling Laws) 재해석

기존 연구들은 모델 크기와 데이터 크기의 스케일링을 강조했으나, LingBot-Vision은 **사전학습 목적 함수의 품질**이 스케일링 효율에 결정적임을 보여준다:
- 161M 데이터로 1,689M 데이터로 훈련된 DINOv3 수준 달성
- 사전학습 목표 설계가 데이터/모델 크기만큼 중요

### 4.2 앞으로 연구 시 고려할 점

#### (가) 방법론적 고려사항

1. **곡선 경계 표현 강화**: 현재 직선 선분 근사(short segment chain)에 의존하므로, 곡선 지오메트리를 직접 모델링하는 필드 표현 연구 필요

2. **코너 포인트 탐지기 통합**: 현재의 고정된 단일 블록 ViT 코너 탐지기 대신, 백본과 함께 엔드-투-엔드 학습이 가능한 구조 탐색

3. **의미론-기하학 균형 최적화**: 현재 $\lambda_i = \lambda_b = 1$의 균등 가중치를 사용하나, 작업별 최적 가중치 스케줄링 연구 필요

4. **3D 경계 확장**: 현재 2D 이미지 경계에 집중하나, 포인트 클라우드나 멀티뷰 3D 데이터에서의 3D 경계 모델링으로 확장 가능성

#### (나) 평가 및 벤치마크 고려사항

5. **분류 성능 트레이드오프 해결**: 이미지 수준 분류에서의 열세(-1.5% vs DINOv3-7B)를 줄이는 방법 연구. 경계 학습과 의미론적 불변성의 공동 최적화 필요

6. **옥외 장면 특화 연구**: 경계가 희소한 도로/하늘 장면에서의 성능 향상을 위한 맥락 인식형 마스킹 전략 개발

#### (다) 응용 및 사회적 고려사항

7. **로보틱스 안전성**: LingBot-Depth 2.0이 실제 로봇 시스템에 통합될 경우, 엣지 케이스(극도의 반사, 안개, 야간)에서의 경계 인식 실패가 안전 문제로 이어질 수 있음 → 불확실성 추정 통합 필요

8. **도메인 편향**: 훈련 데이터의 실내 장면 편향이 특정 옥외 도메인에서의 일반화를 제한할 수 있음

### 종합 평가

"Vision Pretraining for Dense Spatial Perception"은 **경계를 자기-지도 학습의 제1급 시민(first-class citizen)**으로 격상시킨 패러다임 전환적 연구다. 수식적으로 엄밀하게 설계된 범주형 재매개변수화, a-contrario 검증의 통합, 그리고 이중 지도 라우팅의 조합은 의미론-기하학의 협력적 공동 창발을 가능하게 한다. 특히 **데이터 스케일과 사전학습 품질의 복합적 이득**은 미래 연구에서 사전학습 목적 함수 설계의 중요성을 재강조하며, 로보틱스와 체화 AI를 향한 실용적 경로를 제시한다.
