## 3. 제안 방법: 수식과 의미

### 3.1 출발점: 표준 확산·Flow Matching 학습

**[저자 보고: p.3, 식 (1)]** 깨끗한 데이터에 노이즈를 섞는 순방향 과정은 다음과 같습니다.

$$
x_t=\alpha_t x_0+\sigma_t\epsilon,
\qquad
\epsilon\sim\mathcal N(0,I),
$$

$$
v=\dot{\alpha}_t x_0+\dot{\sigma}_t\epsilon.
$$

조건인 프롬프트 $c$를 명시하면, 기본 학습 목적은 다음처럼 쓸 수 있습니다.

```math
\mathcal L_{\text{FM}}(\theta)
=
\mathbb E_{c,x_0,t,\epsilon}
\left[
w(t)\left\|v_\theta(x_t,c,t)-v\right\|_2^2
\right].
```

여기서 $x_0$는 노이즈가 없는 데이터, $x_t$는 시각 $t$의 노이즈 데이터, $\epsilon$은 표준 정규 노이즈, $I$는 단위행렬입니다. $\alpha_t$와 $\sigma_t$는 데이터·노이즈의 비중을 정하는 함수이고, 위의 점은 시간 미분입니다. $v$는 정답 속도, $v_\theta$는 파라미터 $\theta$를 가진 모델의 속도 예측, $w(t)$는 시간별 가중치입니다. $\mathbb E$는 평균, $\|\cdot\|_2^2$는 성분별 오차 제곱의 합입니다. 2509.16117v2

Rectified Flow에서는 다음과 같이 단순해집니다.

$$
\alpha_t=1-t,\qquad \sigma_t=t,
$$

$$
x_t=(1-t)x_0+t\epsilon,
\qquad
v=\epsilon-x_0.
$$

즉, 이미지와 노이즈 사이를 직선으로 연결하는 경로를 학습합니다〔p.3〕. **DiffusionNFT가 순방향 과정에서 학습한다고 해서 이미지도 노이즈를 추가하며 생성한다는 뜻은 아닙니다.** 생성은 여전히 노이즈 쪽에서 데이터 쪽으로 진행합니다. 2509.16117v2

> **용어:** *Flow Matching*은 데이터와 노이즈를 연결하는 경로의 속도를 예측하도록 학습하는 방법입니다. *Rectified Flow*는 여기서 사용한 직선 보간 형태의 특별한 경우입니다.

### 3.2 보상을 긍정·부정 가중치로 바꾸기

**[저자 보고: p.6, Algorithm 1 및 Optimality Reward]** 동일한 프롬프트에서 이미지 $K$개를 생성하고, 원시 보상을 그룹 안에서 중심화한 뒤 $[0,1]$ 구간으로 변환합니다.

원문의 $r^{\text{raw}}$를 아래에서는 $R$로 표기하면,

```math
\bar R_c
=
\frac{1}{K}
\sum_{j=1}^{K}R(x_0^{(j)},c),
```

```math
r(x_0,c)
=
\frac12+
\frac12\,
\text{clip}
\left(
\frac{R(x_0,c)-\bar R_c}{Z_c},
-1,1
\right).
```

$R$은 원시 보상, $\bar R_c$는 같은 프롬프트에서 생성한 이미지들의 평균 보상, $j$는 이미지 번호, $Z_c>0$는 정규화 계수입니다. $\text{clip}(z,-1,1)$은 값이 범위를 벗어나지 않도록 자르는 함수이며, 최종 $r$은 긍정 학습의 가중치로 사용됩니다. 2509.16117v2 2509.16117v2

**중요한 해석:** $r=0.8$은 “이 이미지가 인간 기준으로 올바를 확률이 검증상 80%”라는 뜻이 아닙니다. 알고리즘이 상대적 보상을 **최적성 확률로 해석하도록 변환한 값**입니다. 실제 구현은 이미지를 반드시 둘 중 하나로 분류하지 않고, 긍정 손실에 $r$, 부정 손실에 $1-r$을 부여합니다.

> **용어:** *중심화*는 평균을 빼서 평균보다 좋은지 나쁜지를 나타내는 것입니다. *최적성 확률*은 좋은 결과일 가능성이라는 해석을 부여한 학습용 수치입니다.

### 3.3 긍정 분포와 부정 분포

**[저자 보고: p.4, §3.1; p.14, 식 (7)–(9)]**

```math
\bar r_c
=
\mathbb E_{x_0\sim\pi^{\text{old}}(\cdot\mid c)}
[r(x_0,c)],
```

```math
\pi^+(x_0\mid c)
=
\frac{r(x_0,c)}{\bar r_c}
\pi^{\text{old}}(x_0\mid c),
```

```math
\pi^-(x_0\mid c)
=
\frac{1-r(x_0,c)}{1-\bar r_c}
\pi^{\text{old}}(x_0\mid c).
```

$\pi^{\text{old}}$는 데이터를 수집하는 기존 정책의 분포, $\pi^+$는 높은 보상 이미지의 비중을 높인 분포, $\pi^-$는 낮은 보상 이미지의 비중을 높인 분포입니다. $\bar r_c$는 해당 프롬프트에서의 평균 정규화 보상입니다. 분모가 정의되려면 $0<\bar r_c<1$이어야 합니다. 2509.16117v2 2509.16117v2

**[제 수학적 해석]** 긍정 분포가 왜 더 좋은지 다음 항등식으로 확인할 수 있습니다.

```math
\mathbb E_{\pi^+}[r]
-
\mathbb E_{\pi^{\text{old}}}[r]
=
\frac{\text{Var}_{\pi^{\text{old}}}(r)}
{\bar r_c}.
```

여기서 기대값은 같은 프롬프트에 대해 계산하며, $\text{Var}$는 보상의 분산입니다. 따라서 보상에 차이가 있으면 긍정 분포의 평균 보상이 높습니다. 반대로 **모든 생성 결과의 보상이 같으면 분산이 0이므로 엄격한 개선은 나오지 않습니다.** 이는 본문의 “긍정 정책이 항상 더 좋다”는 표현을 읽을 때 필요한 비퇴화 조건입니다.

> **용어:** *분산*은 값들이 평균에서 얼마나 흩어져 있는지를 나타냅니다. *비퇴화 조건*은 모든 값이 같아져 학습 신호가 사라지는 특수한 경우를 제외한다는 뜻입니다.

### 3.4 긍정 방향과 부정 회피 방향이 일치한다

**[저자 보고: p.4, Theorem 3.1, 식 (4), Figure 3]**

```math
\alpha(x_t)
=
\frac{\pi_t^+(x_t\mid c)}
{\pi_t^{\text{old}}(x_t\mid c)}
\bar r_c,
```

```math
\Delta
=
[1-\alpha(x_t)]
\left(v^{\text{old}}-v^-\right)
=
\alpha(x_t)
\left(v^+-v^{\text{old}}\right).
```

위 식의 속도들은 모두 같은 $(x_t,c,t)$에서 평가합니다. $\pi_t^+$와 $\pi_t^{\text{old}}$는 각각의 깨끗한 데이터 분포에 시각 $t$의 노이즈를 추가한 분포이고, $v^+,v^-,v^{\text{old}}$는 이에 대응하는 이상적 속도 예측입니다. $\alpha(x_t)\in[0,1]$은 노이즈 상태에 따른 긍정 비중이며, 앞 절의 노이즈 스케줄 $\alpha_t$와 다른 기호입니다. $\Delta$가 논문에서 말하는 **강화 유도 방향**입니다. 2509.16117v2

직관은 간단합니다. **좋은 분포 쪽으로 이동하는 방향과 나쁜 분포에서 멀어지는 방향이 연결되어 있으므로, 실패 결과도 유용한 학습 정보가 됩니다.**

저자는 이를 이용해 목표 속도를 다음처럼 정의합니다〔식 (3)〕.

```math
v^*
=
v^{\text{old}}+\frac{1}{\beta}\Delta.
```

$v^*$는 목표 속도이고, $\beta>0$는 유도 강도를 조절하는 하이퍼파라미터입니다. 이 정의에서는 $1/\beta$가 작동 강도이므로, 작은 $\beta$는 더 강한 이동을 뜻합니다. 2509.16117v2

### 3.5 실제 목적함수: 두 암묵적 정책, 하나의 학습 모델

**[저자 보고: p.5, 식 (5)]**

```math
v_\theta^+
=
(1-\beta)v^{\text{old}}+\beta v_\theta,
```

```math
v_\theta^-
=
(1+\beta)v^{\text{old}}-\beta v_\theta,
```

```math
\mathcal L_{\text{NFT}}(\theta)
=
\mathbb E_{c,x_0\sim\pi^{\text{old}},t,\epsilon}
\left[
r\left\|v_\theta^+-v\right\|_2^2
+
(1-r)\left\|v_\theta^--v\right\|_2^2
\right].
```

$v_\theta^+$와 $v_\theta^-$는 각각 암묵적 긍정·부정 정책입니다. **별도 신경망이 아니라 같은 학습 모델 $v_\theta$와 고정된 기존 모델 $v^{\text{old}}$의 출력 조합**입니다. 최적화할 때는 $\theta$를 갱신하고, 해당 학습 구간의 기존 정책은 고정합니다. 2509.16117v2

**[제 수학적 해석: 식 (5)의 전개]** 한 샘플의 손실 $\ell$은 다음과 같이 다시 쓸 수 있습니다.

```math
\ell
=
\beta^2\left\|v_\theta-\tilde v\right\|_2^2+C,
```

```math
\tilde v
=
v^{\text{old}}
+
\frac{2r-1}{\beta}
\left(v-v^{\text{old}}\right).
```

$\tilde v$는 동등한 회귀 목표이며, $C$는 기존 정책이 고정되어 있을 때 $\theta$에 의존하지 않는 항입니다. 이 식은 논문에 제시된 별도 알고리즘이 아니라, 식 (5)를 이해하기 위한 대수적 전개입니다.

특히 $\beta=1$이면 $r=1$일 때 정답 속도 $v$를 학습하고, $r=0$일 때는 기존 예측을 기준으로 반대편인 $2v^{\text{old}}-v$를 학습하며, $r=0.5$이면 기존 예측을 유지하는 목표가 됩니다. 즉, **실패 이미지의 손실을 단순히 크게 만드는 것이 아니라, 실패를 설명하는 방향의 반대편으로 주 모델을 이동시키는 구조**입니다.

저자가 증명한 이상적 최적해는 다음과 같습니다〔Theorem 3.2, 식 (6)〕.

```math
v_{\theta^*}
=
v^{\text{old}}+\frac{2}{\beta}\Delta.
```

$\theta^\*$는 무한한 데이터와 모델 용량 아래에서 목적함수를 최적으로 최소화하는 파라미터입니다. **식 (3)의 계수는 $1/\beta$이고 실제 목적함수의 최적해인 식 (6)의 계수는 $2/\beta$라는 점을 구별해야 합니다.** 2509.16117v2

### 3.6 실제 학습을 안정화하는 장치

**① 샘플링 정책의 EMA 갱신**

$$
\theta^{\text{old}}
\leftarrow
\eta_i\theta^{\text{old}}+(1-\eta_i)\theta.
$$

$i$는 반복 번호, $\eta_i$는 이전 정책을 얼마나 유지할지 결정하는 계수입니다. 저자는 즉시 교체하는 $\eta_i=0$에서는 초기 개선이 빠르지만 붕괴가 발생하고, 지나치게 큰 계수에서는 학습이 느려진다고 보고합니다〔p.6; pp.8–9, Figure 8〕. 2509.16117v2 2509.16117v2

> **용어:** *EMA, 지수이동평균*은 새 파라미터를 한 번에 적용하지 않고 이전 파라미터와 섞어 서서히 갱신하는 방법입니다. *오프폴리시*는 데이터를 만든 정책과 현재 학습 중인 정책이 다를 수 있는 학습 방식입니다.

**주의:** 여기서 오프폴리시라는 말은 “아무 오래된 모델에서 수집한 데이터를 제한 없이 섞어도 보장된다”는 뜻이 아닙니다. Algorithm 1은 현재 수집 정책의 이미지로 학습한 뒤 버퍼를 비웁니다〔p.6〕. 2509.16117v2

**② 적응적 손실 가중치**

Rectified Flow에서는 속도 예측을 깨끗한 데이터 예측으로 바꿀 수 있습니다.

$$
x_\theta=x_t-tv_\theta,
$$

```math
\ell_{\text{adapt}}
=
\frac{\left\|x_\theta-x_0\right\|_2^2}
{\text{sg}\left(
\text{mean}\left(\left|x_\theta-x_0\right|\right)
\right)}.
```

$x_\theta$는 모델이 복원한 깨끗한 데이터, $|\cdot|$는 성분별 절댓값, $\text{mean}$은 성분 평균, $\text{sg}$는 역전파 시 해당 항의 미분을 차단하는 연산입니다. 저자는 이 가중치가 수동으로 정한 시간 가중치와 같거나 더 좋은 학습 속도를 보였다고 보고합니다〔p.6; p.9, Figure 9〕. 2509.16117v2 2509.16117v2

> **용어:** *역전파*는 출력의 오차를 이용해 각 파라미터의 수정 방향을 계산하는 과정입니다. *Stop-gradient*는 특정 계산값을 상수처럼 취급하여 그 경로로는 미분하지 않는 장치입니다.

## 4. 모델 구조와 실험 설계

### 4.1 새로운 생성 신경망이 아니라 새로운 후학습 방법이다

**[저자 보고]** 실험의 기본 모델은 **SD3.5-Medium, 2.5B 파라미터**이며, 주 실험은 $512\times512$ 해상도에서 수행했습니다. LoRA 설정은 rank 32, scale $\alpha=64$이고, 학습률은 $3\times10^{-4}$입니다〔p.7, §4.1–4.2; p.19, Appendix C〕. 2509.16117v2 2509.16117v2

> **용어:** *후학습*은 이미 사전학습한 모델을 특정 목적에 맞게 추가 학습하는 과정입니다. *LoRA*는 전체 가중치를 모두 갱신하는 대신 작은 저차원 가중치 행렬을 추가해 학습하는 기법입니다. *Rank*는 이 추가 행렬의 표현 용량을 제한하는 크기입니다.

**[외부 공식 자료 보완]** SD3.5-Medium의 기본 생성기는 MMDiT-X 계열이며, 공식 모델 카드는 세 개의 고정된 사전학습 텍스트 인코더를 사용하는 구조로 설명합니다. 이는 DiffusionNFT가 새로 제안한 구조가 아니라 가져다 사용하는 기본 모델의 특성입니다. [Hugging Face](https://huggingface.co/stabilityai/stable-diffusion-3.5-medium)

> **용어:** *MMDiT-X*는 텍스트와 이미지 정보를 함께 처리하는 확산 Transformer 구조입니다. *텍스트 인코더*는 프롬프트를 신경망이 처리할 수 있는 수치 표현으로 바꿉니다.

학습 구조는 다음처럼 이해하면 됩니다.

**프롬프트 → 기존 정책으로 이미지 생성 → 보상 평가 → 생성 이미지에 새 노이즈 추가 → 학습 정책과 기존 정책의 속도 예측 → 긍정·부정 손실 계산 → 학습 정책 갱신 → 기존 정책을 EMA로 갱신**

이는 Figure 4와 Algorithm 1에 대응합니다. 추론 때는 학습된 정책을 사용하지만, **학습 중에는 기존 정책의 예측도 필요하므로 “CFG-free”를 “학습 중 모델 사본이 하나만 필요하다”로 해석하면 부정확합니다.** 2509.16117v2 2509.16117v2

> **용어:** *GenEval*은 객체의 색·개수·위치·속성 조합 같은 조건을 자동 평가합니다. *OCR*은 이미지 속 문자를 읽어 목표 문자열과 비교합니다. *PickScore·HPS·ImageReward 등*은 인간 선호나 이미지 품질을 대신 측정하는 평가 모델이며, 실제 사람의 직접 평가와 동일하지 않습니다. OCR 평가 역시 정규화된 문자 오류에 기반하므로 점수 0.97을 “이미지 97%에서 모든 문자가 완벽하다”로 읽으면 안 됩니다. 2509.16117v2 [arXiv](https://arxiv.org/pdf/2505.05470v3)

**[제 해석]** 가장 설득력 있는 결과는 약한 CFG-free 초기 모델만 이긴 것이 아니라, **CFG를 적용한 기본 모델도 여덟 지표 모두에서 넘었다**는 점입니다. 그러나 “모든 비교 모델을 모든 지표에서 이겼다”는 해석은 틀립니다. Table 1에서 FLUX.1-Dev의 CLIPScore는 0.295로 NFT의 0.293보다 높고, 단일 과제 FlowGRPO 모델은 GenEval 0.95, OCR 0.92로 다중 보상 NFT의 0.94와 0.91보다 높습니다. 2509.16117v2

| OCR | **0.97**, 150 반복 | 0.96, 1k 반복 | 빠른 적응을 보여 주지만 다른 평가 지표의 CFG 조건에 주의 |

### 5.3 일반화에 대한 증거를 세 수준으로 나누어야 한다

**첫째, 학습하지 않은 평가 보상으로의 전이는 관찰되었습니다.** Aesthetic·ImageReward·UnifiedReward를 직접 최적화하지 않았는데도 점수가 상승했습니다. 이는 특정 보상 하나만 공략한 결과보다 긍정적인 증거입니다〔p.7, §4.2〕. 2509.16117v2

**둘째, 프롬프트 데이터셋 간 전이도 일부 확인됩니다.** 모델 기반 보상 학습은 Pick-a-Pic에서 수행하고 DrawBench에서 평가합니다. 다만 이것만으로 모든 종류의 새로운 객체·언어·관계에 잘 대응한다고 결론 내릴 수는 없습니다〔p.7, §4.1〕. 2509.16117v2

**셋째, 강한 의미의 일반화 우월성은 입증되지 않았습니다.** 주논문에는 새로운 객체 범주, 학습 범위를 넘어선 객체 개수, 다국어 문자, 장문 복합 지시 등을 체계적으로 분리한 평가가 없습니다. 하나의 기본 모델에 집중했으므로 알고리즘의 모델 간 확장성과 학습된 모델의 입력 일반화도 구분해야 합니다.

특히 **저자는 OCR만 학습하면 다른 지표로의 일반화가 손상된다고 명시하고, OCR 학습 모델의 비-OCR 평가에서는 CFG를 다시 켭니다.** 이 조건은 “모든 단일 보상 학습에서 항상 CFG 없이 범용 성능이 유지된다”는 해석에 대한 직접적인 제한입니다〔p.19, Table 2 설명〕. 2509.16117v2

> **용어:** *분포 밖 일반화, OOD generalization*는 학습 때와 다른 유형의 입력에서도 잘 작동하는 능력입니다. 여기서 논문의 “out-of-domain reward”는 주로 학습에 사용하지 않은 평가 보상을 뜻하므로, 입력 분포 자체가 크게 달라지는 OOD와 완전히 같은 개념이 아닙니다.

### 5.4 중요한 외부 비교: FlowGRPO도 별도의 일반화 실험을 했다

**[외부 원논문 보고]** FlowGRPO 원논문은 60개 객체 범주로 학습하고 20개 미학습 범주를 평가했으며, 2–4개 객체로 학습한 뒤 5–6개를 생성하는 실험을 보고합니다. 해당 설정에서 미학습 객체 종합 점수는 0.64→0.90, 미학습 개수 점수는 0.13→0.48입니다〔FlowGRPO v3, p.9, Table 4〕. [arXiv](https://arxiv.org/pdf/2505.05470v3)

**[제 해석]** 따라서 DiffusionNFT의 보상·시간 효율 우위를 근거로 **FlowGRPO보다 일반화도 우수하다고 단정할 수 없습니다.** 그 결론을 내려면 같은 미학습 객체·개수 분할에서 직접 비교해야 합니다. 위 FlowGRPO 수치는 DiffusionNFT의 GenEval 0.98과 평가 집합이 다르므로 직접적인 점수 대결에 사용할 수 없습니다.

## 7. 이론적·통계적 취약점과 비교 불가능한 수치

### 7.1 이론: 무엇을 증명했고 무엇은 증명하지 않았는가?

**[저자 보고]** Theorem 3.1은 이상적 분포의 속도장 차이가 같은 방향임을 보이고, Theorem 3.2는 무한 데이터·무한 모델 용량에서 제안한 회귀 손실의 최적해를 구합니다〔pp.4–5; pp.14–16〕. 2509.16117v2 2509.16117v2

**[제 평가]** 다음 세 가지를 추가로 구분해야 합니다.

**고정된 $\beta$의 실제 학습에 대한 단조 개선 보장은 아닙니다.** 식 (3)에서 $\beta=\alpha(x_t)$이면 목표가 정확히 $v^+$가 됩니다. 그러나 식 (6)의 최적해가 $v^+$가 되려면 대수적으로 $\beta=2\alpha(x_t)$가 필요합니다. 실험의 상수 $\beta=1$ 또는 $0.1$에 대해 매 반복마다 보상이 증가한다는 정리는 제시되지 않습니다. 2509.16117v2 2509.16117v2 2509.16117v2

**이상적 속도장과 실제 신경망의 출력은 구분해야 합니다.** 증명은 분포에 대응하는 최적 속도 예측과 사후 평균의 관계를 사용합니다. 제한된 모델 용량과 유한 단계 샘플링에서 그 관계가 얼마나 정확한지는 별도 문제입니다〔p.15〕. 2509.16117v2

**실제 적응적 가중치까지 동일하게 증명한 것은 아닙니다.** 정리는 기본 제곱 손실에 대한 것이고, 실제 구현은 예측 오차를 이용한 정규화를 도입합니다. 따라서 기본 정리의 결론을 실용 구현 전체에 그대로 적용하려면 추가 분석이 필요합니다〔pp.5–6〕. 2509.16117v2 2509.16117v2

### 8.2 2026년 최신 연구가 추가한 쟁점

#### A. 우도 없는 학습이 항상 최선인가?

**[외부 저자 보고]** *Rethinking the Design Space of Reinforcement Learning for Diffusion Models: On the Importance of Likelihood Estimation Beyond Loss Design*은 정책 경사 손실, 우도 추정기, 샘플링 방식을 분리하여 분석하고, 최종 샘플만으로 계산하는 ELBO 기반 추정기의 선택이 성능·효율·안정성에 큰 영향을 준다고 보고합니다〔2026년 9월 개정판, 초록〕. [arXiv](https://arxiv.org/abs/2602.04663)

**[제 해석]** 이는 DiffusionNFT의 결과를 부정하지 않습니다. 다만 **“우도 추정이 없기 때문에 반드시 더 낫다”는 인과 설명은 추가 통제 실험이 필요하다**는 뜻입니다. 후속 비교에서는 우도 기반인지 여부뿐 아니라 추정기의 품질과 분산을 함께 통제해야 합니다.

> **용어:** *ELBO*는 직접 계산하기 어려운 로그우도 대신 최적화하거나 추정에 사용하는 하한입니다. *추정기*는 직접 구할 수 없는 수치를 표본으로 근사하는 계산 규칙입니다.

#### B. 적은 생성 단계로 확장하려면 출력의 의미를 맞춰야 한다

**[외부 저자 보고]** *MeanFlowNFT: Bringing Forward-Process RL to Average-Velocity Generators*는 DiffusionNFT의 순간 속도 목적함수를 평균 속도 생성기에 적용하기 위해, 평균 속도로부터 순간 속도 예측을 구성합니다. 이미지·비디오 실험과 이상적 조건의 정책 개선 분석을 보고하며, 개선 정책을 정확히 회복하는 조건에 $\beta=2\alpha$가 명시됩니다〔§3.1–3.2, 식 (8)–(12), Theorem 3.4〕. [arXiv](https://arxiv.org/abs/2607.15273)

**[제 해석]** 중요한 영향은 단순한 “NFT를 다른 모델에 붙인다”가 아닙니다. **새 생성기의 출력이 순간 속도인지, 구간 평균 속도인지에 따라 목적함수의 의미를 다시 맞춰야 한다**는 점입니다. 이는 모델 계열 간 확장성과 실제 일반화를 논할 때 필수적인 조건입니다.

> **용어:** *순간 속도*는 특정 시점의 움직임이고, *평균 속도*는 일정 시간 구간의 전체 이동량을 시간 길이로 나눈 값입니다.

#### C. 다중 보상에서는 무엇을 얼마나 학습할지도 적응시켜야 한다

**[외부 저자 보고]** *Adaptive Reward Routing: Dynamic Multi-Reward Optimization for Joint Audio-Video Diffusion via Forward-Process RL*은 오디오·비디오 생성에서 업데이트할 토큰·레이어와 보상 간 가중치를 동적으로 조정합니다. 두 기본 모델에서 실험하고, 주요 표에 독립 학습 3회에 대한 평균과 표준편차를 제공합니다〔p.7, Table 1; p.8, Table 2〕. [arXiv](https://arxiv.org/abs/2609.37200)

**[제 해석]** 이는 DiffusionNFT의 고정 가중치·수동 단계 전환을 확장하는 방향입니다. 일반화 향상을 위해서는 평균 보상만 높이는 대신 **보상 간 충돌과 약한 과제의 희생을 추적해야 한다**는 시사점이 있습니다. 다만 3회 반복 역시 충분히 큰 표본이라고 보기는 어렵습니다.

> **용어:** *보상 충돌*은 한 평가 기준을 좋게 만드는 업데이트가 다른 기준은 나쁘게 만드는 상황입니다. *라우팅*은 여기서는 학습 신호를 어떤 토큰이나 레이어에 더 많이 전달할지 정하는 것을 뜻합니다.

#### D. EMA가 필요한 이유에 대한 직접적 재해석

**[외부 저자 보고]** 2026년 10월 공개된 *DiffusionART: Efficient, Stable and Scalable Reinforcement of Diffusion Models*는 NFT의 실제 순방향·역방향 속도 차이 때문에 추가적인 일관성 보정 힘이 생기며, 긍정·부정 손실이 이를 완전히 상쇄하지 못한다고 분석합니다. 또한 EMA의 역할을 단순한 오프폴리시 수집보다 **지연된 참조 정책에 의한 복원 효과**로 해석하고, 별도의 안정화 방법을 제안합니다〔§3.1, Proposition 1; §4〕. [arXiv](https://arxiv.org/abs/2610.12572)

이 논문은 HunyuanVideo-13B에서 NFT의 후반 평균 보상 수준에 도달하는 GPU 시간을 12.02배 줄였다고 보고합니다. **[직접 비교 불가]** 이는 다른 모델·과제·보상에서 얻은 최신 저자 보고이며, 원논문의 SD3.5-Medium 기반 25배와 같은 기준의 수치가 아닙니다. [arXiv](https://arxiv.org/abs/2610.12572)

**[제 해석]** 이러한 후속 연구는 “순방향 학습이면 일관성과 안정성이 자동으로 해결된다”는 해석을 경계하게 합니다. 매우 최근의 결과이므로 독립 재현을 통해 적용 범위를 확인해야 합니다.

## 10. 결론과 후속 연구 방향

### 10.1 저자가 제시한 시사점

**[저자 결론]** DiffusionNFT는 긍정·부정 생성 결과의 대비를 표준 확산 학습에 결합함으로써, 우도 추정과 SDE 기반 역방향 최적화에 대한 의존을 줄입니다. 저자들은 이를 **확산 모델에서 지도학습과 강화학습을 통합하고, 여러 데이터 유형으로 확장 가능한 온라인·오프폴리시 학습을 만드는 방향**으로 제시합니다〔p.3; p.10, §6〕. 2509.16117v2 2509.16117v2

다만 논문에는 구체적인 후속 실험 일정이나 확정된 비디오·로봇 확장 계획이 상세히 제시되어 있지 않습니다. 이러한 방향을 저자가 실제로 수행하겠다고 약속한 계획과 동일시하면 안 됩니다.

### 10.2 일반화 향상을 위한 추가 연구 제안

**[제안 1: 가장 먼저 일반화 우월성을 직접 검증해야 합니다.]**  
같은 기본 모델과 보상, 동일한 GPU 예산에서 NFT·FlowGRPO·MixGRPO·AWM 및 강한 최종 샘플 기반 우도 추정 방법을 비교하는 것이 우선입니다. 테스트는 새로운 객체, 학습 범위를 넘는 개수, 새로운 속성 조합, 프롬프트 재표현, 다국어 OCR로 분리해야 합니다. 생성 솔버·CFG·생성 단계 수를 통제하지 않은 비교로는 방법 자체의 일반화 효과를 구별하기 어렵습니다.

평가 시에는 학습 시드와 프롬프트 양쪽의 변동을 고려한 신뢰구간을 보고해야 합니다. 같은 프롬프트에서 생성한 여러 이미지를 완전히 독립적인 표본처럼 취급하지 않는 것도 중요합니다. 이는 원논문에 없는, 제가 제안하는 검증 설계입니다.

**[제안 2: “새 능력 향상”과 “기존 능력 유지”를 동시에 목표로 삼아야 합니다.]**  
다중 보상 평균만 높이면 특정 과제가 희생될 수 있습니다. 따라서 학습 중 검증 집합에서는 각 능력의 하락을 별도로 감시하고, 보상 하나를 제외한 학습으로 그 보상에 대한 전이가 유지되는지도 시험해야 합니다. 최종 테스트는 튜닝에 사용하지 않은 채 남겨 두어야 합니다.

여기서 핵심은 **미사용 평가 모델의 점수 상승**, **새로운 입력에 대한 성공**, **다양성과 안전한 출력의 유지**를 각각 측정하는 것입니다. 이 세 가지를 하나의 “일반화 점수”로 뭉치면 실패 원인을 찾기 어렵습니다.

**[제안 3: 경험적 안정화 장치를 이론과 연결해야 합니다.]**  
유한 데이터, 제한된 LoRA 용량, 샘플링 오차, 보상 추정 오차를 포함한 분석이 필요합니다. 특히 $\beta$와 EMA 계수가 어떤 상황에서 안정성을 높이고 어떤 상황에서 학습을 지나치게 제한하는지를 분리해야 합니다. 앞의 분산 항등식처럼 보상이 모두 같아지는 경우에는 개선 신호가 사라지므로, 희소 보상 상황에서 데이터 수집의 다양성을 어떻게 유지할지도 연구해야 합니다.

**[제안 4: 계산 효율을 더 많은 보상 최적화가 아니라 더 넓은 학습 분포에 투자해야 합니다.]**  
절약한 계산량을 같은 벤치마크를 더 오래 최적화하는 데만 사용하면 평가기 과적합이 커질 수 있습니다. 대신 다양한 프롬프트·희귀 객체·새 언어·실패 유형을 수집하는 데 사용했을 때 일반화가 더 좋아지는지 비교하는 것이 유용합니다. 이는 이 논문의 효율적 학습 구조를 일반화 개선으로 연결하는 직접적인 연구 방향입니다.

> **용어:** *평가기 과적합*은 실제 품질보다 특정 자동 평가기의 점수를 잘 얻는 방향으로 모델이 특화되는 현상입니다. *희소 보상*은 대부분의 결과가 같은 낮은 점수를 받아 무엇을 개선해야 하는지 구분하기 어려운 상황입니다.

### 최종 판단

**DiffusionNFT가 강하게 뒷받침하는 것은 “보상에 따른 생성 모델의 적응을 훨씬 효율적으로 수행할 수 있다”는 주장입니다.**  
**일반화에 관해서는 “여러 보상을 함께 학습하면 일부 미사용 평가 보상과 다른 프롬프트 집합에서도 개선될 수 있다”까지가 현재 원논문의 증거에 부합합니다.**

따라서 후속 연구의 핵심 목표는 최고 보상 점수를 더 높이는 것만이 아니라, **그 개선이 새로운 입력·독립적인 평가·다른 모델에서도 유지되는지, 그리고 어떤 안정화 조건에서 유지되는지를 설명하는 것**이어야 합니다.
