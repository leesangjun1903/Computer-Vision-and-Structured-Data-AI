## 1. Executive summary — 핵심 8문장

1. **PixelDiT의 목적은 별도로 학습된 영상 압축·복원 모델 때문에 발생하는 세부 정보 손실과 학습 목표의 불일치를 줄이면서, 원본 픽셀에서 직접 고품질 영상을 생성하는 것입니다.** [pp. 1–2, Abstract·Introduction] 2511.20645v2

2. 이를 위해 전체 배치와 객체 의미를 처리하는 **패치 수준 경로**와 질감·경계의 세부 표현을 처리하는 **픽셀 수준 경로**를 결합한 이중 수준 Transformer 구조를 제안합니다. [p. 3, Figure 2] 2511.20645v2

3. 핵심 기술은 각 픽셀에 서로 다른 조건을 전달하는 특징 조절 방식과, 픽셀 토큰을 잠시 압축해 전역 상호작용을 계산한 뒤 다시 확장하는 방식이며, 압축 없는 비교 모델의 계산량 82,247 GFLOPs를 전체 PixelDiT의 311 GFLOPs 수준으로 줄입니다. [pp. 4–5, Figure 3; p. 9, Table 6] 2511.20645v2 2511.20645v2

4. 저자들은 주요 설정에서 ImageNet $256\times256$과 $512\times512$의 생성 FID를 각각 **1.61과 1.81**로 보고하며, 부록의 장기 학습에서는 $256\times256$ FID가 **1.54**까지 개선됩니다. [pp. 5–6, Tables 1–2; p. 17, Table 17] 2511.20645v2 2511.20645v2 2511.20645v2  
   > **용어:** FID는 실제 영상과 생성 영상의 특징 분포가 얼마나 다른지 측정하는 지표로, 낮을수록 좋지만 사람의 만족도나 미지의 환경에서의 성능을 직접 뜻하지는 않습니다. [arXiv](https://arxiv.org/abs/2310.11513)

5. 약 13억 매개변수의 텍스트-이미지 모델은 $1024\times1024$에서 **GenEval 0.74, DPG-Bench 83.5**를 달성하지만, 이 결과는 다른 모델과 학습 데이터·학습량까지 동일하게 통제한 비교는 아닙니다. [pp. 6–7, Table 4; p. 12, Table 8] 2511.20645v2 2511.20645v2  
   > **용어:** GenEval은 객체 수·색·위치 등의 지시 이행을, DPG-Bench는 여러 객체·속성·관계가 포함된 복잡한 문장에 대한 영상의 대응성을 평가합니다. [arXiv](https://arxiv.org/abs/2310.11513)

6. 편집 실험에서도 정성적 예시만 제시한 것이 아니라 281개 FlowEdit 사례에서 배경 보존을 평가했으며, PixelDiT의 배경 평균제곱오차는 FLUX보다 약 **6배 낮았습니다**. [p. 1, Figure 1b; p. 16, Table 14] 2511.20645v2

7. 다만 좋은 성능은 구조만의 성과가 아니라 사전학습된 시각 모델의 특징을 학습에 활용하는 방식에도 크게 의존하며, 해상도를 높였을 때 객체 수와 위치 관련 점수가 낮아지는 등 구성적 이해의 한계가 남아 있습니다. [p. 14, Tables 10–11] 2511.20645v2 2511.20645v2

8. 따라서 이 논문의 가장 설득력 있는 기여는 **픽셀 공간 생성의 실용적인 구조 설계와 세부 정보 보존**이고, 모든 픽셀 생성 모델에 대한 절대적 우월성이나 미지의 도메인에 대한 일반화까지 입증했다고 해석해서는 안 됩니다. [pp. 7, 17, 19; 외부 SiD2 원문 p. 7, Table 2] 2511.20645v2 2511.20645v2 [arXiv](https://arxiv.org/pdf/2410.19324)

## 3. 연구의 목적과 필요성

### 3.1 저자들이 해결하려는 두 가지 문제

**[저자 보고] 첫째는 잠재 공간 생성의 구조적 제약입니다.** 기존 잠재 확산 모델은 영상을 압축하는 오토인코더와 압축된 표현에서 생성 과정을 학습하는 모델을 결합합니다. 저자들은 이때 압축·복원 목표와 생성 목표가 완전히 일치하지 않고, 작은 글자나 세밀한 질감이 복원 단계에서 손실될 수 있다고 지적합니다. [p. 2, Introduction; p. 3, §2.1] 2511.20645v2 2511.20645v2

> **용어:** *잠재 공간(latent space)*은 원본 영상을 더 작은 특징 배열로 표현한 공간입니다. *오토인코더*는 영상을 압축하고 복원하도록 학습한 모델이며, *VAE*는 그 압축 표현에 확률적 제약을 부여하는 오토인코더의 한 종류입니다. *고주파 정보*는 작은 글자, 날카로운 경계, 촘촘한 질감처럼 위치에 따라 빠르게 변하는 영상 정보를 말합니다.

**[저자 보고] 둘째는 픽셀 공간에서의 계산 비용입니다.** 픽셀 하나를 토큰 하나로 취급해 모든 위치 사이의 관계를 직접 계산하면 비용이 매우 커집니다. 반대로 큰 패치로만 처리하면 세밀한 픽셀 변화의 학습이 어려워진다는 것이 저자들의 문제 설정입니다. [pp. 2–3, §1·§2.2] 2511.20645v2 2511.20645v2

> **용어:** *토큰*은 Transformer가 처리하는 기본 특징 단위입니다. 영상에서 *패치*는 일정 크기의 작은 사각형 영역이고, *attention*은 한 토큰이 다른 토큰의 정보를 얼마나 참고할지 계산하는 연산입니다.

### 3.2 이 문제 설정에서 구분해야 할 것

**[검토 해석] PixelDiT가 없애는 것은 ‘별도로 학습된 영상 복원 병목’이지 모든 종류의 내부 압축이 아닙니다.** 실제 모델 내부에는 패치화와 토큰 압축이 존재합니다. 또한 VAE의 복원 오류가 존재한다는 사실만으로 생성 FID에 어떤 엄밀한 하한이 생긴다고 증명한 것은 아닙니다. 논문이 설득력 있게 보여주는 것은 **특정 세부 정보가 생성·편집 이전에 이미 손실되는 경로를 피할 수 있다**는 점입니다. [p. 5, Pixel Token Compaction; p. 1, Figure 1b] 2511.20645v2 2511.20645v2

또한 전역 의미와 질감의 ‘분리’는 **모델의 역할을 나누는 설계 원칙**입니다. 두 경로가 실제로 의미와 주파수 정보를 완전히 분리한다는 이론적 증명이나 명시적인 주파수 분해가 제시된 것은 아닙니다. [pp. 3–4, §3.1] 2511.20645v2 2511.20645v2

## 4. 제안 방법: 수식과 모델 구조

### 4.1 생성 과정과 학습 목표

**[저자 보고] PixelDiT는 픽셀 공간에서 Rectified Flow의 속도를 예측합니다.** 새 확률적 생성 원리를 제안하기보다는, 기존의 흐름 학습 목표를 효과적으로 구현하는 영상 모델 구조를 제안한 연구입니다. 원문의 핵심 생성 손실은 다음과 같습니다. [p. 5, Eq. (8)] 2511.20645v2

```math
\mathcal{L}_{\text{diff}}
=
\mathbb{E}_{t,x,\varepsilon}
\left[
\left\|
f_\theta(x_t,t,y)-v_t
\right\|_2^2
\right].
```

**기호 설명:** $x$는 깨끗한 학습 영상, $\varepsilon$는 잡음, $t$는 생성 과정의 시간 또는 잡음 수준, $x_t$는 해당 시점의 중간 영상, $y$는 클래스 또는 텍스트 조건, $v_t$는 목표 속도, $f_\theta$는 매개변수 $\theta$를 가진 PixelDiT의 속도 예측값입니다. $\mathbb{E}$는 여러 학습 사례에 대한 평균이고, $\|\cdot\|_2^2$는 오차 제곱의 합입니다.

> **용어:** *Rectified Flow*는 잡음 분포에서 영상 분포로 이동하는 방향, 즉 ‘속도장’을 학습하는 생성 방법입니다. 여기서 속도는 물리적 물체의 이동 속도가 아니라 영상의 각 픽셀값이 어떻게 변해야 하는지를 뜻합니다. [arXiv](https://arxiv.org/abs/2209.03003)

**[이해를 위한 보충 수식]** 원문 Eq. (8)은 $x_t$와 $v_t$의 세부 정의를 모두 풀어 쓰지 않습니다. 이를 설명하기 위해 잡음이 $t=0$, 깨끗한 영상이 $t=1$인 표준 선형 경로를 사용하면 다음처럼 쓸 수 있습니다.

$$
x_t=(1-t)\varepsilon+tx,
\qquad
\varepsilon\sim\mathcal{N}(0,I),
\qquad
v_t=x-\varepsilon.
$$

**기호 설명:** $\mathcal{N}(0,I)$는 평균 0, 단위 공분산의 가우시안 잡음 분포입니다. 이 시간 방향은 설명을 위해 명시한 것으로, 원래 PixelDiT의 별도 번호가 붙은 식은 아닙니다. 동일한 시간 방향의 표현은 후속 PixelDiT2의 Eq. (1)에서도 명시적으로 사용됩니다. [arXiv](https://arxiv.org/html/2609.24919v2)

### 4.2 전체 구조: 큰 패치로 의미를, 작은 특징으로 픽셀을 처리

*첨부 논문 p. 3, Figure 2 발췌.* 2511.20645v2

**[저자 보고]** 동일한 잡음 영상이 두 경로로 들어갑니다. 패치 경로는 긴 범위의 관계를 학습하고, 픽셀 경로는 그 의미 정보를 조건으로 받아 최종 픽셀 수준 예측을 만듭니다. 두 모델을 따로 학습해 순서대로 붙이는 것이 아니라, **하나의 생성 모델 내부에 역할이 다른 경로를 구성한 것**입니다. [pp. 3–4, Figure 2·§3.1] 2511.20645v2 2511.20645v2

#### 패치 토큰과 조건 벡터

원문 Eq. (1)–(2)를 쓰되, 시간값과 시간 임베딩의 혼동을 피하기 위해 임베딩을 $e_t,e_y$로 명시하면 다음과 같습니다.

$$
L=\frac{H}{p}\frac{W}{p},
\qquad
s_0=W_{\text{patch}}x_{\text{patch}},
$$

$$
c=\text{SiLU}(W_t e_t+W_y e_y+b).
$$

**기호 설명:** $H,W$는 영상 높이와 너비, $p$는 패치 한 변의 크기, $L$은 패치 수입니다. $x_{\text{patch}}$는 각 $p\times p$ 영역을 펼친 입력이고, $s_0\in\mathbb{R}^{B\times L\times D}$는 초기 패치 특징입니다. $B$는 배치 크기, $D$는 패치 특징 차원, $W_{\text{patch}},W_t,W_y$와 $b$는 학습되는 변환과 편향이며, $c$는 조건 벡터입니다. [pp. 3–4, Eq. (1)–(2)] 2511.20645v2 2511.20645v2

> **용어:** *임베딩*은 시간·클래스·텍스트 같은 입력을 신경망이 사용할 수 있는 숫자 벡터로 바꾸는 것입니다. *SiLU*는 벡터를 비선형적으로 변환하는 활성화 함수입니다.

#### 패치 수준 Transformer 블록

원문의 Eq. (3)–(5)는 정규화, 조건에 따른 특징 조절, attention, 작은 전결합 신경망을 결합합니다. 중간 변수를 $u_i$로 구분해 동등하게 정리하면 다음과 같습니다.

$$
\tilde{s}_i=\text{RMSNorm}(s_i),
$$

```math
u_i
=
s_i+
\alpha_1(c)\odot
\text{Attn}
\left(
\gamma_1(c)\odot\tilde{s}_i+\beta_1(c);
\text{RoPE}
\right),
```

```math
s_{i+1}
=
u_i+
\alpha_2(c)\odot
\text{MLP}
\left(
\gamma_2(c)\odot\text{RMSNorm}(u_i)+\beta_2(c)
\right).
```

**기호 설명:** $s_i$는 $i$번째 블록의 입력, $u_i$는 attention 이후 특징입니다. $\gamma$는 특징의 크기를 조절하고, $\beta$는 값을 이동시키며, $\alpha$는 새 정보의 반영 정도를 조절합니다. $\odot$는 원소별 곱입니다. 이 경로에서는 동일한 조건에서 생성한 조절값을 모든 패치에 공통으로 적용합니다. [p. 4, Eq. (3)–(5)] 2511.20645v2

> **용어:** *RMSNorm*은 특징의 크기를 정규화하는 연산입니다. *RoPE*는 attention 계산에 위치 관계를 반영하는 위치 표현 방식입니다. *MLP*는 여러 전결합층으로 구성된 작은 신경망이고, *gate*는 새 정보가 기존 특징에 얼마나 더해질지 결정하는 장치입니다.

### 4.3 Pixel-wise AdaLN: 같은 패치 안에서도 픽셀마다 다른 조건 전달

**[저자 보고]** 패치 경로의 최종 출력으로 픽셀 경로의 조건을 만듭니다.

$$
s_{\text{cond}}=s_N+e_t.
$$

**기호 설명:** $N$은 패치 경로의 블록 수이며, $s_N$은 최종 의미 특징, $e_t$는 시간 임베딩입니다. 한편 픽셀 경로에서는 각 픽셀을 $D_{\text{pix}}$차원 특징으로 변환합니다. 기본값은 $D_{\text{pix}}=16$입니다. [p. 4, §3.1·Eq. (6)] 2511.20645v2

픽셀들을 패치별로 묶으면 특징 배열은 다음 모양이 됩니다.

$$
X\in
\mathbb{R}^{(B L)\times p^2\times D_{\text{pix}}}.
$$

의미 토큰으로부터 픽셀별 조절값을 생성하는 원문 Eq. (7)은 다음과 같습니다.

$$
\Theta=\Phi(s_{\text{cond}})
\in
\mathbb{R}^{(B L)\times p^2\times 6D_{\text{pix}}},
$$

```math
\Theta
=
(\beta_1,\gamma_1,\alpha_1,\beta_2,\gamma_2,\alpha_2).
```

**기호 설명:** $X$는 픽셀 특징, $\Phi$는 학습되는 조절값 생성 변환, $\Theta$는 그 출력입니다. 각 픽셀마다 attention 부분과 MLP 부분에 사용할 이동·크기·gate 값이 각각 생성되므로 총 여섯 묶음입니다. [p. 4, Eq. (6)–(7), Figure 3] 2511.20645v2

> **용어:** *AdaLN*은 조건에 따라 정규화된 특징의 크기와 위치를 조절하는 방식입니다. *Pixel-wise*는 같은 패치 안에서도 각 픽셀에 다른 조절값을 준다는 뜻입니다.

**[검토 해석]** 핵심은 단순히 ‘픽셀을 더 많이 처리한다’가 아니라 **전역 의미 정보를 픽셀 위치별로 다르게 해석하게 한다**는 점입니다. 다만 픽셀별 조절값은 모두 의미 토큰에서 생성되므로, 각 픽셀이 완전히 독립적인 의미 추론기를 갖는 것은 아닙니다. [p. 4, Figure 3·Eq. (7)] 2511.20645v2 2511.20645v2

### 4.4 Pixel Token Compaction: 압축된 토큰끼리 전역 attention

**[저자 보고]** 각 패치의 $p^2$개 픽셀 특징을 하나의 벡터로 압축하고, 패치 사이의 attention을 계산한 뒤 다시 픽셀 특징으로 확장합니다.

$$
\mathcal{C}:
\mathbb{R}^{p^2D_{\text{pix}}}
\rightarrow
\mathbb{R}^{D},
\qquad
\mathcal{E}:
\mathbb{R}^{D}
\rightarrow
\mathbb{R}^{p^2D_{\text{pix}}}.
$$

**기호 설명:** $\mathcal{C}$는 학습되는 압축 변환이고, $\mathcal{E}$는 학습되는 확장 변환입니다. attention은 압축 후 한 영상의 $L$개 토큰을 대상으로 수행됩니다. [p. 5, Pixel Token Compaction] 2511.20645v2

Figure 2의 PiT 블록을 설명용 수식으로 정리하면 다음과 같습니다. **이 식은 도식과 본문을 결합해 재표현한 것이며 원문의 별도 번호가 붙은 식은 아닙니다.**

```math
A
=
\gamma_1\odot\text{RMSNorm}(X)+\beta_1,
```

```math
X'
=
X+
\alpha_1\odot
\mathcal{E}
\left[
\text{Attn}
\left(
\mathcal{C}(A);
\text{RoPE}
\right)
\right],
```

```math
X_{\text{out}}
=
X'
+
\alpha_2\odot
\text{FFN}
\left(
\gamma_2\odot\text{RMSNorm}(X')+\beta_2
\right).
```

**기호 설명:** $A$는 조건 조절 이후 특징, $X'$는 attention 부분을 통과한 특징, $X_{\text{out}}$은 블록 출력입니다. 조절값은 앞의 $\Theta$에서 오며, FFN은 픽셀 특징에 적용되는 전결합 신경망입니다. [p. 3, Figure 2; pp. 4–5, §3.2] 2511.20645v2 2511.20645v2

#### 계산량이 줄어드는 이유

전체 픽셀 수를 $n=HW$라고 하면 attention 토큰 수는 다음처럼 줄어듭니다.

$$
n\rightarrow L=\frac{n}{p^2}.
$$

같은 attention 특징 차원을 가정할 때, 토큰 쌍의 수에 해당하는 이차항의 감소 비율은 다음과 같습니다.

$$
\frac{n^2}{L^2}=p^4.
$$

**기호 설명:** $n$은 픽셀 토큰 수, $L$은 압축된 토큰 수입니다. $p=16$이면 토큰 수는 256분의 1, attention의 토큰 쌍 수는 65,536분의 1이 됩니다. 이는 **attention의 이차항에 관한 계산이지 전체 모델이 65,536배 빨라진다는 뜻은 아닙니다.** 실제 전체 모델의 보고 계산량 차이는 Table 6에서 약 264배입니다. [p. 9, §4.5.2·Table 6] 2511.20645v2

#### ‘세부 정보 보존’은 무손실 압축의 증명인가?

**[저자 보고]** 저자들은 잔차 연결이 압축 경로를 우회하므로 고주파 정보를 보존할 수 있다고 설명합니다. [p. 5] 2511.20645v2

**[검토 해석]** 이는 중요한 설계이지만, $\mathcal{E}$가 $\mathcal{C}$의 정확한 역함수라는 뜻은 아닙니다. 예를 들어 기본 XL 설정에서는 패치당 $256\times16=4096$차원 특징을 1152차원으로 압축하므로, 압축 변환만으로 임의의 입력을 모두 구분하는 것은 불가능합니다. 다만 **압축되지 않은 픽셀 특징이 잔차 경로에 남아 있기 때문에 전체 계산이 그 압축 결과에만 의존하지 않는 것**입니다. [p. 5, 압축 정의; p. 6, Table 3] 2511.20645v2 2511.20645v2

> **용어:** *잔차 연결(residual connection)*은 변환된 특징에 입력 특징을 직접 더하는 우회 경로입니다. 정보가 복잡한 변환을 거치지 않고 다음 층으로 전달될 수 있게 합니다.

### 4.5 REPA: 외부 시각 지식을 학습에 활용

**[저자 보고]** 최종 학습 목표에는 생성 손실 외에 표현 정렬 손실이 추가됩니다.

```math
\mathcal{L}
=
\mathcal{L}_{\text{diff}}
+
\lambda_{\text{repa}}\mathcal{L}_{\text{repa}}.
```

**기호 설명:** $\mathcal{L}\_{\text{repa}}$는 PixelDiT의 중간 패치 특징을 고정된 DINOv2의 특징과 가깝게 만드는 손실이고, $\lambda_{\text{repa}}$는 그 영향력입니다. ImageNet에서는 패치 경로의 8번째 블록에 적용하고 가중치를 0.5로 설정합니다. [pp. 5–6, §3.4·§4.1] 2511.20645v2 2511.20645v2

> **용어:** *REPA*는 생성 모델의 내부 특징을 좋은 시각 표현에 맞추는 학습 기법입니다. *DINOv2*는 사람의 클래스 정답 없이 시각 특징을 학습한 사전학습 모델이며, 여기서 ‘고정’은 PixelDiT 학습 중 그 모델의 가중치를 바꾸지 않는다는 뜻입니다.

**[외부 원문에 근거한 보충]** PixelDiT는 정렬 손실의 상세식을 재기재하지 않으므로, REPA 원문의 일반식을 PixelDiT의 기호에 맞춰 설명하면 다음과 같습니다.

```math
\mathcal{L}_{\text{repa}}
=
-
\mathbb{E}
\left[
\frac{1}{L}
\sum_{\ell=1}^{L}
\text{sim}
\left(
d_\ell(x),
q_\psi(s_\ell^{(k)}(x_t))
\right)
\right].
```

**기호 설명:** $d_\ell(x)$는 깨끗한 영상에서 얻은 교사 모델의 대응 위치 특징, $s_\ell^{(k)}(x_t)$는 PixelDiT의 $k$번째 블록 특징, $q_\psi$는 특징 차원을 맞추는 학습 변환, $\text{sim}$은 유사도 함수입니다. **이것은 REPA 원문의 원리를 풀어 쓴 식이며, 첨부 논문이 공간 정렬·투영 구현의 모든 세부사항을 명시한 것은 아닙니다.** [외부 REPA §3.3, Eq. (8)] [arXiv](https://arxiv.org/html/2410.06940v2)

중요한 예외도 있습니다. **텍스트-이미지 모델은 $512^2$ 학습에서 6번째 블록에 REPA를 적용하지만, $1024^2$ 미세조정에서는 가중치를 0으로 두어 사용하지 않습니다.** 따라서 REPA를 ‘모든 단계에서 반드시 필요한 기술’이라고 일반화하면 부정확합니다. [p. 12, Table 8] 2511.20645v2

**[검토 해석]** 이 구조는 픽셀 경로를 단순하게 유지하지만, 패치 경로가 객체 수나 관계를 잘못 해석하면 픽셀 경로가 그 오류를 독립적으로 바로잡기 어려울 가능성이 있습니다. 이는 구조에서 도출한 가설이며, 논문이 직접 검증한 결론은 아닙니다.

> **용어:** *iteration*은 한 번의 매개변수 갱신 단계입니다. 같은 iteration 수라도 한 번에 처리하는 데이터 수인 배치 크기가 다르면 실제 학습량이 다릅니다. *fp16*은 계산에 사용하는 숫자의 정밀도 형식입니다.

**[검토 해석]** 이 실험은 ‘픽셀 공간에서 1K 텍스트-이미지 학습이 가능하다’는 강한 근거입니다. 하지만 **512에서 배운 모델이 추가 학습 없이 1024로 일반화한다는 근거는 아니며**, 점수 변화도 해상도 하나의 인과적 효과로 해석할 수 없습니다. 해상도뿐 아니라 학습 단계와 설정이 함께 달라지기 때문입니다.

## 6. 통계적으로 취약한 부분과 직접 비교가 어려운 수치

### 6.1 평가 설계의 취약점

| 표시 | 문제 | 왜 중요한가 | 관련 위치 |
|---|---|---|---|
| **통계 미검증** | 핵심 표에 반복 학습 평균·표준편차·신뢰구간이 없습니다. | 5만 장을 생성해도 학습 초기값이나 데이터 순서에 따른 변동까지 확인되는 것은 아닙니다. | Tables 1–2, 4, 11, 14 |
| **선택 편향 가능성** | CFG 크기와 적용 구간을 바꾸어 최적 보고값을 선택합니다. | 별도 검증용 데이터에서 조정했는지 명확하지 않아 평가 지표에 대한 과도한 튜닝 가능성을 배제하기 어렵습니다. | p. 14, Table 9 2511.20645v2 |
| **조건 상이** | 매개변수 수·epoch·사전학습 자원·샘플러가 다릅니다. | 같은 FID 비교가 곧 같은 비용에서의 구조 비교는 아닙니다. | Tables 1, 4, 15; pp. 6–7 |
| **측정 범위 제한** | GFLOPs는 주로 한 번의 forward pass이고, 처리량은 특정 장비·정밀도에서 측정됩니다. | 전체 학습 비용, 외부 모델 비용, 샘플링 호출 수를 모두 포함하는 값과 구분해야 합니다. | pp. 16–17, §E; p. 7 2511.20645v2 |
| **편집 평가 불완전** | 배경 보존과 편집 의도 달성의 공동 평가가 부족합니다. | 덜 편집한 결과와 정확하게 편집하면서 보존한 결과를 구분해야 합니다. | p. 16, Table 14 |
| **부정적 결과의 통제 부족** | 실패한 시도들이 모두 완전히 통제된 설정은 아니라고 저자들이 명시합니다. | 특정 방법이 본질적으로 나쁘다는 일반 결론을 내릴 수 없습니다. | p. 17, §G 2511.20645v2 |

> **용어:** *신뢰구간*은 측정값의 불확실성을 표현하는 범위입니다. *선택 편향*은 여러 설정을 시험한 뒤 가장 좋은 값만 보고할 때 실제 성능보다 낙관적인 인상을 줄 수 있는 문제입니다.

FID 자체의 유한 표본 편향도 고려해야 합니다. Chong·Forsyth는 FID와 IS의 편향이 모델별로 다를 수 있어 **표본 수를 같게 만드는 것만으로 문제가 모두 해결되지 않는다**고 보였습니다. 따라서 1.61 대 1.65 같은 작은 차이를 검증 없이 확정적인 우열로 읽어서는 안 됩니다. [외부 「Effectively Unbiased FID and Inception Score and Where to Find Them」] [arXiv](https://arxiv.org/abs/1911.07023)

### 6.2 특히 중요한 비교상의 문제 세 가지

#### A. “기존 픽셀 생성 모델을 모두 능가한다”는 표현은 과도하다

PixelDiT 본문은 SiD2의 $256^2$ FID **1.38**을 언급하면서 일부 비교 정보가 부족하다는 이유로 Table 1에서 제외합니다. 그러나 SiD2 원문의 Table 2는 $256^2$에서 **1.38**, $512^2$에서 **1.48**을 보고합니다. 두 수치는 PixelDiT의 주요 결과 1.61·1.81보다 낮습니다. [PixelDiT p. 7; SiD2 p. 7, Table 2] 2511.20645v2 [arXiv](https://arxiv.org/pdf/2410.19324)

**판정:** PixelDiT가 여러 강한 비교 모델보다 좋은 **품질-계산량 균형**을 보여준다는 주장은 가능하지만, 픽셀 모델 전체에서 최저 FID라는 주장은 성립하지 않습니다. 반대로 SiD2의 더 낮은 FID만으로 SiD2가 동일 비용에서도 더 낫다고 단정할 수는 없습니다.

#### B. $512^2$ 비교에서 JiT의 더 큰 모델이 빠져 있다

PixelDiT Table 2에는 JiT-H의 FID **1.94**가 실려 있지만, JiT v2 원문의 Table 6에는 더 큰 JiT-G의 **1.78**도 존재합니다. [PixelDiT p. 6, Table 2; JiT v2 Table 6] 2511.20645v2 [arXiv](https://arxiv.org/html/2511.13720v2)

**판정:** 비교 대상 크기가 다르므로 1.78과 1.81은 동등 자원 실험이 아니지만, “모든 이전 픽셀 모델보다 우수하다”는 포괄적 표현에는 추가 제한이 필요합니다.

#### C. PixNerd 수치는 서로 다른 조건의 값이 섞여 있다

PixelDiT의 Table 1은 PixNerd를 **320 epoch, FID 1.93**으로 제시하지만, Table 15에는 **FID 2.15**가 등장합니다. PixNerd 원문은 **160 epoch, 100단계 Euler 샘플링에서 2.15**를 보고합니다. [PixelDiT pp. 5, 17; PixNerd Table 2] 2511.20645v2 2511.20645v2 [arXiv](https://arxiv.org/html/2507.23268v2)

**판정:** 반드시 오기라고 단정할 수는 없고 다른 체크포인트일 가능성이 있습니다. 다만 첨부 논문에서 두 값의 대응 관계를 명확히 설명하지 않으므로, **1.93의 품질과 2.15에 대응하는 설정의 계산량을 임의로 합쳐 하나의 공정한 비교점으로 만들면 안 됩니다.**

추가로 RAE의 1.13은 AutoGuidance를 사용한 결과이며, RAE 원문은 클래스별 생성 수를 정확히 같게 하는지 여부에 따라 FID가 약 0.1 달라질 수 있음을 보고합니다. 따라서 여러 논문의 소수 둘째 자리까지 나열한 순위에는 평가 절차 차이도 들어갈 수 있습니다. [외부 RAE §5, Tables 7–8] [arXiv](https://arxiv.org/html/2510.11690v1)

> **용어:** *AutoGuidance*는 별도의 더 약한 생성 모델을 이용해 주 생성 모델을 안내하는 방식으로, 같은 모델의 조건 유무를 활용하는 CFG와 구분됩니다.

> **용어:** *신경장(neural field)*은 위치 좌표와 조건을 입력받아 픽셀값이나 그 변화량을 출력하는 신경망입니다. *U자형 구조*는 공간 크기를 줄였다가 다시 복원하면서 중간 특징을 우회 전달하는 구조입니다.

### 8.2 가장 중요한 방법론적 쟁점: ‘무엇을 예측하는가’

**[외부 연구 보고]** JiT는 자연 영상이 고차원 픽셀 공간 안의 상대적으로 낮은 차원 구조를 따른다는 가정 아래, 잡음이나 속도보다 **깨끗한 영상 $x$를 직접 예측하는 것이 제한된 모델 용량에 유리할 수 있다**고 주장합니다. [JiT Figures 1–2, §§3–4] [arXiv](https://arxiv.org/html/2511.13720v2)

> **용어:** *다양체 가정(manifold assumption)*은 가능한 픽셀 조합은 매우 많지만 자연스러운 영상이 차지하는 유효한 변화의 자유도는 훨씬 작다는 가정입니다. 이는 모델 설계를 설명하는 가정이지 모든 영상 데이터에 대해 증명된 사실은 아닙니다.

앞서 사용한 선형 경로에서 깨끗한 영상 예측을 $\hat{x}_\theta$라고 하면, 속도는 다음처럼 얻습니다.

```math
\hat{v}_\theta
=
\frac{\hat{x}_\theta-x_t}{1-t},
\qquad t < 1.
```

따라서 분모를 자르는 안정화 처리가 없는 경우에는 다음 관계가 성립합니다.

```math
\left\|
\hat{v}_\theta-(x-\varepsilon)
\right\|_2^2
=
\frac{
\left\|\hat{x}_\theta-x\right\|_2^2
}{
(1-t)^2
}.
```

**기호 설명:** $\hat{x}\_\theta$는 깨끗한 영상 예측, $\hat{v}_\theta$는 그로부터 계산한 속도입니다. 두 번째 식은 앞의 선형 경로에서 도출되는 대수적 관계입니다. 실제 구현에서는 $t$가 1에 가까울 때 분모가 너무 작아지지 않도록 임계값을 적용할 수 있습니다. [JiT §3; PixelDiT2 Eq. (2)–(3)] [arXiv](https://arxiv.org/html/2511.13720v2)

**[검토 해석]** 손실을 대수적으로 연결할 수 있다고 해서 제한된 신경망이 두 목표를 똑같이 쉽게 학습한다는 뜻은 아닙니다. 따라서 PixelDiT의 픽셀 경로가 개선하는 것이 ‘픽셀 생성의 보편적 어려움’인지, ‘직접 속도 예측에서 특히 발생하는 어려움’인지 분리하는 실험이 중요합니다.

원래 PixelDiT도 $x$-prediction을 시험해 손실 급등을 줄일 수 있었지만, 해당 설정에서는 직접 속도 예측보다 좋지 않았다고 보고합니다. 동시에 시간 샘플링과 안정화 임계값의 추가 조정이 필요하다고 명시합니다. [p. 18, §G.3] 2511.20645v2

**따라서 “ $x$ -prediction은 PixelDiT에 효과가 없다”가 아니라 “원문에서 시험한 설정에서는 우월하지 않았다”가 정확한 결론입니다.**

### 8.3 PixelDiT2가 보여주는 후속 발전

**[후속 논문 저자 보고]** PixelDiT2는 고정된 DINOv3에서 현재 잡음 영상의 특징을 얻고, 시간에 따라 조정한 뒤 공간별 조건으로 전달합니다. 원문의 Eq. (4)–(5)를 합치면 다음과 같습니다.

$$
g_t=P_g\bigl(\mathcal{E}_{\text{vision}}(x_t),t\bigr).
$$

**기호 설명:** $\mathcal{E}_{\text{vision}}$은 고정된 시각 인코더, $P_g$는 시간 조건부 변환, $g_t$는 생성 모델에 전달하는 공간적 특징입니다.  
원래 PixelDiT의 REPA 교사는 학습 목표를 제공하지만, PixelDiT2의 이 인코더는 **샘플링 중에도 실행**됩니다. [PixelDiT2 §3.2, Eq. (4)–(5)] [arXiv](https://arxiv.org/html/2609.24919v2)

후속 논문은 $256^2$ 600 epoch에서 FID 1.46, $512^2$ 680 epoch에서 1.48을 보고합니다.  
다만 모델 크기와 구조가 바뀌었으므로 이것을 원래 PixelDiT와 동일 비용에서의 순수 개선으로 해석해서는 안 됩니다. [PixelDiT2 Tables 2–3] [arXiv](https://arxiv.org/html/2609.24919v2)

**[검토 해석]** 이 후속 결과가 주는 중요한 메시지는 **“영상 복원용 잠재 병목을 없애는 것”과 “좋은 사전학습 표현을 활용하는 것”은 양립할 수 있다**는 점입니다. 그러나 더 낮은 ImageNet FID만으로 미지 도메인 일반화까지 확인된 것은 아닙니다.

## 9. 모델의 일반화 성능 향상 가능성

### 9.1 먼저 ‘일반화’를 나누어 평가해야 한다

**[검토 해석]** PixelDiT에서 가장 중요한 구분은 **학습한 분포 안에서 좋은 영상을 만드는 능력**과 **훈련에서 접하지 못한 조건에서도 잘 작동하는 능력**입니다. 논문의 평가 범위는 전자와 일부 구성적 지시 이행, 편집 보존에 집중되어 있습니다. [pp. 6–7, §4.1; pp. 14–16, Tables 10–14] 2511.20645v2 2511.20645v2

| 일반화의 종류 | 논문에서 확인되는 근거 | 아직 확인되지 않은 부분 |
|---|---|---|
| **학습 분포 내 생성** | ImageNet FID·Precision·Recall 개선 | 새로운 데이터 분포에서도 같은 개선이 유지되는지 |
| **구성적 일반화** | GenEval의 객체 수·위치·색 대응 평가 | 훈련에서 배제한 객체-속성-관계 조합의 성공률 |
| **해상도 일반화** | 여러 해상도에서 학습·미세조정한 결과 | 추가 학습 없는 미지 해상도·극단적 종횡비 성능 |
| **도메인 일반화** | 다양한 정성적 이미지 예시 | 의료·위성·과학 영상 등 다른 도메인에 대한 체계적 평가 |
| **편집 일반화** | FlowEdit 281개 사례의 배경 보존 | 편집 성공률을 맞춘 상태의 비교, 복잡한 다중 객체 편집, 다양한 문자 체계 보존 |

> **용어:** *구성적 일반화*는 배운 요소를 새로운 조합으로 처리하는 능력입니다. *도메인 일반화* 또는 *OOD 일반화*는 학습 데이터와 성격이 다른 영상·환경에서도 성능이 유지되는 능력입니다.

### 9.2 향상을 기대할 수 있는 이유와 반대 가능성

**첫째, 세부 정보의 불필요한 손실을 줄일 수 있습니다.**

**둘째, 전역 의미와 국소 묘사의 역할 분담이 새로운 조합에 유리할 수 있습니다.**  
**[가능성]** 같은 객체 의미를 다른 질감·배경과 결합하기 쉬운 구조일 수 있습니다. 반대로 잘못된 객체 수나 공간 관계가 패치 의미 토큰에 들어가면, 픽셀 경로는 그 오류를 정교하게 묘사하는 데 그칠 수 있습니다. 특히 Table 10의 객체 수·위치 점수는 이 가능성을 검증해야 할 이유입니다. [p. 14, Table 10] 2511.20645v2

**[가능성]** REPA의 큰 성능 기여는 좋은 시각 표현을 활용하는 것이 중요하다는 근거입니다. 하지만 자연 영상에 강한 교사가 전문 도메인에서도 적합하다는 보장은 없으므로, 교사 선택이나 정렬 강도가 오히려 특정 도메인에 편향을 줄 가능성도 시험해야 합니다. [p. 14, Table 11] 2511.20645v2

| 우선 연구 방향 | 권장 실험 | 판단할 핵심 결과 |
|---|---|---|
| **구조·예측 목표·외부 지식의 기여 분리** | 이중 경로/단일 경로 × 속도/깨끗한 영상 예측 × REPA 유무를 같은 데이터와 계산 예산에서 비교합니다. | 어떤 요소가 실제 일반화 개선에 기여하는지 분리합니다. |

| **해상도·패치 경계 일반화** | 학습하지 않은 해상도와 종횡비, 패치 경계에 걸친 작은 글자·가는 선을 평가합니다. | 고정 패치 구조의 경계 오류와 해상도 확장 오류를 분리합니다. |
| **편집 보존과 편집 성공의 공동 평가** | 동일 프롬프트·초기 잡음·편집 영역을 사용하고, 편집 성공 수준을 맞춘 뒤 배경·글자·객체 정체성 보존을 비교합니다. | 단순히 덜 바꿔서 점수가 좋은 경우를 배제합니다. |
| **통계적 재현성과 전체 비용** | 여러 학습 초기값, 프롬프트 단위 재표집, 전체 GPU 시간·메모리·외부 모델 비용을 기록합니다. | 작은 점수 차이의 안정성과 실제 비용 대비 이득을 확인합니다. |

> **용어:** *재표집 또는 bootstrap*은 평가 사례를 여러 번 다시 뽑아 점수의 불확실성을 추정하는 방식입니다. 프롬프트 하나에서 여러 영상을 생성했다면 이 영상들을 모두 독립 사례처럼 취급하지 않도록 평가 단위를 설계해야 합니다.

**평가 벤치마크도 갱신할 필요가 있습니다.** 후속 평가 연구인 **GenEval 2**는 기존 GenEval의 자동 평가와 사람 판단 사이의 차이가 최신 모델에서 커질 수 있음을 보고합니다. 이는 PixelDiT의 기존 점수가 틀렸다는 뜻이 아니라, **그 점수만으로 구성적 일반화를 충분히 설명하기 어렵다**는 이유입니다. 새로운 조합 평가와 사람 검증을 함께 사용하는 것이 적절합니다. [arXiv](https://arxiv.org/abs/2512.16853)

## 11. 결론: 저자의 시사점과 추가 연구 방향

### 저자들이 제시한 시사점

**[저자 결론]** 픽셀 공간 생성의 성능 격차는 픽셀 공간이라는 선택만으로 결정되는 것이 아니라, 전역 의미와 세부 표현을 효율적으로 처리하는 구조에 의해 상당 부분 줄어들 수 있습니다. PixelDiT는 이중 수준 Transformer, 픽셀별 조건 조절, 토큰 압축을 통해 그 가능성을 보였다고 정리합니다. [pp. 9–10, Conclusion] 2511.20645v2 2511.20645v2

**[저자가 명시한 한계와 후속 계획]** 손이나 복잡한 건축물처럼 기하와 질감이 동시에 복잡한 대상의 생성이 어렵고, 깊은 모델과 장기 학습에서 속도 예측 손실이 급등할 수 있다고 보고합니다. 이를 해결하기 위해 **모델 용량 확대, 더 크고 질 높은 데이터 구축, 픽셀 확산의 학습 동역학 연구**를 계획합니다. [p. 19, Limitations] 2511.20645v2

> **용어:** *학습 동역학*은 학습 과정에서 손실, 기울기, 내부 표현, 매개변수가 어떻게 변화하는지를 연구하는 것입니다. *손실 급등*은 학습 오차가 갑자기 커져 안정적인 최적화를 방해하는 현상입니다.

### 종합 판단

**[검토 결론] PixelDiT는 “픽셀 공간으로 돌아가면 자동으로 더 잘 일반화한다”는 논문이 아닙니다.**  
더 정확하게는 **전역 의미 학습에 큰 계산 능력을 배정하고, 픽셀별 세부 갱신은 작지만 정교하게 조건화하면 픽셀 생성이 실용적인 선택이 될 수 있다**는 연구입니다.

후속 연구에서 가장 중요한 것은 단순한 모델 확대보다 **구조, 예측 목표, 사전학습 표현, 데이터 구성의 효과를 분리하는 것**입니다.  
특히 ImageNet FID의 개선과 별도로, 미학습 조합·미지 도메인·미지 해상도에서의 결과를 측정해야 실제 일반화 향상을 주장할 수 있습니다.  
원문의 REPA 의존성, 해상도별 구성 평가 차이, 그리고 이후 JiT·PixelDiT2의 다른 설계 선택이 이 연구 방향의 근거입니다. 2511.20645v2 [arXiv](https://arxiv.org/html/2511.13720v2)

**가장 중요한 후속 연구 질문은 “픽셀 공간이 잠재 공간보다 좋은가?”보다, “어떤 데이터·예측 목표·사전학습 지식·계산 예산에서 어떤 표현과 구조가 더 잘 일반화하는가?”입니다.**
