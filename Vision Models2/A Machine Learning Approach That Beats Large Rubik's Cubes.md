# A Machine Learning Approach That Beats Large Rubik's Cubes

---

## 1. Executive Summary (10문장 이내)

본 논문은 루빅스 큐브로 대표되는 **극대형 케일리 그래프(Cayley graph)** 위에서의 경로 탐색 문제를 해결하기 위한 새로운 머신러닝 기반 접근법을 제안한다.  
핵심 아이디어는 랜덤 워크(random walk)로 생성된 데이터를 이용해 **확산 거리(diffusion distance)를 추정하는 신경망**을 학습시키고, 이를 빔 서치(beam search)의 휴리스틱으로 활용하는 것이다.  
제안 방법은 $4\times4\times4$($7.4\times10^{45}$ 원소)와 $5\times5\times5$($1.2\times10^{74}$ 원소) 루빅스 큐브를 해결한 **최초의 머신러닝 솔버**이다.  
$3\times3\times3$ 큐브에서는 98.4% 최적성을 달성해 DeepCubeA(60.3%), EfficientCube(69.6%)를 크게 능가한다.  
복수의 독립적으로 학습된 에이전트(multi-agent)를 앙상블하여 각 에이전트의 다양성을 활용한다.  
학습 데이터로 온라인 랜덤 워크를 사용하므로, 기존 DAVI 방식보다 훈련 데이터 생성 비용이 매우 저렴하다.  
EfficientCube 대비 훈련 시간은 최대 18.5배, 추론 시간은 약 26배 빠르다. $4\times4\times4$ 큐브 평균 해법 길이 46.51은 추측되는 직경(diameter) 48보다 짧아 해법의 질이 매우 높음을 시사한다.  
2023 Kaggle Santa Challenge의 1,000개 이상 팀의 최선 결과를 **모든 개별 케이스에서** 능가한다.  
나아가 본 방법은 루빅스 큐브를 넘어 다양한 계획 문제(planning problem)에 일반적으로 적용 가능하다.

### 1-1. 연구의 목적과 필요성

**목적:**
- 유한 케일리 그래프 위에서 **임의 크기의** 경로 탐색 문제를 머신러닝으로 해결하는 범용 프레임워크 개발
- $4\times4\times4$, $5\times5\times5$ 등 기존 도구가 전혀 작동하지 않는 **초대형 그룹**에 대한 해법 최초 제시

**필요성:**
- 유한 케일리 그래프에서의 최단 경로 탐색은 **NP-hard** 문제 [p.1, ref.30,31]
- GAP 등 기존 컴퓨터 대수 시스템은 $4\times4\times4$ 루빅스 큐브 수준에서 이미 실패 [p.1, ref.33]
- BFS/Dijkstra 등 전통적 방법은 수십억 노드 수준까지만 현실적으로 적용 가능하며, $10^{45}$ 이상 규모에는 불가
- 기존 ML 솔버(DeepCubeA, EfficientCube)는 $3\times3\times3$만 다루었고, 최적성도 60~70% 수준에 그침
- 케일리 그래프는 바이오인포매틱스, 암호학, 양자 컴퓨팅 등 다양한 분야에 활용되므로 범용 해법의 파급 효과가 큼

### 2-1. 해결하고자 하는 문제 / 제안 방법 / 모델 구조 / 성능 향상 및 한계 — 상세 설명

#### 🔴 해결하고자 하는 문제

유한 순열군의 케일리 그래프(상태 공간 그래프)에서 임의의 노드로부터 목표 노드(solved state)까지의 경로를 찾는 것. 그래프 크기가 $10^{74}$에 달하여 BFS, Dijkstra 등 전통적 알고리즘이 전혀 작동하지 않으며 [p.1], 기존 ML 방법도 $3\times3\times3$에만 국한되어 있었다 [p.1].

---

#### 🟠 제안하는 방법 (수식 포함)

**Step 1: 랜덤 워크 기반 훈련 데이터 생성**

solved state $s_0$에서 시작하여 비역추적(non-backtracking) 랜덤 워크를 수행:

$$\text{Random Walk: } s_0 \xrightarrow{r_1} s_1 \xrightarrow{r_2} s_2 \xrightarrow{r_3} \cdots \xrightarrow{r_k} s_k$$

여기서 $r_i$는 임의의 허용 이동(move). 각 노드 $s_k$에 대해 쌍 $(v_k, k)$를 저장하며, $v_k$는 노드의 feature vector(순열 벡터), $k$는 랜덤 워크 길이(diffusion distance 추정값). 훈련 세트의 파라미터: $K_{\max}$ (최대 워크 길이), $T = K \cdot K_{\max}$ (총 노드 수). [p.2, Sec.IV.B (p.7)]

**Step 2: 확산 거리 회귀 학습**

ResMLP를 이용하여:

$$\hat{y} = f_\theta(v), \quad \mathcal{L}(\theta) = \frac{1}{|D|}\sum_{(v,k)\in D}(\hat{y} - k)^2$$

손실 함수: **MSE(Mean Squared Error)**, 옵티마이저: **Adam** (learning rate $= 0.001$). [p.7, Sec.IV.C]

**Step 3: 빔 서치(Beam Search) 기반 경로 탐색**

빔 너비 $W$를 고정하고:

1. 현재 노드 집합 $\mathcal{B}_t$ ($|\mathcal{B}_t| \leq W$)의 모든 이웃 노드 열거
2. 중복 제거(hash function 사용)
3. 신경망 예측값 기준 상위 $W$개 선택:

$$\mathcal{B}_{t+1} = \underset{|\mathcal{S}|=W}{\arg\min_{\mathcal{S} \subseteq \text{Neighbors}(\mathcal{B}_t)}} \sum_{s \in \mathcal{S}} f_\theta(v_s)$$

4. 목표 노드 발견 또는 200 스텝 초과 시 종료 [p.3, Sec.IV.D (p.7)]

**Step 4: 멀티에이전트 앙상블**

$A$개의 에이전트를 독립적으로 학습(각기 다른 랜덤 워크 seed):

$$\text{Solution} = \arg\min_{i \in \{1,\ldots,A\}} \text{len}(\text{path}_i)$$

[p.3, Fig.1a]

---

#### 🟡 모델 구조 (ResMLP)

**입력 인코딩:** 순열 $p = (p(0), p(1), \ldots, p(l-1))$을 One-Hot Encoding으로 변환:

$$6n^2 \text{ 심볼} \rightarrow 6^2n^2 \text{ 차원 One-Hot 벡터 (예: } n=3 \rightarrow 324\text{차원)}$$

**네트워크 구조:**

```
Input (6n² → 6²n²) 
→ [Linear(6²n²×N₁) → BatchNorm → ReLU]      # 첫 번째 블록
→ [Linear(N₁×N₂) → BatchNorm → ReLU]         # 두 번째 블록
→ [ResBlock × Nᵣ]                             # 잔차 블록 (각 블록: 두 개의 Linear(N₂×N₂)+BatchNorm+ReLU, skip connection)
→ [Linear(N₂×1)]                              # 출력: 스칼라 (확산 거리 추정)
```

주요 하이퍼파라미터 [Table II, p.8]:
- $3\times3\times3$ 최종 모델: $N_1=700, N_2=643, N_r=4$, 총 파라미터 $P=4\text{M}$, 10-layer
- $5\times5\times5$ 최종 모델: $N_1=1008, N_2=560, N_r=4$, 총 파라미터 $P=4\text{M}$, 10-layer

### 📌 검토자(본 분석) 해석

1. **훈련 데이터 포화 효과**: 저자들은 이를 "놀라운 발견(surprising finding)"이라 부르나, 이는 신경망이 랜덤 워크로 접근 가능한 상태 공간 표본에서 일반화할 수 있는 정보를 일찍 포화시키기 때문으로 해석됨. 더 많은 데이터보다 **모델 다양성(에이전트 수)** 이 더 효과적인 앙상블 이득을 제공함.

2. **확산 거리 ≠ 실제 거리**: 랜덤 워크 거리 $k$는 실제 그래프 거리(최단 경로)의 상한이 아닌, **확률적 도달 시간의 추정치**임. 따라서 신경망은 실제 최적 경로 길이를 학습하는 것이 아니라 "얼마나 어려운 상태인가"에 대한 프록시를 학습함.

3. **빔 너비의 $\log W$ 선형 관계**: 이는 상태 공간의 지수적 분기(branching factor)와 빔 탐색의 상호작용에서 자연스럽게 발생하는 현상으로, 알고리즘적으로 예측 가능한 결과임.

4. **Santa Challenge 비교의 한계**: Santa Challenge는 UQTM(unfixed corners/centers) 메트릭을 사용하고, 본 연구의 $3\times3\times3$ 기준 결과는 QTM 기반. 두 메트릭은 직접 비교 불가 [Table I 각주 a].

## 7. 가장 중요한 그림 5개 해석

### 📊 Figure 1 (p.3) — 제안 방법 전체 파이프라인

**구성:** (a) 훈련/해결 프로세스 흐름, (b) ResMLP 아키텍처, (c) 빔 서치 트리 예시

**해석:**
- **(a):** 에포크마다 새로운 랜덤 워크 데이터셋을 생성하여 모델을 온라인 업데이트하는 구조를 명확히 시각화. 여러 에이전트가 독립적으로 훈련되고, 해결 단계에서 최단 경로를 선택하는 앙상블 구조를 보여줌.
- **(b):** One-Hot 인코딩 → 선형 레이어 → 잔차 블록 $N_r$개 → 스칼라 출력의 단순하지만 효과적인 구조. 특기할 점은 기존 DeepCubeA, EfficientCube의 MLP를 일반화한 형태임을 명시.
- **(c):** $W=40$으로 $3\times3\times3$ 큐브를 해결하는 빔 서치 과정. 색상 코딩(파란→빨간)으로 신경망 거리 추정값이 감소하는 경로를 시각화. 실제로 최적 경로(진한 빨간)가 빔 내에서 수렴되는 과정을 보여줌.

---

### 📊 Figure 2a (p.4) — 훈련 데이터 크기의 한계 효과

**해석:**
- $3\times3\times3$와 $4\times4\times4$ 모두에서 훈련셋 크기 $T$가 로그 스케일로 증가해도 일정 수준 이상에서 평균 해법 길이가 정체됨.
- 정체 임계점이 모델 크기(1M vs. 4M)와 깊이에 관계없이 유사하게 나타나는 것은 매우 중요한 발견: **데이터보다 모델 다양성(에이전트 수)이 성능 향상의 핵심 레버**임을 시사.
- 이는 훈련 데이터 생성 비용을 절감하고 에이전트 앙상블에 자원을 집중하는 실용적 전략의 근거가 됨.
- ⚠️ **통계적 한계:** 20개 스크램블만 테스트하여 분산이 크고 결론의 강건성이 낮음.

---

### 📊 Figure 2b (p.4) — 빔 너비 $W$의 영향

**해석:**
- $W$를 $2^{12}$에서 $2^{24}$으로 증가시킬 때 평균 해법 길이가 **$\log_2 W$에 거의 선형**으로 감소.
- $3\times3\times3$에서 $W=2^{24}$ 시 최적 해법(평균 20.637)에 근접한 20.65 달성.
- $4\times4\times4$에서 동일 $W$에서 Santa Challenge 최선 결과(53.49) 대비 크게 우수한 50.4 달성.
- **실용적 함의:** 더 많은 GPU 메모리가 가용할수록 직접적으로 해법 품질 향상 가능. 하드웨어 향상이 알고리즘 개선 없이도 성능 개선으로 이어짐.

---

### 📊 Figure 3a-c (p.5) — 에이전트 수 증가 효과

**해석:**
- 3종 큐브 모두에서 에이전트 수 증가 시 앙상블 성능이 **단조 감소하는 로그 곡선**을 보임.
- 랜덤 에이전트 집합(실선)과 최적 에이전트 집합(점선) 사이의 간격이 크다: 즉, **에이전트 선택 전략**이 중요함을 암시 (하지만 논문은 사후 최적 선택만 시연).
- $5\times5\times5$에서 최적 10 에이전트와 단일 에이전트 간 차이가 최대 8 moves에 달함 → 에이전트 다양성이 특히 복잡한 퍼즐에서 중요.
- ⚠️ **실용적 한계:** 실제로 어떤 에이전트가 "좋은 앙상블"을 구성하는지 사전에 알 방법이 없음.

---

### 📊 Figure 3d-f (p.5) — 에이전트별 기여도 색상 코드 맵

**해석:**
- 각 스크램블(열)마다 어떤 에이전트(행)의 해법이 최종 선택되었는지 시각화.
- **핵심 관찰:** "성능이 낮은(worst)" 에이전트도 특정 스크램블 1~2개에서 최단 해법을 제공하여 앙상블에 기여함. 이는 에이전트 다양성의 가치를 정량적으로 보여줌.
- $4\times4\times4$ (Fig.3e)에서 ×표시(미해결 스크램블)가 일부 에이전트에 존재하지만, 앙상블에서는 다른 에이전트가 보완하여 전체 해결률 100% 달성.
- 이 그림은 **"약한 에이전트도 버리지 않는" 전략**의 정당성을 시각적으로 증명함.

## 8. 결론: 시사점, 후속 연구, 추가 제언

### 8-1. 저자 제시 시사점 및 후속 연구 계획

**저자 제시 시사점:**
1. ML 기반 케일리 그래프 경로 탐색이 $10^{74}$ 규모에서 작동 가능함을 실증 [p.2]
2. 학습 데이터 크기보다 **빔 너비와 에이전트 수**가 성능의 핵심 레버 [p.4]
3. 방법이 루빅스 큐브에 국한되지 않고 **수학, 바이오인포매틱스, 프로그래밍 작업**에도 적용 가능 [p.7]
4. 16개 난해 스크램블을 공개 데이터셋으로 배포하여 커뮤니티 연구 촉진 [p.9]

**저자 언급 후속 연구 계획:**
- 케일리 그래프 분석을 위한 **오픈소스 Python 프레임워크 CayleyPy** 개발 지속 [p.2]
- 수학 문제, 바이오인포매틱스, 프로그래밍 태스크에 방법 적용 [p.7]
- 더 강력한 하드웨어로 빔 너비와 에이전트 수 확장 [p.5]

---

### 8-1. 모델의 일반화 성능 향상 가능성 (중점 분석)

**현재 일반화의 강점:**
- 루빅스 큐브의 군론적 구조(Cayley graph)를 직접 활용하지 않고, **순열 벡터만 입력**으로 사용하므로 이론상 임의의 순열군에 적용 가능 [p.2]
- $2\times2\times2$에서 $5\times5\times5$까지 동일한 아키텍처로 작동함이 실증됨 [Table I]
- 동일한 4M 파라미터 모델이 세 가지 큐브 크기 모두에서 경쟁력 있는 성능 달성 [Table II]

**일반화 향상 가능성과 제언:**

1. **타 퍼즐로의 이전(Transfer):**
현재 각 큐브 크기별로 별도 모델을 훈련. 큐브 크기를 조건으로 입력하거나, **메타러닝(meta-learning)** 접근으로 하나의 모델이 다수 그룹을 처리할 수 있다면 일반화 크게 향상 가능.

2. **그래프 구조 정보 활용:**
현재 모델은 순열 벡터만 입력받음. 케일리 그래프의 국소 구조(이웃 관계)를 **GNN(Graph Neural Network)** 으로 인코딩하면 더 풍부한 표현 학습 가능. Wilson et al. (2024) [ref.18]의 "Cayley graph propagation"이 이 방향의 선행 연구.

3. **커리큘럼 학습(Curriculum Learning):**
$K_{\max}$를 단계적으로 늘려가는 커리큘럼 전략으로 어려운 스크램블에 대한 일반화 개선 가능. 현재 고정된 $K_{\max}$ 사용이 16개 난해 스크램블 실패의 원인 중 하나일 수 있음.

4. **대조학습(Contrastive Learning) 도입:**
확산 거리 회귀 대신, 거리가 가까운 상태는 잠재 공간에서 가깝게, 먼 상태는 멀게 표현하도록 학습하는 대조학습 목적함수 도입으로 표현의 일반화 개선 가능.

5. **불변성 활용:**
루빅스 큐브의 대칭성(회전, 반전)을 입력 인코딩 또는 손실 함수에 반영하면 데이터 효율성과 일반화 모두 향상 가능 (DeepCubeA는 이를 부분적으로 활용).

### 8-2. 2020년 이후 관련 최신 연구 비교 분석

> ⚠️ **중요 고지:** 아래 비교는 본 논문의 참고문헌 및 공개된 연구들을 기반으로 작성하였으며, 2025년 2월 이후 출판된 연구에 대해서는 본 분석자가 직접 확인할 수 없어 기술하지 않습니다. 논문 내 언급된 연구들을 중심으로 비교합니다.

| 연구 | 연도 | 방법 | $3\times3\times3$ 최적성 | 핵심 특징 | 본 논문 대비 |
|------|------|------|------------------------|-----------|-------------|
| **DeepCubeA** [ref.3] | 2019 | DAVI + A* / BFS | 60.3% | 강화학습, 14.7M 파라미터 | 최적성 −38%p, 훈련 비용 ↑ |
| **EfficientCube** [ref.36] | 2023 | Self-supervised + Beam | 69.6% | 14.7M 파라미터, 52B 훈련 | 최적성 −29%p, 26× 느림 |
| **Cayley Graph Propagation** [ref.18] | 2024 | GNN on Cayley graphs | 미보고 | 이론적 프레임워크 | 경로 탐색 성능 비교 없음 |
| **AlphaZero 계열** [ref.46,47] | 2016-17 | MCTS + DNN | 게임 특화 | 도메인 지식 필요 | 퍼즐 적용 시 비효율 |
| **본 논문 (CayleyPy)** | 2025 | 랜덤 워크 + ResMLP + Beam | **98.4%** | 4M 파라미터, 최초 4×4×4,5×5×5 ML 해결 | — |

**본 논문이 앞으로의 연구에 미치는 영향:**

1. **ML의 수학적 적용 가능성 확장:** 논문은 ML이 이론수학의 도구로서 $10^{74}$ 규모 구조를 다룰 수 있음을 실증하여, 군론·조합론 문제에 ML을 적용하는 후속 연구의 촉매가 될 것.

2. **벤치마크 제고:** $4\times4\times4$, $5\times5\times5$ 루빅스 큐브가 새로운 ML 경로 탐색 벤치마크로 자리잡을 가능성. 16개 난해 스크램블 데이터셋은 즉각적 벤치마크로 활용 가능.

3. **CayleyPy 오픈소스 생태계:** GitHub/Kaggle/Zenodo에 공개된 코드와 데이터셋 [ref.64-68]이 후속 연구자들의 진입 장벽을 크게 낮춤.

4. **계획 문제(Planning)로의 일반화:** 제안 방법이 임의의 케일리/슈라이어 그래프에 적용 가능함을 명시하여, 로봇 계획, 분자 설계, 단백질 폴딩 등 분야로의 확장 연구 방향을 제시.

**앞으로 연구 시 고려할 점:**

| 고려사항 | 상세 |
|---------|------|
