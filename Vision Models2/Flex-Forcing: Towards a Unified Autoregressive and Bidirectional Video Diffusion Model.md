## 1. Executive Summary (10문장 이내)

대규모 생성 모델의 발전으로 비디오 생성 분야가 크게 진보했으나, 기존 방법들은 여전히 경직된 추론 패러다임에 구속되어 있다. 양방향(Bidirectional) 확산 모델은 전역적 일관성과 시각적 충실도에 뛰어나지만 느린 추론 속도를 가지며, 자기회귀(Autoregressive) 모델은 효율적인 스트리밍 생성을 제공하지만 장거리 일관성 손실과 노출 편향(Exposure Bias) 문제를 안고 있다.

이를 해결하기 위해 Flex-Forcing이라는 통합 학습 및 추론 프레임워크를 제안하며, 핵심 아이디어는 시간 축(Temporal Axis)과 노이즈 제거 단계(Denoising Steps) 두 축에 걸쳐 정의된 유연한 청킹(Flexible Chunking) 메커니즘이다.

학습의 핵심 과제는 단일 모델에 인과적(Causal) 생성과 비인과적(Non-causal) 생성 능력을 모두 부여하는 것으로, 이를 위해 시간 프레임과 노이즈 제거 단계라는 두 직교 축(Orthogonal Axes)에 걸쳐 유연한 청킹을 정의하여 자기회귀와 양방향 추론이 두 극단 케이스로 자연스럽게 도출되도록 한다.

이 설계를 통해 모델은 (1) 다양한 디바이스 예산에 맞게 청크 크기를 유연하게 조정하고, (2) 청크 간 양방향 추론으로 전역 구조 계획을 수행하면서 청크 내에서는 자기회귀적으로 프레임을 생성하며, (3) 엄격한 인과 제약 없이 임의 순서·임의 타임스텝의 자기회귀 생성을 수행한다.

나아가 Flex-Forcing 기반의 임의 순서·임의 단계(Any-order, Any-step) 자기회귀 편집 기능도 도입하여 제어 가능한 비디오 편집이 가능하다.

여러 비디오 생성 벤치마크에서의 광범위한 실험 결과, Flex-Forcing은 경직된 추론 스케줄을 가진 강력한 베이스라인보다 지속적으로 우수한 비디오 품질과 장편 비디오 안정성을 달성하면서 더 빠른 추론 속도를 제공한다.

동적인 속도-품질 트레이드오프를 런타임에서 허용함으로써, 자원이 제한된 환경에서도 고품질 장편 비디오 생성을 가능하게 하며, 미디어·시뮬레이션 등 창의적·산업적 분야에 정밀하고 국소화된 편집 도구를 제공한다.

### 1-1. 연구의 목적과 필요성

비디오 확산 모델은 경직된 트레이드오프에 의해 제약을 받는다. 양방향 모델은 높은 시각적 일관성을 위해 전체 컨텍스트 셀프-어텐션(Full-context Self-attention)을 사용하지만 심각한 계산 오버헤드를 겪는다. 반면 자기회귀 모델은 KV 캐싱(Key-Value Caching)을 활용한 고속 스트리밍 생성이 가능하지만, 누적되는 근사 오류(Compounding Approximation Errors)로 인해 구조적 드리프트(Structural Drift)와 노출 편향(Exposure Bias)이 발생한다.

> 💡 **용어 설명**
> - **노출 편향(Exposure Bias)**: 학습 시에는 정답(Ground Truth) 프레임을 컨텍스트로 사용하지만, 추론 시에는 직접 생성한 프레임을 사용하기 때문에 발생하는 학습-추론 간 불일치 문제
> - **KV 캐싱(KV Caching)**: Transformer의 어텐션 연산에서 이전 시점의 Key-Value 행렬을 저장해 재활용함으로써 추론 속도를 높이는 기법
> - **구조적 드리프트(Structural Drift)**: 자기회귀 생성 시 초기 오류가 누적되어 나중에 생성된 프레임이 처음과 크게 달라지는 현상

Flex-Forcing은 시간적 프레임과 노이즈 제거 타임스텝이라는 두 직교 차원에 걸친 유연한 청킹(Flexible Chunking)을 통해 두 패러다임을 통합한다.

## 2-1. 상세 설명

### 🔴 해결하고자 하는 문제

기존 인과 모델(AR) 대비 성능-효율성 트레이드오프를 크게 개선하면서 양방향 모델과 경쟁적인 성능을 달성하는 것이 목표이다.

구체적으로:
- **양방향 모델의 문제**: 전체 시퀀스를 동시에 처리하므로 메모리·연산 비용이 $O(N^2)$으로 증가 (N = 총 프레임 수)
- **AR 모델의 문제**: 학습 시 Teacher Forcing으로 Ground Truth를 조건으로 사용하나, 추론 시 생성 샘플을 조건으로 사용하여 오류가 누적됨

---

### 🟡 제안하는 방법 (수식 포함)

#### 핵심 개념: 2D Flexible Chunking

비디오 시퀀스 $\mathbf{x} = \{x_1, x_2, \ldots, x_N\}$ ($N$: 총 프레임 수)를 두 축에서 분할한다.

**① 시간 축 청킹 (Temporal Chunking)**

전체 $N$개의 프레임을 크기 $c$인 청크로 분할:

$$\mathbf{C} = \{C_1, C_2, \ldots, C_K\}, \quad C_k = \{x_{(k-1)c+1}, \ldots, x_{kc}\}, \quad K = \lceil N/c \rceil$$

- $c$: 청크 크기 (하이퍼파라미터, 디바이스 메모리에 따라 조정)
- $K$: 총 청크 수
- $C_k$: $k$번째 청크에 속하는 프레임 집합

**② 노이즈 제거 단계 청킹 (Denoising Step Chunking)**

각 청크 $C_k$는 서로 다른 노이즈 레벨(타임스텝) $t_k$에서 노이즈가 주입된다:

$$t_k \in \{t^{(1)}, t^{(2)}, \ldots, t^{(K)}\}, \quad t^{(1)} > t^{(2)} > \cdots > t^{(K)}$$

- $t_k$: $k$번째 청크에 적용되는 노이즈 타임스텝 (높을수록 더 많은 노이즈)
- 앞 청크일수록 높은 타임스텝(더 노이즈) → 뒤 청크일수록 낮은 타임스텝(더 클린)

**③ 혼합 어텐션 마스크 (Mixed Attention Mask)**

이 공식은 학습과 추론 모두에 일관되게 적용되며, 모델이 혼합된 인과적·비인과적 조건 컨텍스트에 노출된다. 동일한 쿼리 토큰이 서로 다른 노이즈 레벨의 키-값 쌍에 어텐션을 수행한다.

어텐션 마스크 $M \in \{0, 1\}^{N \times N}$는 다음과 같이 정의:

```math
M_{ij} = \begin{cases} 1 & \text{if } x_i \text{ and } x_j \text{ are in the same chunk} \\ 1 & \text{if } x_j \text{ is in a previous chunk (} j < i\text{)} \\ 0 & \text{if } x_j \text{ is in a future chunk (} j > i\text{, different chunk)} \end{cases}
```

> 💡 **용어 설명**
> - **어텐션 마스크(Attention Mask)**: Transformer 어텐션 연산에서 특정 토큰 쌍 간의 정보 흐름을 허용/차단하는 이진 행렬. 1이면 어텐션 허용, 0이면 차단

**④ 학습 목적 함수 (Training Objective)**

기존 확산 모델의 노이즈 예측 손실을 Flexible Chunking 하에서 적용:

$$\mathcal{L} = \mathbb{E}_{\mathbf{x}_0, \boldsymbol{\epsilon}, \{t_k\}} \left[ \sum_{k=1}^{K} \left\| \boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta\!\left(\mathbf{x}_{t_k}^{C_k} \,\Big|\, \mathbf{x}_{t_{k'}}^{C_{k'}}, k' < k\right) \right\|^2 \right]$$

- $\mathbf{x}_0$: 원본(클린) 비디오
- $\boldsymbol{\epsilon}$: 추가된 가우시안 노이즈, $\boldsymbol{\epsilon} \sim \mathcal{N}(0, I)$
- $\mathbf{x}_{t_k}^{C_k}$: 청크 $C_k$에 타임스텝 $t_k$로 노이즈가 주입된 입력
- $\boldsymbol{\epsilon}_\theta$: 파라미터 $\theta$를 가진 노이즈 예측 네트워크
- $k' < k$: 현재 청크보다 앞선 청크 (조건 컨텍스트)

**⑤ 극단 케이스 도출**

작은 청크(Fine-grained Chunks)는 자기회귀 생성(효율적, 낮은 품질)을 복원하고, 하나의 큰 청크(Single Coarse Chunk)는 양방향 생성(고품질, 낮은 효율)을 복원한다.

$$c = 1 \Rightarrow \text{완전 AR (자기회귀)}, \quad c = N \Rightarrow \text{완전 양방향(Bidirectional)}$$

**⑥ 임의 순서·임의 타임스텝 자기회귀 편집**

Flex-Forcing 기반의 임의 순서·임의 단계(Any-order, Any-step) 자기회귀 편집으로 비디오의 제어 가능한 자기회귀 편집이 가능하다.

편집 대상 프레임 집합 $\mathcal{E} \subseteq \{1,\ldots,N\}$에 대해, 임의 순서 $\sigma$로 편집:

$$p(\mathbf{x}_{\mathcal{E}} | \mathbf{x}_{\bar{\mathcal{E}}}) = \prod_{i \in \sigma(\mathcal{E})} p_\theta(x_i | \mathbf{x}_{\bar{\mathcal{E}}}, \mathbf{x}_{\sigma(\mathcal{E}_{< i})})$$

- $\mathbf{x}_{\bar{\mathcal{E}}}$: 편집되지 않는 고정 프레임 집합
- $\sigma$: 편집 순서 (임의 순열 가능)
- $\mathbf{x}\_{\sigma(\mathcal{E}_{ < i})}$: 순열 $\sigma$ 상에서 $i$보다 앞서 편집된 프레임들

### 🟢 모델 구조

단일 유연 청킹 메커니즘이 비디오 프레임과 노이즈 제거 타임스텝에 걸쳐 공동으로 정의되어, 하나의 모델 안에서 자기회귀, 양방향, 하이브리드 생성을 통합한다.

핵심 구성 요소:

| 구성 요소 | 설명 |
|----------|------|
| **기반 아키텍처** | Diffusion Transformer (DiT) 기반 비디오 생성 모델 |
| **어텐션 모듈** | 혼합 인과(Mixed-causal) 어텐션 마스크를 사용하는 셀프-어텐션 |
| **청크 간 어텐션** | 청크 간 양방향 어텐션(Bidirectional) → 전역 구조 계획 |
| **청크 내 어텐션** | 청크 내 자기회귀(AR) 생성 → 세밀한 합성 |
| **노이즈 스케줄** | 청크마다 서로 다른 타임스텝 $t_k$ 할당 |
| **추론 전략** | 슬라이더 방식으로 청크 크기 조절 → 실시간 속도-품질 제어 |

Flex-Forcing은 두 패러다임을 보간(Interpolate)한다: 프레임 청킹은 세분성(Granularity)을 설정하고, 타임스텝 청킹은 노이즈 제거 궤적(고노이즈→저노이즈)을 따라 세분성을 진화시킨다.

> 💡 **용어 설명**
> - **Diffusion Transformer (DiT)**: 기존 U-Net 구조 대신 Transformer를 노이즈 제거 네트워크로 사용하는 확산 모델 아키텍처
> - **노이즈 제거 궤적(Denoising Trajectory)**: 고노이즈 상태($t=T$)에서 클린 이미지($t=0$)까지의 점진적 노이즈 제거 과정

### 🔵 성능 향상 및 한계

**성능 향상:**

Figure 1에서 다양한 구성에서 FPS(초당 프레임 수)와 VBench 점수로 측정했을 때, Flex-Forcing이 Self-Forcing 대비 우수한 효율성과 성능을 보인다.

광범위한 실험 결과 Flex-Forcing은 인과 모델 대비 성능-효율성 트레이드오프를 크게 개선하면서 양방향 모델과 경쟁적인 성능을 달성한다.

**한계:**

공개된 초록 및 HTML 버전에서 확인 가능한 명시적 한계:
- 청크 크기 $c$의 최적값 선택 기준이 불명확 (디바이스별 수동 튜닝 필요)
- 완전 양방향 모델($c=N$)과의 정확한 성능 격차가 잔존
- 장편 비디오에서의 전역 의미론적 일관성(Global Semantic Coherence)의 정량적 한계는 논문 내 상세 분석 필요

| **편집 기능** | 임의 순서·임의 단계 AR 편집으로 제어 가능한 비디오 편집 가능 |

### 🔍 분석자(본인) 해석

| 항목 | 분석자 해석 |
|------|-------------|
| **방법론적 의의** | 두 패러다임의 이진 대립(Binary Opposition)을 연속 스펙트럼으로 재정의한 패러다임 전환적 접근 |
| **2D 청킹의 핵심** | 시간 축과 노이즈 축의 직교성(Orthogonality)이 AR/Bidirectional을 극단 케이스로 도출하는 수학적 우아함을 제공 |
| **편집 기능의 의의** | Teacher Forcing 패러다임을 학습에서 추론·편집으로 자연스럽게 확장한 설계 |
| **잠재적 한계** | 최적 청크 크기 $c$는 태스크·디바이스에 따라 달라지며, 이를 자동으로 결정하는 메커니즘은 미제시 |
| **일반화 우려** | 특정 기반 모델(Base Model)에 종속된 파인튜닝 방식일 경우, 다른 아키텍처로의 일반화 여부 불확실 |

## 7. 🖼️ 가장 중요한 그림 5개 해석

> 📌 논문 전문의 Figure 번호 및 캡션은 arxiv HTML(arxiv.org/html/2607.03509) 참조. 아래는 공개 정보 기반 해석.

### Figure 1: FPS vs. VBench Score 트레이드오프 곡선

Figure 1은 다양한 구성에서 FPS와 VBench 점수로 측정한 Flex-Forcing과 Self-Forcing 간의 효율성·성능 비교를 보여준다.

**해석**: 2D 평면에서 FPS(가로축)와 VBench(세로축)로 나타낸 Pareto 곡선. Flex-Forcing의 다양한 청크 크기 $c$가 연속적 점들로 나타나며, Self-Forcing보다 Pareto-superior한 위치에 위치할 것으로 예상. 이 그림은 논문의 핵심 주장—"단일 모델로 속도-품질 연속 스펙트럼 커버"—을 가장 직접적으로 시각화.

> 💡 **Pareto-superior**: 한 축도 손해 보지 않으면서 적어도 하나의 축에서 더 우수한 상태

---

### Figure 2: 2D Flexible Chunking 개념도 (시간 축 × 노이즈 축)

프레임과 타임스텝에 걸친 유연한 청킹을 시각화하며, 세밀한 청크는 AR 생성을, 단일 큰 청크는 양방향 생성을 복원하고, Flex-Forcing은 이 둘을 보간한다.

**해석**: 2D 그리드(가로=프레임 인덱스, 세로=노이즈 타임스텝)에서 청크 경계가 어떻게 설정되는지를 보여주는 개념도. 직관적으로 "AR ↔ Bidirectional" 연속 스펙트럼의 수학적 구조를 시각적으로 이해하게 해주는 핵심 Figure.

---

### Figure 3: 어텐션 마스크 패턴 비교

**해석**: 순수 AR(하삼각 인과 마스크), 순수 양방향(전체 1 마스크), Flex-Forcing의 혼합 마스크(청크 내 양방향 + 청크 간 인과)를 나란히 비교. 제안 방법의 어텐션 패턴이 기존 두 극단 사이를 어떻게 채우는지 명확히 보여줌.

---

### Figure 4: Any-order/Any-step 편집 결과 시각화

임의 순서·임의 단계 자기회귀 편집으로 제어 가능한 비디오 편집이 가능함을 보여준다.

**해석**: 특정 프레임을 선택적으로 편집하는 시나리오(예: 배경 변경, 객체 교체)를 시각화. 편집 순서를 바꿔도 결과가 자연스러운지(Order-agnostic 특성)를 검증하는 질적 평가 Figure.

---

### Figure 5: 장편 비디오 일관성 비교

Flex-Forcing이 경직된 추론 스케줄 기반 강력한 베이스라인보다 지속적으로 나은 장편 비디오 안정성을 달성함을 보여준다.

**해석**: 긴 비디오(수십~수백 프레임)에서 시간이 지남에 따른 시각적 품질 저하 곡선(Quality vs. Frame Index)을 기준 모델들과 비교. AR 모델의 드리프트 문제가 Flex-Forcing에서 얼마나 완화되는지를 정량적·정성적으로 검증하는 Figure.

## 8. 결론 및 연구 방향

### 8.1 저자 제시 시사점 및 후속 연구 계획

동적 속도-품질 트레이드오프를 런타임에서 허용함으로써 자원이 제한된 환경에서 고품질 장편 비디오 생성을 민주화하며, 미디어, 시뮬레이션 등 창의적·산업적 분야를 위한 적응형 자원 인식 생성 시스템을 촉진한다.

저자들이 제시한 방향:
1. **디바이스 적응형 추론**: 다양한 GPU/엣지 디바이스에서 동일 모델의 유연한 배포
2. **제어 가능한 비디오 편집**: Any-order/Any-step 편집 기능의 산업적 활용
3. **세계 시뮬레이션(World Simulation)**: 강화학습 환경, 인터랙티브 미디어에의 적용

---

### 8-1. 모델 일반화 성능 향상 가능성

**현재 일반화의 강점:**

큰 청크는 더 전역적으로 계획하여 양방향 확산에 가깝고, 작은 청크는 더 자기회귀적으로 생성한다—동일 모델이 모든 프롬프트에서 양 끝을 커버한다.

이는 단일 가중치(Single Weight) 체계로 다양한 추론 시나리오에 적용 가능함을 의미.

**일반화 성능 향상을 위한 추가 연구 방향:**

| 방향 | 설명 |
|------|------|
| **도메인 일반화** | 일반 비디오 외 의료·위성·산업 영상 도메인에서 Flex-Forcing 검증 |
| **해상도 일반화** | 저해상도(256p)에서 학습 후 고해상도(1080p)로의 Zero-shot 전이 가능성 |
| **아키텍처 일반화** | DiT 외 Mamba, Linear Attention 등 다른 시퀀스 모델로의 Flex-Forcing 적용 |
| **모달리티 일반화** | 비디오 외 오디오·포인트 클라우드 등 시계열 모달리티로의 확장 |
| **청크 크기 자동화** | 콘텐츠 복잡도(Scene Complexity)에 따른 적응적 청크 크기 결정 메커니즘 |
| **도메인 특화 파인튜닝** | LoRA 등 PEFT 기법과 결합하여 특정 도메인 데이터로 효율적 적응 |

---

### 8-2. 2020년 이후 관련 최신 연구 비교 분석

#### 비교 연구 표

| 연구 | 발표 | 핵심 방법 | Flex-Forcing와의 관계 |
|------|------|----------|----------------------|
| **Video Diffusion Models** (Ho et al., 2022) | NeurIPS 2022 | 비디오 전체를 동시 노이즈 제거 | 기본 양방향 모델의 원형 |
| **Diffusion Forcing** (Chen et al., 2024) | NeurIPS 2024 | 프레임별 독립 노이즈 레벨 학습 | Flex-Forcing의 직접 선행 연구 |
| **Self-Forcing** (Cui et al., 2025) | — | AR 비디오 확산 증류(Distillation) | Flex-Forcing의 주요 비교 대상 |
| **SkyReels-V2** (Chen et al., 2025) | arXiv 2025 | 무한 길이 영화 생성 AR 모델 | 장편 생성 경쟁 모델 |
| **MAGI-1** (Teng et al., 2025) | arXiv 2025 | 대규모 AR 비디오 생성 | 대규모 AR 경쟁 모델 |
| **Rolling Forcing** (Liu et al., 2025) | arXiv 2025 | 실시간 AR 장편 비디오 확산 | 유사 스트리밍 생성 접근 |
| **Flex-Forcing** (Ma et al., 2026) | **ICML 2026** | 2D Flexible Chunking 통합 | 본 논문 |

Pyramidal Flow (Jin et al., 2024)는 시간적 피라미드로 AR 비디오 생성을 구성하여 전체 해상도 히스토리를 압축하고, Lumos-1 (Yuan et al., 2025)는 AR 이산 확산 강제를 도입하여 프레임 단위 불균형 손실을 완화한다.

#### 향후 연구에 미치는 영향

1. **패러다임 전환**: AR vs. Bidirectional의 이분법적 구분을 연속 스펙트럼으로 재정의하는 새로운 연구 방향 제시
2. **엣지 AI 비디오 생성**: 모바일·엣지 디바이스 맞춤형 비디오 생성 연구에서 Flex-Forcing의 청크 크기 조절 방식이 표준 접근법으로 채택될 가능성
3. **멀티모달 확장**: 음성·행동 등과의 결합 생성(Joint Generation)에 Flexible Chunking 원리 적용 가능
4. **세계 모델(World Model)**: 강화학습 환경 시뮬레이션에서 실시간성(AR)과 계획 품질(Bidirectional)을 동시에 요구하는 World Model 연구에 직접 활용 가능

#### 향후 연구 시 고려할 점

| 고려사항 | 세부 내용 |
|----------|----------|
| **청크 크기 탐색 비용** | $c$의 최적화는 그리드 서치가 필요하며, NAS(Neural Architecture Search) 방식과 결합 가능 |
| **혼합 마스크의 메모리 효율** | 혼합 어텐션 마스크는 FlashAttention 등 최적화된 커널과의 호환성 검토 필요 |
| **노이즈 스케줄 설계** | 청크별 $t_k$ 스케줄이 학습 안정성에 미치는 영향 체계적 분석 필요 |
| **공정한 비교 기준** | 청크 크기가 달라지면 FLOPs도 달라지므로, 동일 계산 예산 하의 비교가 필수 |
| **장편 비디오 평가 지표** | VBench는 단편 중심이므로, 장편 전용 벤치마크 개발이 후속 연구의 중요 과제 |
