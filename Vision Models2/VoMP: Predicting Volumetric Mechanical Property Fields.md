## 3. 해결하려는 문제와 연구의 필요성

### 3.1 문제: 보이는 3D 자산을 물리적으로 반응하는 자산으로 바꾸기

**[저자 보고]** 일반적인 3D 복원·자산 데이터는 물체의 외형과 시각적 질감은 제공하지만, 내부 위치별 기계적 물성은 거의 제공하지 않습니다. 반면 변형 시뮬레이션에는 쿠션·금속 프레임·플라스틱 다리처럼 서로 다른 부위에 서로 다른 물성값이 필요합니다(pp. 1–3). 2510.22975v2 2510.22975v2

이를 설명용으로 다시 쓰면 다음과 같습니다.

```math
\widehat{\mathbf m}(\mathbf x)
=
f_{\Theta}(\mathcal G,\mathcal A;\mathbf x),
\qquad
\mathbf m(\mathbf x)
=
\begin{bmatrix}
E(\mathbf x)\\
\nu(\mathbf x)\\
\rho(\mathbf x)
\end{bmatrix},
\quad
\mathbf x\in\Omega .
```

**기호:** $\mathcal G$는 입력 기하구조, $\mathcal A$는 외관 정보, $\Omega$는 물체 내부 영역, $\mathbf x$는 그 안의 위치, $\Theta$는 학습된 모델 매개변수, $\widehat{\mathbf m}$은 예측 물성입니다. 이 식은 논문의 문제 설정을 재표현한 것이며 원문 번호가 붙은 식은 아닙니다.

**[해석]** 중요한 점은 VoMP가 **물성 예측기**라는 것입니다. 힘을 가했을 때의 운동을 직접 출력하는 모델도 아니고, 물리 법칙을 새로 학습한 시뮬레이터도 아닙니다. 예측한 물성값을 별도의 시뮬레이터가 사용합니다.

### 3.2 왜 어려운가: 외관으로 내부 물성을 유일하게 결정할 수 없다

**[해석]** 겉모양이 같은 의자라도 내부 프레임 재질이 다를 수 있고, 동일한 외피 안에 폼·공기·금속이 들어갈 수 있습니다. 입력 기하구조와 외관이 같다면 결정론적 모델은 같은 답을 출력하므로, 이들 가능성을 항상 구분할 수는 없습니다. 따라서 VoMP의 내부 예측은 상당 부분 **학습 데이터에서 얻은 재료·구조의 사전지식**에 의존한다고 보는 것이 적절합니다.

> **용어 — 역문제와 식별 가능성:** 역문제는 관측된 결과에서 숨겨진 원인을 추정하는 문제입니다. 식별 가능성은 서로 다른 원인이 관측상 구별되는지를 뜻합니다. 같은 외관을 만드는 내부 구성이 여럿이면 외관만으로는 유일한 정답을 정할 수 없습니다.

저자도 이 문제를 형상·외관만으로 체적 물성을 추정하는 어려운 역문제로 정의하며, 숨겨진 부품의 주석에는 객체 용도와 재료 이름을 사용하도록 지시합니다(p. 3, p. 37, Fig. 22). 2510.22975v2 2510.22975v2

## 4. 제안 방법: 데이터, 수식, 모델 구조

### 4.1 학습 데이터: 실측 재료 범위와 객체별 추정 주석을 구분해야 한다

#### MTD: Material Triplets Dataset

**[저자 보고]** MatWeb, Cambridge Materials Data Book 등의 자료에서 재료별 $(E,\nu,\rho)$ 범위를 수집하고, 각 범위에서 수치 삼중값을 샘플링합니다. 범위 크기에 비례해 샘플 수를 정하고 중복을 제거합니다(p. 6, §5.1). 2510.22975v2

**[해석]** 따라서 “약 10만 개의 데이터”는 **약 10만 개의 서로 다른 재료를 실험한 결과**를 뜻하지 않습니다. 부록 Table 13에는 원천 재료 범위가 249개로 제시됩니다. 또한 같은 재료 범위에서 만들어진 여러 삼중값은 새로운 재료 종류에 대한 독립적인 증거가 아닙니다(p. 39). 2510.22975v2

#### GVM: Geometry with Volumetric Materials

**[저자 보고]** 부품별로 분할된 3D 자산에 대해 다음 정보를 Qwen2.5-VL-72B에 제공합니다.

- 전체 물체 이미지와 부품의 시각 재질을 구에 입힌 이미지
- 부품 재료 이름과 추가 메타데이터
- 이름상 가까운 실제 재료 세 종류의 물성 범위

모델이 출력한 부품별 물성을 해당 부품 내부의 모든 복셀에 부여합니다(p. 6, Fig. 4; pp. 51–53, Figs. 23–25). 2510.22975v2 2510.22975v2

> **용어 — 시각언어모델, VLM:** 이미지와 텍스트를 함께 입력받아 답하는 모델입니다. 여기서는 학습용 물성 주석을 만드는 데 사용되며, VoMP가 새 객체를 처리할 때마다 호출하는 구조는 아닙니다.

**[해석]** 이 설계는 주석 비용을 줄이지만, 최종 모델이 실제 물리량뿐 아니라 **주석 생성기의 추론 습관과 오류**도 학습할 수 있습니다. 특히 프롬프트는 유기물이나 불확실한 재료에도 반드시 숫자를 출력하고 “unknown”을 쓰지 못하게 합니다. 이는 미지의 재료에서 불확실성을 숨긴 정답을 만들 위험이 있습니다(p. 37, Fig. 22; p. 53, Fig. 25). 2510.22975v2 2510.22975v2

### 4.2 물성 정규화

**[저자 보고]** $E$와 $\rho$에는 먼저 $\log_{10}$을 적용하고, 세 속성을 각각 $[0,1]$로 정규화합니다(p. 4, Eq. 1 설명). 2510.22975v2

이를 명시적으로 풀어 쓰면 다음과 같습니다.

```math
\mathbf t(\mathbf m)
=
\begin{bmatrix}
\log_{10}E\\
\nu\\
\log_{10}\rho
\end{bmatrix},
\qquad
\widetilde m_k
=
\frac{t_k-a_k}{b_k-a_k}.
```

**기호:** $\mathbf m=(E,\nu,\rho)^\top$는 원래 물성, $\mathbf t$는 로그 변환 후 벡터, $\widetilde{\mathbf m}$은 정규화된 벡터, $a_k,b_k$는 속성 $k$의 정규화 최소·최대 기준입니다. 단위는 논문 관례대로 $E$는 Pa, $\rho$는 $\mathrm{kg/m^3}$입니다.

> **용어 — 로그 변환:** 값의 차이가 아니라 배수 차이를 다루기 쉽게 만드는 변환입니다. 매우 부드러운 재료와 금속처럼 영률이 여러 자릿수 차이 나는 데이터를 함께 학습할 때 유용합니다.

**[해석]** 정규화는 단순한 전처리가 아니라 모델 성능에 큰 영향을 주는 설계입니다. 다만 정규화된 공간의 동일한 오차가 실제 시뮬레이션에서 동일한 영향력을 갖는다는 뜻은 아닙니다.

### 4.3 MatVAE: 재료 조합의 2차원 잠재공간

#### 재구성 손실 — 원문 Eq. (1)

표기를 단순화하면 다음과 같습니다.

```math
\mathcal L_{\text{Recon}}
=
\frac{1}{N}
\sum_{i=1}^{N}
\left\|
\widetilde{\mathbf m}_i
-
D_{\theta}(\mathbf z_i)
\right\|_2^2.
```

**기호:** $N$은 재료 샘플 수, $\mathbf z_i\in\mathbb R^2$는 2차원 잠재코드, $D_\theta$는 MatVAE 디코더, $\theta$는 그 매개변수입니다. 디코더 출력은 정규화된 물성 삼중값입니다(p. 4). 2510.22975v2

> **용어 — VAE:** 입력을 확률적인 잠재표현으로 바꾼 뒤 복원하는 신경망입니다. 여기서는 물성을 압축하는 것보다, 물성 조합을 정돈된 공간에 배치하는 목적이 더 중요합니다.

#### 정규화 흐름 — 부록 Eqs. (13)–(15)

저자는 단순한 가우시안 잠재분포의 표현력을 보완하기 위해 한 개의 radial normalizing flow를 사용합니다. 손실 가중치와 기호가 겹치지 않도록, 아래에서는 원문의 흐름 매개변수 $\alpha,\beta$를 $a,b$로 바꾸어 표기합니다.

```math
\mathbf u
=
\boldsymbol\mu_{\phi}(\widetilde{\mathbf m})
+
\boldsymbol\sigma_{\phi}(\widetilde{\mathbf m})
\odot\boldsymbol\epsilon,
\qquad
\boldsymbol\epsilon\sim\mathcal N(\mathbf 0,I),
```

```math
\mathbf z
=
f_{\psi}(\mathbf u)
=
\mathbf u
+
\frac{b}{a+\|\mathbf u-\mathbf z_0\|_2}
(\mathbf u-\mathbf z_0),
\qquad
a>0,\quad b>-a.
```

**기호:** $\phi$는 인코더 매개변수, $\boldsymbol\mu_\phi,\boldsymbol\sigma_\phi$는 평균과 표준편차, $\odot$는 원소별 곱, $\boldsymbol\epsilon$은 표준정규 잡음, $I$는 단위행렬, $\mathbf z_0$는 학습되는 변형 중심, $\psi$는 흐름 매개변수입니다. 조건 $a>0,b>-a$는 이 변환의 가역성을 위한 조건입니다(pp. 38–40). 2510.22975v2 2510.22975v2

> **용어 — Normalizing flow:** 확률분포를 되돌릴 수 있는 변환으로 휘어, 복잡한 분포를 표현하는 방법입니다. 물체의 움직임이나 유체 흐름을 뜻하지 않습니다.

#### 최종 목적함수 — 원문 Eq. (2)

```math
\mathcal L_{\text{MatVAE}}
=
\mathcal L_{\text{Recon}}
+
\gamma\,\text{MI}(\mathbf z)
+
\beta\,\text{TC}(\mathbf z)
+
\alpha
\sum_{j=1}^{d}
\max\left(
\delta,
\text{KL}\!\left(q_\phi(z_j)\|p(z_j)\right)
\right).
```

```math
\text{TC}(\mathbf z)
=
\text{KL}\!\left(
\bar q_\phi(\mathbf z)
\;\middle\|\;
\prod_{j=1}^{d}\bar q_\phi(z_j)
\right).
```

**기호:** $d=2$는 잠재차원 수, $\text{MI}$는 입력과 잠재표현 사이의 상호정보량, $\text{TC}$는 잠재 좌표 간 의존성, $\text{KL}$은 두 확률분포의 차이를 측정하는 항입니다. $\bar q_\phi$는 데이터 전체에 대해 집계한 잠재분포, $p$는 사전분포이며, 첫 식의 $q_\phi(z_j)$는 원문의 차원별 주변분포 표기를 유지했습니다. 저자는 $(\gamma,\beta,\alpha)=(1,2,1)$, $\delta=0.1$을 사용합니다(pp. 4–5, 39–40). 2510.22975v2 2510.22975v2

> **용어:** 상호정보량은 두 변수의 정보 공유 정도, 총상관은 여러 잠재 좌표가 얼마나 중복된 정보를 담는지 나타내는 척도입니다. **잠재표현 붕괴**는 일부 좌표가 사실상 사용되지 않는 현상입니다.

**[저자 보고]** 총상관 벌점은 두 잠재차원이 모두 밀도만 표현하는 현상을 줄이고, free-nats 설정은 일부 차원이 사용되지 않는 문제를 완화하려는 장치입니다.

**[해석]** 다만 $\max(\delta,\text{KL})$은 $\text{KL}<\delta$에서 벌점의 기울기를 없애는 방식이지, 각 차원이 반드시 일정량 이상의 정보를 담도록 강제하는 엄밀한 제약은 아닙니다. 또한 이 손실은 **재료 분포 학습 목적함수**이지, 출력 전체에 대한 물리 법칙 증명은 아닙니다.

### 4.4 다중 시점 특징을 내부 복셀로 전달 — 원문 Eq. (3)

```math
\mathbf f_i
=
\frac{1}{|J|}
\sum_{j\in J}
F_j\!\left(\Pi_j(\mathbf p_i)\right)
\in\mathbb R^{1024}.
```

**기호:** $\mathbf p_i$는 복셀 $i$의 중심, $J$는 렌더링 시점 집합, $\Pi_j$는 3D 위치를 시점 $j$의 이미지 좌표로 투영하는 함수, $F_j$는 DINOv2 특징 지도, $\mathbf f_i$는 여러 시점에서 얻은 특징의 평균입니다(p. 5). 2510.22975v2

구현에서는 학습·평가에 150개 시점, $512\times512$ 렌더링을 사용하고, 특징 추출에는 DINOv2-ViT-L/14와 $518\times518$ 입력을 사용합니다. 패치 특징 격자는 $37\times37$입니다(pp. 43–44). 2510.22975v2

> **용어 — 특징 투영·쌍선형 보간:** 3D 점이 이미지의 어느 위치에 보이는지 계산하고, 그 위치 주변의 네 특징값을 가중 평균해 해당 점의 특징으로 사용하는 과정입니다.

**[해석]** 이 연산은 **내부를 직접 관찰하는 것이 아닙니다.** 내부 복셀 위치를 외부 이미지에 투영하여 외관 정보를 전달하는 것이며, 어떤 내부 재료가 들어갈지는 이후 신경망이 학습된 구조적 규칙으로 추론합니다.

Gaussian Splat 입력의 경우에도 관측되지 않은 내부를 고체로 채우는 복셀화 절차를 사용합니다. 따라서 속이 빈 구조와 속이 찬 구조를 구분하는 문제는 물성 예측뿐 아니라 복셀화 가정에도 영향을 받습니다(p. 6, §6.1). 2510.22975v2

### 4.5 Geometry Transformer와 학습 손실 — 원문 Eq. (4)

```math
\widehat{\mathbf z}_i
=
\mathcal F_{\Theta}(X_S)_i,
\qquad
\widehat{\widetilde{\mathbf m}}_i
=
D_\theta(\widehat{\mathbf z}_i),
```

```math
\mathcal L_{\mathcal F}
=
\frac{1}{|S|}
\sum_{i\in S}
\left\|
D_\theta\!\left(\mathcal F_\Theta(X_S)_i\right)
-
\widetilde{\mathbf m}_i
\right\|_2^2.
```

**기호:** $S$는 현재 처리하는 복셀 인덱스 집합, $X_S$는 해당 복셀들의 위치·특징 입력, $\mathcal F_\Theta$는 Geometry Transformer입니다. $D_\theta$는 앞서 학습한 MatVAE 디코더로, 원문 Eq. (4)의 $\mu_\theta$에 대응하며 이 단계에서는 가중치를 고정합니다(pp. 5–6). 2510.22975v2

**핵심 구분:** 잠재코드 자체의 정답과 비교하는 손실이 아니라, **잠재코드를 디코딩한 물성값과 정답 물성을 비교하는 손실**입니다. 또한 이 학습에는 실제 변형 영상이나 힘–변위 측정값을 맞추는 물리 시뮬레이션 손실이 직접 포함되어 있지 않습니다.

> **용어 — Attention·shifted window:** 여러 위치의 정보를 선택적으로 결합하는 연산입니다. 작은 공간 창 안에서 계산하고 창 위치를 바꾸어, 전체 복셀 간 계산보다 비용을 줄이면서 이웃 영역의 정보를 교환합니다.  
> **용어 — 사전학습 초기화:** 다른 대규모 데이터로 이미 학습된 가중치에서 출발하는 방식입니다. 현재 데이터만으로 처음부터 학습하는 것과 구별해야 합니다.

### 4.6 예측 물성의 시뮬레이터 전달

**[저자 보고]** 시뮬레이터가 요구하는 위치에는 가장 가까운 복셀의 물성값을 사용합니다(p. 45, Eq. 21).

```math
i^*(\mathbf x)
=
\text{arg\,min}_{i}
\|\mathbf x-\mathbf x_i\|_2,
\qquad
\widehat{\mathbf m}(\mathbf x)
=
\widehat{\mathbf m}_{i^*(\mathbf x)}.
```

**기호:** $\mathbf x$는 물성을 조회할 위치, $\mathbf x_i$는 예측 복셀 중심, $i^*$는 가장 가까운 복셀의 인덱스입니다. 저자는 재료 경계에서 실제로 존재하지 않는 중간 재료를 만들지 않으려고 고차 보간을 피한다고 설명합니다. 2510.22975v2

등방성 탄성 모델에서는 다음 관계로 물성을 변환합니다.

```math
\lambda
=
\frac{E\nu}{(1+\nu)(1-2\nu)},
\qquad
\mu=G
=
\frac{E}{2(1+\nu)},
\qquad
K
=
\frac{E}{3(1-2\nu)}.
```

**기호:** $\lambda,\mu$는 Lamé 계수, $G$는 전단탄성계수, $K$는 체적탄성계수입니다. 모두 탄성 반응을 표현하는 계수이며 단위는 Pa입니다(p. 32, §D.2; p. 45, Eq. 22). 2510.22975v2 2510.22975v2

> **용어 — 등방성·구성법칙:** 등방성은 어느 방향으로 힘을 가해도 재료의 성질이 같다는 가정입니다. 구성법칙은 재료의 변형과 응력 사이 관계를 정하는 모델입니다. $G$는 비틀리거나 미끄러지는 변형에 대한 저항, $K$는 부피 압축에 대한 저항입니다.

**[해석]** $(E,\nu,\rho)$를 공통 단위로 출력하는 것은 시뮬레이터 간 활용에 유리하지만, 이 세 값만으로 모든 재료의 비선형성·소성·점성·방향 의존성을 결정할 수는 없습니다.

## 5. 성능: 무엇이 얼마나 좋아졌는가

### 5.1 먼저 지표의 의미를 구분해야 한다

원문 부록의 기본 지표는 다음과 같습니다(pp. 31–32, Eqs. 5–8 및 §D.2).

```math
\text{ADE}
=
\frac{1}{N}\sum_i|y_i-\widehat y_i|,
\qquad
\text{ARE}
=
\frac{1}{N}\sum_i
\left|\frac{y_i-\widehat y_i}{y_i}\right|,
```

```math
\text{ALDE}
=
\frac{1}{N}\sum_i
|\log y_i-\log\widehat y_i|,
\qquad
\text{MnRE}
=
\frac{1}{N}\sum_i
\min\left(
\frac{y_i}{\widehat y_i},
\frac{\widehat y_i}{y_i}
\right).
```

**기호:** $y_i$는 정답 물성 또는 질량, $\widehat y_i$는 예측값, $N$은 평가 샘플 수입니다. ADE는 원래 물리 단위의 오차, ARE는 상대오차, ALDE는 로그값 차이입니다. MnRE는 1에 가까울수록 좋고 나머지는 작을수록 좋습니다. 2510.22975v2

영률 ALRE는 §D.2의 “ $\log(E)$에 대한 상대오차” 설명에 대응하며, 설명용으로 쓰면 다음과 같습니다.

```math
\text{ALRE}(E)
=
\frac{1}{N}\sum_i
\left|
\frac{\log E_i-\log\widehat E_i}
{\log E_i}
\right|.
```

**주의:** 이 식은 부록의 문장 정의를 풀어 쓴 것입니다. **ALRE 0.0409를 “영률이 평균 4.09% 틀렸다”로 읽으면 안 됩니다.** 영률 자체가 아니라 로그값의 상대오차이기 때문입니다. 2510.22975v2

예를 들어 정답이 $10^{10}$ Pa이고 예측이 그 두 배이면,

$$
\frac{|\log(2\times10^{10})-\log(10^{10})|}
{|\log(10^{10})|}
\approx 0.0301.
$$

즉 **영률 자체는 100% 과대추정인데 로그 상대오차는 약 3.01%**입니다. 이는 위 정의에서 계산한 예시이지 논문의 실험 결과가 아닙니다. 또한 로그 상대오차는 영률을 Pa 대신 다른 단위의 수치로 표현하면 분모가 달라지므로, 서로 다른 논문의 수치를 비교할 때 단위 관례까지 확인해야 합니다.

## 6. 가장 중요한 그림의 선정과 해석

### Fig. 3, p. 4 — 방법의 핵심: 내부 특징 전달과 물성 사전지식의 분리

**[저자 보고]** 서로 다른 3D 표현을 복셀 특징으로 통일하고, Geometry Transformer와 MatVAE를 연결하는 전체 구조를 보여줍니다. 2510.22975v2

**[해석]** 이 그림에서 중요한 것은 두 학습 문제가 분리된다는 점입니다. Geometry Transformer는 “어느 위치에 어떤 재료가 들어가는가”, MatVAE는 “어떤 물성 조합이 데이터상 현실적인가”를 담당합니다. 일반화 관점에서는 재료 지식을 여러 객체에 재사용할 수 있는 장점이 있지만, 내부 특징은 외부 이미지에서 전달된 것이라는 정보적 한계도 드러납니다.

### Fig. 4, p. 6 — 성능을 이해하려면 모델만큼 주석 생성기를 봐야 한다

**[저자 보고]** 객체·부품·재료 이름·텍스처·물성 범위가 VLM 주석에 결합됩니다. 2510.22975v2

**[해석]** VoMP의 성과는 신경망 구조만의 성과가 아니라 **좋은 부품 구조와 재료 메타데이터를 가진 자산을 이용한 주석 전략의 성과**이기도 합니다. 이러한 정보가 약한 실제 스캔 데이터로 이동할 때 성능이 유지되는지는 추가 검증이 필요합니다.

### Fig. 6, p. 9 — 가장 중요한 성능 그림이자 주장의 경계를 보여주는 그림

**[저자 보고]** Fig. 6a는 단면 물성장, 6b는 GVM 오차, 6c는 질량 추정, 6d는 실제 재료 범위와의 차이를 보여줍니다. 2510.22975v2

**[해석]** 6b만 보면 강한 우세지만, 6c에서는 상대오차가 최상이 아니고, 6d에서도 VoMP의 재료 범위 대비 오류가 완전히 0은 아닙니다. 따라서 그림 전체를 함께 읽어야 “정확도 향상”을 “항상 정확하고 항상 유효함”으로 확대하지 않게 됩니다.

### Fig. 7, p. 10 — 좋은 잠재공간이지만 물리 법칙의 증명은 아니다

**[저자 보고]** 재료값의 재구성, 잠재공간 내 분포, 물성의 연속적 변화, 잠재공간 보간을 보여줍니다. 원래 물성값을 직접 선형 보간하면 MTD 범위 밖으로 나가지만 MatVAE 보간은 알려진 재료 범위에 대응하는 예가 제시됩니다. 2510.22975v2

**[해석]** 여기서 “Invalid”는 **MTD의 모든 재료 범위 밖에 있다는 뜻**입니다. 자연법칙상 존재할 수 없다는 뜻은 아닙니다. 또한 두 재료 사이 잠재공간 보간이 실제 혼합재·복합재 제조 과정과 동일하다는 증거도 아닙니다.

> **용어 — 보간:** 이미 알고 있는 두 값 사이의 중간값을 만드는 것입니다. 수학적으로 부드러운 보간과 실제 재료 혼합 법칙은 서로 다른 개념입니다.

### Fig. 8·9, pp. 23–24 — 활용 가능성과 내부 예측의 한계를 함께 보기

**[저자 보고]** 다양한 표현에서 예측한 물성으로 변형 시뮬레이션을 수행하고, 화분 내부 흙이나 쿠션 내부처럼 외부에서 직접 보이지 않는 영역의 물성을 시각화합니다. 2510.22975v2 2510.22975v2

**[해석]** “화분 안은 흙일 가능성이 높다”는 의미적 추론은 유용하지만, 실제로 비어 있는 화분이나 다른 충전재가 들어 있는 경우까지 구분했다고 볼 수는 없습니다. 또한 “물성을 손으로 재튜닝하지 않았다”는 것은 촬영·복원·충돌·마찰 등 모든 시뮬레이션 설정까지 자동화했다는 뜻이 아닙니다.

### Figs. 18–21, pp. 34–36 — 물성 오차와 시뮬레이션 오차의 연결은 조건부다

**[저자 보고]** 단위 큐브에 대해 네 종류의 힘 조건을 적용하고, 조건당 486회 시뮬레이션으로 물성 변화와 에너지·부피 변화의 관계를 조사합니다. 2510.22975v2 2510.22975v2

**[해석]** 물성 오차의 영향을 해석하려는 시도는 좋지만, 특정 큐브·하중 실험으로 모든 형상과 재료에 공통인 허용 오차를 정할 수는 없습니다. 예를 들어 앞서 제시한 $K=E/[3(1-2\nu)]$에서 $E$가 같을 때 $\nu$가 0.49에서 0.499로 바뀌면 $K$는 10배가 됩니다. 포아송비 자체의 작은 상대오차가 압축 반응에는 큰 차이를 만들 수 있다는 수학적 예입니다.

### 8.2 특히 중요한 후속 연구: AdaVoMP

**[외부 연구의 저자 보고]** 「Adaptive Volumetric Mechanical Property Fields Invariant to Resolution」은 2026년 6월 공개된 ICML 2026 연구로, VoMP의 고정 격자 대신 **Sparse Adaptive Volumetric 구조, SAV**를 사용합니다. 영역별로 Empty·Keep·Subdivide를 선택하고, 비어 있지 않은 영역의 재료 잠재코드를 생성합니다. 최대 해상도는 $64^3$에서 $1024^3$으로 확장되며, 논문의 $16^3$배 표현은 각 축 해상도가 16배라는 의미이지 예측 정확도가 4,096배라는 의미가 아닙니다. [arXiv](https://arxiv.org/abs/2606.18231)

> **용어 — 적응형 희소 구조:** 모든 공간을 같은 크기의 작은 격자로 채우지 않고, 경계나 복잡한 부분은 세밀하게 나누고 균질한 부분은 큰 셀로 유지하는 표현입니다.

**같은 평가 해상도 안에서 비교해야 합니다.** AdaVoMP Table 1의 $64^3$ 평가에서는 영률 ALRE가 VoMP 0.0409에서 AdaVoMP-H 0.0340으로, 밀도 ARE가 0.0921에서 0.0842로 낮아집니다. $1024^3$ 평가에서는 각각 영률 ALRE 0.1226 대 0.0917입니다. **0.0917과 기존 $64^3$의 0.0409를 직접 비교하여 후속 모델이 나빠졌다고 판단하면 안 됩니다.** [arXiv](https://arxiv.org/html/2606.18231v1)

**[해석]** 이 연구는 VoMP의 설계가 후속 연구의 출발점이 되었음을 보여주는 직접적인 사례입니다. 다만 AdaVoMP는 DINOv3 특징, 확장된 데이터, 더 큰 모델도 사용하므로 개선을 적응형 구조 하나만의 효과로 돌려서는 안 됩니다. 또한 실제 방향 의존 재료와 동영상의 물리적 단서를 처리하는 문제는 여전히 후속 과제로 남습니다. [arXiv](https://arxiv.org/html/2606.18231v1)

### 8.3 SLAT-Phys의 9.9초와 VoMP의 3.59초는 직접적인 속도 경쟁 수치가 아니다

**[외부 연구의 저자 보고]** SLAT-Phys는 단일 이미지에서 시작하여 RTX A5000에서 약 9.9초를 보고합니다. 평가 데이터는 PixieVerse이며, 주 물성 오차는 $[-1,1]$ 정규화 공간의 MSE입니다. 입력 잠재복셀은 논문 §III-C에서 예측 표면에 해당한다고 설명합니다. [arXiv](https://arxiv.org/abs/2603.23973)

**[해석]** VoMP와는 입력 조건, 하드웨어, 데이터, 오차 정의가 다릅니다. 따라서 두 시간이나 오차를 직접 나누어 우열을 정할 수 없습니다. 후속 연구에서는 **단일 이미지부터 시작하는 전체 파이프라인**과 **이미 준비된 3D 자산에 물성을 부여하는 단계**를 별도 트랙으로 평가하는 편이 공정합니다.

## 9. 일반화 성능을 높이기 위한 우선순위

### 9.1 현재 입증된 일반화와 아직 입증되지 않은 일반화

**[해석]** VoMP에서 비교적 잘 뒷받침되는 것은 다양한 3D 표현에 대한 적용 예시, 같은 데이터 체계의 미사용 객체에 대한 예측, ABO-500 질량 평가입니다. 반면 **학습에 없던 재료군, 외관은 같지만 내부가 다른 객체, 극단적 촬영 조건, 실제 힘–변위 응답**에 대한 일반화는 별도의 평가가 필요합니다. 근거가 되는 실험 범위는 §6 및 부록 A입니다. 2510.22975v2 2510.22975v2 2510.22975v2

> **용어 — 분포 밖 일반화, OOD:** 학습 때 본 것과 종류나 조건이 다른 데이터에서 성능을 유지하는 능력입니다. 새로운 객체 인스턴스를 맞히는 것보다 새로운 재료군이나 새로운 내부 구조를 맞히는 것이 더 강한 평가입니다.

### 9.2 [제안] 첫 번째 우선순위: 독립적인 계측 정답과 더 엄격한 분할

모델을 더 크게 만드는 것보다 먼저 **평가가 무엇을 측정하는지** 명확히 해야 합니다.

재료군·객체 계열·자산 공급원 단위로 분리한 테스트셋을 만들고, 일부 객체에는 질량·부피·힘–변위·방향별 변형을 실제로 측정해 기준값을 마련하는 것이 우선입니다. 같은 외관에 다른 내부 구조를 가진 반례도 포함해야 합니다. 평가 불확실성은 복셀 수가 아니라 객체 또는 객체 계열 단위로 추정하고, 여러 학습 시드의 결과를 보고하는 것이 적절합니다.

이 제안은 GVM의 부품별 공통 주석과 제한된 수동 검증이 남긴 공백을 겨냥합니다. 2510.22975v2 2510.22975v2

### 9.3 [제안] 두 번째 우선순위: 단일 정답 대신 불확실성과 관측 기반 보정

VoMP를 최종 물성 계측기로 취급하기보다 **빠른 초기 사전분포**로 사용하는 방향이 유망합니다. 이를 개념적으로 쓰면 다음과 같습니다.

$$
p(\mathcal M,\mathcal S\mid I,\mathcal G,\mathbf y,\mathbf a)
\propto
p(\mathbf y\mid\mathcal M,\mathcal S,\mathcal G,\mathbf a)
\,
p_{\Theta}(\mathcal M,\mathcal S\mid I,\mathcal G).
$$

**기호:** $\mathcal M$은 물성장, $\mathcal S$는 속이 비었는지 등을 포함한 내부 구조, $I$는 이미지, $\mathcal G$는 입력 기하, $\mathbf a$는 누르기·밀기 같은 시험 동작, $\mathbf y$는 그에 따른 관측입니다. 오른쪽 두 항은 각각 관측에 대한 설명력과 시각 입력에서 얻은 사전분포입니다.

**이 식은 VoMP의 원래 방법이 아니라 후속 연구 제안입니다.** 실제 구현에서는 몇 번의 저비용 누르기나 짧은 변형 영상으로 예측을 보정할 수 있습니다. 관측을 이용한 물성 식별이라는 방향은 VGPL과 PAC-NeRF가 보여주지만, VoMP와 결합했을 때의 효과는 새로 실험해야 합니다. [Proceedings of Machine Learning Research](https://proceedings.mlr.press/v119/li20j/li20j.pdf)

> **용어 — 베이지안 갱신:** 먼저 가능한 답들의 확률을 정하고, 새로운 관측이 들어올 때 그 관측을 더 잘 설명하는 답의 확률을 높이는 방식입니다.

특히 **MatVAE가 확률적 잠재공간을 가진다는 사실만으로, 새 객체의 물성 예측 불확실성이 잘 보정되어 있다고 볼 수는 없습니다.** 재료 분포의 다양성과 특정 객체에 대해 얼마나 확신하는지는 다른 문제입니다.

### 9.4 [제안] 세 번째 우선순위: 적응형 해상도 이후의 연구

단순히 “더 높은 해상도”를 제안하는 데 그쳐서는 안 됩니다. 그 방향은 이미 AdaVoMP가 구체화했습니다. 다음 질문은 **어디를 더 세밀하게 계산해야 실제 물리 오차가 가장 줄어드는가**입니다. [arXiv](https://arxiv.org/abs/2606.18231)

재료 경계, 모델의 불확실성, 시뮬레이션 응답의 민감도를 이용해 세분화 위치를 결정하는 방법을 제안합니다. 또한 모델 크기·특징 추출기·학습 데이터·계산량을 맞춘 상태에서 비교해야 구조 개선의 순수한 효과를 알 수 있습니다.

### 9.5 [제안] 네 번째 우선순위: 외관 변화와 재료 변화의 분리

조명·시점·노이즈가 바뀌어도 물성은 유지되어야 하지만, 실제 재료가 바뀌면 예측도 바뀌어야 합니다. 따라서 학습에서는 물성을 보존하는 외관 변화를 충분히 제공하고, 평가에서는 도색·코팅·가려짐처럼 외관과 재료의 통상적 관계가 깨지는 상황을 따로 측정하는 것이 좋습니다.

한 물체를 Mesh·SDF·NeRF·Splat으로 각각 표현한 대응 데이터에서도 예측 일치도를 측정할 필요가 있습니다. 이는 단순한 “여러 표현에서 실행된다”보다 강한 **표현 간 일관성** 평가입니다.

### 9.6 [제안] 다섯 번째 우선순위: 재료 모델과 물성값을 함께 확장

저자는 목재처럼 등방성 가정이 맞지 않는 재료, 항복강도·전단계수·열팽창 등의 추가 속성을 후속 과제로 제시합니다(p. 9). 2510.22975v2

**[해석]** 여기서 단순히 출력 숫자만 늘리기보다, 먼저 어떤 구성법칙이 필요한지 구분하는 것이 중요합니다. 예를 들어 탄성체·소성체·점탄성체는 같은 영률을 가져도 하중 제거 후의 거동이 다를 수 있습니다. Pixie가 재료 모델 종류와 연속 물성을 함께 예측하는 점은 이 방향의 비교 기준이 됩니다. [arXiv](https://arxiv.org/html/2508.17437v2)

또한 현재의 등방성 가정에서는 전단계수 $G$가 이미 $E,\nu$에서 계산됩니다. 따라서 전단계수를 독립적으로 추가 예측하는 연구의 가치는 방향 의존성이나 더 일반적인 재료 모델로 확장할 때 명확해집니다.

## 11. 결론: 연구자의 시사점과 추가 연구 방향

### 저자가 제시한 시사점과 계획

**[저자 보고]** VoMP는 3D 표현에 상관없이 물성장을 빠르게 부여함으로써 디지털 트윈·로봇·대화형 디지털 환경에 정확한 물리 시뮬레이션을 통합하는 장벽을 낮추려 합니다. 저자는 고정 격자의 해상도 제한, 이질적 영역의 과도한 평활화, 등방성 가정의 한계를 인정하고, 추가 물성 예측과 빠른 시뮬레이터용 매개변수 변환을 후속 방향으로 제안합니다(p. 9). 2510.22975v2

논문에는 모델·벤치마크 공개 계획이 적혀 있으며, 현재 공식 프로젝트와 저장소에서는 VoMP 코드 및 학습된 모델을 안내하고 있습니다. 다만 원문이 명시한 vegetation 부분집합의 공개 제한과 전체 평가 재현성은 구분해야 합니다. [NVIDIA](https://research.nvidia.com/labs/sil/projects/vomp/) 2510.22975v2

### 최종 평가

**[해석]** VoMP의 중요한 진전은 “외관에서 물성을 맞힌다”는 아이디어 자체보다, **체적 특징 처리·재료 잠재공간·주석 생성·피드포워드 추론을 하나의 재사용 가능한 파이프라인으로 연결했다는 것**입니다. 실제 후속 연구 AdaVoMP가 이를 적응형 고해상도 구조로 확장했다는 점에서, 다음 연구를 가능하게 하는 기반으로서의 영향도 확인됩니다. [arXiv](https://arxiv.org/abs/2606.18231)

그러나 **그럴듯한 재료값**, **주석과 가까운 값**, **실물에 맞는 값**은 끝까지 구분해야 합니다. 일반화 성능을 높이기 위한 가장 우선적인 다음 단계는 더 큰 모델만이 아니라, **독립적인 실측 평가, 미지 재료·내부 구조 분할, 예측 불확실성, 소량의 물리 관측을 통한 보정**입니다.

**결론적으로 VoMP는 물리적으로 반응하는 3D 자산을 빠르게 만드는 강한 초기 추정 도구로 평가할 수 있지만, 외관만으로 실물 내부 물성을 신뢰성 있게 계측하는 문제를 해결했다고 평가하기에는 근거가 부족합니다.**
