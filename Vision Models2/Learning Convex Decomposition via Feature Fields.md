# Learning Convex Decomposition via Feature Fields

---

## 1. Executive Summary (10문장 이내)

이 논문은 3D 형상을 볼록체(convex body)들의 합집합으로 분해하는 **볼록 분해(convex decomposition)** 문제를 **특징 필드 학습(feature field learning)** 으로 재정의한다.  
핵심 아이디어는 형상 표면의 각 점에 연속적인 특징 벡터를 할당하고, 특징 공간에서 가까운 점들이 같은 볼록 성분에 속하도록 학습시키는 것이다.  
볼록성의 고전적 정의("두 점을 잇는 선분이 형상 내부에 있어야 한다")로부터 유도된 자기지도(self-supervised) 대조 손실 함수를 사용하므로, 정답 레이블 없이 순수 기하학적 정보만으로 학습이 가능하다.  
PVCNN 인코더와 트리플레인(triplane) 표현을 결합한 피드포워드(feedforward) 모델을 약 340K 개의 Objaverse 형상으로 학습하여, **오픈 월드(open-world)** 볼록 분해를 위한 최초의 피드포워드 모델을 제안한다.  
추론 시에는 학습된 특징 필드를 재귀적 이진 클러스터링으로 분할하고, 각 클러스터의 볼록 껍질(convex hull)을 출력한다.  
VHACD, CoACD, BSP-Net, Cvx-Net 대비 오목도(concavity)와 재구성 오차 모두에서 일관되게 우수한 성능을 보인다.  
특징 필드 기반 구조 덕분에 메시, 포인트 클라우드, CAD 모델, 3D 가우시안 스플랫 등 다양한 입력 모달리티에 적용 가능하다.  
단일 임계값 조정만으로 다양한 세분화 수준의 분해를 생성할 수 있다.  
충돌 감지 실험에서 원본 메시 대비 **5배 빠른** 시뮬레이션 속도를 달성하였다.  
본 연구는 볼록 분해를 대조 학습 문제로 형식화한 최초의 시도로, 향후 로보틱스, 물리 시뮬레이션, 생성 AI 파이프라인에 광범위하게 활용될 수 있다.

> **💡 용어 설명**
> - **볼록 분해(Convex Decomposition)**: 비볼록 3D 형상을 여러 볼록한 조각들로 나누는 것. 볼록 형상은 임의의 두 내부 점을 이은 선분이 항상 내부에 있는 형상.
> - **피드포워드 모델(Feedforward Model)**: 입력을 한 방향으로 순차적으로 처리하여 출력을 바로 생성하는 신경망. 반복적 최적화 없이 빠른 추론 가능.
> - **오픈 월드(Open-World)**: 학습 데이터에 없던 임의의 새로운 형상 범주에도 일반화 가능한 설정.

## 2-1. 상세 설명

### 해결하고자 하는 문제

3D 형상을 볼록 체들의 합집합으로 분해하는 문제는 (1) NP-hard 조합 최적화 문제이며, (2) 기존 알고리즘은 계산량이 많고, (3) 기존 학습 기반 방법은 특정 카테고리에만 적용 가능하고, (4) 메시 이외의 3D 표현(가우시안 스플랫 등)에는 적용 불가능한 한계가 있다.

---

### 제안하는 방법 및 수식

#### [수식 1] 볼록성의 정의 (p.3, Eq. 1)

$$\lambda x + (1-\lambda)y \in \text{Vol}(\mathcal{M}) \quad \forall x, y \in \mathcal{M}, \quad \forall \lambda \in [0,1]$$

| 기호 | 의미 |
|------|------|
| $x, y$ | 형상 표면 위의 두 점 |
| $\lambda$ | 보간 계수 ($[0,1]$ 범위) |
| $\mathcal{M}$ | 형상 표면 |
| $\text{Vol}(\mathcal{M})$ | 형상의 내부 부피 |

> **💡 해석**: 두 점 $x, y$를 잇는 선분 위의 모든 점이 형상 내부에 있으면, 이 두 점은 **볼록 쌍(convex pair)**.

#### [수식 2] 볼록 쌍 집합의 정의 (p.3, Eq. 2)

$$\mathcal{C}(\mathcal{M}) = \{(x \in \mathcal{M}, y \in \mathcal{M}) : \lambda x + (1-\lambda)y \in \text{Vol}(\mathcal{M}) \quad \forall \lambda \in [0,1]\}$$

#### [수식 3] 이산 분할 최적화 목적함수 (p.3, Eq. 3)

$$\underbrace{\max_{\{S_i\}}}_{\text{partitions}} \quad \underbrace{\iint_{x,y \in \mathcal{C}(\mathcal{M})}}_{\text{convex pairs}} \quad \underbrace{\mathbf{1}_{G(x)=G(y)}\, dx\, dy}_{\text{같은 성분에 속하는 쌍 수}}$$

| 기호 | 의미 |
|------|------|
| $\{S_i\}$ | 형상 표면의 분할 집합 |
| $\mathcal{C}(\mathcal{M})$ | 볼록 쌍 집합 |
| $G: \mathcal{M} \to \{S_i\}$ | 점을 성분에 할당하는 함수 |
| $\mathbf{1}_{G(x)=G(y)}$ | $x$와 $y$가 같은 성분에 있을 때 1, 아니면 0인 지시함수 |

> **💡 해석**: 같은 볼록 쌍에 속하는 점들이 같은 성분에 최대한 많이 배치되도록 분할을 최적화하는 목적. 이는 NP-hard이므로 연속 완화(relaxation)가 필요.

#### [수식 4-5] 연속 특징 임베딩 목적함수 (p.3, Eq. 4-5)

**완화된 목적 (Eq. 4):**
$$\min_{f} \iint_{x,y \in \mathcal{C}(\mathcal{M})} d(f_x, f_y)\, dx\, dy$$

**균형 잡힌 목적 (Eq. 5):**
$$\min_{f} \iint_{x,y \in \mathcal{C}(\mathcal{M})} d(f_x, f_y) - \iint_{x,y \notin \mathcal{C}(\mathcal{M})} d(f_x, f_y)$$

| 기호 | 의미 |
|------|------|
| $f: \mathcal{M} \to \mathbb{R}^k$ | $k$차원 특징 필드 함수 |
| $f_x, f_y$ | 점 $x$, $y$에서의 특징 벡터 |
| $d(f_x, f_y)$ | 특징 공간에서의 거리 |
| $\|f\| = 1$ | 특징 벡터의 정규화 제약 (비유계 성장 방지) |

> **💡 해석**: 볼록 쌍은 특징 공간에서 가깝게(당기기), 비볼록 쌍은 멀리(밀기) 배치하여 클러스터링 시 자연스럽게 좋은 분해가 나오도록 함.

#### [수식 6] 트리플렛 대조 손실 (p.4, Eq. 6)

$$\mathcal{L}_{\text{cc}} = -\frac{1}{2}\Bigg[\log \frac{\text{sim}(f_x, f_p)}{\text{sim}(f_x, f_p) + \text{sim}(f_x, f_n)} + \log \frac{\text{sim}(f_p, f_x)}{\text{sim}(f_p, f_x) + \text{sim}(f_p, f_n)}\Bigg]$$

$$\text{sim}(x, y) = \exp(x \cdot y / \tau)$$

| 기호 | 의미 |
|------|------|
| $x$ | 앵커(anchor) 점 |
| $p$ | 양성 쌍(positive pair): $x$와 볼록 쌍 관계 |
| $n$ | 음성 쌍(negative pair): $x$와 비볼록 쌍 관계 |
| $f_x, f_p, f_n$ | 각 점의 특징 벡터 |
| $\text{sim}(\cdot, \cdot)$ | 코사인 유사도의 지수 변환 |
| $\tau$ | 온도 하이퍼파라미터 (softmax와 유사한 역할) |

> **💡 용어 설명**
> - **트리플렛(Triplet)**: (앵커, 양성, 음성) 세 샘플의 묶음. 양성은 앵커와 유사해야 하고, 음성은 달라야 함.
> - **온도 파라미터 $\tau$(Temperature)**: 유사도 분포의 날카로움을 조절. 낮을수록 분포가 더 뾰족해짐.

#### [수식 7] 다중 음성 트리플렛 손실 (Supplementary, Eq. 7)

$$\mathcal{L} = -\frac{1}{2}\left[\log\left(\frac{\text{sim}(f(x), f(p))}{\text{sim}(f(x), f(p)) + \sum_n \text{sim}(f(x), f(n))}\right) + \log\left(\frac{\text{sim}(f(p), f(x))}{\text{sim}(f(p), f(x)) + \sum_n \text{sim}(f(p), f(n))}\right)\right]$$

#### [수식 8] 오목도 메트릭 (Supplementary, Eq. 8)

$$\text{Concavity}(S) = \max\big(H(\partial S, \partial\,\text{hull}(S)),\; H(\text{Vol}(S), \text{Vol}(\text{hull}(S)))\big)$$

| 기호 | 의미 |
|------|------|
| $H(\cdot, \cdot)$ | 하우스도르프 거리(Hausdorff distance) |
| $\partial S$ | 성분 $S$의 표면 |
| $\text{hull}(S)$ | $S$의 볼록 껍질 |
| $\text{Vol}(S)$ | $S$의 내부 부피 샘플 점 집합 |

> **💡 용어 설명**
> - **하우스도르프 거리(Hausdorff Distance)**: 두 점 집합 간의 최대 최소 거리. 두 형상이 얼마나 다른지를 측정하는 지표.

#### [수식 9] 대안 학습 목적함수 (Supplementary, Eq. 9)

$$L = \frac{1}{2}\Big[-f(x)^\top f(p) + f(x)^\top f(n)\Big]$$

### 모델 구조 (p.5, Sec 3.4)

```
입력: 포인트 클라우드 (표면에서 100,000점 샘플링)
    ↓
[PVCNN 인코더]
 - 포인트별 특징 추출
    ↓
[트리플레인 투영]
 - XY, XZ, YZ 3개 평면에 mean reduction으로 투영
 - 해상도: 512×512, 채널: 128
    ↓
[2D CNN 다운샘플링]
    ↓
[Transformer (6 레이어)]
    ↓
[전치 2D CNN 업샘플링]
    ↓
출력: 448차원 특징 트리플레인
 - 임의의 3D 쿼리 점에서 특징 조회 가능
    ↓
[재귀 이진 클러스터링 (Algorithm 1)]
    ↓
각 클러스터의 볼록 껍질(convex hull) 출력
```

> **💡 용어 설명**
> - **PVCNN(Point-Voxel CNN)**: 포인트 클라우드와 복셀 표현을 결합한 3D 딥러닝 인코더.
> - **트리플레인(Triplane)**: 3D 특징을 세 개의 2D 평면(XY, YZ, XZ)에 투영하여 표현하는 효율적인 3D 표현 방식.
> - **Transformer**: 어텐션 메커니즘 기반의 시퀀스 처리 모델. 전역적 문맥 파악에 강점.

### 해석자 해석

1. **일반화 성공의 핵심 이유**: 자기지도 학습의 성공은 볼록성이 기하학적으로 보편적인 개념이기 때문으로 해석됨. 의미론적 정보 없이 순수 기하학만으로 학습 가능한 특성이 오픈 월드 일반화를 가능하게 한 주요 요인.

2. **트리플레인의 역할**: 트리플레인 표현은 3D 형상 전체에 대한 연속적 특징 필드를 효율적으로 저장하며, 메시·포인트 클라우드·가우시안 스플랫 등 다양한 입력을 동일한 공간 표현으로 통합하는 중간 표현으로 기능.

3. **Hard Negative 전략의 효과**: 유클리드 거리에 반비례하여 음성 샘플을 선택하는 전략은, 실제 물리 시뮬레이션에서 중요한 "인접하지만 다른 볼록 성분에 속하는" 경계 영역 표현 학습에 집중하게 하는 효과가 있음.

4. **재귀 전략의 장점**: 사용자 지정 임계값을 추론 시에만 설정하면 되므로, 동일한 특징 필드로 다양한 세분화 수준의 분해를 재학습 없이 얻을 수 있는 실용적 장점.

## 7. 가장 중요한 그림 5개 해석

### Figure 1 (p.1) — 전체 파이프라인 개요
**내용**: 입력 형상(가우시안 스플랫 포함) → 특징 필드(PCA 색상화) → 볼록 분해 결과
**해석**: 복잡한 해부학적 구조(갈비뼈 케이지)나 인간형 모델에서도 의미 있는 볼록 성분 분리가 가능함을 직관적으로 보여준다. 각 성분이 서로 다른 색으로 구분되어 분해 품질을 시각적으로 확인 가능. 이 그림은 "특징 필드가 볼록 구조를 포착한다"는 핵심 주장의 시각적 증거.

### Figure 3 (p.4) — 학습 및 추론 파이프라인 전체 구조
**내용**: 입력(메시/포인트 클라우드/가우시안 스플랫) → PVCNN+트리플레인 → 학습 시 대조 목적함수, 추론 시 재귀 분할 → 볼록 분해 출력
**해석**: 모델의 전체 설계 원리를 한눈에 보여주는 핵심 다이어그램. 학습 시와 추론 시의 흐름이 명확히 분리됨. 특히 트리플렛 샘플링(볼록/비볼록 쌍 판별)이 순수 기하학적 정보만으로 자기지도 학습을 가능하게 하는 핵심 메커니즘임을 보여줌.

### Figure 4 (p.4) — 트리플렛 샘플링 전략
**내용**: 앵커 점에서 내부 방향 반구로 광선을 쏘아 양성 쌍 생성(좌), 유클리드 거리에 반비례하여 음성 쌍 샘플링(우)
**해석**: 양성 샘플링은 형상 내부를 통과하는 광선을 이용하여 볼록 쌍을 기하학적으로 정확하게 식별. 음성 샘플링에서 가까운 점을 선호하는 전략은 경계 부근의 어려운 사례를 집중적으로 학습시켜 최적화 효율을 높임. 이 설계가 Hard Negative Mining의 기하학적 구현체.

> **💡 용어 설명**
> - **Hard Negative Mining**: 학습 손실에 가장 많이 기여하는 어려운 음성 샘플을 선별적으로 활용하는 기법. 학습 효율과 성능을 크게 향상시킴.

### Figure 7 (p.6) — 다양한 세분화 수준에서의 성능 비교
**내용**: 성분 수(x축) vs 오목도·재구성 오차(y축) 그래프. 우리 방법 vs V-HACD vs CoACD
**해석**: 모든 성분 수 범위에서 제안 방법이 우위에 있음을 보여줌. 특히 적은 성분 수(8-16개)에서 우리 방법의 우위가 두드러지는데, 이는 제한된 성분으로 더 잘 맞는 볼록 근사를 찾는 능력이 뛰어남을 의미. 실용적 관점에서 성분 수가 적을수록 충돌 감지 속도가 빠르므로 중요한 결과.

### Figure 11 (p.8) — 볼록 인식 특징 vs 의미론적 특징 비교
**내용**: 동일한 L자형 입력 형상에 대해, 제안 방법의 특징(위)은 볼록 경계를 잘 포착하고 정확한 분해를 생성. PartField(아래)의 의미론적 특징은 평탄한 영역에 거의 균일한 특징을 할당하여 잘못된 분해를 생성.
**해석**: 의미론적 분할 특징과 볼록 분해 특징이 근본적으로 다른 정보를 인코딩해야 함을 명확히 보여주는 대조 실험. 특히 L자형 형상처럼 의미론적으로는 하나이지만 기하학적으로 비볼록인 경우에서, 제안 방법의 기하학적 목적함수가 필수적임을 입증.

## 8. 결론: 시사점, 후속 연구 계획, 추가 방향

### 8-1. 저자가 제시한 시사점 및 후속 연구 계획 (p.8, Sec 5)

**저자 제시 시사점:**
- 볼록 분해를 특징 필드 학습 문제로 재정의하면 자기지도 대규모 학습이 가능
- 기하학적 목적함수가 의미론적 특징과 질적으로 다른 볼록 인식 특징을 학습시킴
- 피드포워드 모델이 다양한 3D 표현 모달리티에 걸쳐 일반화 가능

**저자 제시 후속 연구:**
1. 장면 스케일 데이터 및 노이즈 주입 데이터로 학습하여 불완전 기하학 대응력 강화
2. 의미론적으로 인식하는 프록시 학습 (예: 물체의 예상 동작에 적응된 볼록 프록시)

### 모델의 일반화 성능 향상 가능성 (8-1 중점)

**현재 일반화 성공 요인:**
- Objaverse 340K 형상으로 다양한 기하학적 패턴 학습
- 자기지도 손실이 카테고리 독립적 (기하학만 사용)
- 트리플레인 표현이 공간적으로 연속적인 특징 필드 제공

**일반화 한계와 개선 방향:**

| 한계 | 개선 방향 |
|------|-----------|
| 장면 스케일 실패 | 3D 장면 데이터셋(ScanNet, Replica 등)으로 파인튜닝 |
| 얇은 구조물 취약 | 얇은 구조물 특화 샘플링 전략 및 손실 가중치 부여 |
| 불완전 기하학 취약 | 학습 시 포인트 클라우드 드롭아웃·노이즈 증강(augmentation) |
| 고정된 트리플레인 해상도 | 계층적 적응 해상도 트리플레인 적용 |
| 단일 스케일 특징 | 멀티스케일 특징 집약으로 세밀한 구조 포착 강화 |

**추가 일반화 강화 방법 (해석자 제안):**
- **도메인 적응**: 메시 학습 후 포인트 클라우드·가우시안 스플랫으로의 제로샷 전이를 체계적으로 분석하고 도메인 정렬(domain alignment) 손실 추가
- **데이터 다양성 확대**: 건축, 지형, 생물학적 구조물 등 현재 데이터셋의 편향을 보완하는 다양한 도메인 데이터 포함
- **메타 학습**: 적은 수의 형상으로도 빠르게 적응하는 메타 학습 프레임워크 적용으로 새로운 도메인 대응력 향상

### 8-2. 2020년 이후 관련 최신 연구 비교 분석

> ⚠️ **주의**: 아래 비교는 본 논문이 인용한 문헌 및 공개된 arXiv/학회 논문 기반입니다. 논문에서 명시적으로 인용되지 않은 연구에 대해서는 확인된 정보만을 기술하고, 불확실한 수치는 제시하지 않습니다.

| 방법 | 연도 | 핵심 차이점 | 본 논문 대비 |
|------|------|-------------|-------------|
| **CoACD** [58] | 2022 | 충돌 인식 오목도 메트릭 + 트리 탐색. 메시에 특화. | 계산 비용 크고 오픈 월드 불가 |
| **RL-ACD** [34] | 2025 | 강화학습으로 분해 탐색 효율화 | 여전히 최적화 기반, 빠른 피드포워드 추론 불가 |
| **BSP-Net** [12] | 2020 | 이진 공간 분할로 볼록 메시 생성 | 고정 카테고리에 한정, 오픈 월드 일반화 실패 |

| **PartField** [31] | 2025 (ICCV) | 의미론적 부분 분할을 위한 특징 필드 | 의미론적 특징이라 볼록 분해에 부적합 (Fig 11) |

| **Navigation-driven ACD** [3] | 2024 (SIGGRAPH) | 내비게이션 목적 특화 볼록 분해 | 특수 목적, 범용 볼록 분해 아님 |

**이 논문이 앞으로의 연구에 미치는 영향:**

1. **볼록 분해의 학습 패러다임 전환**: 탐색 기반에서 특징 학습 기반으로의 패러다임 이동을 주도. 대조 학습을 기하학적 분해 문제에 처음 적용한 사례로서 후속 연구의 기준점이 됨.

2. **로보틱스·시뮬레이션 파이프라인 가속화**: 생성 AI로 대량 생성된 3D 자산에 대해 즉각적 물리 시뮬레이션 준비를 가능하게 하는 핵심 구성요소로 자리매김할 가능성.

3. **다중 모달리티 3D 분석**: 가우시안 스플랫에 적용 가능함을 보인 것은 NeRF/3DGS 기반 표현의 물리적 활용 가능성을 넓히는 중요한 선례.

**앞으로 연구 시 고려할 점 (해석자 추가 제안):**

| 고려 사항 | 구체적 연구 방향 |
|-----------|----------------|
| **평가 메트릭 표준화** | 오목도 외에 실제 충돌 감지 속도·정확도와의 상관관계를 측정하는 메트릭 개발 필요 |
| **동적 형상 대응** | 애니메이션·변형 형상의 볼록 분해를 시간적 일관성 있게 처리하는 방법 |
| **의미론적 볼록 분해** | 물체의 관절 구조나 동작 패턴을 반영한 의미-기하학 통합 볼록 분해 |
