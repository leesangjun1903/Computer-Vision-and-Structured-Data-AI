
# DeepFaceDrawing: Deep Generation of Face Images from Sketches

## 1. 핵심 주장 및 주요 기여

**DeepFaceDrawing**은 손으로 그린 거친 또는 불완전한 스케치로부터 고품질의 얼굴 이미지를 생성하는 딥러닝 시스템이다. 이 논문의 핵심 주장은 다음과 같다:[1]

기존의 스케치-이미지 변환 방법들(pix2pix, pix2pixHD 등)은 스케치를 **하드 제약 조건**으로 취급하기 때문에 전문적인 스케치나 엣지맵 같은 고품질 입력을 요구한다는 문제를 지적한다. 반면 DeepFaceDrawing은 스케치를 **소프트 제약 조건**으로 모델링함으로써 이 문제를 해결한다.[1]

**주요 기여:**

- **로컬-글로벌 접근법**: 얼굴을 5개 컴포넌트(왼쪽 눈, 오른쪽 눈, 코, 입, 나머지)로 분해하여 각 컴포넌트의 특징 공간을 학습[1]

- **매니폴드 기반 스케치 정제**: 입력 스케치의 각 부분을 학습된 컴포넌트 매니폴드에 투영하여 암묵적으로 스케치를 정제[1]

- **다채널 특징맵 중간 표현**: 컴포넌트 특징 벡터를 1채널 스케치가 아닌 32채널 특징맵으로 매핑하여 정보 흐름을 개선[1]

- **새로운 데이터셋**: CelebAMask-HQ를 기반으로 17,000개의 스케치-이미지 쌍으로 구성된 데이터셋 구축[1]

## 2. 문제 정의, 제안 방법 및 모델 구조

### 2.1 문제 정의

스케치 기반 얼굴 이미지 합성은 본질적으로 세 가지 어려움을 내포한다:[1]

1. **도메인 갭**: 현실적인 얼굴 이미지와 손그린 스케치 사이의 큰 차이
2. **추상성의 다양성**: 사용자의 그리기 능력과 스타일에 따른 스케치 품질의 편차
3. **불완전성**: 스케치가 얼굴의 모든 특징을 명확하게 나타내지 못함

### 2.2 제안 방법

#### 2.2.1 컴포넌트 임베딩(Component Embedding, CE) 모듈

각 얼굴 컴포넌트 $$c \in \{1, 2, 3, 4, 5\}$$에 대해 개별 오토인코더 쌍 $$\{E_c, D_c\}$$를 학습한다:[1]

- **인코더** $$E_c$$: 컴포넌트 스케치를 512차원의 특징 벡터로 인코딩
- **디코더** $$D_c$$: 특징 벡터를 다시 1채널 스케치로 디코딩

각 오토인코더는 5개의 인코딩 계층과 5개의 디코딩 계층, 그리고 중간에 완전 연결 계층(fully connected layer)을 포함한다.[1]

#### 2.2.2 매니폴드 투영(Manifold Projection)

입력 스케치의 각 컴포넌트를 학습된 컴포넌트 매니폴드에 투영하기 위해 **국소 선형 임베딩(Locally Linear Embedding, LLE)** 알고리즘의 개념을 적용한다.[1]

$$c$$번째 컴포넌트의 특징 벡터 $$f$$가 주어졌을 때, 먼저 특징 공간에서 $$K=10$$개의 최근접 이웃을 찾는다. 그 다음 다음의 최소화 문제를 풀어 보간 가중치를 계산한다:

$$\min_{\mathbf{w}} \left\| f - \sum_{k} w_k f_k \right\|^2$$

$$\text{subject to} \quad \sum_{k} w_k = 1 \quad \quad (1)$$

여기서 $$w_k$$는 $$k$$번째 이웃 샘플에 대한 보간 가중치이다.[1]

투영된 특징 벡터는 다음과 같이 계산된다:

$$f_{\text{proj}} = \sum_{k} w_k f_k \quad \quad (2)$$

#### 2.2.3 특징 매핑(Feature Mapping, FM) 모듈

투영된 컴포넌트 특징 벡터를 32채널의 다채널 특징맵으로 변환한다. 이는 컴포넌트 간 경계 부분에서의 불일치를 해결하기 위함이다.[1]

각 컴포넌트 $$c$$에 대해 별도의 디코딩 모델을 설계하며, 완전 연결 계층과 5개의 디코딩 계층으로 구성된다. 최종 특징맵의 크기는 스케치 영역과 동일하다.[1]

개별 컴포넌트의 특징맵들은 고정된 깊이 순서(왼쪽/오른쪽 눈 > 코 > 입 > 나머지)에 따라 통합된다.[1]

#### 2.2.4 이미지 합성(Image Synthesis, IS) 모듈

통합된 특징맵을 조건으로 하는 **조건부 GAN**을 사용한다. 생성기는 pix2pixHD의 글로벌 생성기 구조를 따르며, 인코딩 부분, 잔여 블록(residual block), 디코딩 단위를 순차적으로 포함한다.[1]

판별기는 다중 스케일 방식으로 설계되어 여러 해상도에서 입력을 처리한다.[1]

#### 2.2.5 블렌딩 메커니즘(Blending Mechanism)

사용자의 신뢰도에 따라 원본 스케치와 정제된 버전을 보간할 수 있다:

$$f_{\text{blend}} = wb_c \times f + (1 - wb_c) \times f_{\text{proj}} \quad \quad (3)$$

여기서 $$wb_c$$는 컴포넌트 $$c$$의 블렌딩 가중치이다.[1]

### 2.3 2단계 학습 전략

**Stage I**: CE 모듈만 학습한다. 각 컴포넌트에 대해 평균 제곱 오차(MSE) 손실을 사용한 자기 감독 학습을 수행한다.[1]

**Stage II**: 학습된 컴포넌트 인코더의 매개변수를 고정하고 FM 및 IS 모듈의 미지의 매개변수를 엔드-투-엔드로 학습한다. GAN 손실, L1 손실, 지각 손실(perceptual loss)을 결합하여 사용한다.[1]

## 3. 성능 향상 및 정량적 평가

### 3.1 사용성 평가

사용자 연구에서 10명의 참여자(남성 9명, 여성 1명, 20-26세)를 모집하여 평가했다.[1]

- **노범 사용자**(그리기 능력 1-3): 평균 2분 26초에 얼굴 생성
- **중급 사용자**(4-6): 평균 3분 17초
- **전문가 사용자**(7-9): 평균 17분 14초

모든 그룹에서 사용 용이성, 제어 가능성, 결과 다양성, 결과 품질, 기대 적합성 모두에서 긍정적인 피드백을 받았다.[1]

### 3.2 인지적 평가 연구

22개의 입력 스케치에 대해 60명의 참여자를 대상으로 정성 평가를 수행했다.[1]

**품질 점수** (7점 만점):
- DeepFaceDrawing (제안 방법): 5.50
- 글로벌 검색: 5.37
- 로컬 검색: 4.68

**충실도 점수**:
- DeepFaceDrawing: 4.85
- 글로벌 검색: 3.65
- 로컬 검색: 4.23

일원 분산 분석(one-way ANOVA) 결과, 품질($$F(2,63) = 47.26, p < 0.001$$)과 충실도($$F(2,63) = 51.72, p < 0.001$$) 모두에서 유의미한 효과가 있었다.[1]

### 3.3 기존 방법과의 비교

| 방법 | 해상도 | 특징 |
|------|--------|------|
| pix2pix[1] | 256×256 | 기본 조건부 GAN, 낮은 해상도 |
| pix2pixHD[1] | 512×512 | 고해상도 생성, 하드 제약 조건 |
| Lines2FacePhoto[1] | 256×256 | 거리맵 입력, 제한된 범위 |
| iSketchNFill[1] | 128×128 | 형태 완성 모듈, 저해상도 |
| **DeepFaceDrawing**[1] | **512×512** | **소프트 제약, 매니폴드 투영** |

시각적 비교 결과, DeepFaceDrawing이 더 자연스럽고 현실적인 결과를 생성했다.[1]

## 4. 일반화 성능 향상 관련 내용

### 4.1 논문 내 일반화 메커니즘

#### 4.1.1 컴포넌트 단위 매니폴드 모델링

전역 매니폴드를 학습하는 대신 컴포넌트별로 별도의 매니폴드를 학습함으로써 일반화 성능을 향상시킨다. 각 컴포넌트 매니폴드는 저차원으로 가정되므로, 제한된 학습 데이터로도 더 충분히 스팬될 수 있다.[1]

#### 4.1.2 로컬-글로벌 구조

얼굴의 고정된 구조적 특성을 활용하여 로컬 편집을 지원하고, 동시에 글로벌 일관성을 유지한다. 이는 더 다양한 입력 스케치 스타일에 적응할 수 있게 한다.[1]

#### 4.1.3 소프트 제약 조건

스케치를 하드 제약이 아닌 소프트 제약으로 취급함으로써, 모델이 학습 데이터의 얼굴 분포 공간 내에서 가장 그럴듯한 얼굴을 생성할 수 있다.[1]

### 4.2 논문에서 명시된 한계

저자들이 자신의 결론 부분에서 다음과 같은 한계를 인정했다:[1]

- **데이터 의존성**: 제한된 학습 데이터(16,860개) 때문에 컴포넌트 매니폴드를 부정확하게 모델링할 가능성

- **대칭성 문제**: 왼쪽 및 오른쪽 눈을 독립적으로 취급하면서 발생하는 대칭성 위반 문제

- **레이아웃 오류 미수정**: 시스템은 컴포넌트 내 오류는 수정하지만 전체 얼굴 레이아웃의 오류는 수정하지 못함

- **색상 제어 부재**: 흑백 래스터 스케치만 입력으로 받으며 색상 제어 불가능

- **전면 얼굴 제한**: 정면 얼굴만 지원하며 액세서리가 있는 얼굴 미지원

## 5. 최신 연구 기반 영향 및 향후 고려사항

### 5.1 이 논문이 후속 연구에 미친 영향

#### 5.1.1 확산 모델(Diffusion Models) 기반 스케치-이미지 합성으로의 전환

2022-2024년 사이, 스케치-이미지 합성 분야는 **확산 모델**로의 패러다임 시프트를 경험했다.[2][3][4][5]

- **DiffFaceSketch** (2023): 다중 오토인코더를 사용하여 스케치를 특징 공간으로 인코딩하고, 확산 모델의 잠재 공간에서 작업한다. 이는 DeepFaceDrawing의 컴포넌트 기반 접근에서 영감을 받았다.[3]

- **DiffSketching** (2022): GAN 기반 방법을 초월하여 더욱 다양하고 현실적인 이미지를 생성한다. 확산 모델은 모드 붕괴 문제를 근본적으로 해결하여 생성 품질을 향상시킨다.[5]

- **U-Sketch** (2024): MLP 잠재 엣지 예측기를 사용하여 공간 레이아웃을 가이드하는 더욱 효율적인 접근법을 제시한다.[4]

#### 5.1.2 개방 영역(Open-Domain) 일반화 연구

**Adversarial Open Domain Adaptation (AODA)** (2022)는 DeepFaceDrawing의 컴포넌트 기반 접근을 확장하여 학습 데이터에 없는 카테고리의 스케치로부터 이미지를 합성하는 방법을 제시한다. 이는 다음과 같은 전략을 사용한다:[6][7]

- **양방향 매핑**: 사진→스케치 및 스케치→사진 매핑을 동시에 학습
- **도메인 간 갭 최소화**: 합성된 스케치와 실제 스케치 간의 차이를 줄이기 위한 무작위 혼합 샘플링 전략

#### 5.1.3 제어 가능한 합성으로의 확장

**Block and Detail** (2024)는 DeepFaceDrawing의 진행적 스케칭 개념을 확장하여, 사용자가 거친 블로킹 스트로크와 상세한 스트로크를 분리하여 그릴 수 있도록 한다.[8]

**KnobGen** (2025)는 다양한 수준의 스케치 복잡성에 적응할 수 있는 이중 경로 프레임워크를 제시하여, 초보자부터 전문가까지의 사용자를 수용한다.[9]

### 5.2 도메인 일반화 기술의 진화

최근의 도메인 일반화 연구는 다음을 제시한다:[10][11][12]

- **합성 데이터 활용**: 대규모 합성 데이터로 학습된 모델이 실제 도메인에서도 우수한 성능을 발휘할 수 있음을 보여준다.[10]

- **스타일 다양화**: 무작위 스타일 믹스 기법을 사용하여 도메인 시프트에 강건한 모델을 구축한다.[12]

### 5.3 앞으로의 연구 시 고려할 사항

#### 5.3.1 데이터 스케일 및 다양성 증대

- **더 큰 데이터셋**: 현재 17,000개에서 수백만 개 규모로 확대하여 매니폴드를 더 정확하게 모델링

- **다양한 인종, 나이, 표정**: 더 포괄적인 얼굴 표현을 학습

#### 5.3.2 비정면 얼굴 및 액세서리 지원

- **3D 기하학적 정보**: 3D 얼굴 모델과의 결합을 통해 다양한 포즈 지원

- **세그먼테이션 마스크 확대**: 안경, 수염, 모자 등의 액세서리 처리

#### 5.3.3 색상 및 질감 제어

- **색상 힌트 입력**: 사용자가 색상 스트로크로 결과 색상을 가이드할 수 있도록 확장

- **스타일 전이**: 참조 이미지의 텍스처를 합성된 얼굴에 적용

#### 5.3.4 실시간성 및 효율성 개선

- **경량 모델**: 모바일 장치에서 실행 가능한 경량 버전 개발

- **확산 모델의 가속화**: DDIM, consistency models 등을 통한 생성 속도 개선

#### 5.3.5 상호작용성 향상

- **적응형 대표성**: 사용자의 그리기 스타일을 학습하여 동적으로 섀도우 가이드 업데이트

- **명확한 피드백**: 사용자에게 스케치의 어느 부분이 실현 불가능한지 시각적으로 표시

#### 5.3.6 다른 객체 카테고리로의 확장

저자들도 인정했듯이 현재 시스템은 얼굴의 고정된 구조에 특화되어 있다. **일반화된 객체 스케치-이미지 합성**은 다음의 도전 과제를 포함한다:[1]

- **구조적 다양성**: 신체, 건물, 자동차 등 매우 다른 구조

## 결론

**DeepFaceDrawing**은 스케치 기반 얼굴 생성 분야에서 중요한 기여를 했으며, 특히 **소프트 제약 조건** 개념과 **컴포넌트 기반 매니폴드 모델링**이 이후 연구의 기초가 되었다. 2023-2025년의 최신 연구는 확산 모델 기반 방법으로 진화하면서 더 높은 품질과 다양성을 달성했으나, 여전히 DeepFaceDrawing이 제시한 개념들(로컬-글로벌 구조, 컴포넌트 분해, 매니폴드 투영)은 현대 시스템에서도 적용되고 있다.[3][6][5]

앞으로의 연구는 **데이터 규모 확대**, **비정면 얼굴 지원**, **색상 제어 추가**, **다양한 객체 카테고리 확장** 그리고 **도메인 적응 기법의 통합**에 중점을 두어야 한다. 특히 확산 모델의 강력한 생성 능력과 DeepFaceDrawing의 구조적 통찰력을 결합한 연구가 향후 이 분야의 발전을 주도할 것으로 예상된다.
