## 1. 핵심 주장 및 주요 기여 요약

기존의 DUSt3R 같은 3D 포인트맵 회귀 방법들은 정적 장면 재구성을 위해 설계되었으나, 동적 객체의 움직임이 존재할 경우 카메라 포즈 기반 정렬이 무너져 품질이 크게 저하됩니다.

이 논문은 **Dynamic Dense Unconstrained Stereo 3D Reconstruction (D²USt3R)** 을 제안하며, 공간적 구조와 시간적 움직임을 동시에 고려한 **Static-Dynamic Aligned Pointmaps (SDAP)** 를 직접 회귀(regression)하는 새로운 피드포워드 프레임워크입니다.

### 주요 기여 요약

| 기여 항목 | 내용 |
|---|---|
| **새로운 표현**: SDAP | 정적·동적 영역을 동시에 포착하는 포인트맵 |
| **학습 신호 혁신** | 동적 객체 간 밀집 대응 필드를 학습 과정에 직접 도입 |
| **추가 다운스트림 헤드** | 동적 마스크 및 광학 흐름(optical flow) 전용 헤드 추가 |
| **아키텍처 유지** | DUSt3R 원본 구조를 유지하면서 동적 인식 기능 추가 |

## 2. 해결하고자 하는 문제, 제안 방법(수식), 모델 구조, 성능 및 한계

### 2.1 해결하고자 하는 문제

실세계에 만연한 동적 장면은 3D 재구성에 심각한 어려움을 야기합니다. 객체의 움직임은 카메라 포즈 기반 정렬을 방해하고, 동적 객체에서 잘못 정렬된 대응 관계 및 부정확한 깊이 추정을 초래해 정적 영역의 재구성 정확도까지 저하시킵니다.

MonST3R 같은 최근 방법들도 동적 장면 비디오 컬렉션으로 학습을 확장하지만, 여전히 모든 포인트맵을 단일 전역 강체 변환으로 생성된 것처럼 모델링합니다. 결과적으로 동적 객체에 대한 대응 학습이 손상되어 깊이 정확도와 기하학적 복원 능력이 저하됩니다.

---

### 2.2 제안 방법: SDAP와 학습 신호

#### (a) Static-Dynamic Aligned Pointmaps (SDAP)

D²USt3R는 **SDAP(Static-Dynamic Aligned Pointmaps)** 를 직접 회귀하여, 정적 및 동적 3D 장면 기하학을 동시에 포착합니다.

기존 DUSt3R의 포인트맵이 카메라 좌표계 기준의 3D 포인트를 회귀하는 방식이라면, SDAP는 이를 확장하여 정적 영역과 동적 영역을 명시적으로 구분합니다.

기존 DUSt3R의 포인트맵 회귀 목표는 다음과 같이 표현됩니다:

$$\hat{X}^{v,1} = f_\theta(I_1, I_2) \quad \text{(이미지 쌍으로부터 포인트맵 회귀)}$$

SDAP는 이를 정적-동적 분리 표현으로 확장합니다:

$$\text{SDAP} = \{X_{\text{static}}, X_{\text{dynamic}}\}$$

여기서 $X_{\text{static}}$은 카메라 포즈 정렬 기반 정적 포인트맵, $X_{\text{dynamic}}$은 객체 움직임을 반영한 동적 포인트맵을 의미합니다.

#### (b) 밀집 대응 필드 (Dense Correspondence Field)

D²USt3R는 학습 과정에서 동적 객체 간의 밀집 대응 필드를 직접 도입하고, 정적·동적 영역 모두에서 포인트맵의 일관된 정렬을 보장합니다.

동적 객체의 대응 관계 $\mathcal{C}_{\text{dynamic}}$는 다음과 같이 정의될 수 있습니다:

$$\mathcal{C}_{\text{dynamic}} = \{(p_i, p_j) \mid p_i \in I_t, p_j \in I_{t'}, \text{동일 동적 객체에 속함}\}$$

#### (c) 최종 목적 함수 (Objective Function)

최종 목적 함수는 다음과 같이 정의되며, 이 결합 손실 함수는 모델이 동적 장면에서 정확한 3D 기하학과 강건한 대응 관계를 학습하는 동시에 정적 영역에서 DUSt3R의 기능을 유지하도록 합니다. 또한 동적 마스크와 광학 흐름을 명시적으로 모델링하는 두 개의 추가 다운스트림 헤드를 도입합니다.

최종 목적함수는 확인된 정보를 기반으로 다음과 같이 구성됩니다:

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{pointmap}} + \lambda_1 \mathcal{L}_{\text{corr}} + \lambda_2 \mathcal{L}_{\text{mask}} + \lambda_3 \mathcal{L}_{\text{flow}}$$

각 항의 의미:

| 손실 항 | 설명 |
|---|---|
| $\mathcal{L}_{\text{pointmap}}$ | DUSt3R 기반 정적 포인트맵 회귀 손실 (Confidence-weighted regression loss) |
| $\mathcal{L}_{\text{corr}}$ | 동적 객체 간 밀집 대응 필드 정렬 손실 |
| $\mathcal{L}_{\text{mask}}$ | 동적 마스크 예측 손실 |
| $\mathcal{L}_{\text{flow}}$ | 광학 흐름 예측 손실 |
| $\lambda_1, \lambda_2, \lambda_3$ | 각 손실 항의 균형 조절 하이퍼파라미터 |

> ⚠️ 각 손실 항의 구체적인 수식 표현(예: L1/L2 norm, Laplacian NLL 등)은 논문 원문에서 직접 확인을 권장합니다.

### 2.3 모델 구조

D²USt3R는 원본 DUSt3R 아키텍처를 유지하며, 단순히 새로운 학습 신호를 통해 동적 움직임 인식 기능을 도입합니다.

```
입력: 이미지 쌍 (I₁, I₂)
      ↓
[ViT Encoder] × 2  (각 이미지에 독립적으로 적용)
      ↓
[Cross-Attention Decoder]  (이미지 간 상호작용)
      ↓
   ┌──────────────────────────────────┐
   │  헤드 1: SDAP 회귀 헤드          │ ← X_static + X_dynamic
   │  헤드 2: 동적 마스크 예측 헤드   │ ← M_dynamic
   │  헤드 3: 광학 흐름 예측 헤드     │ ← Flow_dynamic
   └──────────────────────────────────┘
      ↓
출력: SDAP + 동적 마스크 + 광학 흐름
```

D²USt3R는 입력 이미지 쌍이 주어지면, 정적 영역뿐만 아니라 동적 영역에서도 밀집 대응 관계를 정확하게 확립하고, 제안된 SDAP를 통해 동적 장면의 3D 재구성을 가능하게 합니다.

---

### 2.4 성능 향상

D²USt3R는 멀티 프레임 깊이 추정 및 카메라 포즈 추정을 포함한 여러 다운스트림 태스크에서 최첨단(state-of-the-art) 성능을 달성하며, 동적 장면의 밀집 3D 재구성에서 우수한 결과를 보여줍니다.

D²USt3R는 HO3D 및 DAVIS 등 표준 벤치마크에서 최첨단 결과를 달성하며, 정적·동적 요소의 정확한 분리, 카메라 움직임과 객체 움직임의 동시 처리, 특정 학습이나 튜닝 없이 실제 장면에서의 동작이 가능합니다.

MonST3R와 비교하여, D²USt3R는 프레임 간 밀집 대응 관계를 효과적으로 포착하고, 대응 관계와 동적 장면 재구성을 상호 연결된 구성 요소로 처리함으로써 동적 요소의 깊이 정확도를 향상시킵니다.

---

### 2.5 한계

논문에서 직접 명시하거나 구조적으로 추론 가능한 한계는 다음과 같습니다:

1. **페어와이즈(pair-wise) 처리의 제한**: 기본적으로 이미지 쌍을 입력으로 사용하므로, 긴 시퀀스에서의 누적 오차 문제가 발생할 수 있습니다.
2. **동적 마스크 품질 의존성**: 동적 마스크 예측 품질이 전체 SDAP 정확도에 영향을 미칩니다.
3. **학습 데이터 다양성**: MonST3R처럼 동적 장면 학습 데이터에 의존하므로, 학습 데이터에 포함되지 않은 비정형 동적 패턴(예: 유체, 연기 등)에서의 일반화 성능이 검증되지 않았습니다.
4. **극단적 폐색(occlusion)**: 동적 객체가 완전히 가려지는 경우의 처리에 한계가 있을 수 있습니다.

## 3. 모델의 일반화 성능 향상 가능성

D²USt3R의 핵심 강점은 장면에서 변하지 않는 부분(건물, 가구 등)과 움직이는 요소(사람, 차량 등)를 분리하는 능력에 있으며, 이 분리가 다른 방식들에서 나타나는 모션 블러 없이 더 깨끗하고 정확한 3D 재구성을 가능하게 합니다.

일반화 성능 향상 가능성은 다음 측면에서 분석할 수 있습니다:

### 3.1 아키텍처적 일반화 우위

D²USt3R는 DUSt3R의 원본 아키텍처를 유지하며 새로운 학습 신호만을 추가하므로, DUSt3R의 대규모 사전학습(pre-training)에서 얻은 강력한 장면 이해 능력을 그대로 상속받아 일반화 기반이 탄탄합니다.

### 3.2 피드포워드 방식의 이점

피드포워드 방식으로 4D 포인트맵을 회귀하면서 시공간적 측면을 명시적으로 통합함으로써, 시공간 밀집 대응 관계를 효과적으로 포착합니다. 이는 테스트 시 최적화(test-time optimization)가 필요 없어 미지의 도메인에서도 안정적으로 동작할 가능성이 높습니다.

### 3.3 멀티태스크 학습을 통한 표현 강화

동적 마스크와 광학 흐름을 보조 태스크로 학습함으로써, 모델이 동적 요소에 대한 풍부한 내부 표현을 학습하게 됩니다. 이는 다양한 유형의 동적 장면으로의 전이 학습(transfer learning)을 용이하게 합니다.

### 3.4 제로샷(Zero-shot) 일반화 가능성

D²USt3R는 특정 학습이나 튜닝 없이도 실제 장면에서 동작 가능함을 보였습니다. 이는 다양한 도메인(의료 영상, 자율주행, AR/VR 등)으로의 제로샷 전이 잠재력을 시사합니다.

### 3.5 향후 일반화 확장 방향

- **학습 데이터 다양화**: 더 다양한 동적 패턴(유체, 비강체 변형 등)을 포함한 데이터 확보
- **비디오 전체 시퀀스 처리**: 페어와이즈에서 시퀀스 전체로 확장 시 시간적 일관성 향상
- **자기지도(Self-supervised) 신호 활용**: 레이블 없이도 동적 대응 관계를 학습하는 방향

## 4. 관련 최신 연구 비교 분석 (2020년 이후)

| 모델 | 연도 | 핵심 방식 | 동적 장면 처리 | 한계 |
|---|---|---|---|---|
| **DUSt3R** | 2024 | ViT 기반 포인트맵 회귀, 피드포워드 | ❌ 정적 장면 전용 | 동적 객체에서 대응 실패 |
| **MonST3R** | 2024 | DUSt3R 확장, 동적 비디오 학습 | ⚠️ 부분적 | 단일 전역 강체 변환 가정, 대응 손상 |
| **MASt3R** | 2024 | 밀집 매칭 + 3D 재구성 결합 | ❌ 주로 정적 | 동적 장면 미특화 |
| **$D^2USt3R$** | 2025 | SDAP + 밀집 대응 + 동적 마스크/플로우 헤드 | ✅ 완전 지원 | 학습 데이터 의존성 |
| **PointSt3R** | 2025 | MASt3R 기반 동적 포인트 추적 | ✅ 지원 | 쌍(pair) 기반 처리 |

DUSt3R와 MonST3R 모두 동적 요소를 포함한 장면을 정확하게 재구성하는 데 어려움을 겪으며, 동적 영역 간에 부정확하게 구축된 대응 필드가 전체 재구성 성능에 부정적인 영향을 미칩니다.

DUSt3R에서 영감을 받은 최근 모델들은 포즈 없는 이미지 쌍으로부터 3D 재구성에 집중하고 있으며, 이미지 쌍의 각 픽셀에 대한 3D 위치를 계산하여 밀집 포인트 대응에 잠재적으로 활용 가능하고, 새로운 회귀 헤드를 통해 다양한 다운스트림 태스크로 쉽게 수정될 수 있음을 보여줍니다.

## 5. 앞으로의 연구에 미치는 영향 및 고려할 점

### 5.1 연구 영향

1. **동적-정적 분리 패러다임의 정립**: SDAP 개념은 향후 동적 장면 재구성의 표준 표현 방식으로 자리잡을 가능성이 높습니다.

2. **DUSt3R 패밀리 확장**: DUSt3R를 움직이는 변형 가능한 객체를 포함하는 데이터로 파인튜닝하면 아키텍처 변경 없이도 동적 재구성이 크게 향상될 수 있음을 보여주어, 후속 연구들에 중요한 설계 방향성을 제시합니다.

3. **3D Gaussian Splatting과의 결합**: 움직이는 사람들이 포함된 장면이나 기존 방법으로 렌더링하기 어려운 동적 장면에서 3D Gaussian Splatting을 직접 학습하는 것이 가능해집니다.

4. **다운스트림 태스크 통합 학습**: 단일 모델에서 깊이 추정, 광학 흐름, 동적 마스크를 동시에 학습하는 멀티태스크 설계가 표준화될 가능성이 있습니다.

### 5.2 향후 연구 시 고려할 점

| 고려 사항 | 설명 |
|---|---|
| **비강체 변형 처리** | 사람의 몸, 천 등 비강체 객체의 국소 변형을 어떻게 모델링할지 |
| **긴 시퀀스 일관성** | 페어와이즈 처리에서 발생하는 누적 오차를 시퀀스 레벨로 어떻게 해소할지 |
| **학습 데이터 편향** | 특정 도메인(실내/실외, 특정 객체 유형)에 편중된 동적 학습 데이터의 다양화 필요 |
| **실시간 처리** | 자율주행·로보틱스 등 실시간 응용을 위한 경량화 연구 필요 |
| **극단적 폐색 처리** | 동적 객체 완전 폐색 시의 대응 복원 전략 필요 |
| **자기지도 학습** | 레이블 획득 비용을 줄이기 위한 비지도/자기지도 방식의 동적 대응 학습 |
| **평가 벤치마크 확장** | HO3D, DAVIS 외 더 다양하고 난이도 높은 동적 장면 벤치마크 필요 |
| **멀티모달 융합** | LiDAR, IMU 등 다른 센서 정보와의 결합을 통한 강인성 향상 |

광범위한 실험 평가를 통해 D²USt3R의 제안 방법이 복잡한 움직임을 포함하는 다양한 데이터셋에서 일관되게 우수한 3D 재구성 성능을 달성함을 입증하였으며, 이는 동적 3D 재구성 분야의 중요한 이정표가 될 것입니다.
