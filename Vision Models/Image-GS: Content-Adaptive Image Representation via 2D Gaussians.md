## 1. 핵심 주장과 주요 기여 (간결 요약)

기존 신경 이미지 표현(Neural Image Representation) 방법들은 학습 기반 워크플로우와 결합하여 시각적 충실도와 메모리 사용량 간의 인상적인 균형을 보여주었으나, 메모리를 비효율적으로 할당하는 고정 데이터 구조 혹은 연산 집약적인 암묵적 모델에 의존하여 실시간 그래픽 응용에 적합하지 않았다.

이에 대응하여, 복사 필드(radiance field) 렌더링의 최근 발전에 착안하여 Image-GS를 제안한다. 커스텀 미분 가능 렌더러를 활용해, 이방성(anisotropic) 유색 2D 가우시안 집합을 적응적으로 할당하고 점진적으로 최적화하여 이미지를 재구성하며, 그래픽 워크플로우에서 자주 등장하는 스타일화된 이미지들, 특히 비균일하게 분포된 특징을 지닌 이미지와 저비트레이트 환경에서 시각적 충실도와 메모리 효율 사이의 우수한 균형을 달성한다.

**주요 기여 요약:**

| 기여 항목 | 내용 |
|---|---|
| **콘텐츠 적응형 표현** | 이미지 그래디언트에 기반한 적응적 가우시안 배치 |
| **미분 가능 렌더러** | 타일 기반 커스텀 CUDA 렌더러 설계 |
| **점진적 최적화** | 에러 기반 가우시안 추가로 LoD 계층 자동 생성 |
| **하드웨어 친화적 접근** | 픽셀 디코딩에 단 0.3K MACs 소요 |
| **다양한 응용** | 텍스처 압축, 의미론적 압축, 이미지 복원 |

## 2. 상세 분석

### 2-1. 해결하고자 하는 문제

기존 방법들은 메모리를 비최적으로 할당하는 고정 데이터 구조, 또는 연산 집약적인 암묵적(implicit) 모델에 의존하여 실시간 그래픽 응용에서의 실용성을 저해한다. 구체적으로:

- **고정 그리드 기반 방법** (ReLU-F, I-NGP): 피처 그리드의 해상도를 낮추면 더 희박한 위치에서 피처 벡터가 보간되어 블록 아티팩트가 발생한다.
- **암묵적 신경 표현** (SIREN, FFN, WIRE): 링잉(ringing), 블러링(blurring), 고스팅(ghosting) 등의 아티팩트가 발생하며, 네트워크 파라미터 감소 시 더욱 심화된다.
- **GaussianImage**: Gaussian Splatting의 훈련 과정이 느리고, 이미지당 고정된 가우시안 수가 다양한 정보 엔트로피에 대한 적응성을 제한한다.

---

### 2-2. 제안하는 방법 (수식 포함)

#### (1) 2D 가우시안 프리미티브 정의

3D Gaussian Splatting과 유사하게, Image-GS의 각 2D 가우시안은 평균 벡터(위치), 공분산 행렬(형태), 색상 벡터로 정의된다. 공분산 행렬은 최적화 과정에서 양반정치(positive semi-definite) 조건을 유지하기 위해 회전 성분과 스케일 성분으로 인수분해된다.

각 2D 가우시안은 다음 파라미터로 구성된다:

$$\mu \in \mathbb{R}^2 \quad (\text{위치}), \quad \theta \in \mathbb{R} \quad (\text{회전}), \quad \mathbf{s} \in \mathbb{R}^2_+ \quad (\text{스케일}), \quad \mathbf{c} \in \mathbb{R}^n \quad (\text{색상})$$

공분산 행렬은 다음과 같이 인수분해된다:

$$\Sigma = R(\theta) \cdot S \cdot S^\top \cdot R(\theta)^\top, \quad S = \text{diag}(\mathbf{s})$$

여기서 $R(\theta)$는 회전 행렬이다. 각 2D 가우시안 프리미티브는 총 $5 + n$개의 학습 가능한 파라미터로 완전히 특징지어지며, 여기서 $n$은 색상 차원이다.

#### (2) 가우시안 래스터화 (렌더링)

픽셀 $\mathbf{x}$에서의 가우시안 응답(opacity)은:

$$\alpha(\mathbf{x}) = \exp\left(-\frac{1}{2}(\mathbf{x} - \mu)^\top \Sigma^{-1} (\mathbf{x} - \mu)\right)$$

3D Gaussian Splatting이 불투명도(opacity)와 깊이 정렬(depth sorting)을 필요로 하는 것과 달리, 2D 가우시안은 적용 순서에 무관하게 단순히 가중 색상을 합산함으로써 렌더링될 수 있다.

최종 픽셀 색상 $\hat{I}(\mathbf{x})$:

$$\hat{I}(\mathbf{x}) = \sum_{i} \alpha_i(\mathbf{x}) \cdot \mathbf{c}_i$$

#### (3) 타일 기반 렌더링

렌더링 및 훈련 속도를 향상시키면서 데이터 로컬리티(빠른 임의 픽셀 접근에 필수)를 유지하기 위해, Image-GS는 각 픽셀에 기여하는 가우시안 수를 제한하는 타일 기반 렌더링 방식을 채택한다. 각 픽셀에 대해 가우시안을 기여값으로 순위를 매겨 상위 $K$개만 유지한다. 이 접근법은 데이터 로컬리티를 향상시킬 뿐만 아니라, 최적화 과정에서 정규화 역할을 수행하여 재구성 품질을 개선한다.

구현에서 타일 크기: $16 \times 16$ 픽셀, 상위 $K = 10$개 가우시안 선택.

#### (4) 콘텐츠 적응형 초기화 (Content-Adaptive Initialization)

초기화 단계에서, 2D 가우시안 그룹은 지역 이미지 그래디언트 크기에 의해 안내되어 적응적으로 생성되며, 고주파 영역에 더 많이 할당된다.

초기화 확률 분포:

$$P_{\text{init}}(\mathbf{x}) = (1 - \lambda) \frac{\|\nabla I(\mathbf{x})\|_2}{\sum_{\mathbf{x}'} \|\nabla I(\mathbf{x}')\|} + \frac{\lambda}{H \times W}$$

여기서:
- $\lambda$: 균일 샘플링 비중 (균형 조절 하이퍼파라미터)
- $\|\nabla I(\mathbf{x})\|_2$: 픽셀 $\mathbf{x}$에서의 이미지 그래디언트 크기
- $H \times W$: 이미지 해상도

#### (5) 점진적 최적화 (Progressive Optimization)

가우시안 파라미터는 타일 기반 미분 가능 렌더러를 통해 목표 이미지를 재구성하도록 최적화되며, 재구성 오류가 높은 이미지 영역에 추가 가우시안이 점진적으로 삽입된다.

점진적 할당 스케줄:
- 초기: $N_g / 2$개의 가우시안으로 시작
- 500 스텝마다 $N_g / 8$개씩 추가

손실 함수 (PSNR/SSIM/LPIPS 기반 복합 손실):

$$\mathcal{L} = \mathcal{L}_{\text{pixel}} + \lambda_{\text{SSIM}} \cdot \mathcal{L}_{\text{SSIM}} + \lambda_{\text{LPIPS}} \cdot \mathcal{L}_{\text{LPIPS}}$$

#### (6) 빠른 임의 접근을 위한 계층적 그리드

추론 속도 향상을 위해, 이진 공간 분할(Binary Space Partitioning)에 기반한 계층적 그리드 구조를 도입하여 최적화된 가우시안을 공간적으로 분할하고 런타임 연산을 줄인다.

### 2-3. 모델 구조

```
[입력 이미지]
      │
      ▼
[그래디언트 맵 계산] → Sobel 필터 기반 ∇I(x)
      │
      ▼
[콘텐츠 적응형 초기화] → P_init(x) 기반 가우시안 배치
      │
      ▼
[미분 가능 타일 기반 렌더러] → 16×16 타일, Top-K=10 가우시안
      │
      ▼
[오류 기반 점진적 가우시안 추가] → 500 스텝마다 N_g/8 추가
      │
      ▼
[BSP 트리 기반 계층적 그리드] → 빠른 임의 접근 지원
      │
      ▼
[최종 이미지 표현] → LoD 계층 구조 포함
```

유연하고 컴팩트한 이미지 표현(Section 3.1), 가우시안을 픽셀값으로 집계하는 미분 가능 렌더러(Section 3.2), 그리고 점진적 최적화(Section 3.3)를 도입한다. 가우시안 파라미터는 이미지 콘텐츠를 재구성하도록 최적화되며, 오류가 많은 영역에 추가 가우시안이 점진적으로 추가된다. 이 결과로 Image-GS는 지역 이미지 영역의 복잡도에 따라 2D 가우시안을 적응적으로 할당하여 시각적 충실도와 메모리/연산 효율 사이의 유리한 균형을 달성한다. 저비용 임의 접근 및 빠른 렌더링을 위해 최적화된 가우시안을 공간적으로 분할하는 이미지별 계층 그리드를 구축한다.

---

### 2-4. 성능 향상

ReLU-F, SIREN, FFN, WIRE, I-NGP, GI 등 6개 신경 이미지 표현과 JPEG 대비, Image-GS는 평가된 전체 비트레이트 범위에서 모든 신경 기반 기준선(baseline)을 능가한다.

비트레이트가 0.244 이하로 떨어지면 Image-GS는 JPEG를 크게 상회하기도 한다. 주목할 점은, JPEG와 GI는 데이터 로컬리티를 깨는 엔트로피 코딩에 의존하는 반면, Image-GS는 그러한 메커니즘에 의존하지 않는다.

또한, 실시간 사용을 위한 하드웨어 친화적 빠른 임의 접근을 지원하며, 픽셀 하나를 디코딩하는 데 단 0.3K MACs만 필요하다.

비교 실험에서의 모델 크기 (2K×2K 해상도 기준):
| 모델 | 크기(KB) |
|---|---|
| ReLU-F | 164 |
| I-NGP | 166 |
| SIREN | 161 |
| FFN | 154 |
| WIRE | 159 |
| GI (GaussianImage) | 164 |
| **Image-GS** | **160** |

에러 기반 점진적 최적화를 통해 Image-GS는 자연스럽게 부드러운 레벨-오브-디테일(LoD) 계층을 구성하며, 텍스처 압축, 의미론적 압축, 이미지 압축 및 복원의 결합 등 다양한 응용에서의 범용성을 입증한다.

### 2-5. 한계

CLIC2020 데이터셋의 검증 분할(자연 이미지)에서 Image-GS는 스타일화된 이미지 결과보다 낮은 점수를 달성한다. 이는 일정 비트레이트에서 저해상도 이미지의 더 제한된 가우시안 예산과 픽셀 특성의 만연에 기인한다.

추가적인 한계점:
- **최적화 기반 per-image 방법**: 새 이미지마다 처음부터 최적화해야 하므로 인코딩 시간이 소요된다.
- **자연 이미지 처리**: 비균일 특징 분포를 가진 그래픽 에셋에서 특히 강력하나, 픽셀 단위 변화가 많은 자연 사진에서의 성능은 상대적으로 낮다.
- 향후 작업으로서, 동적 이진 공간 분할 트리를 통해 가우시안 분포를 안내하고 다양한 스케일의 이미지 특징 간 비교 가능한 중요도를 장려하도록 그래디언트를 적응적으로 스케일링하는 방향이 제안된다.

## 3. 모델의 일반화 성능 향상 가능성

### 3-1. 현재의 일반화 검증

여러 최신 신경 이미지 표현 및 산업 표준 텍스처 압축 알고리즘과의 비교 실험을 통해 Image-GS의 시각적 품질 및 메모리·연산 효율 측면에서의 일반화 성능이 검증되었다. 또한, Image-GS는 하드웨어 친화적인 빠른 임의 접근, 연속 레벨-오브-디테일 적응, 실시간 추론 성능을 지원한다.

메모리 및 연산 요구 사항은 2D 가우시안의 수에만 의존하고 선형적으로 스케일되어, 시각적 충실도와 런타임 효율 사이의 균형에 대한 유연한 제어를 제공한다.

### 3-2. 이미지 유형별 일반화

평가 데이터셋은 사진, 수채화/유화, 애니메이션 포스터, 벡터 스타일 이미지 등 다양한 이미지 유형을 포함하며, Image-GS의 콘텐츠 적응적 특성은 유사한 메모리 소비 하에서 기준 방법들보다 지역 이미지 영역의 복잡도에 따라 자원을 현명하게 할당하고 세밀한 이미지 디테일을 더 잘 보존하게 한다.

### 3-3. 일반화를 위한 후속 연구 방향

기존 per-image 최적화 방식의 일반화 한계를 극복하기 위한 후속 연구가 이미 등장하고 있다:

**① 일반화 가능한 2D GS 프레임워크** (ResearchGate 관련 연구):
일반화 가능하고 자기 적응적인 이미지 표현 프레임워크를 제안하며, 네트워크를 활용해 거친 가우시안 표현을 빠르게 생성하고 최소한의 미세 조정 단계를 거쳐 GaussianImage와 비교 가능한 렌더링 품질을 훈련 시간을 크게 줄이면서 달성한다. 또한 이미지 복잡도에 따라 가우시안 포인트 수를 동적으로 조정한다.

**② GSASR** (2D GS 기반 임의 배율 초해상도):
GS를 초해상도(ASR) 작업에 직접 적용하는 것은 원본 GS가 단일 장면에 대한 과적합 기반 최적화 방법인 반면, ASR에서는 다양한 이미지와 스케일 인수에 일반화할 수 있는 단일 모델을 학습해야 하므로 매우 도전적이다. 이 한계를 극복하기 위해 LR 입력 이미지에 조건화된 2D 가우시안을 예측하는 아키텍처를 정교하게 설계하였다.

**③ Structure-Guided 2DGS** (구조 기반 할당):
자연 이미지에 내재된 공간 구조적 사전 지식에 따라 2D 가우시안을 할당하는 구조 기반 초기화를 도입하고, 양자화 인식 미세 조정 중 복잡한 영역의 소규모 가우시안에 더 높은 정밀도를 부여하는 적응 비트폭 양자화를 제안하며, 가우시안 방향을 지역 그래디언트 방향에 정렬시키는 기하학적 일관성 정규화를 적용한다.

## 4. 향후 연구에 미치는 영향 및 고려 사항

### 4-1. 향후 연구에 미치는 영향

Image-GS는 이미지를 픽셀이나 신경 필드가 아닌 명시적이고 적응적인 유색 2D 가우시안 집합으로 표현하는 새로운 패러다임을 제시하며, 컴팩트하고 유연하며 고충실도, 하드웨어 친화적, 콘텐츠 적응적, 실시간 준비 완료, 의미론적 인식이 가능한 표현 패러다임을 보여준다.

**주요 파급 영향:**

1. **비디오 표현으로의 확장 가능성**: 2D 가우시안 기반 3D 장면 표현에 동역학을 통합한 최근 연구에서 영감받아, 이미지 평면 내 2D 가우시안의 움직임을 추가적으로 모델링하여 비디오를 표현하는 방법에 적용할 계획이 있으며, 이는 비디오 스트리밍과 같은 그래픽 응용에 이점을 줄 것으로 기대된다.

2. **대규모 장면 표현**: 고해상도 시각 데이터의 효율적 인코딩이 중요한 대규모 장면 표현으로 확장될 수 있다.

3. **기계 인식 및 콘텐츠 생성 응용**: 적응적 품질 및 자원 제어를 필요로 하는 기계 인식, 에셋 스트리밍, 콘텐츠 생성과 같은 새로운 응용 분야 개발에 인사이트를 제공한다.

4. **명시적·암묵적 표현의 장점 통합**: 직접 메모리 접근 및 적응형 레벨-오브-디테일(명시적)과 효율적 저장 및 학습 호환성(암묵적)의 장점을 모두 갖춘 새로운 이미지 표현 개발에 인사이트를 제공하며, 특정 하드웨어 및 응용 요구를 지원한다.

### 4-2. 2020년 이후 관련 최신 연구 비교 분석

| 논문 | 연도 | 방법 | 특징 | Image-GS와 차이점 |
|---|---|---|---|---|
| **SIREN** (Sitzmann et al.) | 2020 | 사인 활성화 함수 기반 INR | 고주파 신호 표현에 강 | 고정 네트워크 구조, 비적응적 |
| **I-NGP** (Müller et al.) | 2022 | 다해상도 해시 그리드 + MLP | 빠른 훈련 속도 | 균일 그리드, 저비트레이트 취약 |
| **WIRE** (Saragadam et al.) | 2023 | Gabor 웨이블릿 기반 INR | 자연 이미지에 강 | 암묵적 모델, 느린 디코딩 |
| **GaussianImage** (Zhang et al.) | 2024 | 3DGS를 2D로 확장 | Gaussian Splatting 선구적 적용 | 고정 가우시안 수, 비적응적 초기화 |
| **Image-GS** (Zhang et al.) | 2024/2025 | 콘텐츠 적응형 2D GS | 적응적 초기화 + 점진적 최적화 | **본 논문** |
| **GaussianImage++** | 2024 | 왜곡 기반 밀도화 + 컨텍스트 필터 | GaussianImage 개선 | 제한된 가우시안 프리미티브로 인상적인 표현 및 압축 성능 달성; 왜곡 기반 밀도화 메커니즘 도입 |
| **Structure-Guided 2DGS** | 2024 | 구조 기반 할당 + 적응 비트폭 양자화 | RD 성능 대폭 향상 | Kodak에서 BD-rate 43.44%, DIV2K에서 29.91% 감소 |
| **GSASR** | 2025 | 2DGS + 임의 배율 초해상도 | 일반화 가능한 GS 모델 | 단일 장면 과적합이 아닌 다양한 이미지에 일반화 가능한 단일 모델 |

### 4-3. 향후 연구 시 고려할 점

1. **자연 이미지 일반화 강화**: Image-GS는 스타일화된 이미지에서 강점을 보이지만, 자연 이미지에서는 성능이 상대적으로 제한된다. 학습 기반(feed-forward) 가우시안 생성 네트워크를 결합하여 per-image 최적화 없이 즉시 가우시안을 예측하는 방식이 유망하다.

2. **비디오·동적 콘텐츠 확장**: 이미지 평면에서 2D 가우시안의 움직임을 모델링하여 비디오 표현으로 확장하는 것이 유망한 방향이며, 확장 현실(XR)에서의 파노라마 비디오 스트리밍 같은 응용에 이점을 줄 수 있다.

3. **엔트로피 코딩과의 통합**: JPEG와 GI는 데이터 로컬리티를 깨는 엔트로피 코딩을 활용하는 반면, Image-GS는 이를 사용하지 않는다. 데이터 로컬리티를 유지하면서 엔트로피 코딩을 통합하는 방법이 향후 압축 성능 향상의 핵심이 될 수 있다.

4. **의미론적 인식 강화**: 고정 이미지 세트로 훈련된 방법들은 새로운 이미지에 일반화하는 데 어려움을 겪을 수 있다. 세그멘테이션 정보나 언어 모델 가이던스를 통한 가우시안 할당 정책의 개선이 중요하다.

5. **하드웨어 구현 최적화**: 0.3K MACs의 초저전력 디코딩은 모바일/엣지 기기에서의 응용 가능성을 열지만, BSP 트리 구축 비용 및 메모리 접근 패턴의 하드웨어 최적화가 필요하다.
