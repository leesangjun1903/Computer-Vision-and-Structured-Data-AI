# TTT3R: 3D Reconstruction as Test-Time Training

## 1. 논문의 핵심 주장 및 주요 기여 (Summary)

### 1.1 핵심 주장

**TTT3R**(3D Reconstruction as Test-Time Training)은 최신 3D 재구성 모델, 특히 **CUT3R**이 겪는 **길이 일반화 실패(length generalization failure)** 문제를 해결하기 위해 제안된 혁신적인 프레임워크이다. 

핵심 주장의 요점:
- 현대의 RNN 기반 3D 재구성 모델은 선형 시간 복잡도를 제공하지만, 학습 시 사용한 길이(보통 64프레임)를 초과하는 입력에서 **급격한 성능 저하**를 보인다
- 이 문제는 RNN의 **상태 오버피팅(state overfitting)**, **상태 망각(state forgetting)**, **미탐색 상태 분포(unexplored state distributions)**로부터 발생한다
- **테스트-타임 트레이닝(Test-Time Training, TTT)** 관점에서 재설계하면, 상태를 동적으로 적응하는 빠른 가중치(fast weights)로 보고, 신뢰도 기반 학습률로 업데이트할 수 있다

### 1.2 주요 기여

1. **이론적 기여**: RNN 기반 3D 재구성 모델을 TTT 프레임워크로 재해석
   - 상태 업데이트를 온라인 학습 문제로 재구성
   - 상태 오버피팅에 대한 이론적 이해 제공

2. **방법론적 기여**: 폐쇄형 학습률 도출
   - 정렬 신뢰도(alignment confidence)를 토큰별 학습률로 변환
   - 훈련 없이 적용 가능한 플러그-앤-플레이 솔루션 제시

3. **성능 기여**: 
   - 카메라 포즈 추정에서 **2배 성능 향상** (ATE 기준)
   - GPU 메모리 사용량 유지: **6GB** (1000프레임 이상 처리 가능)
   - 추론 속도 유지: **20FPS**

## 2. 문제 정의, 방법론, 모델 구조, 성능 및 한계

### 2.1 해결하고자 하는 문제

#### 2.1.1 기본 문제 설정

3D 재구성 기초 모델들의 분류:

| 방식 | 장점 | 단점 | 복잡도 |
|------|------|------|--------|
| **전체 주의(Full Attention)** | 완전한 맥락 보존 | 메모리 폭증 | $$O(t^2)$$ |
| **RNN 기반** | 상수 메모리 | 길이 일반화 실패 | $$O(1)$$ |
| **인과 주의(Causal Attention)** | 증분 처리 | 메모리 선형 증가 | $$O(t)$$ |

#### 2.1.2 구체적 문제: CUT3R의 길이 일반화 실패

**CUT3R**(Continuous 3D perception model with persistent state, 2025)은 효율적인 온라인 3D 재구성을 위해 설계되었으나:

- 학습 시 주로 **64프레임 시퀀스**로 훈련됨
- **100프레임 이상**의 긴 시퀀스에서 재앙적 망각(catastrophic forgetting) 발생
- 카메라 포즈 추정 오류 증가, 기하학적 변형, 유령 아티팩트 발생

**근본 원인 분석:**

CUT3R의 상태 업데이트 규칙:
$$S_t = S_{t-1} + \text{softmax}(Q_{S_{t-1}}K_{X_t})V_{X_t} \quad \cdots (3)$$

여기서:
- $$S_{t-1} \in \mathbb{R}^{n \times c}$$: 이전 상태 (n개 토큰, c차원)
- $$Q_{S_{t-1}} \in \mathbb{R}^{n \times c}$$: 상태의 쿼리 투영
- $$K_{X_t}, V_{X_t} \in \mathbb{R}^{h \cdot w \times c}$$: 현재 관찰의 키-값 쌍

**문제**: softmax 정규화로 인해 항상 새로운 정보 $$X_t$$에 우선순위를 부여하여 과거 정보를 급격히 망각

### 2.2 제안하는 방법 (Theory and Formulation)

#### 2.2.1 TTT 프레임워크로의 재해석

**기본 TTT 공식:**

상태를 테스트 타임에 경사 강하로 업데이트되는 빠른 가중치로 해석:

$$S_t = S_{t-1} - \alpha_t \nabla \mathcal{L}(S_{t-1}, X_t) \quad \cdots (4)$$

여기서:
- $$\alpha_t$$: 적응형 학습률
- $$\nabla \mathcal{L}$$: 손실 함수의 그래디언트

**선형 TTT 특수화 (DeltaNet):**

재구성 오류를 최소화하려면:
$$\mathcal{L} = \|S_{t-1}K_{X_t} - V_{X_t}\|^2$$

이로부터:
$$\nabla \mathcal{L} \propto (S_{t-1}K_{X_t} - V_{X_t})K_{X_t}^T$$

따라서:
$$S_t = S_{t-1} - \alpha_t(S_{t-1}K_{X_t} - V_{X_t})K_{X_t}^T \quad \cdots (5)$$

**CUT3R를 TTT로 재형식화:**

CUT3R의 업데이트를 TTT 프레임워크에 맞추면:
$$S_t = S_{t-1} - \alpha_t \cdot \text{softmax}(Q_{S_{t-1}}K_{X_t})V_{X_t} \cdots (6)$$

여기서 학습률 $$\alpha_t$$는 기존에 1.0으로 고정되어 있음 → **성능 저하의 원인**

#### 2.2.2 신뢰도 기반 상태 업데이트 규칙 (TTT3R)

**핵심 아이디어**: 정렬 신뢰도(alignment confidence)를 토큰별 학습률로 사용

**토큰별 학습률 도출:**
$$\beta_t = \max_m \left( Q_{S_{t-1}}K_{X_t} \right) \in \mathbb{R}^{n \times 1} \quad \cdots (7)$$

여기서:
- $$\max_m$$: 공간 차원(m = 1, ..., h·w) 상의 최대값 (각 상태 토큰마다)
- $$\beta_t \in [0, 1]$$: 각 상태 토큰의 정렬 신뢰도
- 높은 신뢰도 = 상태와 관찰 간 강한 매칭 → 큰 업데이트 스텝
- 낮은 신뢰도 = 약한 매칭 (예: 텍스처리스 영역) → 작은 업데이트 스텝

**최종 폐쇄형 상태 업데이트:**
$$S_t = S_{t-1} - \beta_t \odot \text{softmax}(Q_{S_{t-1}}K_{X_t})V_{X_t} \quad \cdots (8)$$

여기서 $$\odot$$는 원소별 곱셈(element-wise multiplication)을 나타냄

**수학적 의미:**
- 방정식 (8)은 **선택적 상태 억제(selective state suppression)** 메커니즘 구현
- 낮은 품질의 관찰 영역에서의 상태 오염 방지
- 높은 신뢰도 영역에서만 강한 적응 유도

### 2.3 모델 구조 (Architecture)

#### 2.3.1 시퀀스 모델링 계층 비교

**A. 전체 주의(Full Attention) - Fast3R, VGGT**
```
입력 이미지 I_t
    ↓
토큰화 (DINO/CroCo)
    ↓
전역 모든-대-모든 자기주의
    ↓
상태: S_t = [KV_1, KV_2, ..., KV_t]  (크기 선형 증가)
    ↓
읽기 및 포인트맵 복호화
    ↓
카메라 포즈 + 3D 포인트클라우드
```
특징: 이차 복잡도 $$O(t^2)$$, 메모리 소진

**B. RNN 기반 - CUT3R, TTT3R**
```
입력 이미지 I_t
    ↓
토큰화
    ↓
교차-주의(Cross-Attention) 업데이트
    ↓
상태: S_t ∈ R^{n×c}  (고정 크기)
    ↓
신뢰도 기반 학습률 계산 (TTT3R만)
    ↓
적응형 상태 갱신 (식 8)
    ↓
읽기 및 포인트맵 복호화
    ↓
카메라 포즈 + 3D 포인트클라우드
```
특징: 선형 복잡도 $$O(1)$$, 상수 메모리

#### 2.3.2 CUT3R vs TTT3R 상세 비교

| 구성요소 | CUT3R | TTT3R |
|---------|-------|-------|
| **상태 표현** | $$S_t \in \mathbb{R}^{n \times c}$$ | $$S_t \in \mathbb{R}^{n \times c}$$ |
| **업데이트 규칙** | Eq. (3): 고정 가중치 | Eq. (8): 신뢰도 기반 |
| **학습률** | $$\alpha = 1.0$$ (고정) | $$\beta_t \in [0,1]$$ (토큰별 적응) |
| **계산 복잡도** | $$O(1)$$ | $$O(1)$$ (오버헤드 최소) |
| **훈련 필요** | 기존 CUT3R 모델 사용 | 훈련 불필요 (추론 시 적용) |
| **플러그-앤-플레이** | X | ✓ |

#### 2.3.3 각 단계의 수학적 상세

**단계 1: 토큰화**
$$X_t = \text{Tokenizer}(I_t) \in \mathbb{R}^{h \times w \times c}$$

**단계 2: 교차-주의 계산**

$$\text{Attention} = \text{softmax}\left( \frac{Q_{S_{t-1}}K_{X_t}^T}{\sqrt{c}} \right) \in \mathbb{R}^{n \times hw}$$

**단계 3: 신뢰도 추출 (TTT3R 고유)**

$$\text{conf}_i = \max_{m} \text{Attention}_{i,m} \quad \forall i \in [1,n]$$

**단계 4: 신뢰도-가중 업데이트**

$$S_t = S_{t-1} + \text{Attention} \cdot V_{X_t} \cdot \text{conf}$$

여기서 conf는 broadcast되어 각 토큰에 적용

### 2.5 한계 (Limitations)

#### 2.5.1 근본적 한계

1. **상태 망각의 완전 해결 불가**
   - TTT3R은 망각을 **완화**하지만 **완전히 제거**하지 않음
   - 1000프레임 이상에서 여전히 성능 저하 발생

2. **오프라인 방법의 성능 격차**
   - VGGT와 비교: 여전히 **3-5% 정확도 차이**
   - 전체 주의 메커니즘의 이점을 완전히 상쇄할 수 없음

3. **설계 공간 미탐색**
   - 신뢰도 기반 학습률이 최적인지 미확인
   - 다른 신뢰도 계산 방식의 효과 미검토

#### 2.5.2 실무적 한계

1. **상태 초기화 문제**
   - 매우 긴 시퀀스(>1000프레임)에서 상태 리셋 필요
   - 리셋 후 정렬 메커니즘이 필요하여 추론 후처리 증가

2. **텍스처리스 영역 처리**
   - 신뢰도가 낮은 영역에서 업데이트 억제 → 정보 손실 가능
   - 동적 장면에서 신뢰도 예측의 신뢰성 낮음

3. **하이퍼파라미터 민감도**
   - 신뢰도 집계 방식($$\max_m$$)이 고정됨
   - 다양한 장면에서의 일반화 성능 미확인

## 3. 모델의 일반화 성능 향상 가능성 (중점 분석)

### 3.1 길이 일반화(Length Generalization) 메커니즘

#### 3.1.1 이론적 설명

**기본 가정**: RNN이 길이에 초과 적합되는 이유는 **상태 분포 시프트**이다.

- **짧은 시퀀스 학습**: 모델은 초기 시퀀스에서 나타나는 상태들 ($$S_1, S_2, ..., S_{64}$$)에만 노출
- **긴 시퀀스 테스트**: 후반부 상태들 ($$S_{500}, S_{600}, ..., S_{1000}$$)은 학습 분포 밖 (OOD)
- **결과**: 모델이 미탐색 상태에서 성능 급락

**TTT3R의 해결책**:

신뢰도-기반 학습률 $$\beta_t$$는 다음과 같이 작동:

1. **초기 프레임** ($t < 64$): 
   - 새로운 정보가 많음 → 높은 신뢰도
   - $$\beta_t \approx 1.0$$ → 강한 학습
   - 상태 급격히 변함

2. **중기 프레임** ($64 < t < 300$):
   - 새로운 정보 감소 → 신뢰도 감소
   - $$\beta_t \approx 0.5-0.7$$ → 온건한 학습
   - 상태 안정화

3. **후기 프레임** ($t > 300$):
   - 재귀 반복 → 저신뢰도 영역
   - $$\beta_t \approx 0.2-0.3$$ → 약한 학습
   - 상태 유지 우선

**결과**: 상태가 **학습 분포 주변에 유지**되어 OOD 상태 회피

#### 3.1.2 정량적 증거

**상태 엔트로피 분석** (가설):
```
학습 시퀀스 길이: 64프레임
상태 엔트로피 범위: [H_min, H_max]

CUT3R의 상태 엔트로피(500프레임):
- 초반 100프레임: [H_min, H_max] 내 (정상)
- 중반 200-300프레임: 범위 이탈 시작 → 성능 저하
- 후반 400-500프레임: H_actual >> H_max (오버피팅된 상태)

TTT3R의 상태 엔트로피(500프레임):
- 초반 100프레임: [H_min, H_max] 내 (CUT3R과 동일)
- 중반 200-300프레임: 신뢰도 감소로 엔트로피 증가 제한
- 후반 400-500프레임: H_actual ≈ H_max 유지 → 성능 안정
```

### 3.2 적응형 학습에서의 일반화

#### 3.2.1 온라인 연상 회상(Online Associative Recall)

TTT3R의 메커니즘을 온라인 메타러닝으로 해석:

**메모리 업데이트 규칙**:
$$S_t = (1 - \beta_t) S_{t-1} + \beta_t \cdot \text{softmax}(Q_{S_{t-1}}K_{X_t})V_{X_t}$$

이는 **지수 이동 평균(EMA)**과 유사:
- $$(1 - \beta_t)$$: 과거 정보 유지 계수
- $$\beta_t$$: 새 정보 학습 계수

**일반화 능력**:
- 빠른 적응 (초반): $$\beta_t$$ 크면 새 정보에 빠르게 응답
- 안정성 (후반): $$\beta_t$$ 작으면 노이즈에 견고

#### 3.2.2 신뢰도 신호의 역할

**신뢰도가 낮은 업데이트 억제**:

텍스처리스 영역에서:
```
Image: [검은색 벽, 텍스처 없음]
    ↓
Key-Value 제너레이션: 식별 정보 부족
    ↓
Attention Score: 낮음 (여러 상태 토큰에 균등 분산)
    ↓
Confidence β_t: 낮음 → 0.1-0.2
    ↓
결과: 이 영역의 상태 업데이트 억제
      노이즈에 의한 모델 오염 방지 ✓
```

**신뢰도가 높은 업데이트 허용**:

강한 특징이 있는 영역에서:
```
Image: [코너, 엣지, 고유한 패턴]
    ↓
Key-Value 제너레이션: 강한 신호
    ↓
Attention Score: 높음 (특정 상태 토큰에 집중)
    ↓
Confidence β_t: 높음 → 0.7-0.9
    ↓
결과: 이 영역의 상태 강하게 업데이트
      중요 기하학적 정보 빠르게 통합 ✓
```

### 3.3 크로스-뷰 컨텍스트의 명시적 매칭

#### 3.3.1 교차-주의 기반 정렬(Cross-Attention Alignment)

TTT3R은 직접적으로 다음을 최적화:

$$\max_t \text{sim}(Q_{S_{t-1}}, K_{X_t})$$

여기서 유사도(similarity)는 정렬 신뢰도로 직접 변환됨

**일반화 메커니즘**:
1. **뷰 간 거리가 큼** (새로운 관점):
   - 적응형 학습률이 자동으로 증가
   - 새로운 기하학적 정보에 빠른 응답

2. **뷰 간 거리가 작음** (반복된 관점):
   - 적응형 학습률이 자동으로 감소
   - 중복 정보에 의한 상태 오염 방지

#### 3.3.2 루프 클로저(Loop Closure) 처리

**시나리오**: 카메라가 이전 장소로 돌아옴
```
프레임 100: 방의 각도 A에서 촬영
프레임 500: 같은 방의 각도 A에서 재촬영
```

**TTT3R의 처리**:
1. 프레임 500의 특징 $$K_{X_{500}}$$이 초기 상태와 높은 정렬
2. Attention score 높음 → $$\beta_{500}$$ 높음
3. 상태가 루프 클로저 정보로 강하게 업데이트
4. 누적 드리프트 교정

### 3.4 경험적 증거

#### 3.4.1 장면 타입별 일반화 성능

| 장면 타입 | 복잡도 | CUT3R (500프레임) | TTT3R (500프레임) | 개선 |
|----------|--------|-----------------|-----------------|------|

**해석**: 텍스처 풍부한 장면에서 더 큰 개선 (신뢰도 신호 활용도 ↑)

## 4. 논문의 앞으로의 영향과 고려할 점

### 4.1 학술적 영향

#### 4.1.1 패러다임 전환

**기존 패러다임**:
- 더 긴 시퀀스로 훈련 → 길이 일반화 개선
- 문제: 계산 비용 폭증, 메모리 요구량 증가

**TTT3R의 새로운 패러다임**:
- **훈련 불필요한 추론 시 적응** → 길이 일반화 개선
- 장점: 추가 훈련 없이, 기존 모델에 즉시 적용 가능

#### 4.1.2 관련 연구 분야에의 파급 효과

**1. 테스트-타임 트레이닝(TTT) 연구 확장**
- TTT가 비전 작업(특히 3D 기하학)에 효과적임을 입증
- 향후 연구: TTT를 다른 3D 작업(SLAM, 3D 객체 탐지)에 적용

**2. RNN 재평가**
- 트랜스포머 중심 연구에서 RNN의 가치 재조명
- Mamba(2023) 등 선형 주의 모델과의 상호 보완 가능성

**3. 온라인 학습 이론**
- 온라인 메타러닝에서의 적응형 학습률 설계 연구 자극
- 신뢰도 신호 활용의 일반화 가능성 탐색

#### 4.1.3 관련 최신 연구와의 연결성

| 연구 | 발표연도 | 관련성 |
|------|---------|--------|

### 4.2 실무적 응용 방향

#### 4.2.1 즉각적 응용 가능 분야

**1. 로보틱스 및 네비게이션**
- 실시간 카메라 포즈 추정 필요 + 메모리 제약
- TTT3R의 강점: 선형 메모리, 20FPS 추론 속도
- 응용: 자율 주행, 드론 네비게이션, 로봇 SLAM

**2. 증강 현실(AR)**
- 수백 프레임의 비디오 스트림 처리 필수
- 기존 방법: 메모리 부족으로 프레임 샘플링 필요
- TTT3R: 1000프레임 이상도 6GB 메모리로 처리

**3. 360도 비디오 3D 재구성**
- 긴 비디오에서 완전한 장면 복원
- TTT3R의 길이 일반화 + 온라인 처리 활용

**4. 영화/게임 프로덕션**
- 고해상도 다중 카메라 영상 처리
- 실시간 프리뷰 필요 (기존 오프라인 방법 불충분)
- TTT3R: 스트리밍 입력 처리 가능

#### 4.2.2 장기 응용 방향

**1. 통합 3D 센싱 시스템**
```
센서 입력 → TTT3R → 온라인 장면 이해
   ↓
실시간 카메라 포즈
   ↓
밀도 포인트클라우드
   ↓
장면 그래프 생성
   ↓
인터랙티브 AR/VR 경험
```

**2. 지속 학습(Continual Learning)**
- 기존 훈련된 모델에 새로운 장면 적응 가능
- 추가 훈련 없이 배포된 모델 개선
- 개인화된 3D 재구성 시스템 구축

### 4.3 향후 연구 시 고려할 점

#### 4.3.1 이론적 미탐색 영역

**1. 신뢰도 계산 방식의 최적성**
```
현재 (TTT3R): 최대값 집계
  β_t = max_m(Attention[i,m])
  
대안 (미탐색):
  - 상위 K 값의 평균
  - 엔트로피 기반 신뢰도
  - 학습 가능한 신뢰도 가중치
  
연구 질문: 어떤 신뢰도 계산이 최적인가?
```

**2. 상태 오버피팅의 이론적 분석**
- 상태 분포 시프트의 정량적 측정
- 신뢰도 기반 업데이트가 상태 분포 유지하는 메커니즘의 엄밀한 증명
- 경계(bound) 설정 가능성 탐색

**3. 학습률 적응의 수렴성**
```
질문: 동적 학습률 β_t하에서 수렴 보장되는가?

기존 이론 (고정 학습률):
  ||S_t - S*|| ≤ O(1/√t)
  
제안 (적응형 학습률):
  ||S_t - S*|| ≤ O(?)  
  
필요 연구: 적응형 학습률의 수렴 분석
```

#### 4.3.2 방법론적 개선 방향

**1. 상태 리셋 메커니즘의 개선**

- 기하학적 일관성 기반 신뢰도
```

```
문제: 현재 방법은 정적 장면 가정
  
개선:

### 4.4 인접 분야의 영향

#### 4.4.1 3D 기하학 분야

**구조-움직임(Structure-from-Motion, SfM)의 미래**:
- 전통 방법: 대규모 최적화 기반 (느림)
- TTT3R: 신경망 기반 온라인 처리 (빠름)
- 통합 방향: 신경망 기하학 + 최적화 정제

**SLAM 시스템의 재구상**:
```
기존 SLAM:
특징 추출 → 대응성 매칭 → 포즈 추정 → BA 최적화

TTT3R 기반 신경망 SLAM:
    입력 프레임
        ↓
    CNN 특징 추출 (사전훈련)
        ↓
    TTT3R 모듈 (온라인 상태 업데이트)
        ↓
    포즈 및 깊이 회귀
        ↓
    (선택적) BA 정제
```

#### 4.4.2 컴퓨터 비전의 시사점

**온라인 학습 적응의 일반화**:
- 물체 추적(tracking)에의 응용
- 의미 분할(semantic segmentation)에의 응용
- 동작 추정(optical flow)에의 응용

**신뢰도 신호 활용의 확대**:
- 불확실도 정량화 (Bayesian 관점)
- 능동적 탐색(active vision)
- 이상 탐지(anomaly detection)

### 4.5 종합 평가 및 향후 방향

#### 4.5.1 TTT3R의 위치

```
3D 재구성 방법의 계보

전통 방법 (SfM/MVS)
   ↓ (2010s)
심층 학습 초기 (단일 이미지 깊이)
   ↓ (2020-2023)

   ├─ 오프라인 전역 주의 (VGGT) ─ 정확하지만 느림
   └─ 온라인 RNN (CUT3R) ─ 빠르지만 짧음
   ↓ (2024-2025)
적응형 방법 (TTT3R) ← 현재
   └─ 빠름 + 길음 ✓

향후 (2025+):
   ├─ 신경망 + 최적화 하이브리드
   ├─ 멀티모달 기초 모델
   └─ 구체화된 AI (embodied AI) 통합 3D 인식
```

#### 4.5.2 핵심 기여의 재평가

| 관점 | 기여도 | 부각점 |

| **TTT (Speech)** | 2025 | 음성 향상 | 잡음 환경 적응 |

| **Test-Time Learning (Forecasting)** | 2024 | 시계열 예측 | Mamba와 결합 |

### 5.2 3D 재구성 기초 모델

#### 5.2.1 주요 방법 발전 흐름

```
2024년:
DUSt3R (CVPR 2024)
  └─ 쌍별 포인트맵 회귀, 비제약 재구성
  
2024-2025년 발전:
├─ Fast3R (CVPR 2025): 다중 뷰 일반화, 1000+ 이미지
├─ VGGT (CVPR 2025): 시각 기하학 기반, 상태-of-art 정확도
├─ MUSt3R (2025): 다중 스테레오 재구성, 쌍 수 감소
├─ Point3R (2025): 명시적 포인트 메모리 (CUT3R 확장)
├─ CUT3R (CVPR 2025): 온라인 RNN 기반, 선형 메모리
├─ StreamVGGT (2025): VGGT 스트리밍 확장
└─ TTT3R (2025): RNN + TTT 적응 (본 논문)
```

#### 5.2.2 각 방법의 특성

| 방법 | 구조 | 복잡도 | 온라인 | 길이 한계 | 핵심 아이디어 |
|------|------|--------|--------|----------|-------------|
| **DUSt3R** | 쌍별 | $$O(n^2)$$ | ✗ | 쌍 기반 | 포인트맵 회귀 |
| **Fast3R** | 다중뷰 트랜스포머 | $$O(n^2)$$ | ✗ | 메모리 한계 | 병렬 처리 |
| **VGGT** | 전역 주의 | $$O(n^2)$$ | ✗ | 메모리 한계 | 시각 기하학 그라운딩 |
| **CUT3R** | RNN | $$O(1)$$ | ✓ | 상태 망각 | 온라인 처리 |
| **TTT3R** | RNN + TTT | $$O(1)$$ | ✓ | **개선됨** | **신뢰도 적응** |

### 5.3 적응형 학습률 및 온라인 학습

#### 5.3.1 관련 아키텍처

| 이름 | 연도 | 학습률 메커니즘 | 상태 |
|------|------|-------------|------|
| **RetNet** | 2023 | 입력 종속 스칼라 | 고정 크기 |
| **DeltaNet** | 2021 | 선형 TTT 기반 | 고정 크기 |
| **Mamba** | 2023 | 선택적 상태 공간 | 가변 크기 |
| **Mamba-2** | 2024 | 고급 선택성 | 고급 제어 |
| **TTT3R** | 2025 | 토큰별 신뢰도 | 고정 크기 + 신뢰도 |

#### 5.3.2 선택적 상태 공간 모델(Selective SSM) 연구

**Mamba (Gu & Dao, 2023)**:
- 선택적 상태 공간 모델로 선형 시간 복잡도 달성
- 언어/오디오/게놈 모달리티에서 트랜스포머 성능 상회

**의미**: TTT3R과 Mamba는 보완적 관점
```
Mamba: 전체 아키텍처가 선택적 구조
TTT3R: 기존 모델(CUT3R)에 적응 계층 추가

향후 결합 가능성: TTT3R 원리를 Mamba 기반 3D 모델에 적용
```

### 5.4 길이 일반화(Length Generalization) 연구

#### 5.4.1 최근 중요 발견

| 논문 | 연도 | 발견 사항 |
|------|------|----------|
| **길이 일반화 이해 (Ruiz & Gu)** | 2025 | 상태 오버피팅이 주요 원인 |
| **LongMamba** | 2025 | RNN 수용 필드 확장으로 길이 일반화 개선 |
| **Decimamba** | 2024 | Mamba의 길이 외삽 능력 탐색 |
| **xLSTM** | 2024 | 확장 LSTM으로 긴 시퀀스 처리 |

#### 5.4.2 TTT3R과의 연결점

```
TTT3R = 온라인 적응을 통한 길이 일반화
LongMamba = 수용 필드 설계를 통한 길이 일반화

향후 작업: 두 접근의 결합
├─ 적응형 학습률 + 확대된 수용 필드
└─ 더 강력한 길이 일반화 기대
```

### 5.5 실시간 3D 센싱 및 SLAM

#### 5.5.1 신경망 기반 SLAM

| 방법 | 연도 | 특징 |
|------|------|------|
| **DROID-SLAM** | 2021 | 심층 학습 기반 SLAM |
| **MonoGS** | 2023 | 단안 가우시안 스플래팅 |
| **PreF3R** | 2024 | 포즈 자유 피드포워드 3D GS |
| **MegaSAM** | 2025 | 정확한 대규모 움직임 구조 추정 |

**TTT3R의 SLAM 적용 가능성**:
- 온라인 카메라 포즈 추정 모듈로 활용
- 매우 긴 영상 시퀀스 처리 가능
- 기존 최적화 기반 BA와 하이브리드 가능

### 5.6 종합 요약: 관련 연구의 생태계

```
테스트-타임 트레이닝 (TTT)
    ↓
    ├─ RNN 기반 적응 (RetNet, Mamba, TTT3R)
    └─ 자기지도 학습 기반 (TTT, MATE)

        3D 재구성 기초 모델 발전
            ↓
            ├─ 오프라인: DUSt3R → Fast3R → VGGT
            └─ 온라인: CUT3R → **TTT3R** ← 본 논문
            
                길이 일반화 문제 해결
                    ↓
                    ├─ 아키텍처 설계 (Mamba)
                    ├─ 훈련 전략 (LongMamba)
                    └─ **테스트 타임 적응 (TTT3R)** ← 새로운 방향
                    
                        실무 응용
                            ↓
                            ├─ 로보틱스 (온라인 포즈 추정)
                            ├─ AR/VR (실시간 3D 장면)
                            └─ 신경망 SLAM (기하학 + 학습)
```

## 결론

**TTT3R**은 3D 재구성 분야에서 **온라인 적응과 효율성의 경계**를 새롭게 정의한 중요한 작업이다. 

### 핵심 성과:
- ✓ 길이 일반화 **2배 향상** (1000프레임에서)
- ✓ 메모리 효율성 유지 (6GB)
- ✓ 추가 훈련 불필요 (플러그-앤-플레이)

### 학술적 의의:
- TTT 프레임워크의 3D 기하학 도메인 검증
- 신뢰도 신호 활용의 새로운 패러다임 제시
- RNN 기반 시퀀스 모델의 재평가 기회 제공

### 미래 방향:
1. **이론적 심화**: 상태 분포 시프트의 수학적 특성화
2. **방법론 확장**: 동적 신뢰도, 다중 스케일 적응
3. **응용 개발**: SLAM, AR, 로보틱스 통합 시스템
4. **하이브리드 접근**: 오프라인 정확도 + 온라인 효율성

TTT3R은 단순한 방법론 개선을 넘어, **온라인 학습의 적응성과 효율성을 동시에 추구하는 새로운 철학**을 제시하며, 향후 3D 기하학 학습의 중요한 방향을 제시한다.
