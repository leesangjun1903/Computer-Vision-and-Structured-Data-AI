
# CARD: Classification and Regression Diffusion Models

## 1. 핵심 주장 및 주요 기여

CARD 모델은 조건부 확산 모델(Conditional Diffusion Model)을 분류 및 회귀 분석에 적용하는 혁신적인 접근법을 제시합니다. 논문의 핵심 주장은 다음과 같습니다.[1]

**주요 기여:**

1. **CARD 모델 구축**: 사전 학습된 조건부 평균 추정기를 포함한 조건부 확산 모델을 제안하여 $p(y|x)$의 정확한 추정을 실현했습니다.[1]

2. **새로운 평가 지표 제시**: 조건부 분포의 적합도를 평가하기 위한 새로운 지표인 **QICE (Quantile Interval Coverage Error)**를 제안했습니다.[1]

3. **최첨단 성능 달성**: UCI 회귀 벤치마크에서 RMSE 9/10, NLL 8/10, QICE 5/10 데이터셋에서 최고 성능을 기록했습니다.[1]

4. **인스턴스 수준의 신뢰도 평가**: 분류 작업에서 개별 예측에 대한 모델 신뢰도를 평가하는 혁신적인 프레임워크를 도입했습니다.[1]

## 2. 해결하고자 하는 문제

### 2.1 기존 방법의 한계

기존 지도 학습 방법들은 조건부 평균 $E[y|x]$를 추정하는 데만 집중하며, 다음과 같은 문제를 갖고 있습니다:[1]

- **가법 노이즈 가정의 제한**: 회귀에서 $y \sim f(x) + \mathcal{N}(0, \sigma^2)$, 분류에서 $y = \arg\max_c f_c(x) + \epsilon_c$로 가정하는 것은 실제 데이터의 복잡한 분포를 반영하지 못합니다.

- **다중 양식 분포의 표현 불가**: 예를 들어, 성별이 누락된 환자 데이터에서 약물 반응이 양봉 분포(bi-modal distribution)를 따를 때, 조건부 평균은 실제 가능한 값들 중 어느 것도 나타내지 못합니다.[1]

- **불확실성 정량화의 부족**: 베이지안 신경망(BNN)도 가우시안 분포를 가정하여 임의적입니다.

### 2.2 CARD의 해결책

CARD는 매개변수적 분포 가정을 하지 않으면서도 전체 조건부 분포 $p(y|x, D)$를 정확히 복원할 수 있습니다.[1]

## 3. 제안 방법

### 3.1 수학적 기초: ELBO 목표함수

CARD는 다음과 같은 ELBO (Evidence Lower Bound) 최적화를 기반으로 합니다:[1]

$$\log p(y_0|x) \geq \mathbb{E}_{q(y_{1:T}|y_0,x)} \left[ \log \frac{p(y_{0:T}|x)}{q(y_{1:T}|y_0,x)} \right]$$

이를 분해하면:[1]

$$\mathcal{L}_{ELBO}(y_0, x) = L_0(y_0, x) + \sum_{t=2}^{T} L_{t-1}(y_0, x) + L_T(y_0, x)$$

여기서:
- $L_0(y_0, x) = \mathbb{E}\_q[\log p(y_0|y_1, x)]$
- $L_{t-1}(y_0, x) = \mathbb{E}\_q[D_{KL}(q(y_{t-1}|y_t, y_0, x) || p(y_{t-1}|y_t, x))]$
- $L_T(y_0, x) = \mathbb{E}\_q[D_{KL}(q(y_T|y_0, x) || p(y_T|x))]$

### 3.2 조건부 사전분포 설정

CARD의 혁신적인 점은 확산 과정의 끝점을 단순 가우시안이 아닌 정보 있는 사전분포로 설정한 것입니다:[1]

$$p(y_T|x) = \mathcal{N}(f(x), I)$$

여기서 $f(x)$는 사전 학습된 조건부 평균 추정기(예: MSE로 학습된 신경망)입니다.

### 3.3 전진 확산 과정(Forward Process)

조건부 전진 확산은 다음과 같이 정의됩니다:[1]

$$q(y_t|y_{t-1}, f(x)) = \mathcal{N}\left(y_t; \sqrt{1-\beta_t}y_{t-1} + \sqrt{1-(1-\beta_t)}f(x), \beta_t I\right)$$

임의의 타임스텝 $t$에서의 폐쇄형 샘플링 분포:[1]

$$q(y_t|y_0, f(x)) = \mathcal{N}(y\_t; \alpha_t y_0 + (1-\alpha_t)f(x), (1-\bar{\alpha}_t)I)$$

여기서 $\alpha_t = 1 - \beta_t$, $\bar{\alpha}\_t = \prod_{i=1}^{t} \alpha_i$

### 3.4 후진 확산 과정(Reverse Process)

신경망 $\epsilon_\theta(x, y_t, f(x), t)$는 전진 확산에서 샘플링된 노이즈를 예측합니다. DDPM 재매개변수화를 따르면:

$$y_{t-1} = \frac{1}{\sqrt{\alpha_t}}(y_t - \sqrt{1-\alpha_t}\epsilon_\theta) + \sigma_t z$$

### 3.5 회귀(Regression) 알고리즘

**훈련 (Algorithm 1):**[1]
1. $f(x)$를 MSE로 사전 학습
2. 무작위 타임스텝 $t \sim \text{Uniform}(1, \ldots, T)$ 샘플링
3. 노이즈 $\epsilon \sim \mathcal{N}(0, I)$ 샘플링
4. 손실 계산: $\mathcal{L} = ||\epsilon - \epsilon_\theta(x, y_t, f(x), t)||^2$

**추론 (Algorithm 2):**[1]
- $y_T \sim \mathcal{N}(f(x), I)$에서 시작
- $t = T$부터 $1$로 역방향 진행
- 매 단계마다 확산된 표본 생성

### 3.6 분류(Classification) 적용

분류는 일반화된 회귀 프레임워크로 구현됩니다:[1]

1. 연속 공간에서의 원-핫 인코딩 표현 사용
2. 소프트맥스 확률로 변환:[1]

$$\Pr(y=k) = \frac{\exp(-(y_0-1_C)^2_k / \tau_0^2)}{\sum_{i=1}^C \exp(-(y_0-1_C)^2_i / \tau_0^2)}$$

최종 예측:[1]

$$\hat{y} = \arg\max_k (y_0-1_C)^2_k$$

## 4. 모델 구조

### 4.1 확산 신경망 아키텍처

회귀 작업의 신경망 구조:[1]

입력 $(x, y_t, f(x), t)$ → 3개의 FC 레이어 (128 차원) → Hadamard 곱 × 타임스텝 임베딩 → 4번째 FC 레이어 → 노이즈 예측

분류 작업의 신경망 구조:[1]

- 이미지 인코더: 3개 FC 레이어 → 4096 차원
- 응답 임베딩: $y_t, f(x)$ 연결 후 FC 레이어
- 특징 통합: Hadamard 곱으로 이미지와 응답 임베딩 결합

### 4.2 주요 하이퍼파라미터

- 타임스텝: $T = 1000$
- 노이즈 스케줄: 선형, $\beta_1 = 10^{-4}$, $\beta_T = 0.02$
- 옵티마이저: Adam (lr=0.001)
- 회귀 에폭: 5000, 분류 에폭: 1000[1]

## 5. 성능 향상 및 평가 지표

### 5.1 회귀 성능

UCI 벤치마크에서 CARD의 우수성:[1]

| 메트릭 | RMSE (9/10) | NLL (8/10) | QICE (5/10) |
|--------|-------------|-----------|-----------|
| CARD | ✓ 최고 성능 달성 | ✓ 2순위 | - |
| BNN 평균 | 경쟁력 있음 | 성능 저하 | 부정확 |

**구체적 예시 (Boston 데이터셋):**[1]
- RMSE: 2.61 ± 0.63 (CARD) vs 2.75 ± 0.58 (GCDS)
- NLL: 2.35 ± 0.12 (CARD) vs 2.35 ± 0.16 (Deep Ensembles)

### 5.2 새로운 평가 지표: QICE

기존 PICP의 한계를 보완하기 위해 제안된 QICE:[1]

$$\text{QICE} = \frac{1}{M}\sum_{m=1}^{M}\left|r_m - \frac{1}{M}\right|$$

여기서 

```math
r_{m}=\frac{1}{N}\sum _{n=1}^{N}\mathbb{1}(y_{nm}^{\text{low}} < y_{n} < y_{nm}^{\text{high}})
```

QICE는 10개의 분위수 구간(quantile intervals)에서 균등 분포를 가정하며, 최적값은 0입니다.[1]

### 5.3 분류 성능

**CIFAR-10 결과:**[1]
- 기본 분류기 정확도: 90.39%
- CARD 개선 정확도: 90.93% ± 0.02%
- NLL: 0.46 ± 0.00 (다른 BNN 대비 경쟁력)

**인스턴스 수준 신뢰도 (Table 5):**[1]
- 올바른 예측의 PIW: 2.37 × 10⁻²
- 오류 예측의 PIW: 21.52 × 10⁻²
- PIW만으로 예측 시 정확도: 87.84%

### 5.4 대규모 데이터셋 성능

**ImageNet 결과 (Table 11):**[1]
- CIFAR-100: 71.42% (기본 71.37%)
- ImageNet-100: 82.35% (기본 82.30%)
- ImageNet-1K: 74.28% ~ 80.35% (기본 대비 개선)

## 6. 모델의 일반화 성능 향상 가능성

### 6.1 다중 양식 분포 학습

CARD는 기존 모델들이 실패하는 다중 양식 조건부 분포를 정확히 모델링합니다.[1]

**장난감 예제 성과:**[1]
- Linear/Quadratic: 단일 양식 분포 정확 복원
- 8 Gaussians/Full Circle: 복잡한 다중 양식 구조 학습 성공
- 이질분산(Heteroscedasticity) 처리: 로그-로그 회귀에서 분산 변화 정확 포착

### 6.2 비매개변수적 분포 가정

CARD는 분포 형태에 제약을 두지 않습니다:[1]

- **가우시안 가정 불필요**: BNN은 조건부 분포를 가우시안으로 제한
- **암시적 분포 모델링**: 확산 모델의 유연성으로 임의의 분포 학습 가능
- **KL 발산 기반 근사의 제한 극복**: BNN이 사후 $q(W)$에 단순 분포(보통 가우시안) 가정

### 6.3 인식론적 vs 우연론적 불확실성

**CARD의 초점:** 우연론적 불확실성(Aleatoric Uncertainty)을 정확히 포착[1]

- 우연론적 불확실성: 데이터 내재적 노이즈, 감소 불가능
- 인식론적 불확실성: 모델 불확실성, 데이터로 감소 가능

CARD는 알려진 공변량만으로 학습 데이터와 동일 분포(In-distribution) 범위 내에서 우연론적 불확실성을 완벽히 모델링합니다.[1]

### 6.4 Informative Prior의 효과

사전분포 설정 방식의 중요성을 입증했습니다:[1]

**표 19 (UCI Boston):**
- $\mathcal{N}(f(x), I)$ 사전: $T$ 감소 시 성능 안정적
- $\mathcal{N}(0, I)$ 사전: $T$ 감소 시 RMSE, NLL, QICE 급격한 악화

결론: 사전학습된 조건부 평균 추정기를 포함하는 것이 정보있는 사전분포 역할을 하여 일반화 성능을 크게 향상시킵니다.

## 7. 모델의 한계

### 7.1 인식론적 불확실성의 미흡

**주요 한계:** CARD는 분포 외(Out-of-Distribution) 데이터에 대한 인식론적 불확실성을 모델링하지 못합니다.[1]

- 외삽(Extrapolation) 작업에서 성능 미흡 가능성
- 신경 프로세스 계열(Neural Processes Family)이 few-shot 시나리오에 더 적합

저자들은 미래 연구에서 외삽 능력 탐색을 언급했습니다.[1]

### 7.2 분류의 이산화 문제

**연속 공간 가정의 부작용:** 분류을 연속 공간의 원-핫 벡터로 모델링함으로써:[1]

- 이산 확산 모델(D3PM, Austin et al. 2021)에 비해 NLL 성능 하락 가능
- 온도 매개변수 $\tau_0$에 대한 민감성
- 확률 공간 변환 후 PIW 대비 감소

### 7.3 계산 효율성

**성능 vs 비용 트레이드오프:**[1]

- 훈련: 100-200 스텝/초 (회귀), 44 스텝/초 (분류)
- 추론: 100개 샘플당 ~1.05초 (FashionMNIST)
- 대규모 데이터셋에서 효율성 추가 탐구 필요

### 7.4 광범위한 가정

**저자들의 한계 인정:**[1]

- 가우시안 확산만 고려 (비-가우시안 대안 미탐구)
- 사전분포 $f(x)$로 결정론적 신경망만 사용 (BNN 결합 미시도)
- 안전성 우려: 다중 양식 분포 활용의 악의적 목적 가능성

## 8. 앞으로의 연구 영향 및 고려사항

### 8.1 학문적 영향

#### 8.1.1 확산 모델의 새로운 응용 영역 개척

CARD는 확산 모델을 조건부 생성 모델링(conditional distribution prediction)으로 처음 체계적으로 적용합니다.[2][1]

- **이전 연구**: 주로 무조건부 이미지 생성에 집중
- **CARD의 기여**: 지도 학습(supervised learning)에 적응, 회귀와 분류 모두 통합 프레임워크
- **파급 효과**: 이후 연구들이 시계열 예측, 의료 영상, 물리적 예측 등 다양한 분야에 확산 모델 적용

#### 8.1.2 불확실성 정량화 방법론의 진화

CARD의 성공은 기존 베이지안 방법론의 대안을 제시합니다.[1]

- **BNN의 한계 노출**: 매개변수적 가정이 실제 데이터의 복잡한 분포를 표현 불가
- **새로운 패러다임**: 생성 모델을 통한 비매개변수적 불확실성 정량화의 유효성 입증
- **실무 적용**: 의료, 금융, 자율주행 등 고위험 응용에서 신뢰도 높은 불확실성 추정 필요성 증대

#### 8.1.3 다중 양식 분포 학습의 이론적 진전

CARD는 다중 양식 조건부 분포를 처음으로 대규모 회귀/분류에서 정확히 학습합니다.[1]

- **이론적 의의**: 혼합 밀도 네트워크(MDN), 가우시안 혼합(GMM)의 한계를 보이며 확산 모델의 우월성 증명
- **통계학적 함의**: 누락된 공변량(missing covariates)이 있을 때의 조건부 분포 정확히 학습

### 8.2 2020년 이후 관련 최신 연구 동향

#### 8.2.1 조건부 확산 모델의 발전

최신 연구들이 CARD의 기본 개념을 확장하고 있습니다:[3][4][5]

**2024-2025년 주요 진전:**

- **BIPSDA (2025)**: 베이지안 역문제(inverse problems) 해결을 위한 확산 기반 후방 샘플링 프레임워크, CARD의 분포 복원 능력을 역 추론에 적용[4]

- **U2Diff (2025)**: 다중 에이전트 궤적 모델링에서 상태별 불확실성 추정을 동시에 수행하는 확산 모델, CARD의 기본 원리를 시계열에 확장[5]

- **Deterministic Diffusion Model (2024)**: 불확실성 정량화를 위해 베이지안 추론을 결정론적 확산에 포함, CARD의 우연론적 불확실성 정확화 보완[6]

#### 8.2.2 시계열 예측의 확산 모델 응용

최근 급성장하는 분야로, CARD와 관련:[7][8]

- **Diffusion-Informed MPC (2025)**: 확산 기반 예측을 모델 예측 제어에 통합, 에너지 가격 예측에서 고전 모델 대비 38.8% 성능 개선[9]

- **DiffLoad (2024)**: 전기 부하 예측에서 에피스템적·우연론적 불확실성 분리, CARD의 불확실성 분리 철학 확장[10]

- **시계열 확산 (2025-현재)**: 금융, 기후, 에너지 분야에서 확산 기반 확률적 예측 표준화 추세[3]

#### 8.2.3 불확실성 정량화의 진화

CARD 이후 관련 연구의 다양화:[11][12]

- **확산 앙상블 (2024)**: DECU 프레임워크로 조건부 확산 모델 앙상블의 효율적 학습, 에피스템적 불확실성 정량화[11]

- **픽셀별 우연론적 불확실성 (2024)**: 샘플링 단계에서 노이즈 항의 분산으로 우변론적 불확실성 추정, CARD의 기본 원리 정밀화[12]

- **조건부 괴롭혀 흐름 (2024)**: ODE 기반 조건부 분포 학습의 수렴 이론 증명, CARD의 확산 모델 이론적 기초 강화[2]

### 8.3 향후 연구에서 고려할 주요 점

#### 8.3.1 인식론적 불확실성의 통합

**필요성**: CARD는 우연론적 불확실성만 모델링

**개선 방향:**
- 베이지안 신경망과 확산 모델의 결합[1]
- 부트스트랩/앙상블 기법과 결합하여 에피스템적 불확실성 추가 모델링
- 드롭아웃, 표본 핸간 베이지안 방법 통합[1]

#### 8.3.2 계산 효율성 개선

**현재 병목:**
- 1000 타임스텝 필요
- 추론 시 다중 샘플 필요

**개선 방안:**
- **DDIM 가속화**: 확산 단계 수 감소 (100-200 스텝으로 단축)
- **조건부 샘플링**: 초기 타임스텝부터 조건화로 수렴 가속
- **캐시 메커니즘**: 반복 추론에서 계산 재사용

#### 8.3.3 이산 확산 모델의 개발

**한계 극복:**
- 분류를 연속 공간으로 취급하는 근사 제거
- D3PM(Discrete Diffusion Probabilistic Models) 스타일의 이산 공간 직접 모델링[1]
- 다중 정수 응답 회귀 등 순서 변수 정확 처리

#### 8.3.4 외삽(Extrapolation) 능력 강화

**현재 문제:** 분포 외 데이터에서 에피스템적 불확실성 미흡

**해결책:**
- 메타-학습(meta-learning) 접근으로 새로운 분포 빠르게 적응
- 적응형 사전분포 $f(x)$ 구조 (예: 불확실성 인식 사전)
- OOD 탐지 메커니즘 통합

#### 8.3.5 특정 도메인 적용

**유망한 응용 영역:**

1. **의료 진단**: 
   - 다중 양식 임상 결과 분포 학습
   - 개인화된 치료 반응 분포 추정
   
2. **기후/날씨 예측**:
   - 극한 사건 가능성의 다중 양식 분포
   - 공간적 상관성 유지[3]
   
3. **금융 리스크 평가**:
   - 자산 수익률의 복잡한 꼬리 분포
   - 신용 위험 포트폴리오 분포[13]
   
4. **자율주행 경로 계획**:
   - 다양한 가능한 움직임의 일체 분포
   - 실시간 불확실성 기반 의사결정[5]

#### 8.3.6 인간-AI 협업 프레임워크 확장

**CARD의 기여:** 인스턴스 수준 신뢰도로 인간-기계 협업 가능

**확장 방안:**
- 불확실성 기반 동적 작업 할당 자동화
- 설명 가능성(explainability) 통합: 왜 특정 인스턴스에서 불확실한지 설명
- 활동적 학습(active learning): 모델 불확실성이 높은 샘플 우선 라벨링

#### 8.3.7 다중 작업 학습 및 전이 학습

**미탐구 영역:**
- 관련 회귀/분류 작업 간 지식 전이
- 소수 데이터 시나리오에서의 few-shot 학습
- 도메인 적응(domain adaptation)에서의 불확실성 추정

### 8.4 안전성 및 윤리적 고려사항

**CARD 저자들의 경고:** 다중 양식 분포 학습 능력의 악용 가능성[1]

**필요한 사전조치:**
- 개인정보 역추출(privacy leakage) 방지 메커니즘
- 의료/금융 데이터 사용 시 규제 준수 체계
- 공정성(fairness): 소수 집단의 다양한 결과 분포 표현[1]

## 결론

CARD는 확산 모델을 지도 학습에 혁신적으로 적용하여 조건부 분포 학습 분야에 패러다임 전환을 가져왔습니다. 특히 다중 양식 분포 학습, 비매개변수적 불확실성 정량화, 인스턴스 수준 신뢰도 평가라는 세 가지 핵심 기여는 이후 연구에서 확산 모델의 광범위한 응용과 불확실성 정량화 방법론의 발전을 촉발했습니다. 

향후 연구는 인식론적 불확실성 통합, 계산 효율성 개선, 이산 공간 직접 모델링, 외삽 능력 강화, 특정 고위험 도메인 적용 등에 집중해야 하며, 동시에 개인정보 보호, 공정성, 설명 가능성 등 윤리적 측면도 함께 고려해야 합니다.
