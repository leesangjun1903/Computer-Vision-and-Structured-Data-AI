## 1. 핵심 주장과 주요 기여 요약

### 핵심 주장

PartField는 사전 정의된 템플릿이나 텍스트 기반 이름에 의존하지 않고, 파트(part)의 일반적인 개념과 그 계층 구조를 학습하는 피드포워드(feedforward) 방식의 3D 특징 학습 접근법이다. 핵심 아이디어는 연속적인 3D 특징 필드(feature field)를 학습하는 모델을 훈련시키는 것이며, 특징 간의 거리가 동일한 파트에 속할 가능성을 나타낸다.

### 주요 기여

| 기여 항목 | 내용 |
|-----------|------|
| **피드포워드 추론** | 추론 시 단 1회의 3D 피드포워드 패스만 필요 |
| **클래스-비종속(Class-Agnostic)** | 사전 정의 템플릿·텍스트 없이 오픈-월드 형상에 적용 |
| **계층적 분해** | 클러스터링을 통한 멀티스케일 파트 계층 구조 생성 |
| **크로스-형상 일관성** | 학습된 필드의 일관성이 여러 형상에 걸쳐 발현 |
| **속도 및 정확도** | 기존 대비 최대 20% 정확도 향상, 수 배~수십 배 속도 향상 |

PartField는 모달리티, 의미 클래스, 스타일 측면에서 다양한 입력에 적용 가능하며, 학습된 특징 필드는 형상 간 일관성을 보여 코-세그멘테이션(co-segmentation), 대화형 선택, 대응(correspondence) 등의 응용을 가능하게 한다.

## 2. 해결하고자 하는 문제, 제안 방법, 모델 구조, 성능 및 한계

### 2-1. 해결하고자 하는 문제

기존 3D 파트 분할 방법들은 다음과 같은 한계를 가지고 있었다:

Find3D를 제외한 대부분의 기존 방법들은 2D 기반 모델의 결과와 특징을 3D로 올리거나 증류하기 위해 형상별 최적화(per-shape optimization)를 수행하여, 단 하나의 3D 형상을 추론하는 데도 상당한 시간이 소요된다.

- **사전 정의 의존성**: 특정 카테고리 템플릿이나 텍스트 레이블에 의존
- **느린 추론 속도**: 형상별 최적화로 인한 비효율성
- **범용성 부족**: 특정 클래스나 모달리티에 제한

파트 프로포절에는 제약이 없으며, 의미론적, 기하학적 또는 다른 기준에 따라 다양한 세분성 수준으로 정의될 수 있다. 신중하게 선택된 대조적 목적 함수(contrastive objective)를 활용하여, 동일 파트의 샘플은 더 유사하고 다른 파트의 샘플은 더 구별되도록 장려함으로써, 다양한 파트 세분성과 파트의 다른 개념으로 인한 어려움을 우회하고 대규모 오픈-월드 데이터로 학습이 가능하다.

### 2-2. 제안하는 방법 (수식 포함)

#### (1) 특징 필드 정의

PartField는 입력 3D 형상 $S$에 대해 파트 및 그 계층 구조의 기저 구조를 인코딩하는 연속적인 3D 특징 필드를 피드포워드 방식으로 예측한다. 이 특징 필드는 임의의 3D 포인트를 다음과 같이 매핑한다:
$$f(\mathbf{p}; S): \mathbb{R}^3 \rightarrow \mathbb{R}^n$$
파트 구성 개념은 두 포인트 간의 특징 거리로 모델링된다.

즉, 두 포인트 $\mathbf{p}_i, \mathbf{p}_j$가 같은 파트에 속할수록 다음을 만족하도록 학습된다:

$$d(f(\mathbf{p}_i; S),\ f(\mathbf{p}_j; S)) \approx 0 \quad \text{(same part)}$$
$$d(f(\mathbf{p}_i; S),\ f(\mathbf{p}_j; S)) \gg 0 \quad \text{(different parts)}$$

#### (2) 대조 학습 손실 (Contrastive Loss)

훈련은 같은 파트 내 포인트의 특징은 유사하게, 다른 파트의 포인트 특징은 분리되도록 장려하는 **트리플렛 손실(triplet loss)** 함수를 사용하며, 이는 학습 시 명시적인 파트 레이블이 필요 없다.

트리플렛 손실의 일반 형식은:

$$\mathcal{L}_{\text{triplet}} = \max\left(d(f_a, f_p) - d(f_a, f_n) + \alpha,\ 0\right)$$

여기서:
- $f_a$: anchor 포인트의 특징 (임의의 3D 포인트)
- $f_p$: positive 포인트의 특징 (같은 파트)
- $f_n$: negative 포인트의 특징 (다른 파트)
- $\alpha$: 마진(margin) 하이퍼파라미터

#### (3) 2D & 3D 지식 증류

모델은 이미지 공간 마스크에서 증류된 오픈-월드 데이터와, 가용할 때의 3D 지도 데이터 모두에 대해 대조 손실로 학습된다.

2D 지도의 경우: 3D 형상의 멀티뷰 이미지를 SAM2 등 2D 기반 모델로 분할하여 지도 신호를 생성한다.

### 2-3. 모델 구조

PartField는 점 샘플링된 3D 형상을 입력으로 받아(메시, 가우시안 스플랫, 기타 표현에서 올 수 있음) 트리플레인(triplane)으로 표현된 특징 필드를 예측하는 피드포워드 모델이다.

```
┌──────────────────────────────────────────────────────────┐
│  입력: 3D Point Cloud (Mesh / Gaussian Splats / 포인트)  │
└────────────────────────┬─────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────┐
│  PVCNN Encoder (per-point feature 추출)                 │
│  - 각 포인트별 특징 추출                                 │
└────────────────────────┬────────────────────────────────┘
                         │ Mean Reduction (직교 투영)
                         ▼
┌─────────────────────────────────────────────────────────┐
│  Triplane (XY, YZ, XZ 축 정렬 3개의 2D 평면)            │
└────────────────────────┬────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────┐
│  2D CNN (Downsampling) → Flatten                        │
│  → Transformer (문맥화)                                 │
│  → Transposed 2D CNN (Upsampling)                       │
└────────────────────────┬────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────┐
│  Feature Field Triplane 출력                            │
│  → 임의 3D 위치에서 특징 샘플링 가능                    │
└────────────────────────┬────────────────────────────────┘
                         │
                         ▼
┌─────────────────────────────────────────────────────────┐
│  K-Means / Agglomerative Clustering                     │
│  → 계층적 파트 분해 (Part Decomposition)                │
└─────────────────────────────────────────────────────────┘
```

모델은 두 가지 주요 컴포넌트로 구성된다. 첫째, PVCNN 인코더가 포인트별 특징을 추출하고, 이를 평균 리덕션(mean-reduction)을 통해 3개의 축-정렬 2D 평면에 직교 투영하여 초기 트리플레인 표현을 형성한다. 이 트리플레인은 2D CNN으로 다운샘플링, 플래튼(flatten), 트랜스포머를 거친 다음, 전치 2D CNN(transposed 2D CNN)으로 다시 트리플레인으로 업샘플링된다.

추론 시에는 학습된 네트워크를 적용하여 특징 필드 트리플레인을 생성하고, 파트 특징을 원하는 대로 샘플링한다. 이후 K-means나 응집 클러스터링 같은 클러스터링 알고리즘을 사용해 3D 형상의 파트-인식 분해를 수행한다.

---

### 2-4. 성능 향상

PartField는 최신 클래스-비종속 파트 분할 방법들과 비교하여 최대 **20% 더 높은 정확도**를 달성하고, **수 배에서 수십 배** 더 빠른 속도를 보인다.

단일 형상 파트 분해를 넘어, 학습된 필드에서 형상 간 일관성이 자연스럽게 발현되어 **코-세그멘테이션(co-segmentation)** 및 **대응(correspondence)** 과 같은 작업을 가능하게 한다.

PartField는 다양한 2D 및 3D 데이터에 대한 대규모 대조 학습을 통해 **멀티스케일 파트의 계층 구조를 암묵적으로 학습**한다.

PartSAM 논문에서 보고된 비교 수치 (mIoU 기준):


| 방법 | PartObjaverse-Tiny | PartNetE |
|------|--------------------|----------|
| PartSLIP | 31.5 | 34.9 |
| Find3D | 21.3 | 21.7 |
| SAMPart3D | 53.5 | 56.2 |
| SAMesh | 56.9 | 26.7 |
| **PartField** | **51.5** | **59.1** |

### 2-5. 한계

PVCNN & 트리플레인 아키텍처는 빠른 추론을 가능하게 하지만 본질적으로 외재적(extrinsic)이어서, 특징 공간이 3D 위치와 약하게 상관관계를 가진다. 파트 분할은 이에 무관하지만, **크로스-형상 응용**은 형상이 일관되게 정렬되어 있을 것을 요구한다.

현재 연구는 객체 규모(object-scale)에서만 PartField를 탐구하며, **향후 연구에서 대규모 장면으로 확장**될 수 있다.

SAMPart3D와 PartField는 특징 클러스터링에 의존하기 때문에, 복잡하고 세밀한 구조에서 어려움을 겪을 수 있으며, 클러스터링 과정이 파편화되거나 의미론적으로 무의미한 파트를 생성하는 경우가 있다.

## 3. 모델의 일반화 성능 향상 가능성

PartField의 일반화 능력은 다음 세 가지 핵심 설계 결정에서 비롯된다.

### 3-1. 다양한 3D 입력 모달리티 지원

입력 형상은 깨끗하거나 실제 환경의 메시(mesh), 포인트 클라우드, 가우시안 파티클로 올 수 있으며, 3D 포인트 클라우드로 샘플링된 후 모델에 입력된다. 이 모델은 임의의 공간 위치에서 평가 가능한 트리플레인으로 인코딩된 특징 필드를 출력한다.

### 3-2. 대규모 비지도 데이터로부터의 학습

모델은 레이블된 데이터셋과 비지도 이미지 분할로부터 2D 및 3D 파트 프로포절을 증류하는 대조 학습 공식을 사용해 훈련된다. 이 접근법은 파트의 단일 개념에 얽매이지 않고 다양한 데이터에서 학습할 수 있게 하여, 가능한 파트와 다중 수준 분해의 넓은 범위를 커버한다.

### 3-3. 크로스-형상 일관성의 창발적 발현

현재 연구는 객체 규모에서만 PartField를 탐구하며, 향후 연구에서 대규모 장면으로 확장될 수 있다. 크로스-형상 응용은 이 방법의 놀라운 창발적 특성을 조사하는 소규모 연구로서, 3D 형상 분석의 기반이 되는 특징을 위한 파트 대조 학습에 대한 지속적인 연구를 촉진할 것으로 기대된다.

### 3-4. 제로샷(Zero-Shot) 일반화 능력

파트 분할 성능이 카테고리 레이블을 필요로 하는 방법과 동등하거나 이를 초과하며, 효과적인 **제로샷 학습(zero-shot learning)** 능력을 보여주고 실제 스캔된 객체에서도 강건한 성능을 보인다.

### 3-5. 다운스트림 태스크로의 전이 가능성

PartField가 학습한 특징 표현은 다른 연구에서도 백본으로 활용되고 있다. PartSAM은 훈련 시 각 분기를 PartField의 사전 학습된 가중치로 초기화하며, 동결된 분기는 대조 학습을 통해 학습된 SAM에서 증류된 풍부한 2D 지식을 포함한다.

Affogato(어포던스 그라운딩 연구)의 Espresso-3D 모델도 3D 시각 입력 처리를 위해 PartField 아키텍처를 활용하며, 공식 PartField 저장소에서 소개된 PVCNN과 트리플레인 트랜스포머의 하이브리드 3D 인코더를 채택한다.

## 5. 앞으로의 연구에 미치는 영향과 연구 시 고려할 점

### 5-1. 앞으로의 연구에 미치는 영향

#### (a) 3D 기반 모델(Foundation Model)로의 발전 가능성
크로스-형상 응용은 이 방법의 놀라운 창발적 특성을 조사하는 것으로, **3D 형상 분석의 기초 특징을 위한 파트 대조 학습**에 대한 지속적인 연구를 촉진할 것으로 기대된다.

#### (b) 다운스트림 태스크 기반으로서의 활용
PartField 생성 지도(supervision)는 고정된 의미 분류 체계 없이 비지도적, 기하학-조율적 파트 레이블을 제공하는 방법으로, 멀티모달 학습과 대조 손실을 통해 높은 크로스-형상 일관성과 강건한 계층적 분할을 보장한다. 이 접근법은 빠른 피드포워드 추론과 인상적인 mIoU 점수로 CAD 모델의 신경 파이프라인에 통합된다.

#### (c) 3D 생성 모델과의 시너지
이 시스템은 파트 인식 형상 생성 기술을 활용하여 파트 관계와 계층 구조에 대한 이해를 향상시킨다.

#### (d) 로보틱스·AR/VR 등 응용 분야로의 확장
오픈-월드 3D 파트 분할은 로보틱스(robotics) 및 AR/VR과 같은 다양한 응용에서 중추적인 역할을 한다.

---

### 5-2. 향후 연구 시 고려할 점

1. **장면 수준 확장 (Scene-Level Extension)**
현재 연구는 객체 규모에서만 PartField를 탐구하며, 향후 연구에서 대규모 장면으로의 확장이 과제로 남아 있다.

2. **방향 불변성 (Orientation Invariance)**
PVCNN & 트리플레인 아키텍처는 본질적으로 외재적(extrinsic)이어서 크로스-형상 응용에서는 형상이 일관되게 정렬되어야 한다는 제약이 있다. 향후 연구에서는 **회전-불변(rotation-invariant) 또는 내재적(intrinsic) 아키텍처**를 도입하는 것이 중요하다.

3. **세밀한 파트 경계 처리**
SAMPart3D와 PartField는 특징 클러스터링에 의존하기 때문에, 복잡하고 세밀한 구조에서 파편화되거나 의미론적으로 무의미한 파트를 생성하는 경우가 있어, 향후 더 정교한 클러스터링 전략이나 경계 인식 학습이 필요하다.

4. **프롬프트 가능한(Promptable) 인터페이스 통합**
기존 접근법이 포인트 클라우드 네트워크에만 의존하는 것과 달리, 연속 트리플레인 특징 필드 내에 파트를 인코딩하고 듀얼-브랜치 네트워크로 다양한 모달리티의 사전 정보를 효과적으로 활용하는 방향으로 발전이 가능하다.

5. **대규모 비지도 데이터 활용 전략**
SAMPart3D가 최근 대규모 3D 객체 데이터셋 Objaverse로 확장하여 복잡하고 비일반적인 객체를 처리하는 것처럼, PartField 역시 더 다양하고 방대한 비지도 3D 데이터를 활용하는 전략이 일반화 향상의 핵심이 될 것이다.
