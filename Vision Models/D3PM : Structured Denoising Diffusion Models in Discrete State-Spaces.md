# D3PM : Structured Denoising Diffusion Models in Discrete State-Spaces

## 1. 핵심 주장 및 주요 기여 요약

### 1.1 논문의 핵심 주장

"Structured Denoising Diffusion Models in Discrete State-Spaces" (D3PM)은 **이산 상태 공간에서의 확산 모델을 일반화 및 확장**하는 논문이다. Austin et al.이 NeurIPS 2021에 발표한 이 연구는 다음의 핵심 주장을 제시한다:

1. **기존 이산 확산 모델의 한계**: Hoogeboom et al.이 제안한 균등 전이 확률(uniform transition probabilities)을 가진 다항식 확산 모델(multinomial diffusion)은 충분하지 않다.

2. **구조화된 전이 행렬의 중요성**: 문제 영역에 맞는 구조화된 전이 행렬(transition matrices)을 설계하면 데이터 생성 과정을 더 효과적으로 제어할 수 있다.

3. **일반적 프레임워크**: 텍스트와 이미지 모두에서 적용 가능한 통일된 D3PM 프레임워크는 다양한 전이 행렬 설계를 수용한다.

### 1.2 주요 기여

**기술적 기여:**
- **구조화된 전이 행렬 설계**: 균등 확산, 흡수 상태(Absorbing state), 이산화된 가우스, 토큰 임베딩 거리 기반 4가지 주요 전이 행렬 제안
- **새로운 손실 함수**: 변분 하한(VLB)과 보조 교차 엔트로피 손실을 결합한 $L_\lambda$ 손실 함수
- **상호정보 기반 노이즈 스케줄**: 일반적 전이 행렬에 적용 가능한 새로운 스케줄 제안

**개념적 기여:**
- **이론적 연결**: D3PM이 BERT, 자동회귀 모델, 마스크 언어 모델과의 수학적 관계 규명
- **확장성**: 큰 어휘 크기로의 확장을 위한 저랭크 부패(low-rank corruption)와 행렬 지수(matrix exponential) 방법 제시

## 2. 해결하고자 하는 문제, 제안하는 방법, 모델 구조

### 2.1 해결하고자 하는 문제

#### 2.1.1 기존 이산 확산 모델의 문제점

연속 상태 공간에서의 확산 모델(DDPM)은 이미지와 음성 생성에서 뛰어난 성과를 보였지만, 텍스트나 범주형 데이터와 같은 **이산 데이터에 대한 효과적인 확산 모델은 부족**했다.

기존 접근법들의 한계:
1. **균등 확산(Multinomial Diffusion)**: 모든 상태로의 전이 확률이 동일하여, 데이터의 의미적/순서적 관계를 활용하지 못함
2. **연속화 임베딩**: 이산 데이터를 연속 공간에 강제로 임베딩하면 정보 손실 및 부자연스러운 처리 발생
3. **단일 설계 선택**: 다양한 데이터 타입(이미지, 텍스트, 분자 구조 등)에 대한 최적화된 전이 과정 부재

#### 2.1.2 구체적 문제

- **텍스트 생성**: 문자 수준 텍스트 생성에서 비자동회귀 모델들이 자동회귀 모델에 비해 성능 부족
- **이미지 생성**: 이산화된 이미지에 대해 연속 DDPM 수준의 성능 달성 불가
- **일반화 성능**: 서로 다른 데이터 타입과 문제에 최적화된 단일 프레임워크 부재

### 2.2 제안하는 방법: D3PM 프레임워크

#### 2.2.1 전체 프레임워크 개요

D3PM은 다음 구조를 따르는 **구조화된 마르코프 확산 과정**을 제안한다:

**정방향 과정 (Forward Process):**

$$q(x_t|x_{t-1}) = \text{Cat}(x_t; p = x_{t-1}Q_t)$$

여기서:
- $x_t$: 시간 $t$에서의 이산 상태 (K개 범주)
- $Q_t$: K×K 전이 행렬 (행이 1로 합산)
- 누적 전이: $Q^t = Q_1 Q_2 \cdots Q_t$
- 주변 분포: $q(x_t|x_0) = \text{Cat}(x_t; p = x_0Q^t)$

**역방향 과정 (Reverse Process):**

신경망 $\text{nn}_\theta$를 사용하여 $x_0$ 예측:

$$p_\theta(x_{t-1}|x_t) \propto \sum_{\tilde{x}_0} q(x_{t-1}, x_t|\tilde{x}_0) \tilde{p}_\theta(\tilde{x}_0|x_t)$$

#### 2.2.2 핵심 수식

**변분 하한 (Variational Lower Bound):**

$$L_{vb} = \mathbb{E}_{q(x_0)} \left[ D_{KL}[q(x_T|x_0)||p(x_T)] + \sum_{t=2}^{T} \mathbb{E}_{q(x_t|x_0)} \left[D_{KL}[q(x_{t-1}|x_t, x_0)||p_\theta(x_{t-1}|x_t)]\right] - \mathbb{E}_{q(x_1|x_0)}[\log p_\theta(x_0|x_1)] \right]$$

**제안된 하이브리드 손실 함수 ($L_\lambda$ 손실):**

$$L_\lambda = L_{vb} + \lambda \mathbb{E}_{q(x_0)}\mathbb{E}_{q(x_t|x_0)}[-\log \tilde{p}_\theta(x_0|x_t)]$$

여기서:
- 첫 번째 항: 변분 상한 (확률 모델링)
- 두 번째 항: 보조 교차 엔트로피 손실 (직접적 $x_0$ 예측 강화)
- $\lambda$: 가중치 하이퍼파라미터 (일반적으로 0.001 또는 0.01)

**후진 과정 포스테리어 (Backward Process Posterior):**

$$q(x_{t-1}|x_t, x_0) = \text{Cat}\left(x_{t-1}; p = \frac{x_t Q_t^\top \odot x_0 Q^{t-1}}{x_0 Q^t x_t^\top}\right)$$

여기서 $\odot$는 원소별 곱셈(Hadamard product)을 의미한다.

### 2.3 제안된 전이 행렬 설계 (Transition Matrices)

#### 2.3.1 균등 확산 (Uniform D3PM)

모든 상태로의 전이 확률이 동일:

$$[Q_t]_{ij} = \begin{cases} 1 - \frac{K-1}{K}\beta_t & \text{if } i = j \\ \frac{1}{K}\beta_t & \text{if } i \neq j \end{cases}$$

또는: $Q_t = (1-\beta_t)I + \frac{\beta_t}{K}11^T$

**특성**: 정상 분포가 균등 분포, 가장 기본적 형태

#### 2.3.2 흡수 상태 확산 (Absorbing State D3PM)

특정 상태(예: [MASK])로의 비가역적 전이:

$$[Q_t]_{ij} = \begin{cases} 1 & \text{if } i = j = m \\ 1 - \beta_t & \text{if } i = j \neq m \\ \beta_t & \text{if } j = m, i \neq m \\ 0 & \text{otherwise} \end{cases}$$

또는: $Q_t = (1-\beta_t)I + \beta_t e_m 1^T$

**특성**: [MASK] 토큰 사용, BERT 스타일 학습 목표, 텍스트에서 최고 성능

#### 2.3.3 이산화된 가우스 확산 (Discretized Gaussian D3PM)

연속 가우스 커널 모방:

$$[Q_t]_{ij} = \begin{cases} \frac{\exp\left(-\frac{4|i-j|^2}{(K-1)^2\beta_t}\right)}{\sum_{n=-(K-1)}^{K-1} \exp\left(-\frac{4n^2}{(K-1)^2\beta_t}\right)} & \text{if } i \neq j \\ 1 - \sum_{l \neq i}[Q_t]_{il} & \text{if } i = j \end{cases}$$

**특성**: 순서형 데이터(이미지)에 최적, 유사한 상태로의 선호적 전이

#### 2.3.4 토큰 임베딩 거리 기반 확산 (Token Embedding Distance D3PM)

임베딩 공간에서의 의미적 유사성 활용:

1. k-최근린 그래프 구성: $[G]_{ij} = 1$ if $w_i$ is k-NN of $w_j$
2. 대칭화: $A = (G + G^T)/(2k)$
3. 속도 행렬(rate matrix):

```math
[R]_{ij}=\begin{cases}-\sum _{l\ne i}A_{il}&\text{if}i=j\\ A_{ij}&\text{otherwise}\end{cases}
```

4. 행렬 지수: $Q_t = \exp(\alpha_t R)$

**특성**: 의미적 관계 포착, 문자 수준에서는 음절 관계 활용 가능

### 2.4 노이즈 스케줄 (Noise Schedules)

#### 2.4.1 상호정보 기반 스케줄

일반 전이 행렬에 적용 가능한 원칙적 방법:

$$\frac{t}{T} = 1 - \frac{I(x_t; x_0)}{H(x_0)} = \frac{H(x_0, x_t) - H(x_t)}{H(x_0)}$$

여기서:
- $I(x_t; x_0)$: 시간 $t$에서의 상호정보
- $H(x)$: 엔트로피
- 의미: 시간 $t$까지 원본 데이터의 정보량 중 $t/T$ 비율만큼 손실

**흡수 상태의 특수한 경우:**
상호정보 스케줄이 정확히 Sohl-Dickstein의 원본 스케줄로 축소:

$$\beta_t = \frac{1}{T - t + 1}$$

#### 2.4.2 기타 스케줄

- **코사인 스케줄** (Nichol & Dhariwal 적응): 균등 확산에 효과적
- **선형 스케줄**: 가우스 확산에 사용

### 2.5 모델 구조

#### 2.5.1 신경망 아키텍처

**이미지 생성:**
- PixelCNN++ 기반 U-Net
- 4개 특성맵 해상도 단계
- 각 해상도에 2개 합성곱 잔여 블록
- 16×16 해상도에 자기주의 블록 추가
- Wide ResNet 백본, 그룹 정규화

**텍스트 생성:**
- T5 스타일 트랜스포머 인코더
- 12 계층, 약 70M 파라미터
- 12 주의 헤드, MLP 차원 3072, QKV 차원 768

#### 2.5.2 역방향 프로세스 파라미터화

**$x_0$ 파라미터화의 장점:**

$$p_\theta(x_{t-1}|x_t) \propto \sum_{\tilde{x}_0} q(x_{t-1}, x_t|\tilde{x}_0) \tilde{p}_\theta(\tilde{x}_0|x_t)$$

1. **자동 희소성 보존**: 선택된 전이 행렬의 희소성 패턴이 자동으로 보존
2. **다단계 추론**: $p_\theta(x_{t-k}|x_t)$로 확장 가능
3. **의미적 일관성**: 최적 역과정은 데이터에 대해서만 KL=0

#### 2.5.3 서수형 데이터를 위한 截断 로지스틱 분포

이미지와 같은 서수형 데이터에 순서형 귀납 편향 추가:

- 기저 연속 분포: 截단 로지스틱 분포
- 신경망이 위치($\mu$)와 로그 스케일(log $s$) 예측
- 기저 분포를 이산화하여 카테고리 로짓 계산

## 3. 성능 향상 및 한계

### 3.1 성능 향상

#### 3.1.1 텍스트 생성 결과

**Text8 (문자 수준):**

| 모델 | NLL (bits/char) | 샘플 시간 (s) |
|------|-----------------|----------------|
| D3PM uniform | ≤1.61 ± 0.02 | 3.6 ± 0.4 |
| D3PM NN | ≤1.59 ± 0.03 | 3.1 |
| **D3PM absorbing** | **≤1.45 ± 0.02** | 3.4 ± 0.3 |
| Discrete Flow | 1.23 | 0.16 |
| IAF/SCF | 1.88 | 0.04 |

**관찰:**
- 흡수 상태(마스킹) 모델이 최고 성능
- 최고 성능 비자동회귀 모델 중 하나
- 자동회귀 트랜스포머보다 빠른 샘플링

**LM1B (대규모 어휘):**

| 모델 | 1000 스텝 | 128 스텝 | 64 스텝 |
|------|----------|---------|--------|
| D3PM uniform | 137.9 ± 2.1 | 139.2 ± 1.2 | 145.0 ± 1.2 |
| D3PM absorbing | **76.9 ± 2.3** | 80.1 ± 1.2 | 83.6 ± 6.1 |
| Transformer | - | 43.6 | - |

**한계:**
- 비자동회귀 모델 중 좋은 성과이지만 자동회귀 대비 여전히 뒤처짐
- 토큰 임베딩 거리 모델이 예상외로 성능 저하

#### 3.1.2 이미지 생성 결과 (CIFAR-10)

**Inception Score (IS):**

| 모델 | IS (↑) | FID (↓) | NLL (bits/dim) |
|------|--------|--------|-----------------|
| D3PM uniform | 5.99 ± 0.14 | 51.27 ± 2.15 | ≤5.08 ± 0.02 |
| D3PM absorbing | 6.26 ± 0.10 | 41.28 ± 0.65 | ≤4.83 ± 0.02 |
| D3PM Gauss | 7.75 ± 0.13 | 15.30 ± 0.55 | ≤3.966 ± 0.005 |
| **D3PM Gauss + logistic** | **8.56 ± 0.10** | **7.34 ± 0.19** | **≤3.435 ± 0.007** |
| DDPM Lsimple | 9.46 ± 0.11 | 3.17 | ≤3.75 |
| Improved DDPM Lsimple | - | 2.90 | ≤3.37 |

**주요 발견:**

1. **전이 행렬의 중요성**: 이산화 가우스가 균등/흡수 상태보다 훨씬 우수
   - 서수형 데이터에서 구조화된 전이의 중요성 입증

2. **손실 함수 영향**: $L_\lambda$ 손실 (보조 교차 엔트로피)이 유의미한 개선
   - Lsimple보다는 낮지만 유사한 원리
   - 표준 VLB보다 우수한 그래디언트 노이즈 특성

3. **로지스틱 파라미터화의 가치**: 서수형 귀납 편향 추가로 추가 개선
   - D3PM Gauss + logistic이 연속 DDPM과 경쟁 가능 수준

4. **로그우도 성과**: 일부 지표에서 연속 DDPM 초과
   - IS/FID에서는 연속 모델이 여전히 우수
   - 로그우도(likelihood)에서는 경쟁 가능

### 3.2 한계 및 제약

#### 3.2.1 샘플 품질 한계

**이미지 생성:**
- IS/FID에서 연속 DDPM 및 개선된 DDPM에 미치지 못함
- 최고 성능 (D3PM Gauss + logistic): IS=8.56, FID=7.34
- 비교: Improved DDPM Lsimple: IS=11.47, FID=2.90
- GAN 기반 모델(StyleGAN2+ADA): IS=9.74, FID=3.26

**원인 분석:**
1. 이산 상태 공간의 표현력 제약
2. 전이 행렬 설계의 부정확성 (완벽한 가우시안 모방 불가)
3. 신경망 용량 및 아키텍처 최적화 부족 가능성

#### 3.2.2 텍스트 생성에서의 한계

**텍스트 성능 격차:**
- LM1B에서 D3PM absorbing: 76.9 perplexity
- 비교 Transformer: 43.6 perplexity
- 대형 Transformer XL: 21.8 perplexity
- **격차**: 약 1.75배 이상의 성능 차이

**원인:**
1. **자동회귀적 편향의 강력함**: 언어는 본질적으로 인과 관계 강함
2. **병렬화의 한계**: 비자동회귀 모델도 결국 반복적 정제 필요
3. **토큰 상호작용**: 마스킹 방식이 언어의 복잡한 의존성 충분히 포착 불가

#### 3.2.3 임베딩 거리 기반 방법의 실패

**예상과 달리 나쁜 성능:**

| 모델 | Text8 (NLL) | LM1B (Perplexity) |
|------|-----------|-------------------|
| D3PM uniform | ≤1.61 | 137.9 |
| **D3PM NN** | **≤1.59** | 149.5 |

**분석:**
- 문자 수준에서 임베딩 유사성이 의미 있지만, 효과 미미
- 단어 수준에서 오히려 성능 저하
- **시사점**: 모든 구조적 정보가 생성 품질 향상에 도움이 되는 것은 아님
- 의미적 유사성보다 명시적 마스킹이 더 효과적인 신호

#### 3.2.4 계산 효율성 한계

**추론 시간 문제:**

- 텍스트8에서 1000 스텝: 3.6초 (샘플링)
- 자동회귀 트랜스포머: 0.36초 (약 10배 느림)
- 256 스텝 사용 시에도 0.58초 (약 1.6배 느림)

**메모리 요구:**

- 큰 K에 대해 전이 행렬 $Q^t$ 저장: $O(K^2 T)$ 복잡도
- 저랭크 방법으로 완화 ( $O(r^2 T)$ ), 하지만 여전히 제약

## 4. 모델의 일반화 성능 향상 가능성 (중점)

### 4.1 이론적 일반화 분석

#### 4.1.1 현재 논문에서의 일반화 관련 내용

**논문의 명시적 일반화 논의 부족:**

원 D3PM 논문(2021)은 일반화에 대해 명시적으로 다루지 않았으나, 다음이 암시됨:

1. **VLB 최적화의 원칙성**: 변분 하한 최적화는 모델 적응(overfitting)을 제어하는 정규화 효과
2. **구조화된 전이의 귀납 편향**: 문제 구조를 인코딩하면 OOD 일반화 향상 가능

#### 4.1.2 관련 최신 연구 (2020-2025)

##### **A. 확산 모델의 일반화 이론**

**"On the Generalization Properties of Diffusion Models" (2025)**
- 확산 모델의 일반화 특성을 이론적으로 분석
- "Modes shift" 현상이 일반화를 해친다고 지적
- 학습된 분포와 실제 분포 간의 모드 이동이 오버피팅 발생

**"Principled Out-of-Distribution Generalization via Simplicity" (2025)**
- 확산 모델이 합성적 일반화(compositional generalization)를 수행하는 방식 규명
- 핵심 발견: **모델 단순성이 OOD 일반화의 핵심 메커니즘**
- 이미지 생성에서 견고한 OOD 일반화 관찰
- 정규화된 최대우도 추정에서 샘플 복잡도 $\tilde{O}(1/n)$

**"Local Mechanisms of Compositional Generalization in Conditional Diffusion" (2025)**
- 조건부 확산 모델의 합성적 일반화 기제 분석
- 점수 함수(score function)의 **지역성(locality)**이 일반화 가능하게 함
- 지역적 조건부 점수를 명시적으로 강제하면 길이 일반화 달성 가능

##### **B. 이산 확산 모델의 이론적 분석**

**"How Discrete and Continuous Diffusion Meet: Comprehensive Analysis via Stochastic Integral Framework" (ICLR 2025)**

이산 확산 모델의 첫 포괄적 오류 분석 프레임워크 제시:

1. **Lévy 적분 프레임워크**: 포아송 무작위 측도를 이용한 이산 확산 정식화
2. **변수 변환 정리**: Itô 적분과 Girsanov 정리에 유사한 이산 버전 개발

**오류 분해 (Error Decomposition):**

$$D_{KL}(p_\delta || \hat{q}_{T-\delta}) \lesssim \exp(-\tau) + \epsilon + \kappa T$$

여기서:
- **$\exp(-\tau)$ (절단 오류)**: 정상 분포로의 수렴 오류
  - 연속 OU 과정의 지수 수렴과 다름
  - 그래프 라플라시안의 수정된 대수갭에 의존
  
- **$\epsilon$ (점수 함수 오류)**: 신경망 근사 오류
  - 베르만 발산 손실 사용
  - 헬린저 거리로 제어
  
- **$\kappa T$ (이산화 오류)**: 시간 이산화 오류
  - 대역폭 선택에 영향받음

**상태 크기 독립적 오류 경계:**

"State Size Independent Statistical Error Bound for Discrete Diffusion Models" (NeurIPS 2024)는 다음을 달성:

- **다항로그 의존성**: 오류 경계가 $\log M$에만 의존 ($M$은 상태 수)
- **신경망 근사**: 심 베소프 공간의 고유벡터 근사로 구현
- **개선된 수렴율**: 상태 크기에 대한 의존성 제거

$$\text{Error} \lesssim \text{poly}(\log M) \text{ (최적 추측에 가까움)}$$

##### **C. 마스크된 확산 모델의 확장성**

**"Scaling up Masked Diffusion Models on Text" (2024)**

첫 마스크된 확산 모델(MDM) 확장법 수립:

1. **확장법 발견**: 마스크된 확산이 자동회귀 모델과 비교 가능한 확장 특성
   
2. **계산-최적 손실**:
$$L(C) = L_\infty - C^{-\alpha}, \quad \alpha \approx 0.07$$
   
   - $C$: FLOPs
   - 자동회귀 모델과 유사한 지수

3. **실증 결과**:
   - 1.1B 파라미터 MDM 학습 ($10^{20}$ FLOP)
   - 16배 더 많은 사전학습 시간으로 동등 크기 자동회귀 모델 초과

4. **일반화 함의**: 대규모 학습 시 마스크된 확산의 귀납 편향이 자동회귀와 경쟁 가능

**"Scaling Behavior of Discrete Diffusion Language Models" (2025)**

다양한 노이즈 타입에서의 확장 행동 연구:

1. **노이즈 타입의 영향**:
   - 마스크된 확산: 작은 모델에서 우수하지만 대역폭 효율 낮음
   - 균등 확산: 높은 매개변수 효율, 데이터 제한 환경에서 강력
   - **하이브리드**: 두 방식의 중간값, 유연한 절충

2. **10B 규모 균등 확산 모델**: 경쟁 가능한 성능 달성
   - 더 깊은 모델 크기에서 마스킹 기반 편향 감소

### 4.2 D3PM의 일반화 강화 방법

#### 4.2.1 구조화된 전이가 일반화를 돕는 이유

**1. 귀납 편향(Inductive Bias) 추가**

구조화된 전이 행렬은 문제 도메인의 사전 지식을 인코딩:

- **이산화 가우스**: "인접한 상태가 더 유사하다"는 순서형 구조
- **흡수 상태**: "일부 정보는 돌이킬 수 없다"는 현실성
- **임베딩 기반**: "의미적 유사성이 중요하다"는 신호 (아직 검증 필요)

**이론적 기초:**
- 적절한 귀산 편향은 샘플 복잡도 감소
- D3PM의 구조화된 전이는 학습 가능한 가설 공간 감소

**경험적 증거:**
- 텍스트에서 마스킹이 모든 방법 중 최고 (강력한 귀산 편향)
- 이미지에서 가우시안이 균등보다 우수 (구조화의 가치)

#### 4.2.2 보조 손실 함수 ($L_\lambda$)의 일반화 효과

**메커니즘:**

$$L_\lambda = L_{vb} + \lambda \mathbb{E}_{q(x_0)}\mathbb{E}_{q(x_t|x_0)}[-\log \tilde{p}_\theta(x_0|x_t)]$$

**일반화 개선 방식:**

1. **조기 학습 신호**: 
   - 보조 손실이 모든 시간 단계에서 직접적인 $x_0$ 예측 신호 제공
   - 초기 학습 단계에서 빠른 진전
   - 표현 학습 강화

2. **그래디언트 노이즈 개선**:
   - Nichol & Dhariwal 관찰 재현
   - $L_{t-1}$은 작은 $t$에서 크기 크게 변함
   - 보조 손실이 시간 단계에 무관한 일정한 스케일 유지
   - **결과**: 더 안정적인 학습 동역학

3. **정규화 효과**:
   - 다중 목표 최적화가 암묵적 정규화 제공
   - VLB만의 오버피팅 위험 감소

**경험적 증거:**
- 이미지에서 $\lambda=0.001$일 때 현저한 개선
  - IS: 7.75 → 8.54
  - FID: 15.30 → 7.34
- 텍스트에서도 $\lambda=0.01$이 흡수 모델에서 유효

#### 4.2.3 상호정보 기반 노이즈 스케줄의 원칙성

**이론적 근거:**

$$\frac{t}{T} = 1 - \frac{I(x_t; x_0)}{H(x_0)}$$

**일반화 함의:**

1. **문제에 독립적**: 전이 행렬 형태에 관계없이 적용 가능
2. **정보 이론적 원칙**: 정상 분포 도달을 정보 손실로 측정
3. **적응적 스케일링**: 다양한 데이터 분포에 자동 조정

**현실화:**
- 흡수 상태의 경우 정확히 Sohl-Dickstein 스케줄로 축소
- 이는 이론적 원칙성 증명

#### 4.2.4 D3PM 프레임워크의 유연성

**다양한 문제에 적응 가능:**

| 응용 영역 | 권장 전이 행렬 | 이유 |
|----------|-----------------|------|
| 이미지 생성 | 이산화 가우스 | 픽셀 강도의 순서성 |
| 텍스트 생성 | 흡수 (마스킹) | 병렬 생성 + BERT 목표 |
| 분자 구조 | 임베딩 거리 | 화학적 유사성 |
| 음악 | 주파수 기반 | 음악 이론 |

### 4.3 2020-2025 관련 최신 연구의 일반화 진전

#### 4.3.1 마스크된 확산의 확장성과 일반화

**"Scaling up Masked Diffusion Models on Text" (2024)의 기여:**

1. **확장법 발견**: MDM이 자동회귀 모델과 유사한 $L(C) \propto C^{-0.07}$ 따름
2. **일반화 능력**: 1.1B 파라미터에서 다양한 하류 작업에 강력 성능
3. **함의**: D3PM 기반 마스크된 확산이 대규모에서도 일반화 가능

**구체적 성과:**
- MT-Bench (조건부 생성): 1.1B MDM이 강력한 성능 유지
- 4개 이해 작업: 16배 더 많은 사전학습으로 자동회귀 초과
- **결론**: 데이터 양증가는 마스크된 확산의 장점 강화

#### 4.3.2 이산 확산의 이론적 기초 강화

**오류 분석 (2025)**이 제공하는 일반화 인사이트:

1. **상태 크기 독립성**: 큰 어휘에도 적용 가능성 증대
2. **점수 함수 오류**: 신경망 근사 능력이 전체 성능 결정
3. **시간 이산화**: 최적 스케줄 설계로 오류 감소 가능

**"State Size Independent Error Bounds"의 의미:**

원 D3PM에서 LM1B의 8K 어휘로 확장 가능한 이론적 보증:

$$\text{Generalization Error} \lesssim \text{poly}(\log 8000) \text{ (매우 작음)}$$

### 4.4 D3PM의 일반화 개선을 위한 미래 방향

#### 4.4.1 전이 행렬 설계의 개선

**문제:** 토큰 임베딩 거리가 예상 반대로 실패

**원인 분석:**
- 임베딩 공간이 생성 태스크에 최적화되지 않음
- 사전학습 임베딩의 기하 구조가 생성에는 부적절할 수 있음

**개선 방향:**

1. **작업별 맞춤형 임베딩**:
   - 생성 태스크에 최적화된 임베딩 학습
   - 사전학습 + 세부조정 방식

2. **하이브리드 전이**:
   - 마스킹 + 구조화된 전이 혼합
   - $Q_t = \alpha Q_{mask} + \beta Q_{structure} + (1-\alpha-\beta)I$

3. **학습 가능한 전이 행렬**:
   - 고정된 구조에서 매개변수화된 전이로 진화
   - 메타 학습으로 최적 전이 발견

#### 4.4.2 손실 함수와 목표의 개선

**다층적 보조 손실:**

$$L = L_{vb} + \lambda_1 L_{x_0} + \lambda_2 L_{consistency} + \lambda_3 L_{diversity}$$

여기서:
- $L_{consistency}$: 시간 단계 간의 일관성 (예: 근처 시간 단계의 예측 유사성)
- $L_{diversity}$: 다양성 유지 (생성 다양성)

**연결된 목표:**
- Score matching 목표와의 결합 (Song et al. 2019)
- Flow matching 프레임워크와의 통합 (최신 연구)

#### 4.4.3 노이즈 스케줄의 최적화

**적응적 스케줄:**

$$\alpha_t = \text{learned}(t, \text{data statistics})$$

- 데이터 엔트로피에 기반한 동적 스케줄
- 각 계층이나 배치별로 조정 가능한 스케줄

**다중 궤적 학습:**
- 서로 다른 스케줄로 학습한 모델 앙상블
- 각 스케줄의 강점 활용

#### 4.4.4 신경망 아키텍처의 최적화

**D3PM 특화 아키텍처:**

1. **이산성 인코딩**:
   - 연속 임베딩 대신 이산 특성 벡터 사용
   - 범주형 정보 손실 방지

2. **시간-상태 합동 임베딩**:
   - 시간 정보와 현재 상태의 상호작용 모델링
   - Transformer 기반 설계

3. **스케일-불변 정규화**:
   - 서로 다른 시간 단계 간의 크기 변화에 대응
   - 적응적 정규화 기법

#### 4.4.5 데이터 증강과 정규화

**D3PM 특화 증강:**

1. **토폴로지 증강**:
   - 임베딩 공간의 국소 구조 보존 증강

2. **혼합 상태 증강**:
   - 여러 시간 단계의 상태 혼합
   - 판별적 특성 향상

3. **대비 학습 결합**:
   - 유사한 순서쌍 vs 비유사한 순서쌍
   - 표현 학습 강화

### 5.2 D3PM의 현재 위치

#### 5.2.1 강점

1. **개념적 단순성 + 이론적 원칙성**:
   - 명확한 프레임워크
   - 최신 이론적 검증 지원

2. **다용도성**:
   - 다양한 문제 영역에 적응 가능
   - 구조화된 전이로 도메인 지식 인코딩

3. **확장성**:
   - 최신 이론이 큰 어휘, 큰 모델로의 확장 보증
   - 1.1B+ 스케일에서 경쟁 가능 성능

4. **해석 가능성**:
   - 전이 행렬이 명시적 의미
   - 설계 선택이 투명함

#### 5.2.2 약점

1. **이미지 샘플 품질**:
   - IS/FID에서 연속 DDPM에 못 미침
   - 로그우도에서만 경쟁

2. **텍스트 성능**:
   - 자동회귀 모델에 비해 여전히 뒤처짐
   - 대규모 사전학습에서도 격차 유지

3. **계산 비용**:
   - 샘플링이 자동회귀보다 느림
   - 전이 행렬 저장 및 계산 오버헤드

4. **경험적 설계**:
   - 토큰 임베딩 거리의 실패 (예상 반대)
   - 최적 전이 행렬 선택의 체계적 방법 부족

### 5.3 D3PM vs. 주요 대안들

#### 5.3.1 연속 DDPM vs. D3PM

**연속 DDPM:**
- 장점: 우수한 샘플 품질, 확립된 최적화
- 단점: 이산 데이터 임베딩 필요, 해석성 낮음

**D3PM:**
- 장점: 이산 데이터 직접 처리, 구조적 유연성
- 단점: 샘플 품질, 계산 비용

**결론**: 이미지는 연속, 텍스트와 범주형은 이산 모델이 더 적절

#### 5.3.2 자동회귀 모델 vs. D3PM

**자동회귀 (Transformer):**
- 장점: 우수한 성능, 빠른 샘플링, 언어에 최적화
- 단점: 순차 처리, 병렬화 불가

**D3PM:**
- 장점: 병렬 생성, 유연한 조건화, 비자동회귀
- 단점: 성능 격차, 느린 샘플링

**결론**: 성능 중심이면 자동회귀, 유연성과 해석성은 D3PM

#### 5.3.3 최신 하이브리드 접근

**"Scaling up Masked Diffusion Models" (2024):**
- MDM + 자동회귀의 장점 결합
- 16배 더 많은 계산으로 자동회귀 초과 가능
- **함의**: 계산 가용성 있으면 D3PM 경쟁 가능

## 6. 향후 연구에 미치는 영향과 고려 사항

### 6.1 이론적 영향

#### 6.1.1 확산 모델 이론의 확장

**D3PM의 기여:**

1. **이산 확산의 정식화**:
   - 전이 행렬 프레임워크 제시
   - 연속과 이산의 수학적 대응 관계 수립

2. **최근 이론 발전의 기초**:
   - 2024-2025의 모든 오류 분석이 D3PM 정식화 사용
   - Lévy 적분 프레임워크도 D3PM에서 영감

**미래 이론 방향:**

1. **최적 전이 행렬**:
   - 주어진 데이터에 대한 최적 전이 이론 개발
   - 일반화 오류의 명시적 하한

2. **적응적 스케줄**:
   - 동적 스케줄 선택의 이론적 기초
   - 최적 시간 이산화

3. **신경망 용량**:
   - 이산 확산에 필요한 신경망 크기 이론화
   - 샘플 복잡도와 모델 크기의 관계

#### 6.1.2 확산 모델 이해의 심화

**D3PM으로부터:**

1. **귀산 편향의 역할**:
   - 구조화된 전이 = 귀산 편향
   - 적절한 편향이 샘플 효율성 향상

2. **정보 이론적 관점**:
   - 상호정보 스케줄의 일반성
   - 생성 과정의 정보 이론적 해석

### 6.2 실용적 영향

#### 6.2.1 응용 분야 확대

**현재 활용 중인 분야:**

1. **텍스트 생성**:
   - 마스크된 확산 기반 D3PM 직접 사용
   - 병렬 텍스트 생성 시스템

2. **이미지 생성**:
   - 이산화 이미지에 D3PM 적용
   - 저해상도 생성에서 경쟁 가능

3. **분자/화학**:
   - 분자 구조 생성에 D3PM 아이디어 적용
   - 화학적 제약 인코딩

**향후 유망 분야:**

1. **로봇 제어**:
   - "TopoCut" 연구: 이산 확산 정책으로 로봇 학습
   - 양자화된 동작에 D3PM 원칙 적용

2. **단백질 설계**:
   - 이산 아미노산 수열 생성
   - 구조-서열 전이 행렬 설계

3. **음악 생성**:
   - 이산 음표/리듬 생성
   - 음악 이론 기반 전이 행렬

4. **그래프 생성**:
   - 분자 그래프의 범주형 속성
   - 네트워크 토폴로지 생성

#### 6.2.2 멀티모달 생성

**D3PM의 확장:**

1. **혼합 모드**:
   - 연속(이미지) + 이산(텍스트) 결합
   - 각 모드에 최적 확산 선택

2. **제약 생성**:
   - 물리적/화학적 제약을 전이 행렬에 인코딩
   - 제약 만족 생성

### 6.3 향후 연구 시 고려할 점

#### 6.3.1 방법론적 고려사항

##### **1. 전이 행렬 설계의 원칙화**

**문제**: 최적 전이 행렬 선택이 대부분 휴리스틱

**해결 방안**:

a) **데이터 주도 설계**:
   ```
   - 학습 데이터의 통계로부터 최적 전이 추론
   - 메타 학습으로 데이터 분포에 맞는 행렬 학습
   - 검증 집합에서 전이 행렬 선택
   ```

b) **다중 전이 행렬 앙상블**:
   ```
   - 여러 전이 행렬로 학습한 모델 결합
   - 각 모델의 강점 활용
   - 불확실성 정량화
   ```

c) **이론적 가이드**:
   ```
   - 데이터 기하학으로부터 전이 유도
   - 최적성 조건 도출
   - 수렴 보증
   ```

##### **2. 손실 함수의 최적화**

**현재 상태**: $L_\lambda = L_{vb} + \lambda L_{x_0}$가 좋지만 $\lambda$ 선택이 경험적

**개선:**

a) **적응적 가중치**:
   ```
   - $\lambda_t = f(t)$: 시간 단계별 가중치
   - 자동 하이퍼파라미터 선택 (베이지안 최적화)
   - 작업별 맞춤형 $\lambda$
   ```

b) **다층적 손실**:
   ```
   - 점수 함수 매칭 추가
   - 일관성 정규화
   - 다양성 목표
   ```

##### **3. 신경망 아키텍처**

**현재**: 연속 확산의 아키텍처 재사용

**개선 필요:**

a) **이산성 명시 인코딩**:
   ```
   - 범주형 임베딩 개선
   - 이산 토폴로지 고려 계층
   - 비연속성 처리
   ```

b) **효율적 설계**:
   ```
   - 이산 데이터에 최적화된 아키텍처
   - 저차원 표현 학습
   - 계산 효율성 향상
   ```

#### 6.3.2 실험적 고려사항

##### **1. 공정한 비교**

**문제**: D3PM vs. 자동회귀 모델의 비교 시 계산량 차이

**권장:**

```
- 동일 FLOPs 기준 비교
- 동일 메모리 제약
- 동일 학습 시간
- 여러 시드로 신뢰도 확보
```

##### **2. 평가 지표**

**현재 지표의 한계**: IS/FID가 모든 응용에 적절하지 않음

**개선:**

```
- 작업별 맞춤형 평가
- 다양한 품질 차원 측정
  - 샘플 다양성
  - 조건화 정확성
  - 제약 만족
- 인간 평가 포함
- 공정성/편향 평가
```

##### **3. 일반화 검증**

**필수 실험:**

```
- 도메인 내 일반화: 데이터셋 크기 변화
- 도메인 외 일반화: OOD 데이터 테스트
- 길이 일반화: 더 긴 시퀀스
- 합성적 일반화: 보지 못한 조합
- 전이학습: 새로운 작업
```

#### 6.3.3 이론적 고려사항

##### **1. 오류 한계의 개선**

**현재 상태**: 보수적 한계, 실제 성능과 간격

**필요한 연구:**

```
- 더 타이트한 한계 유도
- 특정 구조에 특화된 분석
- 적응적 한계 (데이터 의존)
- 실증 검증
```

##### **2. 최적성 특성화**

**미해결 문제**: 주어진 문제에 대한 최적 전이는 무엇인가?

**접근:**

```
- 정보 이론적 최적성 정의
- 제약 하의 최적성
- 계산-정확도 트레이드오프
- 학습-실행 효율성
```

##### **3. 수렴 분석**

**필요:**

```
- 비볼록 최적화 하에서의 수렴 보증
- 표본 복잡도 경계
- 시간 복잡도 분석
- 병렬화 효율성
```

#### 6.3.4 윤리적/사회적 고려사항

**D3PM 응용 시 주의:**

1. **편향 및 공정성**:
   - 생성 모델의 편향 증폭 가능성
   - 평가 지표의 공정성
   - 다양한 그룹에 대한 성능

2. **투명성**:
   - 이산 전이 행렬의 해석성 강점 활용
   - 설계 선택의 명시적 문서화
   - 귀산 편향의 공개

3. **책임성**:
   - 합성 데이터 생성의 영향
   - 저작권/지적재산권 고려
   - 오용 가능성 검토

1. **확장성 검증**:

2. **전이 행렬 설계 자동화**:

## 7. 결론

### 7.1 D3PM의 기여 평가

**"Structured Denoising Diffusion Models in Discrete State-Spaces"**는 이산 데이터 생성의 패러다임을 제시했다:

1. **개념적 깊이**: 구조화된 전이 행렬로 도메인 지식 인코딩
2. **이론적 원칙성**: 정보 이론적 기초와 수학적 엄밀성
3. **실용적 유연성**: 다양한 문제에 적응 가능한 프레임워크
4. **선행 가치**: 2024-2025의 이론적 발전의 기초 제공

### 7.2 현재 상태와 미래

**현재 (2025):**
- 텍스트 생성에서 마스크 기반 확산이 표준화
- 1.1B+ 스케일에서 자동회귀와 경쟁 가능
- 이론적 기초 강화 중
- 다양한 응용 분야 개척 중

**미래 전망:**
- 계산 비용 감소 시 자동회귀 모델과 대등한 경쟁
- 구조화된 생성(단백질, 분자 등)에서 자동회귀 초과
- 멀티모달 생성의 핵심 기술으로 부상
- 확산 모델 이론의 기초 역할 지속

### 7.3 연구자에게의 조언

**D3PM 기반 연구를 진행할 때:**

1. **전이 행렬 설계가 핵심**: 데이터 구조를 세심하게 분석하여 전이 행렬 설계
2. **다양한 손실 함수 시도**: $L_\lambda$ 하이브리드 손실은 필수, 추가 손실 실험
3. **철저한 기초선 비교**: 공정한 조건에서 자동회귀 및 다른 방법과 비교
4. **이론적 기초 확보**: 최신 오류 분석 이론을 적용하여 일반화 보증 제공
5. **확장성 검증**: 대규모 실험으로 확장성 실증
6. **도메인별 최적화**: 일반적 설계보다 도메인 특화 설계가 중요

### 7.4 최종 평가

D3PM은 **개념적으로 우아하고 이론적으로 견고하며 실용적으로 유연한** 프레임워크다. 2021년 발표 이후 4년이 지난 현재, 그 가치는 더욱 명확해졌다:

- **이론적 기초 역할**: 모든 최신 이산 확산 이론의 출발점
- **실용적 성공**: 마스크 기반 확산의 대규모 확장성 입증
- **개념적 우아성**: 다양한 모델 (BERT, 자동회귀, MLM)을 통일하는 프레임워크

**향후 주목할 점:**
- 계산 리소스 증가 시 D3PM 기반 모델의 경쟁력
- 구조화 생성 작업에서의 우월성
- 멀티모달 생성에서의 중심 역할

이 논문은 단순히 과거 기여를 넘어, **생성 모델의 미래를 형성하는 지속적 영향을 미치고 있다**.
