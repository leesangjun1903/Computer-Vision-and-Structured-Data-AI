# LEO: Generative Latent Image Animator for Human Video Synthesis

## 1. 핵심 주장과 주요 기여

### 1.1 핵심 주장
LEO는 **시공간적 일관성(Spatio-temporal Coherency)**을 강조하는 인간 비디오 생성 프레임워크다. 기존 방법들이 모션과 외형의 완전한 분리에 실패하여 공간 왜곡(spatial distortion)과 시간 떨림(temporal jittering)을 발생시키는 문제를 해결한다.

### 1.2 주요 기여
1. **흐름 지도 기반 모션 표현**: 모션을 흐름 지도 시퀀스로 명시적으로 표현하여 모션을 외형으로부터 본질적으로 분리
2. **잠재 공간 학습**: Latent Motion Diffusion Model (LMDM)을 통해 저차원 모션 코드 공간에서 모션 분포 학습
3. **선형 모션 조건화(LMC)**: 임의 길이의 비디오 생성을 가능하게 하는 메커니즘
4. **다중 작업 지원**: 
   - 무조건부 비디오 생성
   - 단일 이미지 기반 조건부 생성
   - 콘텐츠 보존 비디오 편집
   - 무한 길이 비디오 생성

---

## 2. 해결하고자 하는 문제

### 2.1 주요 문제점
비디오 합성(특히 인간 비디오)에서 **완전한 모션-외형 분리의 부재**:

| 문제 | 원인 | 결과 |
|------|------|------|
| 공간 왜곡 | 불완전한 분리로 인한 의미론적 섭동 | 얼굴 신원 변형, 신체 구조 왜곡 |
| 시간 떨림 | 프레임 간 의미론적 불일치 | 16프레임 단기 비디오도 떨림 발생 |
| 장기 생성 불가 | 누적 오류 | 50프레임 이상에서 품질 급격히 저하 |

### 2.2 기존 접근법의 한계
- **다중 네트워크 방식**: 외형과 모션 특징을 위해 별도 네트워크 사용 → 강제 제약 부재
- **2단계 파이프라인**: 이미지 생성 후 시간 네트워크 추가 → 부분적 분리만 가능
- **결과**: 미묘한 섭동도 픽셀 공간에서 큰 변화로 증폭

## 3. 제안하는 방법 및 수식

### 3.1 전체 프레임워크 구조

**비디오 시퀀스 공식화**:

$$v = \{x_i\}_{i=1}^L, \quad x_i \sim X \in \mathbb{R}^{3 \times H \times W}$$

$$v = \{T(x_1, G(\alpha_i))\}_{i=2}^L, \quad \alpha_i \sim A \in \mathbb{R}^{1 \times N}$$

여기서:
- $x_i$: 프레임 $i$
- $\alpha_i$: 프레임 $i$의 잠재 모션 코드
- $G$: 흐름 생성기 (모션 코드 → 흐름 지도)
- $T$: Warp-and-Inpaint 연산자

### 3.2 단계 1: 잠재 모션 코드 학습

**LIA (Latent Image Animator) 기반 학습**:

$$\alpha = E(x_s, x_d)$$
$$\phi = G(\alpha)$$

자감독 학습 목표:
$$\mathcal{L}_{LIA} = \|x_d - \text{Reconstruct}(\phi, x_s)\|^2$$

**이점**:
1. 고품질 지각 결과 달성
2. 모션 코드 $\alpha$가 **순수 모션 정보만 포함** (외형 간섭 없음)

### 3.3 단계 2: 모션 사전 학습

#### 3.3.1 기본 LMDM

**확산 모델 표준 학습**:

$$\mathcal{L}_{LMDM} = \mathbb{E}_{\epsilon \sim \mathcal{N}(0,1), t} \left[ \|\epsilon - \epsilon_\theta(a_t, t)\|_2^2 \right]$$

여기서:
- $a_t$: 시간 $t$의 노이즈 추가 모션 코드
- $\epsilon_\theta$: 노이즈 예측 네트워크
- 추론: Gaussian 노이즈 $a_T$에서 $a_0 = \{\alpha_i\}_{i=1}^L$로 반복 제거

#### 3.3.2 조건부 LMDM (cLMDM)과 선형 모션 조건화(LMC)

**선형 모션 분해**:
$$\alpha_i = \alpha_1 + m_i, \quad i \geq 2$$
$$a = \alpha_1 + m$$

여기서 $m = \{m_i\}_{i=2}^L$는 모션 차이 시퀀스

**cLMDM 학습 목표**:

$$\mathcal{L}_{cLMDM} = \mathbb{E}_{\epsilon \sim \mathcal{N}(0,1), t} \left[ \|\epsilon - \epsilon_\theta(m_t, \alpha_1, t)\|_2^2 \right]$$

**LMC 메커니즘의 핵심**:
- 훈련 중: $m_t$에만 노이즈 추가, $\alpha_1$은 고정
- 추론: $a_0 = [\alpha_1, m_0]$로 최종 시퀀스 구성

**이점**:
- 생성된 모션 시퀀스가 더 안정적
- 강력한 신호로 $\alpha_1$이 초기 모션 제약
- 길이 제약 없음: 이전 시퀀스 마지막 코드를 다음 시퀀스 $\alpha_1$으로 사용

#### 3.3.3 무조건부 생성을 위한 시작 프레임 모듈

**추가 단순 확산 모델**:
$$p(\alpha_1) \text{ 학습 (프레임별)}$$

cLMDM + 단순 DM = LMDM (조건부/무조건부 모두 지원)

### 3.4 시작 프레임 생성

**옵션 1**: 기존 이미지 사용
$$\alpha_1 = E(x_1)$$

**옵션 2**: 조건부 DDPM (cDDPM)
$$x_1 \sim p(x_1 | \alpha_1)$$

## 4. 모델 구조

### 4.1 전체 구조 (2단계)

```
┌─────────────────────────────────────────────────────────────┐
│                     LEO Framework                           │
├─────────────────────────────────────────────────────────────┤
│ Phase 1: Image Animator (LIA) Training                       │
│ ─────────────────────────────────────────────────────────   │
│  Input: Video sequence {x_i}                                │
│  ↓                                                           │
│  Encoder E: Extract motion code α = E(x_s, x_d)             │
│  ↓                                                           │
│  Generator G: Generate flow φ = G(α)                        │
│  ↓                                                           │
│  Warp-and-Inpaint: Reconstruct driving frame                │
│  ↓                                                           │
│  Loss: Reconstruction with self-supervision                 │
│                                                             │
│ Phase 2: LMDM Training (Frozen LIA)                         │
│ ─────────────────────────────────────────────────────────   │
│  Input: Motion code sequences a = {α_i}^L_{i=1}             │
│  ↓                                                           │
│  Linear Motion Decomposition: a = α_1 + m                  │
│  ↓                                                           │
│  cLMDM: Learn motion distribution p(m | α_1)                │
│  ↓                                                           │
│  Loss: Diffusion denoising on m with condition α_1          │
│                                                             │
│ Inference:                                                  │
│ ─────────────────────────────────────────────────────────   │
│  Given: Starting frame x_1 or generated by cDDPM            │
│  ↓                                                           │
│  α_1 = E(x_1)                                               │
│  ↓                                                           │
│  LMDM generates motion sequence {α_i}                       │
│  ↓                                                           │
│  LIA generates flow sequence {φ_i}                          │
│  ↓                                                           │
│  Warp-and-Inpaint: Generate video frames                    │
│  ↓                                                           │
│  Output: Video v = {x_i}                                   │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 핵심 모듈 상세

#### 4.2.1 Image Animator (LIA)
- **Encoder**: 두 이미지 입력 → 1×N 차원 모션 코드
- **Generator**: 모션 코드 → H×W 흐름 맵
- **Warp Module**: 소스 프레임 + 흐름 → Warped 프레임
- **Inpainting Module**: Warping 구멍 채우기 + 전체 이미지 개선
- **구현**: LIA-CVPR2022 (최신 image animator)

#### 4.2.2 Latent Motion Diffusion Model (LMDM)
- **Architecture**: 1D U-Net (3D diffusion 대신)
- **입력 크기**: 64×20 (64 = 시퀀스 길이, 20 = 모션 코드 차원)
- **확산 스텝**: 1000
- **학습률**: 1e-4
- **효율성**: 단일 GPU 필요

#### 4.2.3 선형 모션 조건화 (LMC)
```
Training:
  m_t = m + √(1-ᾱ_t) · ε  (노이즈는 m에만 추가)
  α_1 고정 (노이즈 추가 안 함)
  입력: [m_t, α_1] 연결

Inference:
  무작위 Gaussian → 반복 제거 → m_0
  최종 시퀀스: [α_1, m_0]
```

#### 4.2.4 무한 길이 생성 메커니즘
```python
# Autoregressive approach
for segment in segments:
    if first_segment:
        α_1 = initial_motion_code
    else:
        α_1 = last_code_from_previous_segment  # 이전 끝 → 현재 시작
    
    m = LMDM_generate(α_1, noise)
    current_sequence = [α_1, m]
    
    video_frames = LIA_generate_frames(current_sequence)
    concatenate_to_output(video_frames)
```

## 5. 성능 향상 및 실험 결과

### 5.1 정량적 평가

#### 5.1.1 단기 비디오 생성 (16프레임)

| 데이터셋 | 지표 | DIGAN | TATS | StyleGAN-V | LEO (조건부) |
|---------|------|-------|------|-----------|------------|
| TaichiHD 128 | FVD↓ | 128.1±4.9 | 136.5±1.2 | - | **57.6±2.0** |
| TaichiHD 128 | KVD↓ | 20.6±1.1 | 22.2±1.0 | - | **4.0±1.5** |
| TaichiHD 128 | ACD↓ | 2.17 | 2.28 | - | **1.22** |
| TaichiHD 256 | FVD↓ | 156.7±6.2 | - | - | **94.8±4.2** |
| FaceForensics | FVD↓ | 62.5 | - | 47.4 | **35.9** |
| FaceForensics | ACD↓ | - | - | 0.36 | **0.27** |
| CelebV-HQ | FVD↓ | 72.9 | - | 69.1 | **40.2** |

**결과 해석**:
- LEO가 모든 데이터셋에서 FVD, KVD, ACD에서 최우수
- ACD (평균 콘텐츠 거리): 신원 일관성에서 LEO가 0.27로 가장 우수
- FVD의 한계 지적: StyleGAN-V가 FVD 상으로는 낮지만 얼굴 구조 왜곡 발생 (정성 평가에서 확인)

#### 5.1.2 장기 비디오 생성 (128프레임)

| 데이터셋 | 방법 | FVD↓ | KVD↓ | ACD↓ |
|---------|------|------|------|------|
| TaichiHD 128 | TATS | 1194.58±1.1 | 462.03±8.2 | 2.85 |
| TaichiHD 128 | **LEO** | **155.54±2.6** | **48.82±5.9** | **2.06** |
| FaceForensics 128 | StyleGAN-V | 89.34 | - | 0.49 |
| FaceForensics 128 | **LEO** | **96.28** | - | **0.34** |

**해석**:
- TaichiHD에서 LEO가 TATS보다 FVD에서 **86.9% 개선** (1194.58 → 155.54)
- TATS는 50프레임 이상에서 붕괴, LEO는 512프레임도 고품질 유지

#### 5.1.3 사용자 연구

| 비교 | 품질 평가 | 일관성 평가 |
|------|---------|-----------|
| LEO vs TATS | 93.0% | 98.6% |
| LEO vs StyleGAN-V | 91.33% | 93.2% |

**해석**: 사용자 대부분이 LEO를 선호, FVD 메트릭의 한계 확인

### 5.2 정성적 평가

#### 5.2.1 강점
1. **신체 구조 보존**: 팔, 다리 등 완전한 인간 구조 생성
2. **얼굴 신원 유지**: StyleGAN-V가 대형 모션에서 얼굴 변형하는 것과 달리 신원 보존
3. **다양한 모션**: 같은 인물 다양한 동작 (권투, 태극권 등)

#### 5.2.2 정성적 비교 (Figure 4, 5)
- **DIGAN/TATS**: 팔다리 생략, 불완전한 신체
- **StyleGAN-V**: 얼굴 구조 왜곡
- **LEO**: 명확한 시각 품질, 우수한 일관성

### 5.3 제거 실험 (Ablation Study)

**LMC의 효과**:

| 방법 | TaichiHD FVD | FaceForensics FVD |
|------|-------------|-----------------|
| w/o LMC | 118.6 | 60.03 |
| with LMC | **100.4** | **52.32** |
| 개선율 | 15.3% | 12.9% |

**결론**: LMC 조건화가 모션 시퀀스 안정성을 유의미하게 향상

## 6. 모델의 일반화 성능 향상 가능성

### 6.1 현재 제한 사항

#### 6.1.1 기하학적 모호성
```
문제: 2D 흐름 맵은 3D 폐색(occlusion) 처리 불가
결과: 태극권 데이터셋에서 신체 겹침 부분 생성 실패

해결책:
  1. NeRF 기반 3D 인식 생성기 통합
  2. Tri-plane 표현 도입
  → 3D 공간에서 명시적으로 폐색 처리 가능
```

#### 6.1.2 일반화 성능 (Table 6: UCF101)

| 방법 | FVD↓ |
|------|------|
| MoCoGAN-HD | 1729.6 |
| DIGAN | 1630.2 |
| StyleGAN-V | 1431.0 |
| **LEO (현재)** | **1356.2** |
| Make-A-Video | 367.23 |
| Video LDM | 550.61 |
| LaVie | 540.30 |

**분석**:
- LEO: 기존 GAN 방법들보다 우수하지만 대규모 확산 모델(Make-A-Video, LaVie)과 격차 있음
- **원인**: LIA가 human-centric으로만 학습됨, 일반 비디오 생성 시 일반화 부족

### 6.2 일반화 개선 방안

#### 6.2.1 모델 아키텍처 개선

**현재 한계**:
- Convolutional network만 사용
- Transformer 미도입

**개선 방향**:

$$\text{Encoder}_{new} = \text{Attention}(CNN_{backbone}) + \text{Transformer}_{blocks}$$

$$\text{LMDM}_{new} = \text{3D Transformer} + \text{Temporal Attention}$$

**기대 효과**:
- 장거리 시간적 의존성 학습
- 복잡한 모션 패턴 포착

#### 6.2.2 데이터셋 확대

**현재**: Human-centric 데이터 (TaichiHD, FaceForensics, CelebV-HQ)

**필요**:
$$D_{expanded} = D_{human} \cup D_{general} \cup D_{scene}$$

1. **대규모 고품질 데이터셋**:
   - OpenHumanVid (2024): 고품질 인간 비디오
   - 일반 비디오 (동물, 장면, 물체)

2. **다양성 확대**:
   - 실내/실외 장면
   - 다양한 카메라 이동
   - 특이한 포즈와 동작

#### 6.2.3 LIA 개선

**현재 제약**:
```
LIA (기존):
  → Talking head/human body 특화
  → 일반 비디오 객체 처리 불가
```

**개선 방안**:
```
LIA_general:
  1. 객체 기반 분해 (사람, 동물, 무생물 별도)
  2. 신경 복사(neural rendering) 기반 표현
  3. 카메라 모션 분리 추가
  
공식:
  α_general = E(x_s, x_d) → [α_motion, α_camera, α_appearance]
  → 더 정밀한 분해 가능
```

#### 6.2.4 조건화 강화

**현재**: 텍스트 조건화 미지원

**추가 가능 조건**:

$$\mathcal{L}_{enhanced} = \mathbb{E} \left[ \|\epsilon - \epsilon_\theta(m_t, \alpha_1, c_{text}, c_{pose}, t)\|_2^2 \right]$$

여기서:
- $c_{text}$: 텍스트 임베딩 (CLIP)
- $c_{pose}$: 포즈 조건화

**결과**: Text-to-Video 기능 추가, 제어 능력 향상

### 6.3 일반화 성능 향상 로드맵

```
Phase 1 (3-6개월):
  ├─ Transformer 기반 LMDM 설계
  ├─ NeRF 기반 3D 인식 LIA 개발
  └─ Human-centric 데이터로 사전학습

Phase 2 (6-12개월):
  ├─ 대규모 일반 비디오 데이터 수집 (1M+ 영상)
  ├─ 멀티 도메인 학습 (human, animal, object, scene)
  └─ 텍스트/포즈 조건화 추가

Phase 3 (12개월+):
  ├─ 계층적 모션 분해 (global + local)
  ├─ 카메라 모션 명시적 모델링
  └─ 인터랙티브 제어 UI 개발

예상 효과:
  현재 (UCF101 FVD 1356.2) 
    ↓↓↓
  개선 후 (FVD 400-600) 
    → Video LDM/LaVie 경쟁력 수준
```

## 7. 모델의 한계

### 7.1 명시적 한계

| 한계 | 영향 | 제안 해결책 |
|------|------|-----------|
| **기하학적 모호성** | 2D 흐름으로 3D 폐색 처리 불가 | NeRF/Tri-plane 통합 |
| **일반화 부족** | 인간 중심 학습으로 일반 비디오 약함 | 대규모 다중도메인 데이터 |
| **아키텍처 제약** | CNN만 사용, Transformer 미도입 | Attention 기반 LMDM |

### 7.2 암묵적 한계

1. **시간적 극단성**: 급격한 모션 변화에 약할 가능성
2. **카메라 모션**: 명시적 모델링 부재
3. **상호작용**: 다중 객체 간 상호작용 처리 미흡

## 8. 논문의 영향과 향후 연구 고려사항

### 8.1 학문적 영향

#### 8.1.1 패러다임 시프트

After LEO:

- Diffusion model의 **잠재 공간 활용** 증명

#### 8.1.3 모션 표현 학습

## 9. 요약 및 결론

### 9.1 핵심 성취

LEO는 **명시적 모션 표현(optical flow)**을 통해 모션-외형 분리 문제를 근본적으로 해결한 획기적 연구다:

$$\text{Key Innovation: } \alpha_i = \text{Motion Code} \rightarrow \phi_i = \text{Flow} \rightarrow \text{Video}$$

**3가지 핵심 기여**:
1. **하드 제약**: 흐름 지도로 모션 정보만 캡처
2. **효율적 학습**: Latent space 기반 1D LMDM
3. **길이 확장**: LMC로 임의 길이 생성

### 9.2 성능 요약

| 측면 | 성과 |
|------|------|
| 단기 생성 (16f) | SOTA (ACD 1.22) |
| 장기 생성 (128f) | SOTA (FVD 155.54 vs TATS 1194.58) |
| 시공간 일관성 | 사용자 선호 93-98% |
| 계산 효율성 | 단일 GPU, 초 단위 추론 |

### 9.3 향후 방향

**단기** (1-2년):
- Transformer 기반 아키텍처로 성능 향상
- 포즈/카메라 조건화 추가
- 인간 중심 대규모 데이터셋 활용

**중기** (2-3년):
- 3D 인식 확장 (NeRF 통합)
- 텍스트 조건화 추가
- 다중 객체 상호작용

**장기** (3년+):
- 일반 비디오 생성으로 확대 (UCF101 FVD < 600)
- 실시간 추론 (10+ FPS)
- 인터랙티브 제어 인터페이스

### 9.4 최종 평가

LEO는:
- ✅ **인간 비디오 합성의 기준선** 설정
- ✅ **효율성과 품질의 최적 균형**
- ✅ **향후 연구의 견고한 기초**
- ⚠️ **일반화 개선 필요** (향후 중점)
- ⚠️ **3D 인식 확장 가능성** (미래 방향)

## 부록: 수식 완전 정리

### A. 비디오 생성 기본 공식

$$\text{Video Sequence: } v = \{x_i\}_{i=1}^L, \quad x_i \in \mathbb{R}^{3 \times H \times W}$$

$$\text{With Motion: } v = \{T(x_1, G(\alpha_i))\}_{i=2}^L$$

### B. LMDM 확산 과정

**Forward Process (Diffusion)**:

$$q(a_t | a_0) = \sqrt{\bar{\alpha}_t} a_0 + \sqrt{1-\bar{\alpha}_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0,I)$$

**Reverse Process (Diffusion Model)**:

$$p_\theta(a_{t-1} | a_t) = \mathcal{N}(a_{t-1}; \mu_\theta(a_t, t), \Sigma_\theta(a_t, t))$$

**Loss Function**:

$$\mathcal{L} = \mathbb{E}_{a_0, \epsilon, t} \left[ \|\epsilon - \epsilon_\theta(a_t, t)\|_2^2 \right]$$

### C. 선형 모션 조건화

**Decomposition**:

$$\alpha_i = \alpha_1 + m_i, \quad i \geq 2$$

**cLMDM Loss**:

$$\mathcal{L}_{cLMDM} = \mathbb{E}_{\epsilon, t} \left[ \|\epsilon - \epsilon_\theta(\sqrt{\bar{\alpha}_t} m_0 + \sqrt{1-\bar{\alpha}_t}\epsilon, \alpha_1, t)\|_2^2 \right]$$

**Inference**:

$$m_0 = \text{LMDM}(\alpha_1, \text{noise})$$

$$a = [\alpha_1, m_0]$$

$$v = \{T(x_1, G(\alpha_i))\}_{i=2}^L$$
