## 1. 핵심 주장 및 주요 기여 (요약)

Spann3R는 순서 있는 또는 순서 없는 이미지 컬렉션으로부터 밀집(dense) 3D 재건을 수행하는 새로운 접근법으로, DUSt3R 패러다임 위에 구축된 트랜스포머 기반 아키텍처를 사용하여 장면이나 카메라 파라미터에 대한 사전 지식 없이 포인트맵(pointmaps)을 직접 회귀(regress)한다.

DUSt3R가 각 이미지 쌍별로 로컬 좌표계에서 포인트맵을 예측하는 것과 달리, Spann3R는 글로벌 좌표계에서 이미지별 포인트맵을 직접 예측함으로써 최적화 기반 글로벌 정렬의 필요성을 제거한다. 핵심 아이디어는 이전의 모든 관련 3D 정보를 추적하도록 학습된 **외부 공간 메모리(External Spatial Memory)**를 관리하는 것이며, 이 공간 메모리를 쿼리하여 다음 프레임의 3D 구조를 글로벌 좌표계에서 예측한다.

### 주요 기여 요약표

| 기여 항목 | 내용 |
|---|---|
| **글로벌 포인트맵 예측** | 최적화 없이 전역 좌표계에서 직접 회귀 |
| **공간 메모리 모듈** | 이전 프레임의 3D 정보를 저장·쿼리하는 외부 메모리 |
| **실시간 처리** | 50 fps 이상의 온라인 재건 가능 |
| **일반화 능력** | 다양한 미지의 데이터셋에서 경쟁력 있는 성능 |

## 2. 문제 정의, 제안 방법, 모델 구조, 성능 및 한계

### 2.1 해결하고자 하는 문제

DUSt3R는 사전 장면 정보 없이 이미지 쌍으로부터 포인트맵을 직접 회귀하는 패러다임을 도입하였으나, 포인트맵이 이미지 쌍의 로컬 좌표계에서 표현되기 때문에 2장 이상의 이미지를 재건하려면 글로벌 정렬을 위한 per-scene 최적화가 필요하다. 이는 실시간 증분 재건과 다수 이미지로의 확장성을 제한한다.

즉, Spann3R가 해결하고자 하는 핵심 문제는:
1. **최적화 의존성**: 기존 방식은 장면마다 bundle adjustment 등의 최적화가 요구됨
2. **실시간 처리 불가**: pairwise 처리 방식의 높은 계산 비용
3. **글로벌 정렬 부재**: 로컬 좌표계로 예측된 포인트맵 간의 정합 문제

---

### 2.2 제안하는 방법 및 수식

#### 핵심 파이프라인

핵심 아이디어는 이전 상태를 기억하고 다음 프레임 예측을 위해 메모리 내 모든 관련 정보를 쿼리하는 메모리 네트워크 개념을 외부 메모리로 유지하는 것이다. 경량 트랜스포머 기반 메모리 인코더를 사용하여 이전 예측을 메모리 값으로 인코딩하고, 두 개의 MLP 헤드를 통해 기하학적 특징을 쿼리 특징과 메모리 키로 변환하여 메모리에서 정보를 검색한다.

#### 공간 메모리 구조

공간 메모리는 **밀집 작업 메모리(Dense Working Memory)**, **희소 장기 메모리(Sparse Long-term Memory)**, 그리고 메모리에서 특징을 추출하는 **메모리 쿼리 메커니즘**으로 구성된다.

메모리 쿼리는 attention 메커니즘을 기반으로 다음과 같이 공식화할 수 있다:

$$\mathbf{f}_{\text{fused}} = \text{Attention}(\mathbf{Q}, \mathbf{K}_{\text{mem}}, \mathbf{V}_{\text{mem}})$$

여기서:
- $\mathbf{Q}$: 현재 프레임의 타겟 디코더에서 생성된 **쿼리 특징**
- $\mathbf{K}_{\text{mem}}$: 공간 메모리의 **키(key)**
- $\mathbf{V}_{\text{mem}}$: 공간 메모리의 **값(value)**
- $\mathbf{f}_{\text{fused}}$: 메모리에서 읽어온 **융합(fused) 특징**

#### 학습 손실 함수 (Training Loss)

Spann3R는 학습을 위해 신뢰도 인식 회귀 손실(confidence-aware regression loss)과 스케일 손실(scale loss)을 함께 사용한다:

$$\mathcal{L} = \mathcal{L}_{\text{conf}} + \mathcal{L}_{\text{scale}}$$

각 항목의 의미:
- $\mathcal{L}_{\text{conf}}$: 예측 포인트맵의 신뢰도를 반영한 회귀 손실 (DUSt3R에서 상속)
- $\mathcal{L}_{\text{scale}}$: 글로벌 좌표계에서 예측 스케일의 일관성을 보장하는 손실

또한 모델은 다양한 카메라 움직임과 특징 연결에 적응하기 위해 훈련 과정에서 샘플링 윈도우 크기를 조정하는 **커리큘럼 학습(Curriculum Training) 전략**을 사용한다.

### 2.3 모델 구조 상세

아키텍처는 특징 인코딩 및 디코딩을 위해 ViT 인코더와 연결된 디코더들로 구성된다. 타겟 디코더는 메모리 읽기를 위한 쿼리 특징을 생성하고, 레퍼런스 디코더는 검색된 메모리 특징을 기반으로 기하학 구조를 재건한다. 메모리 인코더는 이전 프레임 예측을 처리하여 공간 메모리를 업데이트함으로써 후속 프레임이 일관된 글로벌 좌표계에서 디코딩되도록 한다.

DUSt3R에 비해 추가된 것은 경량 메모리 인코더와 쿼리, 메모리 키, 메모리 값 특징을 인코딩하기 위한 두 개의 MLP 헤드이다. DUSt3R의 두 디코더는 각각 정준 좌표계에서 첫 번째 이미지를 재건하는 레퍼런스 디코더와 첫 번째 이미지의 좌표계에서 두 번째 이미지를 재건하는 타겟 디코더였으나, Spann3R는 이 두 디코더를 재목적화(repurpose)하여 타겟 디코더는 주로 메모리 쿼리를 위한 특징을 생성하고, 레퍼런스 디코더는 메모리에서 융합된 특징을 입력받아 재건을 수행한다.

#### 전체 아키텍처 흐름 (시간 스텝 $t$ 기준)

```
입력 이미지 I_t
        ↓
   [ViT Encoder]
        ↓
 시각 특징 f_visual
    ↙         ↘
[Target Decoder]  [Reference Decoder]
    ↓                    ↑
쿼리 특징 Q  →  메모리 쿼리  →  Fused Feature
                   ↕
            [Spatial Memory]
           ┌───────────────┐
           │ Dense Working  │
           │    Memory      │
           │ Sparse Long-  │
           │  term Memory  │
           └───────────────┘
        ↓                    ↓
  다음 쿼리 특징   글로벌 포인트맵 P_t (재건)
```

쿼리 특징은 공간 메모리에서 읽기 위해 사용되어 융합 특징을 생성하고, 이 융합 특징과 새 프레임의 시각 특징은 각각 레퍼런스 디코더와 타겟 디코더에 입력된다. 레퍼런스 디코더의 포인트맵과 특징은 공간 메모리에 인코딩되며, 타겟 디코더의 특징은 다음 시간 스텝의 쿼리 특징으로 유지된다.

### 2.4 성능 향상

7Scenes, NRGBD, DTU 등의 데이터셋에 대한 정성적·정량적 실험에서 Spann3R는 기존 방법들에 대해 경쟁력 있는 성능을 보여주며, **초당 50프레임 이상**의 실시간 처리가 가능하다.

Spann3R의 성능은 실내 평가를 위한 7Scenes, NRGBD와 객체 레벨 재건을 위한 DTU를 포함한 여러 실내외 데이터셋에서 평가되었으며, FrozenRecon 및 DUSt3R와 같은 기존 방법들과 비교하여 정확도 및 완성도(Completion) 등 여러 지표에서 동등하거나 우월한 성능을 보였다.

최적화 기반 글로벌 정렬의 필요성을 제거함으로써 3D 재건 파이프라인을 보다 robust하고 실시간 애플리케이션에 확장 가능하게 만들었으며, 실시간 3D 모델 증분 업데이트는 자율주행, 로보틱스, 증강 현실과 같이 빠르고 지속적인 환경 이해가 필요한 응용 분야에 중요하다. 메모리 관리 전략은 긴 시퀀스에서도 과도한 계산 오버헤드 없이 효과적으로 확장된다.

---

### 2.5 한계점

Spann3R는 특히 반사(reflections)나 고도로 세밀한 텍스처를 포함하는 복잡한 환경에서 **드리프트(drift)** 현상이 나타난다.

현재 방법은 정적 장면에 제한되어 있어 동적 객체를 처리하지 못하며, 비강체(non-rigid) 장면 요소를 지원하는 것이 중요한 미래 과제이다. 또한 자기지도(self-supervised) 학습 방식이 모든 종류의 장면과 카메라 움직임에 일반화되지 않을 수 있으며, 대규모 장면의 경우 공간 메모리의 메모리 사용량과 계산 비용도 잠재적 한계이다.

## 3. 일반화 성능 향상 가능성 (중점 분석)

### 3.1 현재 일반화 강점

DUSt3R의 사전 학습 가중치를 활용하고 일부 데이터셋에서 추가 파인튜닝함으로써, Spann3R는 다양한 미지의(unseen) 데이터셋에서 경쟁력 있는 성능과 일반화 능력을 보여주며 실시간으로 순서 있는 이미지 컬렉션을 처리할 수 있다.

학습에 사용되지 않은 자체 촬영 이미지로 재건된 정성적 예시들은 Spann3R의 일반화 능력을 잘 보여준다.

### 3.2 다양한 데이터셋으로의 확장 (v1.01)

Spann3R v1.01은 ScanNet, ScanNetpp, WildRGBD, Co3D, Aria, ArkitScene, BlendMVS, Waymo, Tartanair, OminiObject3d, Megadepth, Vkitti2, Unreal, Spring, Pointodyssey를 포함하는 15개 데이터셋의 혼합으로 10-프레임 시퀀스에서 추가 훈련되었으며, 동적 장면이 포함되어 이제 정적/동적 장면 재건을 모두 지원한다.

### 3.3 일반화 성능 향상 전략 분석

일반화 성능 향상을 위한 핵심 설계 선택들:

| 전략 | 설명 | 일반화 기여 |
|---|---|---|
| **DUSt3R 사전학습 가중치 활용** | 수백만 이미지 쌍으로 학습된 표현 재사용 | 광범위한 시각 특징 표현력 |
| **커리큘럼 학습** | 점진적으로 시퀀스 길이·복잡도 증가 | 다양한 카메라 움직임 대응 |
| **외부 메모리 분리** | 모델 파라미터와 분리된 공간 메모리 | 새로운 장면 구조에 동적 적응 |
| **15개 이종 데이터셋 훈련** | 실내외, 정적·동적, 합성·실제 데이터 혼합 | 도메인 다양성 확보 |

핵심 혁신인 공간 메모리 모듈은 프레임 전반에 걸쳐 일관된 특징 추적 및 매핑을 가능하게 하여 도전적인 시나리오에서도 더 일관된 3D 모델을 생성한다. 수작업 특징 매칭에 의존하는 전통적인 SfM이나 SLAM 접근법과 달리, Spann3R는 학습된 표현과 신경망 공간 메모리 아키텍처를 사용하여 입력 시퀀스 전반에 걸쳐 일관된 3D 정보를 유지한다.

### 3.4 일반화 성능 향상을 위한 미래 방향

미래 작업으로는 대규모 장면을 처리하는 방법 확장, 번들 조정(Bundle Adjustment) 기법 통합, 그리고 캐주얼 비디오에서의 자기지도(self-supervised) 학습 탐색이 제안된다.

계층적 메모리 구조를 통해 매우 큰 장면에서의 확장성을 향상시키거나, 번들 조정과 같은 고전적 기법을 트랜스포머 기반 아키텍처에 통합하는 것도 중요한 연구 방향이다.

## 4. 관련 최신 연구 비교 분석 (2020년 이후)

### 4.1 주요 선행 연구 비교

| 방법 | 연도 | 핵심 접근법 | Spann3R 대비 차이점 |
|---|---|---|---|
| **NeRF** (Mildenhall et al.) | 2020 | 암시적 신경 복사장(Neural Radiance Field) | Per-scene 최적화 필수, 실시간 불가 |
| **3D Gaussian Splatting** | 2023 | 가우시안 기반 명시적 표현 | 초기 포인트 클라우드 입력 필요, SfM 의존 |
| **DUSt3R** | 2024 | 포인트맵 직접 회귀 | 이미지 쌍 단위 처리, 글로벌 정렬 최적화 필요 |
| **MASt3R** | 2024 | DUSt3R + 매칭 강화 | 특징 매칭 강화, 글로벌 정렬 여전히 필요 |
| **Spann3R** | 2024 | 공간 메모리 + 글로벌 예측 | **최적화 없는** 실시간 글로벌 재건 |

### 4.2 후속 연구: Point3R

DUSt3R가 도입한 패러다임을 따르는 이후 방법들은 묵시적(implicit) 메모리를 유지하여 더 많은 이미지에서 밀집 3D 재건을 달성하려 했으나, 이러한 묵시적 메모리는 용량에 한계가 있고 초기 프레임의 정보를 잃을 수 있다. 이에 Point3R는 현재 장면의 3D 구조와 직접 연결된 **명시적 공간 포인터 메모리(Explicit Spatial Pointer Memory)**를 유지하는 온라인 스트리밍 밀집 3D 재건 프레임워크를 제안하며, 각 포인터에 특정 3D 위치를 할당하고 글로벌 좌표계에서 주변 장면 정보를 집계하고, 최신 프레임의 정보가 이 포인터 메모리와 명시적으로 상호작용함으로써 현재 관측을 글로벌 좌표계로 밀집 통합한다.

이는 Spann3R의 **묵시적 메모리의 한계(정보 손실, 용량 제한)** 를 직접 겨냥한 개선으로, Spann3R가 열어놓은 연구 방향의 중요성을 방증한다.

## 5. 앞으로의 연구에 미치는 영향 및 고려할 점

### 5.1 연구에 미치는 영향

**① 패러다임 전환의 가속화**

Spann3R는 트랜스포머 기반 네트워크와 공간 메모리를 결합한 프레임워크를 도입하여 3D 재건 분야에서 중요한 발전을 이루었으며, 이미지 컬렉션으로부터 실시간으로 정확하고 확장 가능한 3D 재건을 가능하게 하여 컴퓨터 비전 및 관련 분야의 다양한 응용에 광범위한 함의를 가진다.

**② 메모리 증강 아키텍처의 부상**

Spann3R의 공간 메모리 개념은 이후 Point3R (명시적 포인터 메모리) 등의 연구에 직접 영감을 주었으며, 단순한 feedforward 아키텍처를 넘어서 **순환적·메모리 증강 3D 재건** 패러다임을 정립하였다.

**③ 실용적 응용 확장**

실시간 3D 모델의 증분 업데이트 능력은 자율주행, 로보틱스, 증강 현실과 같이 빠르고 지속적인 환경 이해가 필요한 응용 분야에 중요한 기여를 한다.

**④ NeRF / 3DGS와의 통합 가능성**

Spann3R는 신경 렌더링 프레임워크인 Nerfstudio와의 통합을 제공하여 재건 데이터를 Nerfstudio 포맷의 카메라 포즈 및 내부 파라미터로 변환할 수 있다. 이는 3DGS나 NeRF의 초기화로 Spann3R를 활용하는 파이프라인 연구를 자극할 수 있다.

---

### 5.2 앞으로 연구 시 고려할 점

**① 드리프트 문제와 루프 클로저**

반사나 세밀한 텍스처가 있는 복잡한 환경에서 Spann3R는 드리프트 현상을 보인다. 이를 해결하기 위한 루프 클로저 탐지 또는 키프레임 기반 메모리 전략 연구가 필요하다.

**② 메모리 효율성과 대규모 장면**

묵시적 메모리는 용량에 한계가 있고 초기 프레임의 정보를 잃을 수 있다. 대규모 실외 장면으로 확장하기 위한 계층적 메모리 관리, 압축, 또는 선택적 메모리 삭제(forgetting) 전략이 중요하다.

**③ 동적 장면 처리**

Spann3R v1.01은 동적 장면을 포함한 학습을 통해 현재 정적/동적 장면 재건을 모두 지원하기 시작했으나, 비강체 객체나 급격한 움직임에 대한 강인성 개선은 여전히 열린 문제이다.

**④ 자기지도 학습 가능성**

캐주얼 비디오에서의 자기지도 학습 탐색은 레이블이 없는 대규모 비디오 데이터를 활용하여 일반화 성능을 대폭 향상시킬 수 있는 핵심 연구 방향이다.

**⑤ Bundle Adjustment와의 하이브리드 접근**

대규모 장면 재건 탐색, 번들 조정 등 전통적인 기법의 추가 통합, 비구조적 비디오 데이터에서의 자기지도 학습 활용이 주요 미래 방향으로 제시되었다. 학습 기반 방식과 고전적 기하학적 최적화의 하이브리드 접근은 양방향의 강점을 결합할 수 있다.

**⑥ 불확실성 정량화**

신뢰도 인식 손실 $\mathcal{L}_{\text{conf}}$를 기반으로 한 불확실성 추정을 더욱 발전시켜, 메모리 업데이트 시 신뢰도 낮은 예측을 적절히 필터링하는 메커니즘 연구가 필요하다.
