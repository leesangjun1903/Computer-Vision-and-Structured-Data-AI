## 1. 핵심 주장과 주요 기여

- **핵심 아이디어**
    - 비디오의 각 프레임에 추가하는 노이즈를
        - 모든 프레임이 공유하는 **base noise**
        - 프레임마다 다른 **residual noise**
로 분해하고, 이에 대응하는 **두 개의 네트워크(기저 생성기 + 잔차 생성기)**를 함께 학습하는 **Decomposed Diffusion** 프레임워크(VideoFusion)를 제안.[^1_3][^1_1]
- **주요 기여**

1. **분해된 확산 과정**: 프레임 간 공통 부분을 base noise가, 시간에 따른 변화(동작/잔차)를 residual noise가 담당하도록 설계하여, 시간적 일관성이 높은 비디오를 더 쉽게 복원할 수 있게 함.[^1_1]
2. **대형 이미지 DPM 재활용**: DALL·E 2 디코더 기반의 대형 이미지 확산모델을 base generator로 사용해, **한 개 프레임만으로 전체 비디오의 base noise를 추정**하고 모든 프레임에 공유함으로써, 사전학습된 이미지 priors를 효율적으로 비디오로 전이.[^1_1]
3. **성능 향상**: UCF101, Sky Time-lapse, TaiChi-HD 등에서 기존 GAN 계열(VGAN, TGAN, MoCoGAN-HD, StyleGAN-V, TATS, DIGAN 등)과 기존 비디오 확산모델(VDM)을 **FVD/IS 기준으로 일관되게 상회**.[^1_1]
4. **효율성·확장성**: 동일한 base generator를 모든 프레임에 공유하기 때문에, VDM을 동일 백본으로 재구현한 버전 대비 **GPU 메모리 21.8% 감소, 추론 레이턴시 57.5% 단축**을 달성하면서 더 나은 품질을 얻음.[^1_1]
5. **콘텐츠/모션 분해와 제어**: 적절한 학습 전략(Weizmann 행동 데이터셋에서 base noise = 사람 ID, residual noise = 동작을 공유하도록 배치 구성)을 사용하면, **동일 인물이 다른 동작을 하거나, 다른 사람이 동일 동작을 하는 비디오를 제어 생성**하는 능력을 보임.[^1_1]
6. **장기 비디오 생성**: base noise를 고정한 채 auto-regressive하게 확장하는 방식으로, 16프레임 모델로부터 **512프레임 비디오까지 내용 일관성을 상당히 유지**하면서 생성 가능함을 실험적으로 보임.[^1_1]

## 2. 해결하려는 문제

### 2.1 표준 비디오 확산에서의 문제점

기존 비디오 확산모델(예: VDM)은 비디오를 프레임 집합 $x = \{x_i\}_{i=1}^N$으로 보고, 각 프레임에 **서로 독립적인 노이즈**를 추가하는 표준 DDPM/DDIM 과정을 그대로 사용합니다.[^1_4][^1_1]

일반적인 DDPM 전방 확산은 다음과 같습니다.[^1_1]

$$
z_t = \sqrt{\hat{\alpha}_t}\,x + \sqrt{1-\hat{\alpha}_t}\,\epsilon_t,\quad
\epsilon_t \sim \mathcal{N}(0,I),\quad
\hat{\alpha}_t = \prod_{k=1}^{t}\alpha_k.
$$

비디오에서는 프레임 $x_i$마다 독립 노이즈 $\epsilon_{i,t}$를 사용해

$$
z_{i,t} = \sqrt{\hat{\alpha}_t}\,x_i + \sqrt{1-\hat{\alpha}_t}\,\epsilon_{i,t}
$$

로 인코딩합니다.[^1_1]

이 경우

- 프레임 간 **내용 중복과 시간적 상관관계가 완전히 파괴**되고,
- 복원(역확산) 시 네트워크가 **고차원 공간에서 공간·시간 상관성을 동시에 모델링**해야 해 학습이 매우 어렵습니다.[^1_3][^1_1]


### 2.2 VideoFusion이 겨냥하는 목표

VideoFusion은 다음을 동시에 달성하는 것을 목표로 합니다.[^1_1]

- 프레임 간 **공통 콘텐츠(배경, 피사체 정체성)를 유지**하면서
- **시간축 방향의 자연스러운 변화(동작, 카메라 모션)를 모델링**하고
- 대형 이미지 확산모델의 사전학습 지식을 **효율적으로 재사용**해
    - 적은 추가 파라미터로
    - 다양한 데이터셋(UCF101, Sky Time-lapse, TaiChi-HD, WebVid-10M 등)에 **잘 일반화**하는 비디오 생성기를 만드는 것.

## 3. 제안 방법: 분해된 확산 과정 (수식 중심)

### 3.1 프레임 분해: base frame과 residual frame

비디오 $x = \{x_i\}_{i=1}^N$에서 각 프레임 $x_i$를 **공통 base frame $x^0$**와 **잔차 $\Delta x_i$**로 분해합니다.[^1_1]

$$
x_i = \sqrt{\lambda_i}\,x^0 + \sqrt{1-\lambda_i}\,\Delta x_i,\quad i = 1,\dots,N,
$$

여기서 $\lambda_i \in [0,1]$은 프레임 $x_i$가 base frame과 공유하는 비율을 의미합니다.[^1_1]

- $\lambda_i = 1$: $x_i = x^0$, 완전히 동일한 프레임
- $\lambda_i = 0$: $x_i$와 $x^0$는 공통 부분이 없음

실제 구현에서는 단순하면서도 의미 있는 선택으로 **가운데 프레임**을 base frame으로 두고 $\lambda_{\lfloor N/2\rfloor} = 1$로 설정합니다.[^1_1]

$$
x^0 = x_{\lfloor N/2\rfloor},\quad \Delta x_{\lfloor N/2\rfloor} = 0.
$$

### 3.2 노이즈 분해: base noise와 residual noise

확산과정에서 추가되는 노이즈 $\epsilon_{i,t}$도 **공유 base noise와 프레임별 residual noise**로 분해합니다.[^1_1]

$$
\epsilon_{i,t}
= \sqrt{\lambda_i}\,b_t + \sqrt{1-\lambda_i}\,r_{i,t},\quad
b_t \sim \mathcal{N}(0,I),\ r_{i,t}\sim\mathcal{N}(0,I).
$$

- $b_t$: 시각 $t$에서 **모든 프레임이 공유**하는 base noise
- $r_{i,t}$: 프레임마다 다른 residual noise

이를 앞의 분해된 프레임 표현에 대입하면,

$$
\begin{aligned}
z_{i,t}
&= \sqrt{\hat{\alpha}_t}\,x_i + \sqrt{1-\hat{\alpha}_t}\,\epsilon_{i,t} \\
&= \sqrt{\hat{\alpha}_t}\bigl(\sqrt{\lambda_i}x^0 + \sqrt{1-\lambda_i}\Delta x_i\bigr)
  + \sqrt{1-\hat{\alpha}_t}\bigl(\sqrt{\lambda_i}b_t + \sqrt{1-\lambda_i}r_{i,t}\bigr).
\end{aligned}
$$

이를 두 부분으로 해석하면,[^1_1]

- $x^0$에 대한 확산: base frame의 공유된 노이즈 $b_t$
- $\Delta x_i$에 대한 확산: 프레임별 residual $r_{i,t}$

즉, **latent video 공간 자체가 base 성분과 residual 성분으로 분해**됩니다.[^1_1]

가운데 프레임 $i_0 = \lfloor N/2\rfloor$에 대해 $\lambda_{i_0}=1$이므로

$$
z_{i_0,t} = \sqrt{\hat{\alpha}_t}\,x_{i_0} + \sqrt{1-\hat{\alpha}_t}\,b_t,
$$

즉, **하나의 프레임만으로 base noise $b_t$를 추정할 수 있는 구조**가 됩니다.[^1_1]

### 3.3 사전학습 이미지 DPM을 이용한 base noise 추정

이 구조를 활용해, 저자는 **사전학습된 이미지 확산모델의 U-Net 디코더를 그대로 base generator로 사용**합니다.[^1_1]

- $z^b_\phi$: 이미지 확산모델의 $\epsilon$-prediction 네트워크(예: DALL·E 2 디코더)
- 가운데 프레임의 noisy latent $z_{i_0,t}$를 입력으로 받아 $b_t\approx z^b_\phi(z_{i_0,t}, t)$를 추정

다른 프레임 $i\neq i_0$에 대해, 우선 추정된 base 성분을 제거한

$$
z'_{i,t}
= z_{i,t} - \sqrt{\lambda_i}\,\sqrt{1-\hat{\alpha}_t}\,z^b_\phi(z_{i_0,t},t)
$$

를 계산하고, residual generator $z^r_\psi$를 통해 $r_{i,t}\approx z^r_\psi(z'_{i,t}, t,i)$를 추정합니다.[^1_1]

최종적으로 전체 노이즈 $\epsilon_{i,t}$의 추정치는

$$
\epsilon_{i,t} =
\begin{cases}
z^b_\phi(z_{i_0,t},t), & i = i_0,\\[4pt]
\sqrt{\lambda_i}\,z^b_\phi(z_{i_0,t},t)
+ \sqrt{1-\lambda_i}\,z^r_\psi(z'_{i,t}, t,i), & i\neq i_0.
\end{cases}
$$[file:1]

이를 DDIM 또는 DDPM 샘플링 식에 대입해 한 스텝씩 역확산합니다.[file:1]

### 3.4 학습 목적함수와 joint training

DDPM의 $\epsilon$-prediction 손실을 기반으로, base/residual에 대해 다음과 같은 손실을 정의합니다.[file:1]

$$
L_t =
\begin{cases}
\lVert \epsilon_{i,t} - z^b_\phi(z_{i_0,t},t)\rVert^2, & i = i_0,\\[4pt]
\left\lVert
\epsilon_{i,t} -
\sqrt{\lambda_i}\,[z^b_\phi(z_{i_0,t},t)]_{\text{sg}}
- \sqrt{1-\lambda_i}\,z^r_\psi(z'_{i,t}, t,i)
\right\rVert^2, & i\neq i_0,
\end{cases}
$$

여기서 $[\cdot]_{\text{sg}}$는 **stop-gradient** 연산입니다.[^1_1]

- base generator는
    - 가운데 프레임에 대한 손실만으로 미세 조정(finetune)되고,
    - 다른 프레임에 대한 손실은 **gradient를 막아서** 사전학습 지식을 파괴하지 않도록 설계합니다.[^1_1]
- residual generator는 모든 프레임의 잔차를 학습하며, 비교적 작은 네트워크(약 0.5B 파라미터)를 사용해 효율성을 확보합니다.[^1_1]

이 구조 덕분에,

- **어려운 이미지 복원(정적 콘텐츠)**은 대형 이미지 DPM이 담당하고,
- **상대적으로 쉬운 잔차(동작·잔변화)**는 작은 residual 네트워크가 담당해,
    - 데이터 효율성과 일반화 성능을 함께 확보합니다.[^1_1]

## 4. 모델 구조

### 4.1 Base generator

- 구조: 2D U-Net 기반 이미지 확산모델 디코더(예: DALL·E 2의 decoder)를 그대로 사용.[^1_1]
- 입력: 가운데 프레임의 noisy latent $z_{i_0,t}$, timestep $t$, CLIP visual embedding, 텍스트 embedding 등 조건.[^1_1]
- 역할:
    - **base frame 복원**
    - 나아가, 모든 프레임에 공유되는 **base noise $b_t$**를 추정.

데이터셋에 따라 작은(0.29B 파라미터) 버전과 큰(2.0B 파라미터) 버전을 사용.[^1_1]

### 4.2 Residual generator

- 구조: 2D U-Net 계열 네트워크(0.22B 또는 0.59B 파라미터)로, 입력은 base 노이즈 제거 후의 $z'_{i,t}$와 timestep $t$, 프레임 index $i$, 동일한 조건 embedding.[^1_1]
- 역할:
    - 각 프레임별 **잔차 노이즈 $r_{i,t}$**를 예측해 frame-to-frame variation(동작, 카메라 움직임 등)을 모델링.


### 4.3 Prior 및 조건부 생성

- CLIP 비주얼 인코더로부터 **중앙 프레임 임베딩**을 추출하고,[^1_1]
- 텍스트 조건(캡션, 클래스 레이블 등)이 있는 경우, **prior 네트워크**가 텍스트에서 latent embedding을 생성해 base/residual generator 모두에 조건으로 주입.[^1_1]
- WebVid-10M에서 text-to-video 학습을 수행해, 텍스트 조건 비디오 생성에서도 경쟁력 있는 품질(예시 샘플 제공)을 보임.[^1_3][^1_1]

## 5. 성능 향상 및 한계

### 5.1 정량적 성능

#### UCF101

- **무조건 생성 (16×64×64)**
    - VDM: IS 57.00, FVD 295.[^1_1]
    - VideoFusion: IS 71.67, FVD 139.[^1_1]
- **무조건 생성 (16×128×128)**
    - VideoFusion: IS 72.22, FVD 220.[^1_1]

대부분의 GAN·VQ-VAE 기반 모델(TGAN, MoCoGAN-HD, StyleGAN-V, TATS, DIGAN, VideoGPT 등)을 **IS·FVD 모두에서 상회**합니다.[^1_1]

#### Sky Time-lapse \& TaiChi-HD (16×128×128)

- Sky Time-lapse:
    - MoCoGAN-HD FVD 183.6 vs VideoFusion 47.0.[^1_1]
- TaiChi-HD:
    - TATS FVD 94.6 vs VideoFusion 56.4.[^1_1]

즉, **시간적 일관성(FVD)과 분포 유사도(KVD)에서 큰 폭으로 개선**됨을 보여줍니다.[^1_1]

#### 효율성

동일 base 백본으로 재구현한 VDM*과 비교 시, 비디오 16프레임 생성 기준으로:[^1_1]

- GPU 메모리: 63.82GB → 49.85GB (약 21.8% 감소)
- 레이턴시: 0.40s → 0.17s (약 57.5% 감소)

이는 **공유 base noise 구조 덕분에, 큰 base 네트워크를 한 번만 호출**하고, residual은 소형 네트워크가 맡기 때문입니다.[^1_1]

### 5.2 정성적 결과

- UCF101, Sky Time-lapse, TaiChi-HD에서 TATS, DIGAN 등과 비교 시, VideoFusion이 **텍스처·배경·사람 형상에서 더 사실적이며, 프레임 간 깜빡임이 적은 시퀀스**를 생성합니다.[^1_1]
- WebVid-10M 기반 text-to-video에서는 **“dramatic ocean sunset”, “a turtle swimming in the ocean”** 같은 프롬프트에 대해, 상업용 도구에 근접한 수준의 자연스러운 동작과 시각 품질을 보여줍니다.[^1_5][^1_1]


### 5.3 한계

1. **고정 $\lambda_i$의 한계**
    - $\lambda_i$가 너무 작으면(예: 0.1), 프레임 간 공유 정보가 부족해 시간적 상관관계를 충분히 활용하지 못하고,
    - 너무 크면(예: 0.75), 프레임들이 지나치게 유사해 동작 다양성이 감소합니다.[^1_1]
    - 실험상 $\lambda_i=0.5$ 부근이 UCF101에서 IS/FVD 절충이 가장 좋지만, **비디오 종류마다 최적 $\lambda_i$가 다를 수 있어 고정값은 일반화의 한계**가 됩니다.[^1_1]
2. **사전학습 이미지 DPM과의 도메인 갭**
    - DALL·E 2가 학습된 대규모 이미지 도메인(예: LAION-5B)과 UCF101·Taichi 등 비디오 도메인의 차이로 인해, **base generator를 고정(freeze)하면 성능 저하**가 발생합니다.[^1_1]
    - joint finetuning + stop-gradient를 통해 일부 완화하지만, 완전한 도메인 적응은 아닙니다.[^1_1]
3. **장문 텍스트 조건의 한계**
    - 현재 residual generator는 DALL·E 2 prior가 생성한 **고정 길이 latent embedding**에만 조건을 둡니다.[^1_1]
    - 이 임베딩이 긴 문장의 시간적 구조를 충분히 담지 못할 경우, **복잡한 시나리오·스토리 비디오에 대한 일반화가 제한**될 수 있다고 저자들은 명시합니다.[^1_1]
4. **모션–콘텐츠 완전 분리의 어려움**
    - Weizmann 실험에서 batch 구성 제약(같은 사람/같은 동작에 노이즈 공유)을 명시적으로 주어야 **base=콘텐츠, residual=동작** 구조가 잘 학습되며, 자동으로 이 분해를 완전히 학습하는 것은 쉽지 않다고 보고합니다.[^1_1]

## 6. 일반화 성능 향상 측면에서의 분석

VideoFusion의 설계는 여러 관점에서 **일반화 성능에 유리한 inductive bias**를 도입합니다.

### 6.1 사전학습 이미지 DPM 활용에 따른 일반화

- **비디오 학습 전에 거대한 이미지 데이터셋에서 학습된 priors**를 base generator가 이미 보유하고 있음.[^1_6][^1_1]
- 비디오 도메인에서 다시 학습해야 할 것은 주로
    - (1) base frame의 domain adaptation,
    - (2) frame 간 residual 동작 구조
로 한정되므로, **소규모 비디오 데이터셋에서도 더 나은 일반화**를 기대할 수 있습니다.

아블레이션에서:[^1_1]

- VDM: IS 57.00, FVD 295
- VideoFusion (no pretrain): IS 65.29, FVD 183
- VideoFusion (with pretrain): IS 71.67, FVD 139

즉,

1. **분해된 구조 자체만으로도 VDM보다 일반화가 좋아지고**,
2. 사전학습 base generator까지 더하면 **한 단계 더 향상**된다는 점을 실증적으로 보입니다.[^1_1]

### 6.2 공유 base noise에 의한 시계열 일반화

- 모든 프레임에 **동일한 base noise를 공유**시키는 것은, 모델에
    - “프레임들 사이에는 커다란 공통 구조가 존재한다”는 강한 사전 가정을 주입합니다.[^1_1]
- 이는
    - **사람 ID, 배경, 전체 색감**과 같은 time-invariant 요소를 안정적으로 유지하고,
    - 동작·카메라 움직임만 residual로 학습하게 하는 강제력으로 작동해,
    - 데이터가 달라져도 “공통 구조 + 시간적 잔차”라는 decomposition을 재활용하도록 합니다.

Weizmann 데이터셋에서 base/residual을 identity/motion에 대응시키는 실험은,

- 이 분해가 실제로 **다른 데이터셋·동작 조합에서도 모션 제어와 콘텐츠 유지에 잘 일반화**될 수 있는 가능성을 보여줍니다.[^1_1]


### 6.3 긴 시퀀스·새로운 길이로의 일반화

- 기존 auto-regressive 방법은 긴 비디오 생성 시 프레임이 진행될수록 **내용 붕괴·drift**가 심해졌습니다.[^1_7]
- VideoFusion은 base noise를 고정한 채 replacement 방법으로 프레임을 확장하여,
    - 16프레임에서 학습된 모델을 512프레임까지 확장해도,
    - **배경·피사체 정체성이 상당히 잘 유지**되는 것을 시각적으로 보여줍니다.[^1_1]

이는 “시간 길이”라는 새로운 조건에 대해서도 분해 구조가 비교적 잘 **길이 불변적으로 일반화**함을 시사합니다.

### 6.4 한계 요인: 고정 $\lambda_i$와 도메인 의존성

동시에, 일반화 성능을 제약하는 요소도 분명히 있습니다.[^1_1]

- $\lambda_i$가 비디오 카테고리마다 다르게 최적임에도, 현재는 **전 비디오에 동일한 값**을 사용.
- base generator가 특정 이미지 도메인에 특화되어 있으면, **해당 도메인과 스타일이 일반화 성능에 강하게 영향을 미침**.
- 장문 텍스트·다양한 스타일 변화가 많은 비디오에서는, **latent 임베딩 기반 조건만으로는 일반화가 충분치 않을 수 있음**.

저자들은 후속 연구 방향으로 **비디오·프레임별 adaptive $\lambda_i$ 예측**과 **텍스트 직접 conditioning(텍스트-비디오 modality gap 해소)**를 제안하고 있습니다.[^1_1]

## 7. 2020년 이후 관련 최신 연구와의 비교 분석

여기서는 VideoFusion과 개념적으로 가까운 **비디오 확산모델·텍스트-투-비디오(T2V)·콘텐츠/모션 분해 계열**을 중심으로 비교합니다.

### 7.1 핵심 관련 논문 요약 (open-access)

아래 논문들은 모두 arXiv 또는 CVF open access로 공개되어 있습니다.

- **VideoFusion: Decomposed Diffusion Models for High-Quality Video Generation**
Zhengxiong Luo et al., CVPR 2023.[^1_2][^1_1]
    - 노이즈를 base/residual로 분해하여, 대형 이미지 DPM을 재사용하고 시간적 상관관계를 명시적으로 활용하는 비디오 확산 프레임워크.
- **Video Diffusion Models**
Jonathan Ho et al., arXiv 2022.[^1_7][^1_4]
    - 2D 이미지를 3D 텐서(프레임 스택)로 확장하여, U-Net을 3D로 일반화한 **VDM**을 제안. 모든 프레임을 동시에 처리하지만, 프레임 간 노이즈는 독립적이며 base/residual 분해는 없음.
- **VideoCrafter1: Open Diffusion Models for High-Quality Video Generation**
Haoxin Chen et al., arXiv 2023.[^1_5]
    - Latent diffusion 기반의 T2V/I2V 오픈소스 모델로, 1024×576 고해상도 영상을 생성. 시간적 modeling은 3D U-Net + temporal attention으로 처리하며, VideoFusion처럼 노이즈 분해는 하지 않음.
- **Latte: Latent Diffusion Transformer for Video Generation**
Xin Ma et al., arXiv 2024.[^1_8]
    - 비디오 latent 토큰에 Transformer를 적용한 Diffusion Transformer 계열 모델. 공간·시간 토큰 분해, temporal positional embedding 등으로 효율적으로 긴 비디오를 생성. 노이즈 자체보다는 **토큰 레벨에서 공간/시간 분해**를 수행.
- **A Survey on Video Diffusion Models**
Andrew Melnik et al., arXiv/TMLR 2024.[^1_9][^1_7]
    - 비디오 확산모델을 비디오 생성·편집·이해로 분류하고, DDPM/Score-SDE·UNet/Transformer·latent diffusion·장기 비디오·조건부 생성 등 전체 landscape를 정리. VideoFusion을 **노이즈 분해 기반 비디오 생성 모델의 대표 사례**로 언급.
- **Survey of Video Diffusion Models: Foundations, Implementations, and Applications**
Yimu Wang et al., arXiv/GitHub 2025.[^1_10][^1_11]
    - 구현·데이터셋·산업 적용까지 포괄하는 최신 survey. VideoFusion과 함께 VDM, VideoCrafter, WALT(Sora 계열), Latte 등을 비교하며, **latent diffusion·Transformer·optical-flow 기반 모델**과의 차이를 정리.
- **ART·V: Auto-Regressive Text-to-Video Generation with Diffusion Models**
CVPR 2024 Workshop.[^1_12]
    - 전체 비디오를 한 번에 생성하는 대신, auto-regressive하게 chunk를 생성하며 diffusion을 적용해 **장기 T2V 품질을 개선**. UCF101에서 VideoFusion·MagicVideo·LVDM·CogVideo보다 나은 FVD/IS를 보고.[^1_12]
- **STDD: Spatio-Temporal Dual Diffusion for Video Generation**
CVPR 2025 예정 논문.[^1_13]
    - 공간·시간 확산을 분리한 **이중(diffusion) 구조**로 UCF101에서 VDM, StyleGAN-V, DIGAN, TATS 등을 상회하는 FVD를 달성. 예를 들어, 128×128 해상도에서 LFDM FVD 214 vs STDD 195.[^1_13]
- **DEMO: Enhancing Motion in Text-to-Video Generation with Decomposed Encoding and Conditioning**
Penghui Ruan et al., arXiv 2024.[^1_14]
    - 텍스트 인코딩을 콘텐츠/모션으로 분해하고, conditioning도 두 갈래로 나누어 **텍스트에서 motion 정보를 명시적으로 추출**하는 T2V 프레임워크. 동영상 자체의 노이즈 분해가 아니라, **텍스트 표현을 분해**하는 점이 VideoFusion과 차별적.
- **Dysen-VDM: Dynamics-aware Text-to-Video Diffusion with LLMs**
Fei et al., CVPR 2024.[^1_15]
    - 대형 언어모델을 이용해 텍스트에서 동작 관련 정보를 추출하고, VDM 기반 T2V에서 모션 modeling을 강화. UCF101·MSR-VTT에서 새 SOTA FVD/IS를 달성.[^1_15]


### 7.2 VideoFusion과의 비교 포인트

1. **시간적 상관관계 처리 방식**
    - VDM, VideoCrafter, Latte, WALT 등 대부분은
        - **3D U-Net 혹은 Transformer 기반 spatio-temporal attention**으로 시간정보를 처리하고,
        - 노이즈는 프레임별 독립으로 두는 구조입니다.[^1_8][^1_5][^1_7]
    - VideoFusion과 STDD는
        - 시간 차원을 **명시적으로 다른 채널/노이즈로 분해**한다는 점에서 공통점이 있으나,
        - VideoFusion은 **노이즈 수준(base/residual) 분해**,
        - STDD는 **공간/시간 diffusion 프로세스를 이중 구조로 분리**한다는 차이가 있습니다.[^1_13][^1_1]
2. **콘텐츠–모션 분해 관점**
    - MoCoGAN, StyleGAN-V 등 GAN 계열은 **latent 코드 수준(content code + motion code)** 분해를 사용합니다.[^1_1]
    - DEMO, Dysen-VDM은 **텍스트/조건 인코딩을 content/motion으로 분해**합니다.[^1_14][^1_15]
    - VideoFusion은
        - **비디오 latent 노이즈를 base/motion residual로 분해**함으로써,
        - 데이터 자체를 “공통 콘텐츠 + 시간 변화”로 나누는 새로운 관점을 제시합니다.[^1_1]
3. **일반화 및 데이터 효율성**
    - VideoCrafter, Latte, WALT 등 최신 모델은 대규모 인터넷 비디오로 사전학습된 **foundation T2V/I2V**로서 강력하지만, 구조 자체는 이미지 모델과 유사하게 “전 프레임 동일 구조+조건” 입니다.[^1_5][^1_8]
    - VideoFusion은
        - 이미지 DPM 사전학습 + base/residual 분해 덕분에,
        - 상대적으로 작은 UCF101·TaiChi-HD 등에서도 좋은 성능을 내며,
        - **“이미지에서 비디오로의 지식 전이”를 구조적으로 최적화한 사례**로 평가됩니다.[^1_7][^1_3][^1_1]
4. **장기 비디오 생성**
    - ART·V, WALT, FlexiFilm 등은 auto-regressive chunking, resampling, temporal upsampling으로 긴 비디오를 생성합니다.[^1_16][^1_12][^1_7]
    - VideoFusion의 장점은 base noise를 고정함으로써,
        - **내용 유지에 특화된 장기 확장**을 달성한다는 점이며,
        - 향후 AR 구조와 결합하면 ART·V류 방법과 상호 보완이 가능해 보입니다.[^1_1]

## 8. 앞으로의 연구에 미치는 영향과 고려할 점

### 8.1 향후 연구에 미치는 영향

1. **“노이즈 분해”라는 새로운 설계 축 제공**
    - 기존에는 latent 공간·토큰·조건만 분해했다면, VideoFusion은 **노이즈 자체를 분해**해 비디오 구조를 반영하는 새로운 관점을 제시했습니다.[^1_7][^1_1]
    - 이후 STDD, DEMO, DSDN(dual-stream content/motion diffusion) 등에서도 **다양한 형태의 분해(공간/시간, 콘텐츠/모션)**가 등장하고 있어, VideoFusion은 이러한 흐름의 초기 대표 예로서 인용되고 있습니다.[^1_16][^1_14][^1_13]
2. **이미지–비디오 멀티모달 foundation 모델 방향성 제시**
    - “**이미지 DPM + 얇은 비디오 전용 헤드**”라는 형태는,
        - 대규모 이미지 모델을 중심으로,
        - 비디오·3D·멀티모달을 plug-in처럼 붙이는 방향을 정당화합니다.[^1_11][^1_1]
3. **콘텐츠/모션 제어 가능한 비디오 생성의 기반**
    - base/residual을 identity/motion으로 매핑하는 실험은,
        - 사용자·캐릭터·배경을 고정한 채 동작·카메라만 바꾸는 **편집·제어 모델**의 설계를 뒷받침합니다.[^1_7][^1_1]
4. **장기 비디오·월드 모델과의 연결**
    - 고정 base noise를 활용한 긴 시퀀스 생성은,
        - 최근 Vid2World, world models, RL 환경 시뮬레이터 등에서 필요한 **긴 시계열 예측**에도 적용 가능성이 있습니다.[^1_17][^1_7]

### 8.2 앞으로 연구 시 고려할 점 (연구자로서의 관점)

1. **적응형 $\lambda_i$ 설계**
    - 장면·동작 복잡도에 따라 **프레임/비디오별로 $\lambda_i$를 동적으로 예측**하는 모듈(예: 작은 predictor 네트워크, attention 기반 gating)이 필요합니다.[^1_1]
    - 학습 시,
        - motion-rich 비디오에서는 작은 $\lambda_i$,
        - static/slow 비디오에서는 큰 $\lambda_i$를 자동 선택하도록 regularization을 설계할 수 있습니다.
2. **도메인 적응형 base generator**
    - 이미지 DPM을 그대로 쓰는 대신,
        - 이미지+프레임 스냅샷 비디오를 함께 pretrain하여 **멀티도메인 base generator**를 만들고,
        - 각 비디오 도메인에 맞게 adapter나 LoRA를 사용해 경량 조정을 하는 방식이 일반화에 유리할 것입니다.[^1_11][^1_7]
3. **텍스트 직접 conditioning과 모션 분해의 결합**
    - DEMO·Dysen-VDM처럼 텍스트를 content/motion으로 분해하고,[^1_14][^1_15]
    - VideoFusion의 base/residual 노이즈에 각각 연결한다면,
        - “문장 중 static 요소(배경, 스타일)”는 base,
        - “동작·이벤트·카메라 지시문”은 residual에 주입하는 **언어–비디오 분해 통합 모델**을 설계할 수 있습니다.
4. **노이즈 분해와 Transformer 기반 구조의 결합**
    - Latte·WALT·Sora 등은 Diffusion Transformer를 사용하며, 토큰 수준에서 공간/시간을 다룹니다.[^1_8][^1_7]
    - VideoFusion의 base/residual 개념을 Transformer 토큰에 입힌다면,
        - 일부 토큰은 base noise-only, 다른 토큰은 residual-only를 담당하도록 설계해,
        - **토큰·노이즈·조건 세 축을 동시에 분해**하는 강력한 foundation 비디오 모델이 가능할 것입니다.
5. **일반화 평가 프로토콜의 정교화**
    - 현재 FVD/IS 평가는 주로 단일 데이터셋 내 분포 재현을 보지만,[^1_9][^1_7]
    - 노이즈 분해·사전학습 활용 모델에서는
        - 도메인 전이(UCF101→Kinetics→WebVid),
        - 길이 전이(16→64→512 프레임),
        - 조건 전이(짧은 캡션→장문 시나리오)
와 같은 **cross-domain/generalization benchmark**를 설계해 평가하는 것이 중요합니다.
