# DiffusionInst: Diffusion Model for Instance Segmentation

### 1. 핵심 주장 및 주요 기여

DiffusionInst는 **인스턴스 분할을 노이즈-투-필터 확산 프로세스로 공식화**한 최초의 연구입니다. 이 논문의 핵심 주장은 확산 모델의 강력한 노이즈-투-이미지 복원 파이프라인이 판별 작업에도 적용될 수 있다는 것입니다. 기존의 쿼리 기반 방법들(예: QueryInst, Mask2Former)을 단일 단계 디노이징만 수행하는 확산 모델의 특수한 경우로 해석하고, 다단계 디노이징을 통해 성능을 향상시킬 수 있는 가능성을 제시합니다.[1]

**주요 기여:**
1. **첫 번째 인스턴스 분할 확산 모델**: 인스턴스 마스크 표현을 인스턴스 인식 필터로 재구성하여 노이즈-투-필터 확산 과정으로 포현합니다.[1]
2. **동적 마스크 헤드 활용**: 개별 영역 마스크가 아닌 전역 마스크 재구성을 위해 다중 스케일 정보를 활용합니다.[1]
3. **경쟁력 있는 성능**: ResNet-50 백본에서 37.3% AP, Swin-Large에서 47.8% AP를 달성하여 기존 방법들과 비교 가능한 성능을 보입니다.[1]

***

### 2. 해결하고자 하는 문제

인스턴스 분할 분야는 역사적으로 두 가지 주요 패러다임으로 나뉩니다:[1]

- **앵커 기반 또는 제안 기반 방법**: RPN(Region Proposal Network) 기반으로 강한 귀납 편향을 가집니다.
- **쿼리 기반 방법**: 랜덤 생성 쿼리를 사용하여 귀납 편향을 줄입니다.

DiffusionInst가 해결하고자 하는 핵심 문제는 다음과 같습니다:

1. **귀납 편향 제거**: RPN에 의존하지 않고 순수한 노이즈로부터 인스턴스를 학습
2. **다단계 디노이징 활용**: 단순히 한 번의 디코딩 대신 반복적 개선이 가능한 구조
3. **세밀한 인스턴스 경계 예측**: 작은 인스턴스와 정확한 경계 표현의 어려움 해결

### 3. 제안하는 방법과 수식

#### 3.1 확산 모델 기초[1]

확산 모델은 두 개의 마르코프 체인으로 구성됩니다. 정방향 노이징 과정은 다음과 같이 정의됩니다:

$$q(x_t|x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t}x_{t-1}, \beta_tI)$$

여기서 $\(\beta_1, \cdots, \beta_T\)$는 분산 스케줄입니다.

주어진 $\(x_0\)$에서 시간 $\(t\)$의 샘플은 다음과 같이 직접 구성됩니다:

$$x_t = \sqrt{\bar{\alpha}_t}x_0 + (1-\sqrt{\bar{\alpha}_t})\epsilon$$

여기서 $\(\bar{\alpha}\_t = \prod_{s=0}^{t}(1-\beta_s)\)$이고 $\(\epsilon \sim \mathcal{N}(0,I)\)$입니다.

#### 3.2 마스크 표현 방법[1]

DiffusionInst는 CondInst의 동적 마스크 헤드 개념을 채택합니다. 인스턴스 마스크는 인스턴스 무관 마스크 특성맵 $\(F_{mask}\)$와 인스턴스 특정 필터 $\(\theta \in \mathbb{R}^d\)$의 조합으로 생성됩니다:

$$m = \phi(F_{mask}; \theta)$$

여기서 $\(m \in \mathbb{R}^{H \times W}\)$는 예측된 이진 마스크이고, $\(\phi\)$는 3개의 1×1 컨볼루션 레이어로 구성된 마스크 헤드입니다. 예를 들어, 채널이 {8, 8, 1}인 경우, 필터의 차원은:

$$d = (8 \times 8 + 8 \times 8 + 8) + (8 + 8 + 1) = 153$$

#### 3.3 학습 단계[1]

학습 중, 모델은 지정된 시간 $\(t \in \{0, 1, \cdots, T\}\)$에서 그라운드 트루스 박스와 필터에 가우시안 노이즈를 추가합니다:

$$b_t = \sqrt{\bar{\alpha}_t}b_{gt} + (1-\sqrt{\bar{\alpha}_t})\epsilon$$

$$\theta_0 = \eta(f(b_t, t))$$

$$m = \phi(F_{mask}; \theta_0)$$

여기서 $\(\eta\)$는 완전 연결 층이고 $\(f(b, t)\)$는 디코더의 디노이징 프로세스입니다.

**전체 손실 함수:**[1]

$$L_{overall} = L_{det} + \lambda L_{dice}(m, m_{gt})$$

여기서 $\(L_{det}\)$는 DiffusionDet의 학습 손실이고, $\(\lambda = 5\)$는 두 손실을 균형 맞추는 가중치입니다.

#### 3.4 추론 단계[1]

추론 중에는 가우시안 분포에서 샘플링된 박스 $\(b_T\)$에서 시작하여 반복적으로 예측을 개선합니다:

$$b_0 = f(\cdots(f(b_{T-s}, T-s)))$$
$$s = \{0, \cdots, T\}$$
$$\theta_0 = \eta(b_0)$$
$$m = \phi(F_{mask}; \theta_0)$$

DDIM(Denoising Diffusion Implicit Models)도 DiffusionDet과 동일하게 사용됩니다.[1]

### 4. 모델 구조

#### 4.1 전체 아키텍처[1]

DiffusionInst의 구조는 네 가지 주요 구성요소로 이루어집니다:

1. **백본 + FPN**: ResNet-50 또는 Swin Transformer를 사용한 다중 스케일 특성 추출
2. **마스크 브랜치**: FPN 특성 {P3, P4, P5}에서 $\(F_{mask} \in \mathbb{R}^{c \times H/4 \times W/4}\)$를 생성
3. **디코더**: 노이즈가 있는 박스와 필터를 입력받아 디노이징을 수행 (DiffusionDet 재사용)
4. **마스크 재구성**: 디노이징된 필터와 마스크 특성을 사용하여 최종 마스크 생성

#### 4.2 핵심 설계 선택[1]

**필터 기반 표현의 장점:**
- 전체 마스크를 직접 디노이징하는 것보다 벡터를 디노이징하는 것이 훨씬 간단합니다.
- 박스 기반 ROI 특성 추출 대신 전역 특성을 사용하여 더 큰 수용 영역을 확보합니다.
- 인스턴스 가장자리 세부 사항이 더 잘 보존됩니다.

### 5. 성능 향상

#### 5.1 벤치마크 결과[1]

**COCO 검증 세트:**
- ResNet-50 (5x): **37.3% AP** (Mask RCNN의 34.4% AP 대비 +2.9%)
- ResNet-101 (5x): **41.0% AP** (CondInst의 39.1% AP 대비 +1.9%)
- Swin-B (5x): **46.6% AP**
- Swin-L (5x): **47.8% AP** (QueryInst의 44.6% AP 대비 +3.2%)

**LVIS(장꼬리) 데이터셋:**
- ResNet-101: **27.0% AP** (Mask RCNN의 21.7% AP 대비 +5.3%)
- Swin-B: **36.0% AP** (가장 강력한 기존 방법 대비 경쟁력 있음)

#### 5.2 성능 특성[1]

1. **스케일 의존성**: 백본이 강할수록 성능 이득이 더 큽니다. ResNet-50에서 Swin-Large로 변경 시 약 10% AP 향상
2. **장꼬리 데이터셋에서의 우수성**: LVIS에서 COCO보다 상대적 개선이 더 큼 (ResNet-101에서 +5.3%)
3. **큰 인스턴스에 우수**: APL(큰 인스턴스) 성능이 우수하지만 작은 인스턴스 성능은 제한적
4. **수렴 속도**: RPN 없이 위치를 스스로 찾아야 하므로 1x 스케줄보다 3x~5x 스케줄 필요

#### 5.3 절제 연구[1]

| 요소 | 설정 | AP |
|------|------|-----|
| 마스크 손실 가중치 | λ=5 & 다중 스테이지 | 37.3% |
| 마스크 채널 | c=8 | 37.3% |
| 마스크 헤드 레이어 | 3 레이어 (d=153) | 37.3% |
| 사전정의 필터 수 | 500 | 37.3% |

### 6. 일반화 성능 향상 가능성 (심층 분석)

#### 6.1 현재의 일반화 특성[1]

DiffusionInst의 일반화 성능 개선 가능성은 다음과 같은 요인에서 나타납니다:

**긍정적 요소:**
1. **다양한 노이즈 분포 학습**: 학습 중 \(T\)개의 다른 시간 단계에서 \(T\)가지 다른 노이즈 분포가 적용됩니다. 이는 모델을 더 견고하게 만들고 정규화 효과를 제공합니다.[1]

2. **백본 특성에 덜 의존**: RPN이 없어서 사전 정의된 앵커나 제안에 덜 의존하며, 순수한 노이즈에서 시작하므로 더 일반적인 패턴을 학습할 수 있습니다.[1]

3. **장꼬리 데이터셋에서의 우수성**: LVIS에서 COCO보다 상대적으로 높은 개선율을 보이므로, 불균형 데이터셋에 대한 견고성이 있습니다.[1]

#### 6.2 한계 및 개선 기회[1]

**식별된 한계:**

1. **작은 인스턴스 성능 저하**: 현재 방법은 작은 인스턴스를 놓치는 경향이 있습니다. 이는 박스에 의존하기 때문입니다.[1]

2. **수용 영역 제약**: 논문에서 명시: "인스턴스 분할은 더 큰 수용 영역을 필요로 합니다. ROI 특성은 다운샘플링된 특성맵에서 추출되어 세부 정보가 손실됩니다."[1]

3. **다단계 디노이징의 제한적 개선**: 4단계 디노이징도 1단계 대비 0.3% AP 미만의 개선만 제공합니다. 이는 구별 작업의 특성상 한 단계로도 충분할 수 있음을 시사합니다.[1]

#### 6.3 제안된 개선 방향[1]

논문의 '논의' 섹션에서 저자들이 제시한 미래 방향:

1. **박스 독립적 학습**: "향후 박스 목적 함수 없이 직접 필터를 학습할 수 있는지 탐색"[1]

2. **더 효과적인 샘플링 전략**: "DDIM 대신 새로운 샘플 전략 탐색으로 다단계 디노이징의 효과 증대"[1]

3. **대표적 백본 특성**: "인스턴스 인식 조건으로서 더 강력한 백본 특성과 큰 수용 영역이 필수"[1]

#### 6.4 관련 연구에서의 일반화 기법

최신 연구들은 확산 모델의 일반화 성능을 다음과 같이 향상시키고 있습니다:[2][3][4]

- **도메인 일반화**: FDS(Feedback-guided Domain Synthesis)는 확산 모델로 의사 도메인을 합성하여 도메인 시프트에 대한 견고성을 향상시킵니다.[3]

- **잠재 공간 활용**: DomainFusion은 잠재 확산 모델의 잠재 공간에서 도메인 무관 특성을 추출하여 4% 이상의 일반화 성능 개선을 달성합니다.[5]

- **테스트 시간 적응**: GDA(Generalized Diffusion Adaptation)는 테스트 시간에 확산 모델을 통해 OOD 샘플을 원본 도메인으로 투영하여 견고성을 향상시킵니다.[6]

### 7. 모델의 한계

#### 7.1 명시적 한계[1]

1. **박스 의존성**: "박스에 의존하므로 작은 인스턴스 성능이 약간 떨어집니다." 이는 구조적 한계로, 박스가 없으면 위치 정보를 인코딩하기 어렵습니다.[1]

2. **다단계 디노이징의 제한적 이득**: "4단계 디노이징도 보통 0.3% AP 미만의 개선만 제공합니다." 이는 판별 작업의 특성상 한 단계로도 충분할 수 있음을 의미합니다.[1]

3. **FPS 저하**: ResNet-50에서 1.7 FPS, Swin-L에서 1.2 FPS로 매우 느립니다 (비교: Mask RCNN 14.0 FPS).[1]

#### 7.2 암시적 한계

1. **수렴 속도**: RPN 없이 1x 스케줄에서만 30.4% AP로 매우 저조합니다. 3x 스케줄에서 35.6%, 5x 스케줄에서 37.3%로 향상되므로, 더 오랜 학습 시간이 필요합니다.[1]

2. **일반화 기술의 부재**: 현재 방법은 추가적인 일반화 기법(예: 강화 데이터 증강, 도메인 적응)을 적용하지 않습니다.

3. **조건화 품질**: "판별 작업의 경우, 노이즈-투-필터 프로세스는 더 정확한 인스턴스 컨텍스트를 조건으로 필요로 합니다. 인스턴스 컨텍스트는 대표적인 백본 특성과 큰 수용 영역에 크게 의존합니다."[1]

### 8. 앞으로의 연구에 미치는 영향

#### 8.1 학술적 영향

DiffusionInst는 **확산 모델의 판별 작업 적용**에 대한 새로운 패러다임을 제시합니다:[1]

1. **새로운 문제 공식화**: 인스턴스 분할을 생성 작업으로 재해석하는 시각을 제공하여, 다른 판별 작업(객체 추적, 포즈 추정 등)에도 적용 가능성을 열어줍니다.

2. **확산 기반 검출/분할의 확산**: 이 논문 이후 다양한 후속 연구가 등장했습니다:
   - **DFormer**(2023): 확산 가이드 트랜스포머로 범용 이미지 분할[7]
   - **MosaicFusion**(2024): 확산 모델을 데이터 증강 도구로 활용한 대어휘 인스턴스 분할[8]
   - **DiffSARShipInst**(2025): 선박 인스턴스 분할에 적용[9]
   - **TRACE**(2025): 확산 모델에서 인스턴스 경계 정보를 추출하는 방법[10]

#### 8.2 기술적 영향

1. **다중 표현 방법의 탐색**: 인스턴스를 필터로 표현하는 방식이 다른 작업에서도 탐색되고 있습니다.

2. **노이즈-기반 정규화**: 다양한 노이즈 분포를 학습 중에 적용하는 아이디어가 일반화 성능 향상에 기여할 수 있다는 것을 보여줍니다.

3. **생성-판별 통합**: 생성 모델의 강점을 판별 작업에 활용하는 방향이 주목받고 있습니다.[11][12]

### 9. 앞으로의 연구 시 고려할 점

#### 9.1 직접적인 개선 방향

**1. 박스 의존성 제거**[1]

```
제안: 순수 필터 기반 확산 학습
- 현재: 노이즈 박스 → 노이즈 필터 생성
- 개선: 가우시안 노이즈 → 필터 직접 생성
- 기대 효과: 위치 정보 제약 제거, 작은 인스턴스 성능 향상
```

**2. 효율적인 샘플링 전략**[1]

DDIM 대신 다음을 탐색할 수 있습니다:
- **조건부 샘플링**: 박스 위치 정보를 통한 가이드된 디노이징
- **적응적 스텝 선택**: 단계별로 필요한 스텝 수를 동적으로 결정
- **계층적 디노이징**: 먼저 큰 인스턴스, 이후 작은 인스턴스 순서

**3. 더 큰 수용 영역**[1]

```
제안: 마스크 브랜치 개선
- 더 높은 해상도 FPN 특성 활용 (P2 포함)
- 마스크 특성 해상도 증가 (H/4 → H/2)
- 마스크 헤드의 대역폭 증가
```

#### 9.2 일반화 성능 향상 전략

최신 연구에서 제시된 방법들이 적용 가능합니다:

**1. 도메인 일반화 데이터 증강**[4][3]

```
FDS(Feedback-guided Domain Synthesis) 통합:
- 확산 모델으로 의사 도메인 생성
- 모델에 어려운 샘플 중점 학습
- 도메인 시프트에 대한 견고성 향상
```

**2. 잠재 확산 모델 활용**[5]

```
DomainFusion 접근:
- 잠재 공간에서 도메인 무관 특성 추출
- 온라인 경량 데이터 증강으로 계산 비용 감소
- 97% 이상의 생성 샘플 수 감소
```

**3. 테스트 시간 적응**[6]

```
GDA(Generalized Diffusion Adaptation) 원칙:
- 테스트 시간에 OOD 입력을 원본 도메인으로 투영
- 확산 모델의 도메인 정규화 능력 활용
- 다양한 도메인 시프트 유형에 대응
```

#### 9.3 구조적 개선

**1. 더 강력한 백본**

```
비전 트랜스포머 활용:
- Swin-L과의 비교에서 이미 경쟁력 있는 성능 확인
- DiNOv2, ViT-22B 같은 최신 백본 탐색
- 지식 증류를 통한 경량화
```

**2. 효율성 개선**

```
현재: 1.2-1.7 FPS (매우 느림)
해결책:
- 동적 단계 수 조정 (쉬운 샘플은 1단계, 어려운 샘플은 다단계)
- 특성 캐싱으로 백본 중복 실행 제거
- 양자화된 확산 모델 탐색
```

#### 9.4 새로운 응용 분야

DiffusionInst의 원리를 확장할 수 있는 분야들:

1. **비디오 인스턴스 분할**: 시간적 일관성을 유지하는 확산 기반 접근
2. **3D 인스턴스 분할**: 포인트 클라우드나 복셀 기반 확산
3. **약지도 학습**: 불완전한 마스크 주석으로부터의 학습
4. **소수 샷 학습**: 제한된 샘플로부터의 빠른 적응
5. **폐쇄루프 도메인 적응**: 타겟 도메인에서의 테스트 시간 개인화

#### 9.5 이론적 고려사항

**1. 확산과 판별 작업의 정렬**

현재 이론적 간극:
- 생성 모델의 확산 과정이 판별 작업의 특성과 정렬되지 않을 수 있음
- 다단계 디노이징이 0.3% AP 미만만 개선하는 이유의 이론적 분석 필요

**2. 노이즈 분포의 최적화**

```
질문: T개의 시간 단계가 최적인가?
- 더 많은 단계가 더 나은가?
- 비균등 시간 샘플링이 더 효과적인가?
- 특정 작업에 최적화된 노이즈 스케줄이 있는가?
```

**3. 확산-쿼리 기반 방법의 관계**

```
논문의 주장: 쿼리 기반 방법 = 한 단계 확산의 특수한 경우
검증 필요:
- 쿼리 기반 방법과 확산 방법의 손실 지형 비교
- 하이브리드 접근의 가능성 탐색
```

### 10. 2020년 이후 관련 최신 연구 동향

#### 10.1 확산 모델의 판별 작업 적용

**조기 연구 (2022-2023):**

1. **DiffusionDet**(2022): 객체 검출을 노이즈-투-박스로 공식화. 동적 박스 수와 반복 평가의 유연성을 제시했습니다.[13]

2. **SegDiff**(2022): 시맨틱 분할을 위한 확산 모델. 확률적 확산 프로세스를 여러 번 적용하여 최종 분할맵을 생성합니다.[14]

3. **DFormer**(2023): 확산 가이드 트랜스포머로 범용 이미지 분할(범위, 인스턴스, 시맨틱)을 수행. 확산 기반 범위 분할 방법과 비교하여 3.6% PQ 개선을 달성합니다.[7]

#### 10.2 확산 모델 기반 데이터 증강 및 생성

**2023-2024년 연구:**

1. **MosaicFusion**(2024): 텍스트-이미지 확산 모델을 대어휘 인스턴스 분할의 데이터 증강 도구로 활용. 훈련 불필요한 접근으로 경쟁력 있는 성능 달성합니다.[8]

2. **DGInStyle**(2024): 잠재 확산 모델을 자율주행 시맨틱 분할 데이터 생성에 사용. 생성된 데이터로 도메인 시프트에 대한 견고성 향상을 입증합니다.[15]

3. **GenMix**(2024): 생성적 데이터 증강으로 도메인 내 및 교차 도메인 이미지 분류의 일반화 성능 향상. 적대적 견고성도 개선합니다.[2]

#### 10.3 도메인 일반화 및 적응

**최신 접근 (2023-2025):**

1. **DIDEX**(2023): 확산 모델로 의사 타겟 도메인을 생성하여 도메인 일반화 성능 향상. GTA5에서 3.8%, SYNTHIA에서 11.8%의 성능 개선을 달성합니다.[4]

2. **FDS**(2024): 다중 소스 조건부 확산 모델로 의사 도메인을 합성. 피드백 기반 메커니즘으로 모델에 어려운 샘플 중점 학습을 구현합니다.[3]

3. **DomainFusion**(2024): 잠재 확산 모델의 잠재 공간과 픽셀 공간을 동시에 활용하여 도메인 일반화. 생성 샘플 수를 97% 이상 감소시키면서 SOTA 성능 달성합니다.[5]

#### 10.4 확산 모델의 특성 추출 및 표현 학습

**새로운 방향 (2024-2025):**

1. **TRACE**(2025): 확산 모델의 자기 주의 맵에서 인스턴스 경계 정보를 추출. 비지도 인스턴스 분할에서 +5.1 AP 개선을 달성합니다.[10]

2. **Generalized Diffusion Detector**(2025): 도메인 일반화 객체 검출에 확산 모델 활용. 확산 모델에서 견고한 특성을 추출하여 검출기의 일반화 성능 향상을 입증합니다.[16]

3. **What's in a Latent?**(2025): 확산 모델의 잠재 공간이 도메인 무관 정보를 포함함을 발견. 다른 사전 학습 특성 공간보다 도메인 분리 성능이 우수하며, 4% 이상의 일반화 성능 개선을 달성합니다.[17]

#### 10.5 특화된 응용

1. **DiffSARShipInst**(2025): SAR(합성 개구 레이더) 이미지에서 선박 인스턴스 분할을 위한 확산 모델. 노이즈-투-박스 및 박스-투-마스크 재구성 프로세스를 채택합니다.[9]

2. **Sequential Amodal Segmentation**(2024): 누적 폐색 학습을 통한 부분 가시 객체의 완전한 분할. 확산 모델의 반복적 개선 능력을 활용합니다.[18]

#### 10.6 이론적 발전

1. **DiffDisEval**(2025): 확산 모델의 생성 능력을 판별 분할 작업으로 평가하는 새로운 벤치마크 방법. 세맨틱 수준의 텍스트-이미지 정렬 평가를 가능하게 합니다.[19]

2. **Model Collapse 분석**(2025): 합성 데이터 주도의 확산 모델 재학습의 부작용. 모델 붕괴 위험을 정량화하고 예측하는 방법론 제시합니다.[20]

#### 10.7 연구 트렌드 요약

### 11. 최종 평가 및 권장사항

#### 11.1 DiffusionInst의 위치

DiffusionInst는 확산 모델을 판별 작업에 적용한 **선구적 연구**입니다. 비록 순수한 성능에서는 Mask2Former(50.1% AP)보다 낮지만, 다음과 같은 가치를 제공합니다:

1. **새로운 패러다임**: 인스턴스 분할을 생성 문제로 재해석
2. **일반화 가능성**: 다양한 노이즈 분포 학습으로 견고성 향상
3. **기술적 기여**: 동적 필터 기반 표현과 확산 프로세스의 결합

#### 11.2 미래 연구자들을 위한 권장사항

**단기 목표 (1-2년):**
1. 박스 독립적 학습 메커니즘 개발
2. 효율적인 샘플링 전략으로 FPS 개선
3. 작은 인스턴스 성능 향상

**중기 목표 (2-3년):**
1. 도메인 일반화 기법 통합 (FDS, DomainFusion 원리)
2. 다중 작업 통합 분할 프레임워크
3. 비디오 및 3D 도메인 확장

**장기 목표 (3년 이상):**
1. 확산-판별 작업의 이론적 통합
2. 약지도 및 자기지도 학습 통합
3. 효율적이고 견고한 통합 비전 시스템

### 결론

**DiffusionInst**는 확산 모델의 판별 작업 적용에 대한 새로운 관점을 제시하는 중요한 연구입니다. 인스턴스 분할을 노이즈-투-필터 프로세스로 공식화함으로써, 다양한 노이즈 분포에 대한 학습을 통한 일반화 성능 향상과 다단계 디노이징의 가능성을 열어주었습니다. 비록 현재의 성능과 효율성에 한계가 있지만, 이 연구는 생성 모델과 판별 작업의 경계를 허무는 중요한 발걸음입니다.

2020년 이후의 연구 동향을 보면, 확산 모델은 단순한 데이터 생성 도구에서 벗어나 **도메인 일반화, 특성 추출, 적응형 학습**의 핵심 기술로 진화하고 있습니다. 후속 연구자들은 DiffusionInst의 한계를 극복하면서도, 최신의 도메인 일반화 및 적응 기법을 통합하여 더욱 견고하고 효율적인 시스템을 개발할 수 있을 것으로 기대됩니다.
