# Intensity Transformations

밝기 변환(Intensity Transformation)은 디지털 영상 처리의 공간 도메인(Spatial Domain) 기법 중 가장 기초적이면서 강력한 기술입니다.  
이는 이미지의 각 픽셀 값을 특정 함수에 통과시켜 새로운 밝기 값으로 맵핑하는 과정을 말합니다. 

### 1. 핵심 개념: 점 처리 (Point Processing) 
밝기 변환의 가장 큰 특징은 '현재 픽셀의 값'만으로 결과값을 결정한다는 것입니다.  
주변 픽셀을 고려하지 않기 때문에 연산 속도가 매우 빠르며, 수식으로는 보통 다음과 같이 표현합니다. 

- $\(s=T(r)\)\(r\)$ : 입력 픽셀의 밝기 (Input Intensity)
- $\(s\)$ : 출력 픽셀의 밝기 (Output Intensity)
- $\(T\)$ : 변환 함수 (Transformation Function)

### 2. 주요 변환 함수 종류 
목적에 따라 다양한 함수가 사용됩니다. 

| 변환 기법 | 주요 특징 및 효과 | 주요 활용 사례 |
| :--- | :--- | :--- |
| **Image Negatives (반전)** | 밝은 곳은 어둡게, 어두운 곳은 밝게 반전 ( $\(s=L-1-r\)$ ) | 의료 영상(X-ray) 등에서 세부 조직 강조 |
| **Log Transformation (로그 변환)** | 어두운 영역의 대비를 높이고 매우 밝은 영역은 압축 | 푸리에 변환 후의 스펙트럼 시각화 |
| **Gamma Correction (거듭제곱 변환)** | $\(s=c\cdot r^{\gamma }\)$ 수식을 사용하여 이미지의 전반적인 밝기 조정 | 모니터/카메라의 장치별 밝기 왜곡 보정 |
| **Contrast Stretching (대비 연장)** | 특정 밝기 범위를 넓게 펼쳐 전체적인 대비를 선명하게 함 | 흐릿하거나 저대비 상태인 사진 개선 |

### 3. 왜 사용하나요? (전문적 활용)
- 이미지 향상(Image Enhancement): 인간의 눈이 인지하기 더 편하도록 시각적 품질을 개선합니다.
- 데이터 전처리: 인공지능 모델이 특징을 더 잘 추출할 수 있도록 이미지의 대비를 균일하게 맞춥니다.
- 임계값 처리(Thresholding): 특정 밝기를 기준으로 이미지를 흑과 백(이진화)으로 나누어 객체를 분리합니다.
